## Identity \{#identity\}

Master CSS is a markup-driven CSS orchestration language for developers and AI agents. Its identity should make the same promise as the product: decisions are explicit, relationships are understandable, and the details stay connected.

The gold mark brings recognition. Neutral surfaces, clear typography and a deliberate rhythm give the work its place. Use this guide when making a Master CSS interface, document or announcement.

## Logo system \{#logo-system\}

The M mark and the horizontal logotype are our signatures. The mark stands on its own in compact spaces; the complete logotype introduces Master CSS where the name needs to be read. Both use the supplied original artwork.

<BrandLogoSystem />

Keep the complete logotype together. The light- and dark-background files are supplied separately; choose the appropriate original rather than recoloring one. The standalone mark and the mark inside the logotype retain their respective source gradients.

## Color \{#color-system\}

Gold identifies the brand. Zinc gives the interface its structure. Functional colors explain a result. Keep those jobs distinct: a selected navigation item can be clear in neutral ink, while a small gold signal marks the action that matters.

<BrandColors />

Use a color role for a job that follows the theme. Use a fixed palette value when the color itself is the subject. Check text against its actual surface in both modes; a decorative swatch does not establish a text contrast guarantee.

## Typography \{#typography\}

Geist carries the interface and Latin text. Noto Sans TC carries Traditional Chinese. IBM Plex Mono carries code, identifiers and aligned readings. Keep the existing families together, with a system sans-serif or monospace fallback when the chosen font is unavailable.

<BrandTypography />

Use the complete `text-` treatment when size, leading and tracking should move together. Keep Chinese tracking natural. Use tabular figures for changing or aligned numbers, while ordinary prose keeps proportional figures. Let a long heading wrap rather than reducing its type size to fit.

These are preset size roles. The brand's opening display is fluid: 2.75–4rem on compact screens and 3–5.5rem on wide screens. Reading prose uses 1.8 leading and a measure up to 42rem. This website's dense code panels use 0.8125rem type with 1.25rem leading—13px on 20px at a 16px root—and scale with text preferences.

## Layout and materials \{#layout-and-materials\}

Spacing explains the relationship. A small interval holds details together; a larger interval separates a new thought. Use the existing spacing and radius scales so a control, a document and a diagram feel related.

<BrandGeometry />

Give each join one clear boundary. A contour describes shape, a contact shadow anchors a surface, and a wider shadow describes distance. Solid panels do not need a bright inner rim. Reserve glass for floating tools with a real backdrop; keep the reading surface opaque.

On a wide document, navigation and contents sit beside a comfortable reading column. Below 64rem, navigation moves into a drawer. Below 80rem, page contents move into a native disclosure. On phones, preserve the reading order and allow labels to wrap.

## Interaction \{#interaction\}

Make the next action clear and its result truthful. Use native links, buttons, radios, ranges and selects, with visible keyboard focus. A selected state, a pressed state and focus communicate different things; keep their labels and geometry stable.

<BrandControls />

<BrandMotion />

Use the fast duration for direct feedback and the normal duration for a change of context. Reversing or repeating an action should follow the current state. Under `prefers-reduced-motion: reduce`, keep the information and remove unnecessary travel, scaling and blur. Standalone touch actions should offer a target of at least 44 × 44 CSS pixels without moving the visible icon. Inline prose links keep the reading rhythm and clearly identify their destination.

Use the established Tabler icons with consistent stroke weight at their rendered size. Pair an icon with a label when its meaning is not obvious, and give every icon-only action an accessible name.

## Voice \{#voice\}

Write as a thoughtful collaborator. Start with the reader’s task, name the thing precisely, and explain the result in plain language. Use concrete verbs and short, connected sentences. Keep claims close to what the product can demonstrate.

<BrandVoice />

Use sentence case for headings. Write “Master CSS” in prose and preserve exact identifiers in code. English and Traditional Chinese should carry the same meaning; keep API names and class strings intact rather than translating them. A message should say what happened and give a useful next action when needed.
