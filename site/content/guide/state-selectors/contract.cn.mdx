<a id="overview"></a>

选择器后缀决定哪个元素或伪元素应用该类的声明。带有完整类名的元素是起点：后缀可以检查该元素、选择相关元素，或同时执行两者。

本页定义选择器的附加方式、编码、分组与优先级。[语法教程](/guide/syntax-tutorial#states)说明如何为组件添加悬停与键盘焦点样式；[CSS 选择器](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Selectors/Selectors_and_combinators)则定义原生匹配行为。

## 附加选择器 \{#basic-selectors\}

将选择器接在已注册工具类后，或原生声明的右括号之后。[条件](/reference/rules/conditions)放在选择器之后，重要性标记放在最末尾：

```txt
utility<selector><conditions>!
(property:value)<selector><conditions>!
```

上方尖括号中的部分和 `!` 是可省略的语法占位符。例如，`underline:hover@sm` 在带有类的元素处于悬停状态且视口匹配 `@sm` 时应用下划线。条件不会改变选择器的目标元素。

<Class2CSS classes={['underline:hover@sm', '(text-decoration-thickness:2px):hover@sm']} />

Master CSS 在生成的 CSS 选择器中转义完整类名。`.underline\:hover` 中的冒号是字面类名的一部分，后接的 `:hover` 才是真正的伪类。HTML 中请像示例一样编写未转义的类名。

## 匹配带有类的元素 \{#matching-the-owner\}

没有组合器时，后缀为带有类的元素增加条件。`underline.active` 仅匹配类列表同时包含 `underline.active` 与 `active` 的元素。

```html
<a class="underline.active active" href="/guide/installation">Installation</a>
```

<a id="id"></a>
<a id="attribute"></a>

| 类 | 带有类的元素须满足的条件 |
| --- | --- |
| `underline.active` | 也带有 `active` 类 |
| `underline#current` | ID 为 `current` |
| `underline[data-current]` | 带有 `data-current` 属性 |
| `underline:hover` | 匹配浏览器的悬停状态 |
| `underline:is(a)` | 是 `a` 元素 |

<Class2CSS classes={['underline.active', 'underline#current', 'underline[data-current]', 'underline:hover', 'underline:is(a)']} />

检查同一元素的类型请用 `:is(a)` 或 `:where(a)`。选择其子元素请用 `>a` 或 `>*`。直接接在工具类名称后的裸标签名不是独立的选择器后缀。

### 组合条件 \{#combined-requirements\}

相邻的简单选择器描述同一个元素。`underline:hover:not([aria-disabled=true])` 要求悬停，并排除 `aria-disabled` 属性为 `true` 的元素；它不会设置或更新该属性。

<Class2CSS classes={['underline:hover:not([aria-disabled=true])']} />

选择器响应 DOM 与浏览器状态，不会创建交互行为。原生属性与 ARIA 保留各自的语义。尤其 `aria-disabled="true"` 只描述禁用状态，本身不会阻止激活操作。

## 相关元素 \{#combinators\}

组合器从带有类的元素移向另一个元素。声明应用于选择器末端的元素，而非从带有类的元素继承而来。

<a id="_--descendant"></a>
<a id="--child"></a>
<a id="--adjacent-sibling"></a>
<a id="--general-sibling"></a>

| 类 | 目标 |
| --- | --- |
| `underline_a` | 任意深度的后代链接 |
| `underline>a` | 直接子链接 |
| `underline+a` | 下一个兄弟元素，且该元素为链接 |
| `underline~a` | 同一父元素下后续的所有兄弟链接 |
| `underline>*` | 每个直接子元素 |

`_` 编码选择器之间表示后代关系的空格。HTML 中真正的空格会开始另一个类。`>`、`+` 和 `~` 保留 CSS 原生含义。

### 状态的位置 \{#state-position\}

状态的位置决定哪个元素必须匹配该状态。这两个类具有相同的父子关系，但在不同位置检查悬停：

| article 上的类 | 悬停条件 | 添加下划线的链接 |
| --- | --- | --- |
| `underline:hover>a` | article 处于悬停状态 | 所有直接子链接 |
| `underline>a:hover` | 直接子链接处于悬停状态 | 仅该链接 |

<ReferenceIllustration id="selector-targets" />

```html
<article class="underline:hover>a">
  <p>Documentation</p>
  <a class="(text-decoration-line:none)" href="/guide/installation">Installation and setup</a>
  <a class="(text-decoration-line:none)" href="/reference/packages">API reference</a>
</article>

<article class="underline>a:hover">
  <p>Documentation</p>
  <a class="(text-decoration-line:none)" href="/guide/installation">Installation and setup</a>
  <a class="(text-decoration-line:none)" href="/reference/packages">API reference</a>
</article>
```

<Class2CSS classes={['(text-decoration-line:none)', 'underline:hover>a', 'underline>a:hover']} />

悬停链接时，其祖先 article 也会处于悬停状态。因此第一个示例中两个链接都符合条件；第二个示例中，另一个链接仍未通过自身的 `:hover` 检查。各类都属于 article，但声明指向它的链接。链接自身的类先移除默认下划线，优先级更高的父子选择器则在悬停条件匹配时恢复下划线。

## 选择器列表 \{#selector-groups\}

顶层逗号会从同一个带有类的元素开始另一条分支。每条分支都要重复组合器：`block>div,>span` 选择直接的 `div` 子元素与直接的 `span` 子元素。第二条分支不会接续第一条分支的目标。

```html
<section class="block>div,>span">
  <div>First child</div>
  <span>Second child</span>
</section>
```

<Class2CSS classes={['block>div,>span', "(content:'“')::before,::after"]} />

函数或带引号属性值中的逗号仍留在该结构内。`underline:is(:hover,:focus-visible)` 是一个包含两种选项的选择器后缀，而不是两条顶层分支。

<Class2CSS classes={['underline:is(:hover,:focus-visible)', "underline[data-label='draft,review']"]} />

### 选择器函数 \{#selector-functions\}

<a id="not"></a>
<a id="has"></a>

| 函数 | 匹配行为 |
| --- | --- |
| `:is(...)` | 匹配列表中的至少一个选择器 |
| `:where(...)` | 与 `:is()` 相同，但函数及其参数的优先级为零 |
| `:not(...)` | 排除匹配列表中任一选择器的元素 |
| `:has(...)` | 从当前选择的元素检查相对关系是否匹配 |

`:has()` 检查关系，但不会将声明移到匹配的相关元素。`b-blue-60:has(>input:checked)` 在 label 的直接子 input 被选中时设置 label 的边框颜色：

```html
<label class="b(1) b-solid b-line-control b-blue-60:has(>input:checked)">
  <input type="checkbox" /> Include archived items
</label>
```

<Class2CSS classes={['b-blue-60:has(>input:checked)', 'underline:has(+input:checked)']} />

相对匹配也可以是兄弟元素：`underline:has(+input:checked)` 在下一个兄弟元素是已选中的 input 时，为带有类的元素添加下划线。原生 [`:has()` 限制](https://www.w3.org/TR/selectors-4/#relational)仍然适用；将 `:has()` 嵌套在自身内部无效。可运行的复选框示例及实用回退方案见[兼容性](/guide/compatibility#new-selectors)。

## 原生状态 \{#pseudo-classes\}

<a id="hover--active--focus"></a>
<a id="first--last--odd--even"></a>
<a id="valid--invalid--required"></a>
<a id="disabled"></a>

<a id="rtl--ltr"></a>

Master CSS 保留原生伪类名称。以下为常用后缀，并非完整的状态注册表：

| 后缀 | 原生匹配上下文 |
| --- | --- |
| `:hover`, `:active` | 指针悬停或激活 |
| `:focus`, `:focus-visible`, `:focus-within` | 元素获得焦点、显示焦点指示，或其内部有焦点 |
| `:first-child`, `:last-child`, `:nth-child(even)` | 兄弟元素间的位置 |
| `:valid`, `:invalid`, `:required` | 原生表单约束 |
| `:disabled` | 已禁用的表单控件 |
| `:checked`, `:indeterminate` | 原生控件状态 |
| `:dir(rtl)`, `:dir(ltr)` | 解析后的文本方向 |

请使用 `:first-child`、`:nth-child(odd)` 这类完整名称。即使 Master CSS 能输出某种写法，浏览器仍可能不支持或视为无效。各状态的详细行为以[原生伪类参考](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/Pseudo-classes)为准。

```html
<ul>
  <li class="bg-surface-inset:nth-child(even)">Draft</li>
  <li class="bg-surface-inset:nth-child(even)">In review</li>
  <li class="bg-surface-inset:nth-child(even)">Published</li>
</ul>
```

## 属性选择器 \{#attribute-selectors\}

属性后缀检查 DOM 值。布尔形式的属性选择器检查属性是否存在：`[open]` 匹配展开的 `details` 元素，`[data-active]` 则在该属性存在时匹配。检查特定状态值时请包含该值，例如 `[aria-pressed=true]`。

<a id="data-keyvalue"></a>
<a id="attrvalue"></a>
<a id="attrvalue-1"></a>
<a id="attrvalue-2"></a>
<a id="attrvalue-3"></a>
<a id="attrvalue-4"></a>
<a id="attrvalue-5"></a>

| 后缀 | 匹配条件 |
| --- | --- |
| `[data-active]` | 属性存在，即使值为空 |
| `[aria-pressed=true]` | 值恰为 `true` |
| `[href^=https]` | 值以 `https` 开头 |
| `[href$='.pdf']` | 值以 `.pdf` 结尾 |
| `[title*=master]` | 值包含 `master` |
| `[lang\|=en]` | 值为 `en` 或以 `en-` 开头 |
| `[title~=css]` | 以空白分隔的值包含单词 `css` |

<ReferenceIllustration id="attribute-word-match" />

引号内的属性文本保留字面含义：`underline[data-state=':first']:first-child` 检查值 `:first`，并另行检查元素位置。`[data-id='a_b']` 中的下划线留在值内；`.is\_active` 中转义的下划线则留在类标识符内。

```html
<a class="underline[data-state=':first']:first-child" data-state=":first" href="/guide">Guide</a>
<a class="underline.is\_active is_active" href="/reference">Reference</a>
```

<Class2CSS classes={["underline[data-state=':first']:first-child", "underline[data-id='a_b']", 'underline.is\\_active']} />

CSS 引号无法阻止 HTML 空格分隔类。属性值中若需要真正的空格，请用 CSS 转义，例如 `[data-label='New\000020collection']`。带引号的值后可直接接大小写标志，例如 `[data-kind='draft'i]` 表示 ASCII 不区分大小写匹配。原生运算符与大小写匹配见[属性选择器](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/Attribute_selectors)。

## 优先级 \{#specificity\}

生成的选择器遵循浏览器的[优先级规则](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Cascade/Specificity)。无论名称内有多少标点，转义后的类名都只贡献一个类选择器的优先级。附加后缀另行计算。

| 类 | ID－类／属性／状态－类型／伪元素 |
| --- | --- |
| `underline` | `0-1-0` |
| `underline:hover` | `0-2-0` |
| `underline>a` | `0-1-1` |
| `underline:where(:hover,#selected)` | `0-1-0` |
| `underline:is(:hover,#selected)` | `1-1-0` |

`:is()`、`:not()` 和 `:has()` 采用选择器列表中最高的参数优先级。`:where()` 不增加优先级，其参数也不增加。组合器与通配选择器同样不增加。这些权重在层叠已决定来源、重要性与层优先顺序后才适用；优先级更高的选择器不会自动胜过另一层中的规则。

<Class2CSS classes={['underline:where(:hover,#selected)', 'underline:is(:hover,#selected)']} />

<ReferenceIllustration id="where-specificity" />

规则排序见[层叠层](/reference/rules/layers)，实际决策见 [指南的覆盖流程](/guide/cascade-layers#override-a-component-locally)。重新排列 HTML 类名不会改变优先级。

## 外部上下文 \{#external-context\}

<a id="of"></a>

后缀以带有类的元素为起点。目标需要根据祖先或前面的兄弟元素应用样式时，可以用原生 CSS 规则直接表达关系：

```css
@layer components {
  .active .contextual { display: none; }
  .active > .child-contextual { display: none; }
  .active + .adjacent-contextual { display: none; }
  .active ~ .sibling-contextual { display: none; }
}
```

要将多个工具类声明包在相同关系中，请使用包含原生选择器与 `@contents` 的混入。[混入内容契约](/reference/directives/definitions#contents)定义展开与转发方式；[复用样式](/guide/reusing-styles#share-a-wrapper-with-contents)说明何时适合选择此形式。

生成 CSS 只能证明规则已输出，不代表浏览器一定支持或匹配该选择器。请检查 DOM 关系、实际状态与原生选择器合法性。普通 CSS 选择器列表中，无效分支可能使整个列表失效；`:is()` 和 `:where()` 则使用[容错列表](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/Selector_list)。浏览器检查及回退设计见[兼容性](/guide/compatibility)。
