## 概覽 [sr-only] \{#overview\}

使用 `text-<token>`，以單一 class 設定完整文字樣式：字級、行高與字距。字重、字型與顏色則分別以其他 class 補上。

<FoundationTypography />

```html
<!-- @MARK text-xs --><!-- @MARK text-2xl --><!-- @MARK text-sm --><!-- @MARK font-regular -->
<p class="text-xs font-regular fg-text-muted">Field notes / 024</p>
<h2 class="text-2xl font-regular fg-text-strong">Make room for the details.</h2>
<p class="text-sm">A consistent type scale helps readers move from the main idea to the supporting detail.</p>
```

<Class2CSS classes={['text-2xl', 'font-regular']} />

此層級運用字級、間距與文字角色，同時維持一般字重。只在內容需要時加入強調；標題不必預設使用更粗的字重。[文字樣式](/reference/tokens/text)列出所有設定與新增方式。

## 文字樣式與字級 \{#without-vs-with-text-token\}

`font-<size>` 只改變字級，保留繼承的行高與字距。`text-<token>` 則同時設定三者。比較兩種寫法在相同字級下的差異：

<TypeIllustration />

<FoundationTypeComparison />

```html
<!-- @MARK font-3xl --><!-- @MARK text-3xl -->
<div class="leading-md tracking-normal">
  <p class="font-3xl">Designing for a clearer reading experience.</p>
  <p class="text-3xl">Designing for a clearer reading experience.</p>
</div>
```

<Class2CSS classes={['font-3xl', 'text-3xl']} />

內文、標題與大型展示文字使用 `text-<token>`。只有設計刻意偏離既有文字樣式時，才使用 `font-<size>`、`leading-<token>` 或 `tracking-<token>`。

`font-` 前綴也接受字型與字重鍵名：`font-sans` 選擇字型，`font-bold` 則要求指定字重。這些命名空間的自訂名稱應保持區別；[字型](/reference/tokens/font)列出各自的值與解析規則。

## 網站字型 \{#site-typeface\}

在 `@theme` 中設定一次應用程式字型。預設集的 base 層會將它套用到文件，因此標記不需字型 class。

```css name=globals.css
@import "@master/css";

@theme {
  --font-sans: "Geist", "Noto Sans TC";
  --font-mono: "IBM Plex Mono";
  --font-feature-sans: "ss02", "ss03", "ss04", "ss06", "ss07", "ss08";
  --font-feature-mono: "cv01", "cv02", "cv29";
}
```

base 層透過 `--font-family-sans` 解析 `--font-sans`，並套用到 `body` 與 Shadow Host；透過 `--font-family-mono` 解析 `--font-mono`，並套用到 `code`、`kbd`、`samp` 與 `pre`。`--font-feature-*` token 可省略，預設退回 `normal`；表單控制項繼承周圍字型。使用 `@font-face` 或字型供應商的樣式表載入字型檔。若只針對單一元素，改用 `font-mono` 這類 class。

## 以實際文字驗證 \{#verify-with-real-text\}

在實際內容寬度下，檢查短標題、長標題與完整段落，再以窄螢幕與放大文字重複檢查。除了計算後的字級，也要留意換行，以及重音符號或下伸部被裁切的情況。

<ReferenceIllustration id="reading-measure" />

<GuideStudy id="type-content-height" />

宣告字型家族只是提出要求，並不能證明字型檔已載入或包含所有字形。請檢查實際呈現的字型，尤其是拉丁文字與中日韓文字混排時。讓容器能隨文字成長；不要只為維持某個英文範例的行數，就固定卡片高度。
