## Overview [sr-only]

Use `text-<token>` for a complete type treatment: font size, line height and letter spacing in one class. Add the weight, family and color as separate classes.

<FoundationTypography />

```html
<!-- @MARK text-xs --><!-- @MARK text-2xl --><!-- @MARK text-sm --><!-- @MARK font-regular -->
<p class="text-xs font-regular fg-text-muted">Field notes / 024</p>
<h2 class="text-2xl font-regular fg-text-strong">Make room for the details.</h2>
<p class="text-sm">A consistent type scale helps readers move from the main idea to the supporting detail.</p>
```

<Class2CSS classes={['text-2xl', 'font-regular']} />

This hierarchy uses size, spacing and text roles while keeping regular weight. Add emphasis only where the content calls for it; a heading does not need a heavier weight by default. See [Text](/reference/tokens/text) for every treatment and how to add one.

## Text treatments and font sizes \{#without-vs-with-text-token\}

`font-<size>` changes only the font size and keeps the inherited line height and letter spacing. `text-<token>` sets all three. Compare the same size in both forms:

<TypeIllustration />

<FoundationTypeComparison />

```html
<!-- @MARK font-3xl --><!-- @MARK text-3xl -->
<div class="leading-md tracking-normal">
  <p class="font-3xl">Designing for a clearer reading experience.</p>
  <p class="text-3xl">Designing for a clearer reading experience.</p>
</div>
```

<Class2CSS classes={['font-3xl', 'text-3xl']} />

Use `text-<token>` for body, heading and display styles. Use `font-<size>`, `leading-<token>` or `tracking-<token>` only when the design deliberately departs from a treatment.

The `font-` prefix also accepts family and weight keys: `font-sans` chooses a family and `font-bold` requests a weight. Keep custom names distinct across these namespaces; [Font](/reference/tokens/font) lists their values and resolution rules.

## Site typeface \{#site-typeface\}

Set the app typeface once in `@theme`. The preset base layer applies it to the document, so markup needs no font classes.

```css name=globals.css
@import "@master/css";

@theme {
  --font-sans: "Geist", "Noto Sans TC";
  --font-mono: "IBM Plex Mono";
  --font-feature-sans: "ss02", "ss03", "ss04", "ss06", "ss07", "ss08";
  --font-feature-mono: "cv01", "cv02", "cv29";
}
```

The base layer resolves `--font-sans` through `--font-family-sans` and applies it to `body` and shadow hosts. It resolves `--font-mono` through `--font-family-mono` and applies it to `code`, `kbd`, `samp` and `pre`. The `--font-feature-*` tokens are optional and fall back to `normal`; form controls inherit the surrounding font. Load the font files with `@font-face` or a provider stylesheet. For a single element, use a class such as `font-mono` instead.

## Verify with real text

Check a short heading, a long heading and a full paragraph at the actual content width. Repeat with narrow screens and larger text. Watch line breaks and clipped accents or descenders, not only the computed font size.

<ReferenceIllustration id="reading-measure" />

<GuideStudy id="type-content-height" />

A declared font family is a request, not proof that its font file loaded or contains every glyph. Inspect the rendered fonts, especially when Latin and CJK text share a line. Keep containers free to grow with the text; do not set a card height just to preserve one English sample's line count.
