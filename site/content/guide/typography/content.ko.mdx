## 개요 [sr-only] \{#overview\}

`text-<token>`으로 글자 크기, 행간, 자간을 하나의 클래스에 담은 전체 텍스트 설정을 적용하세요. 굵기, 글꼴, 색상은 별도 클래스로 추가합니다.

<FoundationTypography />

<DocumentExample>

```html
<!-- @MARK text-xs --><!-- @MARK text-2xl --><!-- @MARK text-sm --><!-- @MARK font-regular -->
<p class="text-xs font-regular fg-text-muted">Field notes / 024</p>
<h2 class="text-2xl font-regular fg-text-strong">Make room for the details.</h2>
<p class="text-sm">A consistent type scale helps readers move from the main idea to the supporting detail.</p>
```

<Class2CSS classes={['text-2xl', 'font-regular']} />

</DocumentExample>

이 계층은 기본 굵기를 유지하며 크기, 간격, 텍스트 역할을 활용합니다. 내용상 필요한 곳에만 강조를 더하세요. 제목이라고 해서 기본적으로 더 굵게 만들 필요는 없습니다. 모든 설정과 추가 방법은 [텍스트](/reference/tokens/text)를 참고하세요.

## 텍스트 설정과 글자 크기 \{#without-vs-with-text-token\}

`font-<size>`는 글자 크기만 바꾸며 상속된 행간과 자간을 유지합니다. `text-<token>`은 세 속성을 모두 설정합니다. 같은 크기에서 두 형태를 비교해 보세요.

<TypeIllustration />

<FoundationTypeComparison />

<DocumentExample>

```html
<!-- @MARK font-3xl --><!-- @MARK text-3xl -->
<div class="leading-md tracking-normal">
  <p class="font-3xl">Designing for a clearer reading experience.</p>
  <p class="text-3xl">Designing for a clearer reading experience.</p>
</div>
```

<Class2CSS classes={['font-3xl', 'text-3xl']} />

</DocumentExample>

본문, 제목, 큰 표시용 텍스트에는 `text-<token>`을 사용하세요. 디자인상 의도적으로 설정에서 벗어날 때만 `font-<size>`, `leading-<token>`, `tracking-<token>`을 사용하세요.

`font-` 접두사는 글꼴과 굵기 키도 받습니다. `font-sans`는 글꼴을 선택하고 `font-bold`는 굵기를 요청합니다. 이 이름 공간들에서 사용자 지정 이름이 겹치지 않도록 하세요. 값과 해석 규칙은 [글꼴](/reference/tokens/font)에 정리되어 있습니다.

## 사이트 글꼴 \{#site-typeface\}

앱 글꼴은 `@theme`에서 한 번 설정하세요. 프리셋의 base 레이어가 문서에 적용하므로 마크업에 글꼴 클래스가 필요하지 않습니다.

```css name=globals.css
@import "@master/css";

@theme {
  --font-sans: "Geist", "Noto Sans TC";
  --font-mono: "IBM Plex Mono";
  --font-feature-sans: "ss02", "ss03", "ss04", "ss06", "ss07", "ss08";
  --font-feature-mono: "cv01", "cv02", "cv29";
}
```

base 레이어는 `--font-family-sans`를 통해 `--font-sans`를 해석하여 `body`와 섀도 호스트에 적용합니다. `--font-mono`는 `--font-family-mono`를 통해 해석하여 `code`, `kbd`, `samp`, `pre`에 적용합니다. `--font-feature-*` 토큰은 선택 사항이며 `normal`로 대체됩니다. 폼 컨트롤은 주변 글꼴을 상속합니다. 글꼴 파일은 `@font-face`나 제공업체 스타일시트로 불러오세요. 한 요소에만 적용하려면 `font-mono` 같은 클래스를 사용하세요.

## 실제 텍스트로 검증 \{#verify-with-real-text\}

실제 콘텐츠 너비에서 짧은 제목, 긴 제목, 전체 문단을 확인하세요. 좁은 화면과 확대된 텍스트에서도 반복하세요. 계산된 글자 크기뿐 아니라 줄바꿈과 악센트 또는 글자의 아래쪽 부분이 잘리는지도 살펴보세요.

<ReferenceIllustration id="reading-measure" />

<GuideStudy id="type-content-height" />

글꼴 패밀리 선언은 요청일 뿐, 글꼴 파일이 로드되었거나 모든 글리프를 포함한다는 증거는 아닙니다. 특히 라틴 문자와 CJK 문자가 한 줄에 섞일 때 실제 렌더링 글꼴을 확인하세요. 컨테이너가 텍스트와 함께 늘어날 수 있게 하세요. 영어 견본 하나의 줄 수를 유지하려고 카드 높이를 고정하지 마세요.
