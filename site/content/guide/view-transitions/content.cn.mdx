## 概览 [sr-only] \{#overview\}
读者从文章集合进入详情视图时，让图片和标题保持视觉连接。用 Master CSS 处理布局、原生 CSS 处理过渡，JavaScript 处理状态变化。先确保界面可用：没有动画时，读者仍必须能访问文章。

## 从文章列表进入详情 \{#article-list-to-detail\}

(click) 打开任一文章，再返回卡片。观察图片、标题和日期的位置变化。键盘焦点会移到文章标题，再回到选中的按钮。

这是**同文档**过渡：JavaScript 替换文章集合，不会导航到其他 URL。浏览器将视觉交接制作成动画。路由、数据加载、浏览器历史和焦点仍由应用负责。实际页面导航请使用本指南后面的[跨文档方案](#cross-document-transitions)。

## 浏览器为哪些内容制作动画 \{#what-the-browser-animates\}

CSS `transition` 会对留在页面中的同一元素插值属性变化。视图过渡则能连接不同 DOM 节点和布局：浏览器捕获旧视图、执行更新，再为旧图像和新视图建立临时伪元素树，并在文档上方为这棵树制作动画。动画开始时，DOM 其实早已改变。

未命名元素时，浏览器通常会交叉淡化根视图。添加匹配名称便能让选定部分独立移动和调整大小。这些默认动画由浏览器提供，无需自行测量两种布局或编写位移关键帧。请参阅 [View Transition 渲染模型](https://www.w3.org/TR/css-view-transitions-1/#rendering-model)。

## 建立文章过渡 \{#build-the-article-transition\}

假设已[安装 Master CSS](/guide/installation)。将以下标记放在文档 body，在 head 中加载 `article-transitions.css`，并将 `article-transitions.js` 作为模块加载。请将图片路径替换为项目中的图片。此简化示例实现一篇文章；实时预览则将相同命名方式应用于两篇。

将布局工具类保留在元素上。原生 `style` 属性提供各快照的标识名称；`.article-capture` 则分配共享的过渡样式组。

```html name=article-list.html
<section data-articles class="max-w-xl mx-auto p-md">
  <article class="grid gap-md">
    <img class="article-capture block w-full h-auto"
      style="view-transition-name: article-aurora-image"
      src="/images/article-aurora.jpg" width="1200" height="750"
      alt="A mountain ridge under soft light" />
    <time class="article-capture block text-sm"
      style="view-transition-name: article-aurora-date"
      datetime="2026-05-12">May 12, 2026</time>
    <h2 class="article-capture text-xl m(0)"
      style="view-transition-name: article-aurora-title">
      Designing transitions that preserve context
    </h2>
    <button type="button" data-read-more>Read article</button>
  </article>
</section>

<template id="article-detail">
  <article class="grid gap-lg">
    <img class="article-capture block w-full h-auto"
      style="view-transition-name: article-aurora-image"
      src="/images/article-aurora.jpg" width="1200" height="750"
      alt="A mountain ridge under soft light" />
    <time class="article-capture block text-sm"
      style="view-transition-name: article-aurora-date"
      datetime="2026-05-12">May 12, 2026</time>
    <h1 tabindex="-1" class="article-capture text-3xl m(0)"
      style="view-transition-name: article-aurora-title">
      Designing transitions that preserve context
    </h1>
    <p>The image, title and date retain their identity in a new layout.</p>
    <button type="button" data-back>Back to collection</button>
  </article>
</template>
```

template 插入前不会启用，因此名称不会与文章集合冲突。此功能的样式表只需加载一次。这里的时间设置只影响文章快照；视图其余部分保留浏览器默认交叉淡化。

```css name=article-transitions.css
@layer components {
  .article-capture {
    view-transition-class: article;
  }

  ::view-transition-group(.article) {
    animation-duration: .5s;
    animation-timing-function: ease-in-out;
  }
}
```

支持具名过渡但不支持 `view-transition-class` 的浏览器仍可配对名称，并保留默认时间设置。固定名称也可直接通过 `::view-transition-group(article-aurora-image)` 选取。

开始过渡前先准备好内容。动画路径会在捕获前解码图片；图片失败仍允许导航，替代文本也保持可用。DOM 替换本身发生在回调内部：

```js name=article-transitions.js
const root = document.querySelector('[data-articles]')
const detail = document.querySelector('#article-detail')
const list = document.createElement('template')
list.content.append(...root.cloneNode(true).childNodes)
const motion = matchMedia('(prefers-reduced-motion: reduce)')
let active
let revision = 0

motion.addEventListener('change', () => {
  if (motion.matches) active?.skipTransition()
})

async function changeView(content, focusSelector) {
  const request = ++revision
  active?.skipTransition()
  const update = () => {
    if (request !== revision) return
    root.replaceChildren(content)
    const target = root.querySelector(focusSelector)
    target.focus({ preventScroll: true })
    target.scrollIntoView({ block: 'nearest', behavior: 'instant' })
  }
  if (!document.startViewTransition || motion.matches) {
    update()
    return
  }

  await Promise.all([...content.querySelectorAll('img')].map(image =>
    image.decode().catch(() => {})
  ))
  if (request !== revision) return
  if (motion.matches) { update(); return }
  const transition = document.startViewTransition(update)
  active = transition
  // Skipping an animation does not mean the DOM update failed.
  transition.ready.catch(() => {})
  const clear = () => { if (active === transition) active = undefined }
  transition.finished.then(clear, clear)
  // Let the caller handle an actual update error. Do not run update twice.
  await transition.updateCallbackDone
}

root.addEventListener('click', event => {
  if (!(event.target instanceof Element)) return
  if (event.target.closest('[data-read-more]')) {
    changeView(document.importNode(detail.content, true), 'h1').catch(reportError)
  } else if (event.target.closest('[data-back]')) {
    changeView(document.importNode(list.content, true), '[data-read-more]').catch(reportError)
  }
})
```

多篇文章时，根据文章 ID 生成各部分的稳定名称，并将焦点还给该文章按钮。过渡开始前先获取数据，避免等待网络请求时持续阻塞渲染。React 中请在回调内用 `flushSync()` 提交状态更新；仅调用 state setter 不能保证新 DOM 已可供捕获。具有自身过渡集成的框架应负责此提交边界。

## 快照命名 \{#naming-snapshots\}

每个捕获状态中，已渲染元素的 `view-transition-name` 必须唯一。在新旧状态**之间**复用名称才会形成配对；在任一状态**内部**重复两次则会跳过过渡。仅出现在旧状态的名称会退场；仅出现在新状态的名称会入场。

| 标识项 | 用途 | 同一状态可共享？ |
| --- | --- | --- |
| HTML `class="article-capture"` | 用普通 CSS 选取实际元素 | 可以 |
| `view-transition-name: article-aurora-image` | 配对一个旧快照和一个新快照 | 不可 |
| `view-transition-class: article` | 用 `::view-transition-group(.article)` 选取多个具名组 | 可以 |

`::view-transition-group(.article)` 中的点表示**过渡类**，不是 HTML 类名。仅指定过渡类不会建立具名快照。[平台分组示例](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/view-transition-class#examples)说明了这一差别。

<TransitionIllustration name="capture-identity" />

使用 `article-aurora-image` 这类稳定、有效的 CSS 标识符，不要用标题或任意用户文本作为名称。当更新后仍是**同一 DOM 元素**，例如带 key 的列表重排，`view-transition-name: match-element` 可让浏览器分配标识。它不会配对替换后的节点或不同文档。本示例会替换节点，因此使用明确名称。

## 为过渡伪元素设置样式 \{#styling-transition-pseudo-elements\}

文档过渡的伪元素始于文档根元素，即使具名元素位于组件深处也一样。默认树包含 `root` 组以及每个具名快照的组。每组内都有一个图像对，包含旧和／或新的子元素。

<TransitionIllustration name="capture-tree" />

旧子元素持有静态快照；新子元素显示更新后元素的实时渲染。它们是视觉表示，不是标记额外产生的可交互副本。

在 `::view-transition-group(...)` 中设置持续时间和缓动，调整移动与尺寸变化。浏览器默认的 old/new 动画会继承组的时间设置。要改变离开和进入内容如何混合，请选取 `::view-transition-old(...)` 和 `::view-transition-new(...)`。组上的 `animation` 简写可能替换浏览器生成的移动动画，因此只覆盖打算改变的属性。

将选择器保留在此功能拥有的全局样式表中：组件作用域内的 `.card::view-transition-old(...)` 无法选取文档根元素的伪元素树。这里的“全局”描述选择器作用范围，并不表示每个功能的规则都必须放入同一个应用全局文件。

## 选择类名或原生 CSS \{#choosing-classes-or-native-css\}

Master CSS 也能表达这些原生属性和选择器。对于小型、固定的快照，下列写法等同于原生声明：

<DocumentExample>

```html
<html class="(animation-duration:.5s)::view-transition-group(.article)">
  <body>
    <img class="(view-transition-name:article-aurora-image) (view-transition-class:article)"
      src="/images/article-aurora.jpg" alt="A mountain ridge" />
  </body>
</html>
```

<Class2CSS classes={[
  '(view-transition-name:article-aurora-image)',
  '(view-transition-class:article)',
  '(animation-duration:.5s)::view-transition-group(.article)'
]} />

</DocumentExample>

伪元素工具类应放在 `html` 上，而非图片上。在已挂载组件中添加该类名，也意味着要管理它在共享根元素上的生命周期。随着动画选择器、关键帧和动效条件增多，原生样式表能将相关决策放在一起，让作用域更易检查。

数据驱动的标识名称，请设置原生属性，不要拼接新工具类：

```js
// article.id is a stable slug controlled by the application, such as "aurora".
image.style.viewTransitionName = `article-${article.id}-image`
```

静态扫描不会执行字符串插值。`'(view-transition-name:article-' + id + '-image)'` 这样的拼接类名，在源代码中不是完整类名。原生 style 值不需要新生成的规则。另一种有效方式是使用完整工具类引用 CSS 自定义属性；请参阅[改变值而不改变类名](/guide/scanning-and-pruning#keep-changing-values-out-of-class-names)。

类名能让局部决策更易读时就使用类名。本功能的默认分工是：标记放布局工具类，数据或原生样式放标识名称，CSS 放过渡选择器。同样分工也为 AI 助手提供各项关注点的明确修改位置；这是编写建议，不是 Master CSS 限制。

## 跨文档过渡 \{#cross-document-transitions\}

文章有自己的 URL 时，请保留普通链接，让浏览器负责导航。两个页面必须同源且都明确启用。将以下内容放入**两份**文档都会加载的样式表：

```css name=page-transitions.css
@view-transition {
  navigation: auto;
}

@media (prefers-reduced-motion: reduce) {
  @view-transition {
    navigation: none;
  }
}
```

在集合页面链接到实际文章 URL。共享图片在两个页面使用相同的明确名称：

```html name=collection.html
<a href="/articles/aurora/">
  <img src="/images/article-aurora.jpg" alt="Read the Aurora article"
    style="view-transition-name: article-aurora-image" />
</a>
```

```html name=article.html
<article>
  <img src="/images/article-aurora.jpg" alt="A mountain ridge"
    style="view-transition-name: article-aurora-image" />
  <h1>The Aurora article</h1>
  <a href="/articles/">Back to collection</a>
</article>
```

<TransitionIllustration name="capture-navigation" />

不要用 `startViewTransition()` 包住 `location.href`：此回调控制的是当前文档更新。跨文档过渡使用符合条件的浏览器导航，而非应用回调。如果路由器拦截链接并替换当前 DOM，请改用其同文档集成。不支持的浏览器仍会打开链接。同文档 API 支持不代表跨文档也支持；请查阅[跨文档要求和生命周期](https://developer.chrome.com/docs/web-platform/view-transitions/cross-document)。

## 减少动态效果 \{#reduced-motion\}

同文档示例会在开始前检查用户偏好；如果偏好改变，也会跳过正在执行的动画。跨文档样式表则在相同偏好下禁用导航动画。两者都不会改变目的地或阻止交互。

仅加入 `@motion-safe` 持续时间覆盖，**不会**禁用浏览器默认过渡：覆盖不再匹配时，默认动画仍存在。必须控制过渡本身是否启动。如果由路由器启动，请使用其动效处理，或在减少动态效果规则中禁用相关伪元素动画。

## 回退方案 \{#fallbacks\}

过渡对象提供三个不同阶段的信号：

<DocumentComparison>

| Promise | 代表意义 |
| --- | --- |
| `updateCallbackDone` | DOM 更新回调已完成或执行失败 |
| `ready` | 动画已准备好，或在开始前被跳过 |
| `finished` | 过渡结束，包括跳过动画的情况；更新失败则拒绝 |

</DocumentComparison>

`finished` 已兑现并不代表动画确实完整播放。主要示例处理 `ready` 拒绝时不会重复更新；更新错误则传给 `reportError`。应用中请将此报告替换为自己的错误边界或恢复界面。参阅[更新回调契约](https://developer.mozilla.org/en-US/docs/Web/API/ViewTransition/updateCallbackDone)。

## 验证完整交互 \{#verify-the-complete-interaction\}

用指针和键盘打开两篇文章再返回。检查焦点、文章标识和可用的滚动，窄屏也要测试。启用减少动态效果和禁用 API 后重复测试：相同内容变更仍必须可用。

内容有变化却没有动画时，请检查：

- 需要配对时，每个已渲染名称在旧状态和新状态中各出现一次。
- 回调完成前确实已提交 DOM 变更。
- 伪元素选择器选取文档根元素，且其 CSS 已加载。
- 图片具有尺寸且已准备好显示；不可用的图片不阻塞更新。
- 捕获和动画期间视口持续稳定。按内容调整高度的 iframe 如果中途改变高度，可能取消原本有效的过渡。使用固定视口和内部滚动可避免此问题。

请观察动画过程中的帧，而不仅是最终 DOM 或 `finished` promise。[视图过渡帧算法](https://www.w3.org/TR/css-view-transitions-1/#handle-transition-frame)明确规定，快照包含块尺寸改变时会跳过动画。
