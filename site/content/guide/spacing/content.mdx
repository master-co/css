## Overview [sr-only]
Use `p-`, `m-` and `gap-` with the same spacing tokens to give a layout a consistent rhythm. Padding creates room inside an element, margin separates it from its neighbors, and gap separates children in a grid or flex layout.

## Customize spacing \{#namespace-for-spacing\}
`p-`, `m-` and `gap-` read the same spacing tokens. `px-` sets `padding-inline`, and `py-` sets `padding-block`; these follow the writing mode. See the [complete family mappings](/reference/tokens/families).

Add a named token when the same distance becomes a repeated design decision:

```css name=index.css
@theme {
  --spacing-sm: 0.75rem;
  --spacing-md: 1rem;
  --spacing-lg: 1.5rem;
  --spacing-wide: 6rem;
}
```

Apply the custom spacing tokens in your markup:

```html
<!-- @MARK mt-md --><!-- @MARK p-sm --><!-- @MARK gap-lg --><!-- @MARK py-wide -->
<section class="py-wide">
  <div class="display:grid gap-lg mt-md p-sm">...</div>
</section>
```

## Use explicit lengths \{#using-explicit-lengths\}
Use native CSS units for local geometry that does not need a named token. `rem` lengths follow the browser’s root font size; `px` lengths retain their CSS pixel value.

```html
<div class="margin:0.25rem"></div>
<div class="padding:0.5rem"></div>
<div class="width:2rem"></div>
<div class="gap:0.75rem"></div>
```

For product surfaces, prefer shared names such as `p-sm`, `gap-md`, and `m-lg`. Use the configured spacing scale for named values and explicit native units for local geometry.

---

## Exact pixel values
Use `0` for resets, explicit `1px` for hairlines, and other `px` units when a value needs exact pixel geometry. Use full property names for direct values: `padding:1px` is a length; `p-1` is not a numeric spacing multiplier.

```html
<!-- @MARK margin:0 -->
<div class="margin:0">margin: 0</div>
<!-- @MARK padding:1px -->
<div class="padding:1px">1px, padding: 1px</div>
<!-- @MARK width:2px -->
<div class="width:2px">width: 2px</div>
```

(!) Avoid mixing named spacing tokens, explicit native lengths, and exact pixel values arbitrarily. Prefer named tokens for layout rhythm, explicit lengths for measured local geometry, and `px` values only for hairlines or exact pixel adjustments.

---

## Name shared spacing clearly \{#common-mistakes\}

<a id="do-not-use-numeric-keys-as-tokens"></a>
Prefer names such as `sm`, `compact` or `section` over numeric token keys. This makes a shared design choice easier to distinguish from a measured length such as `padding:1px`.

```css name=index.css
@theme {
  --spacing-compact: 0.75rem;
  --spacing-section: 6rem;
}
```

```html
<section class="py-section">
  <div class="display:flex gap-compact">...</div>
</section>
```

<a id="summary"></a>
Use named tokens for repeated rhythm and explicit lengths for local geometry. Keep a small set of relationships consistent across a page.
