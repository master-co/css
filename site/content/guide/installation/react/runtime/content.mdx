Add Master CSS to a React application built with Vite. The installer keeps the React plugin and adds the Master CSS plugin to the same Vite configuration.

<StepSection>
  <Step $row>
    <StepL>
      ### <StepNum />Create a project
      If you don't have a React project, create one first.
    </StepL>
    <StepR>
      ```bash name=Terminal
      npm create vite@latest my-app -- --template react-ts
      cd my-app
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### <StepNum />Add Master CSS
      Run the installer with `--mode runtime` from the project root. The browser runtime generates rules for class names that appear after the build.
    </StepL>
    <StepR>
      ```bash name=Terminal
      npm create @master/css@rc -- --framework react --mode runtime --yes
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### <StepNum />Start dev server
      Run the command to start the Vite dev server.
    </StepL>
    <StepR>
      ```bash name=Terminal&action=run
      dev
      ```
    </StepR>
  </Step>
  <Step>
    ### <StepNum />Start using Master CSS
    Replace `src/App.tsx` with the component below. Keep the `src/index.css` import in `src/main.tsx`; that stylesheet contains the Master CSS import added by the installer.
  </Step>
  <HelloWorld url="localhost:5173" />
</StepSection>

```tsx name=src/App.tsx
export default function App() {
  return (
    <h1 className="m-2xl font-style:italic font-5xl font-heavy fg-text-neutral">
      Hello World
    </h1>
  )
}
```

---

If the application needs server-rendered HTML, follow a framework setup such as [Next.js](/guide/installation/nextjs). Choose it for that rendering requirement and measure performance in the target application.

---

## Check the setup
Open the URL printed by Vite. The heading should have a large, heavy italic face and generous margin. If starter styles obscure the result, remove the starter's appearance rules while keeping `@import '@master/css';` in the CSS entry.

The Vite plugin starts the runtime and emits its compiled program; this setup does not require a second manual runtime import. Build and preview the app, then run this in the browser console:

```js
document.querySelector('h1').classList.add('text-decoration-line:underline')
```

The heading should gain an underline even though that class was added after the build. If it does not, check the browser console and the emitted program request before changing the class syntax.
