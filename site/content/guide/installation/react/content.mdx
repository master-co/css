Add Master CSS to a React application built with Vite. The installer keeps the React plugin and adds the Master CSS plugin to the same Vite configuration.

<StepSection>
  <Step $row>
    <StepL>
      ### <StepNum />Create a project
      If you don't have a React project, create one first.
    </StepL>
    <StepR>
      ```bash name=Terminal
      npm create vite@latest my-app -- --template react-ts
      cd my-app
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### <StepNum />Add Master CSS
      Run the installer from the React project root. Static is the default: it scans complete class strings and emits ordinary CSS.
    </StepL>
    <StepR>
      ```bash name=Terminal
      npm create @master/css@rc -- --framework react --yes
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### <StepNum />Start dev server
      Run the command to start the Vite dev server.
    </StepL>
    <StepR>
      ```bash name=Terminal&action=run
      dev
      ```
    </StepR>
  </Step>
  <Step>
    ### <StepNum />Start using Master CSS
    Replace `src/App.tsx` with the component below. Keep the `src/index.css` import in `src/main.tsx`; that stylesheet contains the Master CSS import added by the installer.
  </Step>
  <HelloWorld url="localhost:5173" />
</StepSection>

```tsx name=src/App.tsx
export default function App() {
  return (
    <h1 className="m-2xl font-style:italic font-5xl font-heavy fg-text-neutral">
      Hello World
    </h1>
  )
}
```

---

## Check the setup
Open the URL printed by Vite. The heading should have a large, heavy italic face and generous margin. If starter styles obscure the result, remove the starter's appearance rules while keeping `@import '@master/css';` in the CSS entry.

Run the project's build and preview scripts, then inspect the generated stylesheet. The heading's complete class names should produce CSS without a browser CSS-generation runtime. If the styles are missing, confirm the CSS entry is imported and the Vite configuration includes `masterCSS()`.
