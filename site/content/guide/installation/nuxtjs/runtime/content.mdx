## Load the project stylesheet

Keep the module registration and explicitly load the CSS entry created by the installer. `~~/` points to the project root, including in Nuxt projects whose application directory is `app/`.

```ts name=nuxt.config.ts
export default defineNuxtConfig({
  modules: [['@master/css-nuxt', { mode: 'runtime' }]],
  css: ['~~/assets/css/master.css']
})
```

```css name=assets/css/master.css
@import '@master/css';
```

Run `npm run build`, then serve the generated Nitro output with `node .output/server/index.mjs`. Nuxt still renders HTML on the server, while the Master CSS runtime supplies generated class rules in the browser. Check a later class mutation after startup.
