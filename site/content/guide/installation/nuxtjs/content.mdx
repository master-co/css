Install the Master CSS Nuxt module and load its CSS entry through Nuxt’s `css` option. The module handles CSS delivery without changing Nuxt’s HTML rendering mode.

  <Step $row>
    <StepL>

    </StepL>
    <StepR>
      ```bash name=Terminal
      npm create nuxt@latest my-app
      cd my-app
      ```

    </StepR>
  </Step>
  <Step $row>
    <StepL>

    </StepL>

## Load the project stylesheet

Keep the module registration and explicitly load the CSS entry created by the installer. `~~/` points to the project root, including in Nuxt projects whose application directory is `app/`.

```ts name=nuxt.config.ts
export default defineNuxtConfig({
  modules: [['@master/css-nuxt', { mode: 'static' }]],
  css: ['~~/assets/css/master.css']
})
```

```css name=assets/css/master.css
@import '@master/css';
```

Run `npm run build`, then serve the generated Nitro output with `node .output/server/index.mjs`. Check that the heading is styled with JavaScript disabled. Framework SSR still supplies the HTML; Master CSS static mode supplies its CSS from source scanning.
