## Load the project stylesheet

Keep the module registration and explicitly load the CSS entry created by the installer. `~~/` points to the project root, including in Nuxt projects whose application directory is `app/`.

```ts name=nuxt.config.ts
export default defineNuxtConfig({
  modules: [['@master/css-nuxt', { mode: 'progressive' }]],
  css: ['~~/assets/css/master.css']
})
```

```css name=assets/css/master.css
@import '@master/css';
```

Run `npm run build`, then serve the generated Nitro output with `node .output/server/index.mjs`. Check initial styling before JavaScript and a later class absent from the page manifest. Also test the copied deployment artifact in its target directory; an in-place build does not establish that all manifest and program paths are portable.
