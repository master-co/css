## Check the integration
The installer uses Rsbuild's `tools.rspack` hook to register the Webpack-compatible plugin and creates `src/index.css` as the Master CSS entry. The following shows the Master CSS portion of the configuration. Merge it with your existing configuration, preserving framework plugins, entry points and HTML generation. Do not add a second Master CSS plugin if the installer already registered it.

```ts name=rsbuild.config.ts
import { defineConfig } from '@rsbuild/core'
import MasterCSSPlugin from '@master/css-webpack'

export default defineConfig({
  tools: {
    rspack(config) {
      config.plugins ||= []
      config.plugins.push(new MasterCSSPlugin({ mode: 'runtime' }))
      return config
    }
  }
})
```

```css name=src/index.css
@import '@master/css';
```

```tsx name=src/App.tsx
export default function App() {
  return (
    <h1 className="m-2xl italic font-5xl font-heavy fg-text-neutral">
      Hello World
    </h1>
  )
}
```

## Connect the CSS entry
Import `src/index.css` from your application's JavaScript or TypeScript entry, such as `src/index.tsx`. Keep the entry's existing mount code:

```ts
import './index.css'
```

Replace `src/App.tsx` with the example above. Keep the React plugin and the entry that mounts `<App />`; the `tools.rspack` hook only adds Master CSS processing.

## Verify the result
Build and serve the production output. Confirm the heading is styled and the emitted HTML loads the Master CSS runtime script. After startup, add a new class in the browser console; it should underline the heading without rebuilding:

```js
document.querySelector('h1').classList.add('underline')
```
