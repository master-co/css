    ### <StepNum />Connect the CSS and HTML

The installer registers the Master CSS plugin and creates `src/index.css`. The complete configuration below also supplies native CSS handling and HTML generation for the new project. Create these files before starting the development server.

```js name=webpack.config.mjs
import HtmlWebpackPlugin from 'html-webpack-plugin'
import MasterCSSPlugin from '@master/css-webpack'

export default {
  entry: './src/index.js',
  experiments: { css: true },
  module: {
    rules: [{ test: /\.css$/i, type: 'css/auto' }]
  },
  plugins: [
    new HtmlWebpackPlugin({ template: './index.html' }),
    new MasterCSSPlugin({ mode: 'runtime' })
  ]
}
```

```css name=src/index.css
@import '@master/css';
```

```html name=index.html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Master CSS with Webpack</title>
  </head>
  <body>
    <h1 class="m-2xl italic font-5xl font-heavy fg-text-neutral">
      Hello World
    </h1>
  </body>
</html>
```

Import the CSS entry from the JavaScript entry:

```js name=src/index.js
import './index.css'
```

`HtmlWebpackPlugin` emits the HTML and stylesheet links; serving an unprocessed file from a static directory does not perform that injection.

Run `npx webpack --config webpack.config.mjs --mode production` to verify production output. The emitted HTML must include the Master CSS runtime script. Test a later class mutation after startup.

## Verify the result
Build and serve the production output. Confirm the heading is styled and the emitted HTML loads the Master CSS runtime script. After startup, add a new class in the browser console; it should underline the heading without rebuilding:

```js
document.querySelector('h1').classList.add('underline')
```
