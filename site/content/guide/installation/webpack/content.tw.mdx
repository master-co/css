將 Master CSS 建置到 Webpack、Rspack 或 Rsbuild 應用程式中。三者都使用 `@master/css-webpack`：CSS 進入點提供定義，外掛產生 utility 規則，HTML 外掛則將輸出連結至頁面。請從已有進入點、HTML 範本且可正常運作的應用程式開始。

## 安裝 \{#installation\}

<StepSection>
  <Step $row>
    <StepL>
      ### 加入 Master CSS \{#add-master-css\}
      在既有的 [Webpack](https://webpack.js.org/guides/getting-started/)、[Rspack](https://rspack.dev/guide/start/quick-start) 或 [Rsbuild](https://rsbuild.rs/guide/start/quick-start) 專案中，從專案根目錄執行安裝程式，並指定 `--framework webpack`、`rspack` 或 `rsbuild`。預設使用靜態模式：註冊外掛並建立 `src/index.css`。
    </StepL>
    <StepR>
      ```bash
      npm create @master/css@VERSION -- --framework webpack --yes
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### 匯入 CSS 進入點 \{#import-the-css-entry\}
      安裝程式會建立包含 `@import '@master/css';` 的 `src/index.css`。從應用程式的 JavaScript 或 TypeScript 進入點匯入它，並保留既有的掛載程式碼。請使用全域進入點，讓每個需要這些 utility 的頁面都能載入。
    </StepL>
    <StepR>
      ```js name=src/index.js
      import './index.css'
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### 將 HTML 範本納入掃描 \{#include-html-template\}
      如果將段落放在獨立的 `index.html` 範本中，請用 `@source` 將它納入掃描。路徑相對於 `src/index.css`；如果 HTML 外掛使用不同的範本，請調整路徑。框架元件中的類別會從模組依賴中偵測。
    </StepL>
    <StepR>
      ```css name=src/index.css
      @import '@master/css';
      @source '../index.html';
      ```
    </StepR>
  </Step>
  <Step>
    ### 開始使用 Master CSS \{#start-using-master-css\}
    將段落放進 HTML 範本或框架元件，再啟動開發伺服器。修改獨立範本後，等開發伺服器重新建置，再重新載入頁面。
  </Step>

## 打包工具設定 \{#configuration\}
安裝程式會寫入設定中屬於 Master CSS 的部分。請將其合併至既有設定，保留框架外掛、進入點與 HTML 產生設定，並且只註冊一次外掛。

### Webpack \{#webpack\}
外掛需要原生 CSS 處理與 `HtmlWebpackPlugin`，才能傳遞產生的樣式表：

```js name=webpack.config.mjs
import HtmlWebpackPlugin from 'html-webpack-plugin'
import MasterCSSPlugin from '@master/css-webpack'

export default {
  entry: './src/index.js',
  experiments: { css: true },
  module: {
    rules: [{ test: /\.css$/i, type: 'css/auto' }]
  },
  plugins: [
    new HtmlWebpackPlugin({ template: './index.html' }),
    new MasterCSSPlugin({ mode: 'static' })
  ]
}
```

### Rspack \{#rspack\}
Rspack 使用相同的 Webpack 相容外掛，搭配內建 CSS 支援與 `HtmlRspackPlugin`：

```js name=rspack.config.mjs
import { HtmlRspackPlugin } from '@rspack/core'
import MasterCSSPlugin from '@master/css-webpack'

export default {
  entry: './src/index.js',
  module: {
    rules: [
      {
        test: /\.css$/i,
        type: 'css/auto'
      }
    ]
  },
  plugins: [
    new HtmlRspackPlugin({ template: './index.html' }),
    new MasterCSSPlugin({ mode: 'static' })
  ]
}
```

### Rsbuild \{#rsbuild\}
Rsbuild 透過 `tools.rspack` 掛鉤註冊外掛。保留框架外掛與掛載應用程式的進入點；此掛鉤只加入 Master CSS 處理。

```ts name=rsbuild.config.ts
import { defineConfig } from '@rsbuild/core'
import MasterCSSPlugin from '@master/css-webpack'

export default defineConfig({
  tools: {
    rspack(config) {
      config.plugins ||= []
      config.plugins.push(new MasterCSSPlugin({ mode: 'static' }))
      return config
    }
  }
})
```

在 React 起始專案中，請將段落放在 `src/App.tsx`：

```tsx name=src/App.tsx
export default function App() {
  return (
    <p id="master-check" className="w-fit m(0) p-md b-solid b(1) b-line-divider r-md text-sm font-regular bg-surface-raised fg-text-strong">
      Hello World
    </p>
  )
}
```

## 檢查設定 \{#check-the-setup\}
先在開發伺服器執行時，將原始碼中的 `p-md` 改成 `p-lg`。段落內距應從 `1rem` 增加為 `1.5rem`；確認後改回原值。

使用對應打包工具的指令建置：

<DocumentComparison>

| 打包工具 | 正式環境建置 |
| --- | --- |
| Webpack | `npx webpack --mode production` |
| Rspack | `npx rspack build --mode production` |
| Rsbuild | `npx rsbuild build` |

</DocumentComparison>

以 HTTP 伺服器提供輸出目錄。段落應有 `1rem` 內距、浮起的表面與圓角。靜態模式的 utility 來自連結的 CSS，不使用 Master CSS 執行階段。停用 JavaScript 時，HTML 範本內容仍應有樣式；用戶端渲染的框架則仍需要 JavaScript 建立內容。

HTML 外掛會輸出樣式表連結與所需的執行階段指令碼。直接從開發伺服器靜態目錄提供的檔案，不會取得這些內容。若缺少 CSS 請求，先檢查 HTML 產生流程；若檔案有載入卻沒有 utility，請檢查 CSS 進入點、原生 CSS 處理與外掛註冊。

## 選擇其他渲染模式 \{#rendering-modes\}
預設使用靜態模式。外掛的 `mode` 選項可選擇其他傳遞方式，HTML 外掛會加入其執行階段指令碼：

| 模式 | 外掛選項 | 安裝程式選項 |
| --- | --- | --- |
| 靜態 | `mode: 'static'` | 無 |
| 預先渲染 | `mode: 'prerender'` | `--mode prerender` |
| 執行階段 | `mode: 'runtime'` | `--mode runtime` |
| 漸進式 | `mode: 'progressive'` | `--mode progressive` |

Webpack 外掛也接受 `prerender` 和 `progressive`。獨立使用 Webpack 時，`prerender` 和 `static` 都會透過掃描生成相同的 CSS。`progressive` 則由外掛提供瀏覽器執行階段。若要在這兩種模式從渲染完成的文件生成初始 CSS，HTML 主機須呼叫[伺服器渲染器](/guide/rendering-modes#pre-rendering--ssg-ssr)，並在 `progressive` 模式提供 hydration 資料。

<DocumentDisclosure title="在瀏覽器產生新類別">

執行安裝程式時，指定 `--mode runtime` 與你的 `--framework` 值。它會將外掛選項設為 `mode: 'runtime'`：

```bash
npm create @master/css@VERSION -- --framework webpack --mode runtime --yes
```

建置並提供正式環境輸出。輸出的 HTML 應載入 Master CSS 執行階段指令碼。啟動後，在瀏覽器主控台執行以下程式碼；無須重新建置，段落就應出現底線：

```js
document.querySelector('#master-check').classList.add('underline')
```

</DocumentDisclosure>
