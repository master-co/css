Webpack、Rspack、Rsbuild のアプリに Master CSS を組み込みます。三つとも `@master/css-webpack` を使い、CSS エントリーが定義を供給し、プラグインがユーティリティルールを生成し、HTML プラグインが出力をページにリンクします。エントリーと HTML テンプレートがある、動作するアプリから始めてください。

## インストール \{#installation\}

<StepSection>
  <Step $row>
    <StepL>
      ### Master CSS を追加する \{#add-master-css\}
      既存の [Webpack](https://webpack.js.org/guides/getting-started/)、[Rspack](https://rspack.dev/guide/start/quick-start)、[Rsbuild](https://rsbuild.rs/guide/start/quick-start) プロジェクトのルートで、`--framework webpack`、`rspack`、`rsbuild` のいずれかを指定してインストーラーを実行します。既定の静的モードは、プラグインを登録して `src/index.css` を作成します。
    </StepL>
    <StepR>
      ```bash
      npm create @master/css@VERSION -- --framework webpack --yes
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### CSS エントリーをインポートする \{#import-the-css-entry\}
      インストーラーは `@import '@master/css';` を含む `src/index.css` を作成します。既存のマウントコードを保持し、アプリの JavaScript または TypeScript エントリーからインポートしてください。ユーティリティを必要とするすべてのページで読み込まれるよう、グローバルエントリーを使います。
    </StepL>
    <StepR>
      ```js name=src/index.js
      import './index.css'
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### HTML テンプレートを検出対象に加える \{#include-html-template\}
      段落を独立した `index.html` テンプレートに置く場合は、`@source` で検出対象に加えます。パスは `src/index.css` からの相対パスです。HTML プラグインが別のテンプレートを使う場合は調整してください。コンポーネント内のクラスはモジュールの依存関係から検出されます。
    </StepL>

## バンドラーの設定 \{#configuration\}
インストーラーが書き込むのは、Master CSS に関する設定です。フレームワークのプラグイン、エントリー、HTML 生成を保持して既存の設定に統合し、プラグインは一度だけ登録してください。

### Webpack \{#webpack\}
生成したスタイルシートの配信には、ネイティブの CSS 処理と `HtmlWebpackPlugin` が必要です：

```js name=webpack.config.mjs
import HtmlWebpackPlugin from 'html-webpack-plugin'
import MasterCSSPlugin from '@master/css-webpack'

export default {
  entry: './src/index.js',
  experiments: { css: true },
  module: {
    rules: [{ test: /\.css$/i, type: 'css/auto' }]
  },
  plugins: [
    new HtmlWebpackPlugin({ template: './index.html' }),
    new MasterCSSPlugin({ mode: 'static' })
  ]
}
```

### Rspack \{#rspack\}
Rspack は、同じ Webpack 互換プラグインを組み込みの CSS サポートと `HtmlRspackPlugin` とともに使います：

```js name=rspack.config.mjs
import { HtmlRspackPlugin } from '@rspack/core'
import MasterCSSPlugin from '@master/css-webpack'

export default {
  entry: './src/index.js',
  module: {
    rules: [
      {
        test: /\.css$/i,
        type: 'css/auto'
      }
    ]
  },
  plugins: [
    new HtmlRspackPlugin({ template: './index.html' }),
    new MasterCSSPlugin({ mode: 'static' })
  ]
}
```

### Rsbuild \{#rsbuild\}
Rsbuild は `tools.rspack` フックでプラグインを登録します。フレームワークのプラグインとアプリをマウントするエントリーは保持してください。このフックは Master CSS の処理だけを追加します。

```ts name=rsbuild.config.ts
import { defineConfig } from '@rsbuild/core'
import MasterCSSPlugin from '@master/css-webpack'

export default defineConfig({
  tools: {
    rspack(config) {
      config.plugins ||= []
      config.plugins.push(new MasterCSSPlugin({ mode: 'static' }))
      return config
    }
  }
})
```

React のスターターでは、`src/App.tsx` に段落を置きます：

```tsx name=src/App.tsx
export default function App() {
  return (
    <p id="master-check" className="w-fit m(0) p-md b-solid b(1) b-line-divider r-md text-sm font-regular bg-surface-raised fg-text-strong">
      Hello World
    </p>
  )
}
```

## 設定を確認する \{#check-the-setup\}
まず開発サーバーの実行中に、ソースの `p-md` を `p-lg` に変えます。段落のパディングが `1rem` から `1.5rem` に増えるはずです。確認後、元に戻します。

使うバンドラーに対応するコマンドでビルドします：

<DocumentComparison>

| バンドラー | 本番ビルド |
| --- | --- |
| Webpack | `npx webpack --mode production` |
| Rspack | `npx rspack build --mode production` |
| Rsbuild | `npx rsbuild build` |

</DocumentComparison>

出力ディレクトリーを HTTP サーバーで配信します。段落に `1rem` のパディング、浮き上がった面、角丸があるはずです。静的モードのユーティリティはリンクした CSS から供給され、Master CSS ランタイムは使いません。JavaScript を無効にしても HTML テンプレートの内容にはスタイルが残りますが、クライアントレンダリングのフレームワークは内容の作成に JavaScript が必要です。

HTML プラグインは、スタイルシートのリンクと必要なランタイムスクリプトを出力します。開発サーバーの静的ディレクトリーから直接配信したファイルには、それらは追加されません。CSS のリクエストがない場合は、まず HTML 生成を確認します。読み込まれてもユーティリティがない場合は、CSS エントリー、ネイティブ CSS 処理、プラグインの登録を確認してください。

## 別のレンダリングモードを選ぶ \{#rendering-modes\}
既定は静的モードです。プラグインの `mode` オプションで別の配信方法を選び、HTML プラグインがそのランタイムスクリプトを組み込みます：

| モード | プラグインのオプション | インストーラーのオプション |
| --- | --- | --- |
| 静的 | `mode: 'static'` | なし |
| 事前レンダリング | `mode: 'prerender'` | `--mode prerender` |
| ランタイム | `mode: 'runtime'` | `--mode runtime` |
| プログレッシブ | `mode: 'progressive'` | `--mode progressive` |

Webpack プラグインでは `prerender` と `progressive` も指定できます。Webpack 単体での `prerender` は、`static` と同じくソースの走査で CSS を生成します。`progressive` ではプラグインがブラウザーランタイムを供給します。どちらのモードでも、レンダリング済みの文書から初期 CSS を生成するには、HTML を配信するホストで[サーバーレンダラー](/guide/rendering-modes#pre-rendering--ssg-ssr)を呼び出します。`progressive` ではハイドレーションデータも供給します。

<DocumentDisclosure title="ブラウザーで新しいクラスを生成する">

`--mode runtime` と対象の `--framework` を指定してインストーラーを実行します。プラグインのオプションが `mode: 'runtime'` に設定されます：

```bash
npm create @master/css@VERSION -- --framework webpack --mode runtime --yes
```

本番出力をビルドして配信します。出力 HTML が Master CSS のランタイムスクリプトを読み込むはずです。起動後、ブラウザーのコンソールで次を実行すると、再ビルドせずに段落に下線が付くはずです：

```js
document.querySelector('#master-check').classList.add('underline')
```

</DocumentDisclosure>
