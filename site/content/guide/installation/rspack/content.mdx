## Check the integration
The installer registers the Webpack-compatible plugin in `rspack.config.*` and creates `src/index.css` as the Master CSS entry. The following shows the Master CSS portion of the configuration. Merge it with your existing configuration, preserving framework plugins, entry points and HTML generation. Do not add a second Master CSS plugin if the installer already registered it.

```js name=rspack.config.mjs
import MasterCSSPlugin from '@master/css-webpack'

export default {
  module: {
    rules: [
      {
        test: /\.css$/i,
        type: 'css/auto'
      }
    ]
  },
  plugins: [
    new MasterCSSPlugin({ mode: 'static' })
  ]
}
```

```css name=src/index.css
@import '@master/css';
```

```html
<h1 class="m-2xl font-style:italic font-5xl font-heavy fg-text-neutral">
  Hello World
</h1>
```

## Connect the CSS entry
Import `src/index.css` from your application's JavaScript or TypeScript entry, such as `src/index.tsx`. Keep the entry's existing mount code:

```ts
import './index.css'
```

Place the heading in your framework component or in the HTML template processed by `HtmlRspackPlugin`. A file served directly from a static directory does not receive the plugin’s generated stylesheet links or runtime script.

## Verify the result
Build and serve the production output. The heading should be large, heavy and italic. The generated utilities are ordinary CSS; a client-rendered framework may still need JavaScript to create the heading.
