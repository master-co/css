This setup uses Vite with plain JavaScript. The [Vite starter](https://vite.dev/guide/#scaffolding-your-first-vite-project) below selects the `vanilla` template; use the framework-specific guide for React, Vue or another component framework.

<StepSection>
  <Step $row>
    <StepL>
      ### <StepNum />Create a Vite project
      If you don't have a Vite project, create one first.
    </StepL>
    <StepR>
      ```bash name=Terminal
      npm create vite@latest my-app -- --template vanilla
      cd my-app
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### <StepNum />Add Master CSS
      Run the installer with `--mode runtime` from the project root. The browser runtime generates rules for class names that appear after the build.
    </StepL>
    <StepR>
      ```bash name=Terminal
      npm create @master/css@rc -- --framework vite --mode runtime --yes
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### <StepNum />Start dev server
      Run the command to start the Vite dev server.
    </StepL>
    <StepR>
      ```bash name=Terminal&action=run
      dev
      ```
    </StepR>
  </Step>
  <Step>
    ### <StepNum />Start using Master CSS
    Replace the starter contents of `src/main.js` with the example below. Keep the CSS import so Vite loads the stylesheet updated by the installer.
  </Step>
  <HelloWorld url="localhost:5173" />
</StepSection>

```js name=src/main.js
import './style.css'

document.querySelector('#app').innerHTML = `
  <h1 class="m-2xl font-style:italic font-5xl font-heavy fg-text-neutral">
    Hello World
  </h1>
`
```

---

## Check the setup
Open the URL printed by Vite. The heading should have a large, heavy italic face and generous margin. If starter styles obscure the result, remove the starter's appearance rules while keeping `@import '@master/css';` in the CSS entry.

The Vite plugin starts the runtime and emits its compiled program; this setup does not require a second manual runtime import. Build and preview the app, then run this in the browser console:

```js
document.querySelector('h1').classList.add('text-decoration-line:underline')
```

The heading should gain an underline even though that class was added after the build. If it does not, check the browser console and the emitted program request before changing the class syntax.
