Add Master CSS to an application built with Vite, including React, Vue, React Router framework mode and TanStack Start. The integration generates CSS from complete class names in source. Keep the framework's existing Vite plugin and mount code; Master CSS joins that build through a shared stylesheet.

## Installation

<StepSection>
  <Step $row>
    <StepL>
      ### Add Master CSS
      In an existing [Vite project](https://vite.dev/guide/), run the installer from the project root with the `--framework` value from the [framework table](#frameworks). Static is the default: complete class names in source become ordinary CSS.
    </StepL>
    <StepR>
      ```bash
      npm create @master/css@rc -- --framework vite --yes
      ```
    </StepR>
  </Step>
  <Step>
    ### Check the CSS entry
    The installer adds `masterCSS()` to the Vite plugins and updates the stylesheet listed under [Framework entries](#frameworks). In a plain JavaScript starter, that is:

    ```css name=src/style.css
    @import '@master/css';
    ```

    Keep this entry imported by the application. If the project uses a different filename, check the installer's output and keep the import pointed at that file. The installer does not create a framework application or replace its mount code.
  </Step>
  <Step>
    ### Start using Master CSS
    For a plain JavaScript starter with an `#app` element, use this entry and run `npm run dev`. For a framework application, use its [component example](#frameworks) below instead.
  </Step>

```js name=src/main.js
import './style.css'

    Hello World
  </p>
`
```

## Framework entries \{#frameworks\}
Choose the installer value for your application. These are the conventional starter paths; React and Vue setups can reuse another supported existing CSS entry. Without the flag, the installer detects the framework from the project.

| Framework | `--framework` | CSS entry |
| --- | --- | --- |
| Vite with plain JavaScript | `vite` | `src/style.css` |
| [React](#react) | `react` | `src/index.css` |
| [Vue](#vue) | `vue` | `src/assets/main.css` |
| [React Router](#react-router) framework mode | `react-router` | `app/app.css` |
| [TanStack Start](#tanstack-start) | `tanstack-start` | `src/styles/app.css` |

### React \{#react\}
In a [React project built with Vite](https://vite.dev/guide/#scaffolding-your-first-vite-project), replace `src/App.tsx`. Keep the `src/index.css` import in `src/main.tsx`.

```tsx name=src/App.tsx
export default function App() {
  return (
    <p id="master-check" className="w-fit m(0) p-md b-solid b(1) b-line-divider r-md text-sm font-regular bg-surface-raised fg-text-strong">
      Hello World
    </p>
  )
}
```

### Vue \{#vue\}
In a [Vue project](https://vuejs.org/guide/quick-start), replace `src/App.vue`. Keep the `src/assets/main.css` import in the application entry.

```vue name=src/App.vue
<template>
  <p id="master-check" class="w-fit m(0) p-md b-solid b(1) b-line-divider r-md text-sm font-regular bg-surface-raised fg-text-strong">
    Hello World
  </p>
</template>
```

### React Router \{#react-router\}
In a [React Router framework mode](https://reactrouter.com/start/framework/installation) project, the installer imports `app/app.css` from `app/root.tsx`. Replace the home route and keep it registered in `app/routes.ts`. Retain `Links`, `Scripts`, `Outlet` and the document structure in `app/root.tsx`; they deliver the page and its stylesheet.

```tsx name=app/routes/home.tsx
export default function Home() {
  return (
    <p id="master-check" className="w-fit m(0) p-md b-solid b(1) b-line-divider r-md text-sm font-regular bg-surface-raised fg-text-strong">
      Hello World
    </p>
  )
}
```

### TanStack Start \{#tanstack-start\}
In a [TanStack Start](https://tanstack.com/start/latest) project built with Vite, replace the index route. The installer imports `src/styles/app.css` from `src/routes/__root.tsx`, so every route loads the same CSS entry.

```tsx name=src/routes/index.tsx
import { createFileRoute } from '@tanstack/react-router'

export const Route = createFileRoute('/')({
  component: Home
})

function Home() {
  return (
    <p id="master-check" className="w-fit m(0) p-md b-solid b(1) b-line-divider r-md text-sm font-regular bg-surface-raised fg-text-strong">
      Hello World
    </p>
  )
}
```

## Check the setup \{#check-the-setup\}
Change `p-md` to `p-lg` in the source while the dev server is running. Padding should grow from `1rem` to `1.5rem`. Restore `p-md`, then build the application:

```bash
npm run build
```

Serve the production output with the project's preview or start command. Plain Vite, React and Vue starters normally use `npm run preview`; React Router and TanStack Start use their configured server or deployment adapter. Check that the paragraph still has `1rem` padding and that no Master CSS browser runtime is shipped in static mode.

Client-rendered applications need JavaScript to create the paragraph. For React Router or TanStack Start routes with server rendering enabled, disable JavaScript and reload to check that the server's HTML receives the same stylesheet.

If the file loads but one class is missing, keep its full name in source; see [Scanning and pruning](/guide/scanning-and-pruning). If no utilities work, confirm the CSS entry is imported and the Vite configuration includes `masterCSS()` beside the framework plugin. If starter styles obscure the result, remove their appearance rules while keeping `@import '@master/css';`.

## Choose another rendering mode \{#rendering-modes\}
Static mode is the default and needs no Master CSS startup code. Keep the CSS entry when changing modes:

| Framework | Installer option | Runtime startup |
| --- | --- | --- |
| Vite, React, Vue | `--mode runtime` | Injected into `index.html` by the Vite plugin |
| React Router, TanStack Start | `--mode runtime` | A browser-only import in the root route |

<DocumentDisclosure title="Generate new classes in the browser">

Run the installer with `--mode runtime` and your `--framework` value:

```bash
npm create @master/css@rc -- --framework vite --mode runtime --yes
```

For Vite, React and Vue, the plugin injects the runtime into `index.html` and emits its compiled program. Do not add a second runtime import.

React Router and TanStack Start produce their own HTML, which does not pass through Vite's `index.html` injection. Add a browser-only runtime import beside the stylesheet import in the existing root route, keeping its route definitions and component exports:

```tsx name=app/root.tsx
import './app.css'

if (!import.meta.env.SSR) {
  void import('virtual:master-css-runtime')
}
```

```tsx name=src/routes/__root.tsx
import '../styles/app.css'

if (!import.meta.env.SSR) {
  void import('virtual:master-css-runtime')
}
```

The guard keeps the virtual runtime out of server execution; load it once per document. Add the client types in a declaration file such as `app/master-css.d.ts` or `src/master-css.d.ts`:

```ts
/// <reference types="@master/css/client" />
```

Build and preview the app, then run this in the browser console. The paragraph should gain an underline without rebuilding:

```js
document.querySelector('#master-check').classList.add('underline')
```

Server-rendered HTML does not include runtime-generated CSS before JavaScript runs. If the class has no effect, check the console and the emitted program request.

</DocumentDisclosure>
