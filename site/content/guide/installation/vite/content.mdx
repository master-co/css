## Framework entries \{#frameworks\}
Each `--framework` value keeps the framework's Vite plugin and updates the CSS entry its starter already imports. Without the flag, the installer detects the framework from the project.

| Framework | `--framework` | CSS entry |
| --- | --- | --- |
| Vite with plain JavaScript | `vite` | `src/style.css` |
| [React](#react) | `react` | `src/index.css` |
| [Vue](#vue) | `vue` | `src/assets/main.css` |
| [React Router](#react-router) framework mode | `react-router` | `app/app.css` |
| [TanStack Start](#tanstack-start) | `tanstack-start` | `src/styles/app.css` |

### React \{#react\}
In a [React project built with Vite](https://vite.dev/guide/#scaffolding-your-first-vite-project), replace `src/App.tsx`. Keep the `src/index.css` import in `src/main.tsx`.

```tsx name=src/App.tsx
export default function App() {
  return (
    <h1 className="m-2xl italic font-5xl font-heavy fg-text-neutral">
      Hello World
    </h1>
  )
}
```

### Vue \{#vue\}
In a [Vue project](https://vuejs.org/guide/quick-start), replace `src/App.vue`. Keep the `src/assets/main.css` import in the application entry.

```vue name=src/App.vue
<template>
  <h1 class="m-2xl italic font-5xl font-heavy fg-text-neutral">
    Hello World
  </h1>
</template>
```

### React Router \{#react-router\}
In a [React Router framework mode](https://reactrouter.com/start/framework/installation) project, the installer imports `app/app.css` from `app/root.tsx`. Replace the home route and keep it registered in `app/routes.ts`. Retain `Links`, `Scripts`, `Outlet` and the document structure in `app/root.tsx`; they deliver the page and its stylesheet.

```tsx name=app/routes/home.tsx
export default function Home() {
  return (
    <h1 className="m-2xl italic font-5xl font-heavy fg-text-neutral">
      Hello World
    </h1>
  )
}
```

### TanStack Start \{#tanstack-start\}
In a [TanStack Start](https://tanstack.com/start/latest) project built with Vite, replace the index route. The installer imports `src/styles/app.css` from `src/routes/__root.tsx`, so every route loads the same CSS entry.

```tsx name=src/routes/index.tsx
import { createFileRoute } from '@tanstack/react-router'

export const Route = createFileRoute('/')({
  component: Home
})

function Home() {
  return (
    <h1 className="m-2xl italic font-5xl font-heavy fg-text-neutral">
      Hello World
    </h1>
  )
}
```

## Check the setup \{#check-the-setup\}
Run the project's build and preview or start scripts. The heading should have a large, heavy italic face and generous margin, and the output should contain no browser CSS-generation runtime. React Router and TanStack Start render on the server, so their heading also stays styled with JavaScript disabled.

If styles are missing, confirm the CSS entry is imported and the Vite configuration includes `masterCSS()` beside the framework plugin. If starter styles obscure the result, remove their appearance rules while keeping `@import '@master/css';`.

## Choose another rendering mode \{#rendering-modes\}
Static mode is the default and needs no Master CSS startup code. Keep the CSS entry when changing modes:

| Framework | Installer option | Runtime startup |
| --- | --- | --- |
| Vite, React, Vue | `--mode runtime` | Injected into `index.html` by the Vite plugin |
| React Router, TanStack Start | `--mode runtime` | A browser-only import in the root route |

<DocumentDisclosure title="Generate new classes in the browser">

Run the installer with `--mode runtime` and your `--framework` value:

```bash
npm create @master/css@rc -- --framework vite --mode runtime --yes
```

For Vite, React and Vue, the plugin injects the runtime into `index.html` and emits its compiled program. Do not add a second runtime import.

React Router and TanStack Start produce their own HTML, which does not pass through Vite's `index.html` injection. Add a browser-only runtime import beside the stylesheet import in the existing root route, keeping its route definitions and component exports:

```tsx name=app/root.tsx
import './app.css'

if (!import.meta.env.SSR) {
  void import('virtual:master-css-runtime')
}
```

```tsx name=src/routes/__root.tsx
import '../styles/app.css'

if (!import.meta.env.SSR) {
  void import('virtual:master-css-runtime')
}
```

The guard keeps the virtual runtime out of server execution; load it once per document. Add the client types in a declaration file such as `app/master-css.d.ts` or `src/master-css.d.ts`:

```ts
/// <reference types="@master/css/client" />
```

Build and preview the app, then run this in the browser console. The heading should gain an underline without rebuilding:

```js
document.querySelector('h1').classList.add('underline')
```

Server-rendered HTML does not include runtime-generated CSS before JavaScript runs. If the class has no effect, check the console and the emitted program request.

</DocumentDisclosure>
