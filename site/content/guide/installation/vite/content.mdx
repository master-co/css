This setup uses Vite with plain JavaScript. The [Vite starter](https://vite.dev/guide/#scaffolding-your-first-vite-project) below selects the `vanilla` template; use the framework-specific guide for React, Vue or another component framework.

<StepSection>
  <Step $row>
    <StepL>
      ### <StepNum />Create a Vite project
      If you don't have a Vite project, create one first.
    </StepL>
    <StepR>
      ```bash name=Terminal
      npm create vite@latest my-app -- --template vanilla
      cd my-app
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### <StepNum />Add Master CSS
      Run the installer from the Vite project root. Static is the default: it scans complete class strings and emits ordinary CSS.
    </StepL>
    <StepR>
      ```bash name=Terminal
      npm create @master/css@rc -- --framework vite --yes
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### <StepNum />Start dev server
      Run the command to start the Vite dev server.
    </StepL>
    <StepR>
      ```bash name=Terminal&action=run
      dev
      ```
    </StepR>
  </Step>
  <Step>
    ### <StepNum />Start using Master CSS
    Replace the starter contents of `src/main.js` with the example below. Keep the CSS import so Vite loads the stylesheet updated by the installer.
  </Step>
  <HelloWorld url="localhost:5173" />
</StepSection>

```js name=src/main.js
import './style.css'

document.querySelector('#app').innerHTML = `
  <h1 class="m-2xl italic font-5xl font-heavy fg-text-neutral">
    Hello World
  </h1>
`
```

---

## Check the setup
Open the URL printed by Vite. The heading should have a large, heavy italic face and generous margin. If starter styles obscure the result, remove the starter's appearance rules while keeping `@import '@master/css';` in the CSS entry.

Run the project's build and preview scripts, then inspect the generated stylesheet. The heading's complete class names should produce CSS without a browser CSS-generation runtime. If the styles are missing, confirm the CSS entry is imported and the Vite configuration includes `masterCSS()`.
