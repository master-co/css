Use this setup for a Vue application built with Vite. The installer keeps the Vue plugin and adds Master CSS to the same configuration.

<StepSection>
  <Step $row>
    <StepL>
      ### <StepNum />Create a project
      If you don't have a Vue.js project, create one first.
    </StepL>
    <StepR>
      ```bash name=Terminal
      npm create vue@latest my-app
      cd my-app
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### <StepNum />Add Master CSS
      Run the installer from the Vue.js project root. Static is the default: it scans complete class strings and emits ordinary CSS.
    </StepL>
    <StepR>
      ```bash name=Terminal
      npm create @master/css@rc -- --framework vue --yes
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### <StepNum />Start dev server
      Run the command to start the Vite dev server.
    </StepL>
    <StepR>
      ```bash name=Terminal&action=run
      dev
      ```
    </StepR>
  </Step>
  <Step>
    ### <StepNum />Start using Master CSS
    Replace `src/App.vue` with the component below. Keep the `src/assets/main.css` import in your application entry; the installer adds `@import '@master/css';` to that stylesheet.
  </Step>
  <HelloWorld url="localhost:5173" />
</StepSection>

```vue name=src/App.vue
<template>
  <h1 class="m-2xl font-style:italic font-5xl font-heavy fg-text-neutral">
    Hello World
  </h1>
</template>
```

---

## Check the setup
Open the URL printed by Vite. The heading should have a large, heavy italic face and generous margin. Starter styles may still affect the page; remove their appearance rules if needed while keeping the Master CSS import.

Run the project's build and preview scripts and confirm the same styled heading appears. If it does not, check that `src/assets/main.css` is loaded and that the Vite configuration includes `masterCSS()`. Keep conditional class names complete so the source scanner can find both branches.
