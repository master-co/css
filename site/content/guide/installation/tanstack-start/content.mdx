This guide uses TanStack Start with Vite. The [blank starter](https://tanstack.com/cli/latest/docs/quick-start) keeps the first page small and omits starter styling; retain Vite when choosing build options.

<StepSection>
  <Step $row>
    <StepL>
      ### <StepNum />Create a project
      If you don't have a TanStack Start project, create one first.
    </StepL>
    <StepR>
      ```bash name=Terminal
      npx @tanstack/cli@latest create my-app --blank
      cd my-app
      ```
    </StepR>
  </Step>

    <StepL>
      ### <StepNum />Add Master CSS

    </StepL>

    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### <StepNum />Start dev server
      Run the command to start the TanStack Start dev server.
    </StepL>
    <StepR>
      ```bash name=Terminal&action=run
      dev
      ```
    </StepR>
  </Step>
  <Step>
    ### <StepNum />Start using Master CSS
    Now style your first route using Master CSS syntax.
  </Step>
  <HelloWorld url="localhost:3000" />
</StepSection>

The installer registers `@master/css-vite` in static mode, creates `src/styles/app.css`, and imports it from `src/routes/__root.tsx`.

```tsx name=src/routes/index.tsx
import { createFileRoute } from '@tanstack/react-router'

export const Route = createFileRoute('/')({
  component: Home
})

function Home() {
  return (
    <h1 className="m-2xl italic font-5xl font-heavy fg-text-neutral">
      Hello World
    </h1>
  )
}
```

---

## Check the setup
Build the application and serve it using the deployment adapter selected for the project. The heading should have a large, heavy italic face and generous margin. Keep `src/styles/app.css` imported by the root route so page navigation continues to load the same CSS entry.

With server rendering enabled, disable JavaScript and reload: the heading should remain styled. Static CSS generation does not require a Master CSS browser runtime.
