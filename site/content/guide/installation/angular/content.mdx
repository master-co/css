---

The installer creates `master.css` as the source entry and imports the generated `src/master.generated.css` from `src/styles.css`. Keep `src/styles.css` in Angular's global styles configuration. The generated file is build output; do not edit it or import it from `master.css`.

Before each production build, regenerate the CSS:

```bash
npx master-css generate --output src/master.generated.css
npm run build
```

During development, run `npx master-css generate --output src/master.generated.css --watch` in a separate terminal. Static rendering needs complete class strings in templates or an explicit safelist. CSS custom properties can still supply dynamic values.

For class names created in the browser, use the [Angular runtime guide](/guide/installation/angular/runtime).

The current Angular CLI uses `src/app/app.html` by default. Existing projects using the [2016 file naming convention](https://angular.dev/cli/new) may use `src/app/app.component.html`; edit the template referenced by your root component.

## Verify the result
Build after generating CSS and serve Angular’s browser output. The heading should be large, heavy and italic. To check the watcher, change `font-style:italic` to `font-style:normal` in the template; the preview should update while the watcher is running.

Static refers to CSS generation. A browser-rendered Angular app still needs JavaScript to create its HTML.
