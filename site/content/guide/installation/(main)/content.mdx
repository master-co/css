## Installation [sr-only]
Add Master CSS to an existing project with the installer. It detects common frameworks, applies the matching setup, and can install the required packages. Supported build integrations use static rendering by default: complete class names in source become ordinary CSS without a browser engine.

## Install in your project

<StepSection>
  <Step $row>
    <StepL>
      ### Add Master CSS
      Run the installer from the root of an existing project, such as a [Vite app](https://vite.dev/guide/). It detects the framework, updates the project setup and installs matching packages from the `rc` channel with the detected package manager.
    </StepL>
    <StepR>
      ```bash name=Terminal
      npm create @master/css@rc -- --yes
      ```
    </StepR>
  </Step>
  <Step>
    ### Start using Master CSS
    Start the dev server, then use Master CSS classes in your markup.
  </Step>
  <HelloWorld url="localhost:5173" />
</StepSection>

```html name=index.html
<h1 class="m-2xl italic font-5xl font-heavy fg-text-neutral">
  Hello World
</h1>
```
