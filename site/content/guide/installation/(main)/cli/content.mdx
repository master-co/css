Generate a static stylesheet from your HTML without adding a bundler. The CLI scans complete class names and writes CSS that you load with a normal stylesheet link. Use this setup when your project does not have a matching [framework integration](/guide/installation/integrations).

## Installation [sr-only]
<StepSection>
  <Step $row>
    <StepL>
      ### <StepNum />Install Master CSS
      Install Master CSS [CLI](https://www.npmjs.com/package/@master/css-cli) as a development dependency.
    </StepL>
    <StepR>
      ```bash name=Terminal
      npm install -D @master/css-cli@rc
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### <StepNum />Create your CSS entry
      Create a stylesheet that imports the default Master CSS entry.
    </StepL>
    <StepR>
      ```css name=main.css
      @import "@master/css";
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### <StepNum />Run the build command
      Run the command to scan sources and write `master.css`.
    </StepL>
    <StepR>
      ```bash name=Terminal
      npx @master/css-cli generate "index.html" --output master.css --watch
      ```
    </StepR>
  </Step>
  <Step>
    ### <StepNum />Start using Master CSS
    Master CSS scans raw sources and generates the `./master.css` file for you.

    Now style your first element using Master CSS syntax!
  </Step>
  <HelloWorld />
</StepSection>

```html name=index.html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <link rel="stylesheet" href="./master.css"> <!-- [!code highlight] -->
</head>
<body>
  <!-- @MARK italic m-2xl fg-text-neutral font-5xl font-heavy -->
  <h1 class="m-2xl italic font-5xl font-heavy fg-text-neutral">Hello World</h1>
</body>
</html>
```

## Build for deployment

The watch command stays running and updates the output when a selected source changes. For a production build, omit `--watch` so the command writes its output and exits:

```bash name=Terminal
npx @master/css-cli generate "index.html" --output master.css
```

Deploy `index.html`, `master.css` and the neighboring CSS assets referenced by the generated stylesheet. Preserve their relative paths: copying only `master.css` can leave its imported styles missing. Keep each generated asset set together when publishing a new build.

Load the deployed page and check that every stylesheet request succeeds. The heading should use the generated font, color and spacing with JavaScript disabled. [Scanning latent classes](/guide/scanning-latent-classes) explains how to include sources outside the ordinary application scope.
