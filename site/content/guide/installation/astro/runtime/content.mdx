Let the browser generate utilities for the classes that appear in an Astro page, including later DOM updates. The installer configures the integration and creates the CSS entry; the page below imports that entry.

<StepSection>
  <Step $row>
    <StepL>
      ### <StepNum />Create a project
      If you don't have an Astro project, create one first.
    </StepL>
    <StepR>
      ```bash name=Terminal
      npm create astro@latest my-app
      cd my-app
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### <StepNum />Add Master CSS
      Run the installer in runtime mode from the Astro project root. Runtime mode generates CSS in the browser and skips Astro middleware pre-rendering.
    </StepL>
    <StepR>
      ```bash name=Terminal
      npm create @master/css@rc -- --framework astro --mode runtime --yes
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### <StepNum />Start dev server
      Run the command to start the Astro dev server.
    </StepL>
    <StepR>
      ```bash name=Terminal&action=run
      dev
      ```
    </StepR>
  </Step>
  <Step>
    ### <StepNum />Start using Master CSS
    Import `src/styles/global.css` from the page frontmatter, then add the heading. Use the same import in a shared layout when several pages need it.
  </Step>
  <HelloWorld url="localhost:4321" />
</StepSection>

```astro name=src/pages/index.astro
---
import '../styles/global.css'
---
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <meta name="viewport" content="width=device-width" />
    <title>Hello Master CSS</title>
  </head>
  <body>
    <h1 class="m-2xl italic font-5xl font-heavy fg-text-neutral">
      Hello World
    </h1>
  </body>
</html>
```

---

## Check the setup
Run the project's build and preview scripts. The heading should have a large, heavy italic face and generous margin. The integration injects its runtime, so this setup does not need a separate browser bootstrap.

Inspect the browser console and network requests if the heading remains unstyled. Runtime mode depends on JavaScript and its compiled program loading successfully. To test a later class change, run:

```js
document.querySelector('h1').classList.add('underline')
```

The heading should gain an underline without rebuilding. This checks a class introduced after the initial page was generated.
