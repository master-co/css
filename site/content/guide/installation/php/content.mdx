Use static rendering when PHP templates contain complete class strings and you want Vite to build a generated CSS asset before PHP serves the page.

<StepSection>
  <Step $row>
    <StepL>
      ### <StepNum />Open your project
      Start from the PHP or CodeIgniter project root.
    </StepL>
    <StepR>
      ```bash name=Terminal
      cd my-php-app
      npm init -y
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### <StepNum />Install Vite and Master CSS
      Install Vite and the Master CSS Vite integration.
    </StepL>
    <StepR>
      ```bash name=Terminal
      npm install @master/css@rc
      npm install -D vite @master/css-vite@rc
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### <StepNum />Configure Vite
      Build static CSS into `public/assets`.
    </StepL>
    <StepR>
      ```ts name=vite.config.ts
      import { defineConfig } from 'vite'
      import masterCSS from '@master/css-vite'

      export default defineConfig({
        base: './',
        plugins: [
          masterCSS({ mode: 'static' })
        ],
        build: {
          outDir: 'public/assets',
          emptyOutDir: false,
          rollupOptions: {
            input: 'resources/main.ts',
            output: {
              entryFileNames: 'app.js',
              assetFileNames: 'app[extname]'
            }
          }
        }
      })
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### <StepNum />Create the asset entry
      Import Master CSS and scan PHP files where complete class strings are written.
    </StepL>
    <StepR>
      ```ts name=resources/main.ts
      import './app.css'
      ```

      ```css name=resources/app.css
      @import "@master/css";

      @source "../app/**/*.php";
      @source "../public/**/*.php";
      ```
    </StepR>
  </Step>
  <Step>
    ### <StepNum />Hello world
    Load the generated CSS and style your first PHP template.
  </Step>
  <HelloWorld url="localhost" />
</StepSection>

```html name=public/index.php
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Master CSS with PHP</title>
  <link rel="stylesheet" href="/assets/app.css">
</head>
<body>
  <h1 class="m-2xl font-style:italic font-5xl font-heavy fg-text-neutral">
    Hello World
  </h1>
</body>
</html>
```

For CodeIgniter, scan `app/Views/**/*.php` and load `/assets/app.css` with your normal asset helper. Static rendering depends on complete class strings in scanned source files.

Build assets with `npx vite build` before starting or publishing the host application. During development, run `npx vite build --watch` in a separate terminal. The output keeps other host assets; deploy `app.css` and every CSS file it imports together, preserving their names and relative paths.

## Check the page
For a plain PHP project, run `php -S localhost:8000 -t public` after building the assets, then visit `http://localhost:8000`. Use your framework’s normal server for CodeIgniter. This example assumes `public` is the web root; adjust URLs if the app lives under a subpath.

The heading should remain large, heavy and italic with JavaScript disabled. If the stylesheet loads but the classes have no effect, check the `@source` paths and regenerate the CSS.
