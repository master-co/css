Use Vite static rendering to build a CSS asset for Shopify Liquid themes. Shopify still serves the theme; Vite only turns complete class strings from Liquid templates into `assets/master.css`.

<StepSection>
  <Step $row>
    <StepL>
      ### <StepNum />Open your theme
      Start from a local Shopify theme directory.
    </StepL>
    <StepR>
      ```bash name=Terminal
      cd my-shopify-theme
      npm init -y
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### <StepNum />Install Vite and Master CSS
      Install Vite and the Master CSS Vite integration.
    </StepL>
    <StepR>
      ```bash name=Terminal
      npm install @master/css@rc
      npm install -D vite @master/css-vite@rc
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### <StepNum />Configure Vite
      Emit the compiled CSS into Shopify's `assets` directory.
    </StepL>
    <StepR>
      ```ts name=vite.config.ts
      import { defineConfig } from 'vite'
      import masterCSS from '@master/css-vite'

      export default defineConfig({
        base: './',
        plugins: [
          masterCSS({ mode: 'static' })
        ],
        build: {
          outDir: 'assets',
          emptyOutDir: false,
          rollupOptions: {
            input: 'src/master.ts',
            output: {
              entryFileNames: 'master.js',
              assetFileNames: '[name][extname]'
            }
          }
        }
      })
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### <StepNum />Create the asset entry
      Import Master CSS and scan Liquid theme files explicitly.
    </StepL>
    <StepR>
      ```ts name=src/master.ts
      import './master.css'
      ```

      ```css name=src/master.css
      @import "@master/css";

      @source "../layout/**/*.liquid";
      @source "../sections/**/*.liquid";
      @source "../blocks/**/*.liquid";
      @source "../snippets/**/*.liquid";
      @source "../templates/**/*.liquid";
      @source "../templates/**/*.json";
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### <StepNum />Load the asset
      Add this tag inside the existing theme layout’s `<head>`. Preserve `content_for_header`, `content_for_layout`, and the theme’s other assets.
    </StepL>
    <StepR>
      ```liquid name=layout/theme.liquid
      {{ 'master.css' | asset_url | stylesheet_tag }}
      ```
    </StepR>
  </Step>
  <Step>
    ### <StepNum />Hello world
    Add the heading to a section that the current template renders. Keep its existing Liquid logic and schema.
  </Step>
  <HelloWorld url="localhost:9292" />
</StepSection>

```html name=sections/main-page.liquid
<h1 class="m-2xl font-style:italic font-5xl font-heavy fg-text-neutral">
  Hello World
</h1>
```

Build with `npx vite build` before previewing or publishing the theme. While editing, run `npx vite build --watch` beside `shopify theme dev`. The configuration keeps other theme assets; upload `master.css` and every CSS file it imports together, preserving their names and relative paths.

If your theme has no asset build, use the [CLI guide](/guide/installation/cli) with the same Liquid source globs and output to `assets/master.css`.

## Verify the theme preview
Build the CSS and preview the theme with `shopify theme dev`. Navigate to the page containing the section; the heading should remain large, heavy and italic with JavaScript disabled. Creating a section file alone does not add it to a page—keep it referenced by the template or add it through the theme editor.

The scan covers [Liquid templates, sections, theme blocks and snippets](https://shopify.dev/docs/storefronts/themes/architecture). Theme-editor values can produce class names absent from those files; map settings to complete class strings or safelist a bounded set. A preview update does not rerun the local CSS build, so keep the Vite watcher running.

Master CSS’s preset includes global base styles. Check existing storefront components after adding it, and decide which resets and unlayered theme styles to retain. Use [Cascade layers](/guide/cascade-layers) to inspect precedence.
