Use this setup for [React Router framework mode](https://reactrouter.com/start/framework/installation). The installer adds the Master CSS Vite plugin and imports `app/app.css` from the root route.

<StepSection>
  <Step $row>
    <StepL>
      ### <StepNum />Create a project
      If you don't have a React Router framework project, create one first.
    </StepL>
    <StepR>
      ```bash name=Terminal
      npx create-react-router@latest my-app
      cd my-app
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### <StepNum />Add Master CSS
      Run the installer from the React Router project root. Static is the default: it scans complete class strings and emits ordinary CSS.
    </StepL>
    <StepR>
      ```bash name=Terminal
      npm create @master/css@rc -- --framework react-router --yes
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### <StepNum />Start dev server
      Run the command to start the React Router dev server.
    </StepL>
    <StepR>
      ```bash name=Terminal&action=run
      dev
      ```
    </StepR>
  </Step>
  <Step>
    ### <StepNum />Start using Master CSS
    Now style your first route module using Master CSS syntax.
  </Step>
  <HelloWorld url="localhost:5173" />
</StepSection>

```tsx name=app/routes/home.tsx
export default function Home() {
  return (
    <h1 className="m-2xl font-style:italic font-5xl font-heavy fg-text-neutral">
      Hello World
    </h1>
  )
}
```

---

## Check the setup
Replace the starter's home route with the component above, keeping the route registered in `app/routes.ts`. Retain `Links`, `Scripts`, `Outlet` and the document structure in `app/root.tsx`; they are part of React Router's page delivery.

Build the app and start the production server using its existing scripts. If styles are missing, check the root CSS import and preserve the React Router Vite plugin alongside Master CSS.

With server rendering enabled, the heading should remain styled after disabling JavaScript and reloading. Use complete class strings for conditional states so the source scanner can find them.
