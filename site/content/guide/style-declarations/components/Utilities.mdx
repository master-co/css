Use fixed utilities for common native values, `(property:value)` for any other direct value, canonical token families for theme values, and utilities for reusable class recipes.

```html
<div class="block absolute (border-radius:50%)"></div>
```

A fixed utility such as `absolute` or a declaration such as `(border-radius:50%)` describes a native CSS property and value; a named token such as `p-md` reads a theme value.

Recipes express a reusable combination or static parameter operation. The preset includes `sr-only`, `clamp-lines(3)`, `grid-cols(3)`, and `text-sm`. Projects register their own class recipes with `@utility`. A `@mixin` supplies CSS reuse through `@apply` and does not register a markup class.

```html
<div class="grid-cols(3) gap-md"></div>
```

Complete native shorthand properties remain supported. Documentation examples prefer independent styling decisions; this authoring preference does not remove native CSS shorthand syntax or expand native CSS declarations into resets.

For project-specific recipes, see [utility definitions](/reference/directives/definitions#utilities).

Animation tokens such as `animate-fade` use the built-in `animate` family and emit `animation: var(--animate-fade)`. See [animation tokens](/reference/tokens/motion#animate).
