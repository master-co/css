Syntax: <code><span className="mcss token">(<span className="Mkey token">property</span><span className="Mvalueroot token"><span className="Mcolon token">:</span><span className="Mvalue token">value</span></span>)<span className="Mimportant token">!</span></span></code>

Add `!` at the end of the class to emit `!important`. A native `!important` at the end of a parenthesized value has the same effect, and using both still emits it once.
```html
<div class="(text-align:center)! (color:red!important) flex!">
```

Use it as a last resort for integration boundaries or unavoidable third-party CSS. For normal Master CSS classes, cascade layers and rule priority usually give you a cleaner override path.
