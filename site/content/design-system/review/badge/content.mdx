`DemoBadge` labels a state or category. Its `size` is `xs`, `sm`, `md` or `lg`; `tone` and `variant` use the same paint roles as `DemoItem`. The default is neutral, soft and medium. It renders a native span.

```tsx
<DemoBadge tone="blue" size="sm">Selected layer</DemoBadge>
```

Keep state labels outside measured layouts unless their dimensions are part of the lesson. Use a native button for an action.
