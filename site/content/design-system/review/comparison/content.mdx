`DemoComparison` renders `div.ui-compare` with one `figure` per item: a `figcaption` naming the condition and a `ui-stage` holding the specimen. Put it in a tray with `frame="none"` so the stages sit directly in the tray.

```tsx
<Demo title="Stacked below 40rem" frame="none">
  <DemoComparison items={[
    { label: '@media (width < 40rem)', children: <Stacked /> },
    { label: '@media (width ≥ 40rem)', children: <Side /> },
  ]} />
</Demo>
```

```html
<div class="ui-compare">
  <figure><figcaption>@media (width &lt; 40rem)</figcaption><div class="ui-stage">…</div></figure>
  <figure><figcaption>@media (width ≥ 40rem)</figcaption><div class="ui-stage">…</div></figure>
</div>
```

Two browsers compare the same way: `DemoThemeComparison` and `DemoStyleComparison` place a `DemoViewport` under each `figcaption`.
