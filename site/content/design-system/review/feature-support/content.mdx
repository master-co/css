`DemoFeatureSupport` shows the `condition` as inline code and a dot `ui-badge` with the result: green when supported, neutral when the fallback applies.

```tsx
<DemoFeatureSupport condition="(field-sizing: content)" />
<ProjectStyleExample name="nativeField" />
```

`DemoViewTransition` loads a dedicated example page in a `DemoViewport`, so the root snapshot never captures the documentation. Reduced motion and an unavailable API use the same immediate update.
