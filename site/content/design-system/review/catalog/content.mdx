`DemoCatalog` takes `groups`. Each group has `id`, `title` and `entries`; each entry supplies `id`, `title`, `label`, `href` and `children`.

The complete scenes stay server rendered inside native disclosures. Use distinct IDs when multiple catalogs share a page. Keep the first working example of a lesson directly visible.

See the [complete working recipes](/design-system/authoring#utility-recipes) and the [layout contract](/design-system/authoring#keep-examples-portable).
