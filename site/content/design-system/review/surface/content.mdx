`DemoSurface` renders `div.ui-sheet`. It adds no padding, dimensions, layout or clipping; the example supplies them. `elevation="flat"` (the default) is a hairline sheet; `elevation="raised"` maps to `data-elevation="1"`.

```tsx
<DemoSurface className="p-md">A quiet content surface.</DemoSurface>
<DemoSurface elevation="raised" className="p-md">A raised layer.</DemoSurface>
```

```html
<div class="ui-sheet" data-elevation="flat">…</div>
<div class="ui-sheet" data-elevation="1">…</div>
<div class="ui-well">…</div>
```

A sheet uses `--ui-surface-sheet` and the elevation roles; a well uses `--ui-surface-well` with `--ui-elevation-sink`. Never invent a surface color: when a lesson teaches surfaces, use the preset `bg-surface-*` utilities in the specimen instead.
