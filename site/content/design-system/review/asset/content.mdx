`DemoAsset` renders a tray: `title` and `description` in the head, the artwork on the stage and a caption with the format badge and a download link styled as `ui-button`. `surface="light"` or `"dark"` sets the stage itself in that mode, so the artwork needs no sheet of its own; `"transparent"` (the default) uses the checkerboard stage.

```tsx
<DemoAsset
  title="Master CSS mark"
  description="Original SVG artwork."
  src="/images/logo.svg"
  alt="Master CSS gold mark"
  width={216.6}
  height={120}
  surface="dark"
/>
```

The file is unchanged; only the preview is constrained by the image’s intrinsic dimensions.
