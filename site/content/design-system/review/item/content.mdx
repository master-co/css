`DemoItem` renders `div.ui-item`, a raised tile with a 3rem minimum and centered content. `tone` (`neutral`, `blue`, `violet`, `amber`, `green`, `red`) maps to `data-tone`; `variant` (`soft`, `solid`, `outline`, `ghost`) maps to `data-variant`. Utilities on the item set its size and layout.

```tsx
<Demo>
  <div className="flex gap-sm">
    <DemoItem>Context</DemoItem>
    <DemoItem tone="blue">Subject</DemoItem>
  </div>
</Demo>
```

```html
<div class="ui-item">Context</div>
<div class="ui-item" data-tone="blue">Subject</div>
<div class="ui-item" data-tone="violet" data-variant="outline">Compare</div>
```

Use neutral for context, blue for the subject and violet for a comparison; name every tone with a legend or label. The item is a noninteractive `div`; use a native button or link for an action.
