`DemoScrollArea` renders `div.ui-scroll` with `tabIndex={0}`: native overflow in a sunken well, capped at 16rem high. Set the lesson's width or a smaller height; it adds no child and does not change the layout inside the scrollport.

```tsx
<DemoScrollArea role="region" aria-label="Layer collection" className="(height:10rem)">
  {/* Overflowing content */}
</DemoScrollArea>
```

```html
<div class="ui-scroll" tabindex="0" role="region" aria-label="Layer collection">…</div>
```

Name the region when the collection needs a landmark, and keep the focus outline visible.
