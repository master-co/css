`DemoLabel` identifies a class, object or condition with a compact monospace line. The current label uses tabular numerals and wraps long utilities. It adds no background, border or spacing; the scene sets the distance to its subject.

```tsx
<div>
  <DemoLabel>shadow-sm</DemoLabel>
  <DemoSurface className="mt-xs p-md">Standard surface</DemoSurface>
</div>
```

Keep a label outside the measured flex or grid parent unless it is part of the layout lesson. The [elevation guide](/guide/elevation) retains its original labels, and the [label review](/design-system/review/label) shows the current shared label.
