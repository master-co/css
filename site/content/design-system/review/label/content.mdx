`DemoLabel` renders `span.ui-label` in the mono label face. It keeps its text as written (`data-case="as-is"`) so class names and values stay exact; set `upper` for an uppercase heading.

```tsx
<DemoLabel>shadow-sm</DemoLabel>
<DemoLabel upper>Collection / 024</DemoLabel>
```

```html
<span class="ui-label" data-case="as-is">shadow-sm</span>
<span class="ui-label">Collection / 024</span>
```

Place a label outside any measured flex, grid or float parent unless the label is the lesson.
