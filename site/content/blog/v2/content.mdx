## New Configuration API

### Native keyframes
Store complete [animation tokens](/reference/tokens/animate) and their native keyframes in the project CSS entry:
```css name=index.css
@prune native;
@theme {
  --animate-reveal: reveal .5s ease;
}
@keyframes reveal {
  from { opacity: 0; }
  to { opacity: 1; }
}
```
Apply the token with its matching class:
```html
<!-- @MARK animate-reveal -->
<div class="animate-reveal"></div>
```
The class emits `animation: var(--animate-reveal)`. With pruning enabled, the token and keyframes
are generated when used. This shorthand runs once because it omits a repetition
count; preset animation tokens include `infinite` explicitly.
