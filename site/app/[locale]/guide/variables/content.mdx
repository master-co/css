## Overview [sr-only]
<Default />
In Master CSS, variables are design tokens defined in the project CSS entry with native custom property declarations. They can represent colors, spacing, typography, shadows, screen sizes, motion tokens, generated content, and mode-specific theme values.
<Overview />

---

## Add variables
Define variables inside the root `@master` block.

```css name=index.css
@master {
    --content-hash: " #";
    --content-external: " ↗";
    --color-primary: #4f46e5;
    --spacing-card: 24;
    --font-family-sans: Inter, ui-sans-serif, system-ui, sans-serif;
}
```

Use the variables in markup:

```html
<!-- @MARK content:hash --><!-- @MARK bg:primary --><!-- @MARK p:card --><!-- @MARK font:sans -->
<div class="content:hash bg:primary p:card font:sans">…</div>
```

The property prefix after `--` becomes the variable namespace. For example, `--color-primary` becomes `color.primary`, and `--spacing-card` becomes `spacing.card`.

---

## Use custom colors
Add custom colors with native color values.

```css name=index.css
@master {
    --color-primary: #1192e8;
    --color-primary-10: #e5f6ff;
    --color-primary-20: #bae6ff;
}
```

Apply them using color-related syntax:

```html
<!-- @MARK bg:primary --><!-- @MARK fill:primary-20 -->
<button class="bg:primary">Save</button>
<svg class="fill:primary-20">20</svg>
```

If a color is used only once, you can keep it inline in markup instead of creating a token:

```html
<button class="bg:#ceb195">Milk Tea</button>
```

---

## Add aliases
Reference another token with `$`.

```css name=index.css
@master {
    --color-brand: #4f46e5;
    --color-primary: $color-brand;
    --color-primary-soft: $color-brand/.16;
}
```

```html
<!-- @MARK bg:primary --><!-- @MARK bg:primary-soft -->
<div class="bg:primary">…</div>
<div class="bg:primary-soft">…</div>
```

---

## Add mode variables
Use mode blocks for theme-specific values.

```css name=index.css
@master {
    light {
        --color-primary: #4f46e5;
        --color-surface: #ffffff;
    }

    dark {
        --color-primary: #818cf8;
        --color-surface: #111827;
    }
}
```

Using modes for variables gives you one semantic source of truth:

```html
<!-- @MARK bg:primary --><!-- @MARK bg:surface -->
<div class="bg:surface">
    <button class="bg:primary">Save</button>
</div>
```

See [variables and modes](/guide/variables-and-modes) for mode triggers, default mode behavior, and manual mode switching.

---

## Override preset variables
Define the same token key as a preset token to override it.

```css name=index.css
@master {
    --color-blue: #4589ff;
}
```

Presets, user variables, and imported CSS files in the project entry graph are resolved into one config. Later definitions win when the same root variable key is repeated.
