## Start with the project CSS entry

Use CSS directives when a choice belongs to the project: shared theme values, reusable component styles or source policy. Start with one value and compile it together with the class that consumes it:

<ConfiguredExample source={'@theme { --spacing-card: 1.5rem; }'} classes={['p:card']} />

Keep the normal Master CSS import in your application entry. The example above adds its theme to the current preset to show the complete dependency and generated result.

## Choose a directive by its effect

- Change a shared value with [theme directives](/reference/directives/theme).
- Define reusable component or utility classes with [managed definitions](/reference/directives/definitions).
- Add an exceptional content location with [source boundaries](/reference/directives/source).
- Include or exclude bounded class candidates with [candidate policy](/reference/directives/candidates).
- Reuse utility declarations inside a rule with [composition](/reference/directives/compose).

Compile the complete entry when checking a custom class. A class that depends on project configuration cannot be verified against the default preset alone. The [Directives reference](/reference#directives) defines scope, interactions and restrictions.
