## Overview [sr-only] \{#overview\}

```html
<!-- @MARK :hover -->
<button type="button" class="fg:blue-60:hover">Preview</button>
<!-- @MARK :invalid -->
<label>Email <input type="email" class="b:red:invalid" /></label>
<!-- @MARK [open] -->
<details class="surface:raised[open]">
  <summary>Release details</summary>
  <p>Published today.</p>
</details>
```
State selectors let one declaration apply only when a selector matches. Append the selector after the declaration value:

```txt
property:value<selector>
```

Common examples include interaction states such as `:hover`, validation states such as `:invalid`, and attributes such as `[disabled]` or `[open]`.

```html
<!-- @MARK :hover --><!-- @MARK :active -->
<h2 class="font:lg font:2xl:hover font:3xl:active">Release notes</h2>
```
Selectors can be stacked when the CSS selector itself needs more detail.
```html
<!-- @MARK :hover:not(.active) -->
<div class="bg:blue-20:hover:not(.active)">Preview</div>
```
If you also need a breakpoint, mode, or other condition, put the [conditional query](/reference/rules/conditions) after the selector.

```html
<!-- @MARK :hover@md -->
<button type="button" class="bg:blue-60:hover@md">Save</button>
```

For readability, Master CSS includes built-in selector aliases for selectors that appear often.
```html
<div class="mt:sm:first"></div><!-- [!code highlight] -->
<div class="mt:sm:first-child"></div>
<div class="mt:sm:odd"></div><!-- [!code highlight] -->
<div class="mt:sm:nth-child(odd)"></div>
<div class="mt:sm:rtl"></div><!-- [!code highlight] -->
<div class="mt:sm:dir(rtl)"></div>
```
Write longer project-specific selectors directly.
```html
<div class="font:semibold_:is(h1,h2,h3,h4,h5,h6)"></div><!-- [!code highlight] -->
```

## Basic selectors \{#basic-selectors\}
Master CSS accepts native selector syntax. The selector is relative to the element that owns the class unless a combinator points to another element.

| Selector              | Description                                           |
|-----------------------|-------------------------------------------------------|
| `*`                   | Universal selector                                    |
| `element`             | Type selector                                         |
| `.class`              | Class selector                                        |
| `#id`                 | ID selector                                           |
| `[attribute]`         | Attribute selector                                    |
| `:pseudo-class`       | Pseudo-class selector                                 |
| `::pseudo-element`    | Pseudo-element selector                               |

<Class2CSS>{['bg:blue-60.active', 'b:red:invalid', 'surface:raised[open]']}</Class2CSS>

### `*` — Universal \{#--universal\}
Use `*` as a wildcard. In `>*`, every direct child matches.
```html
<!-- @MARK * -->
<div class="bg:blue-60>*">
  <div>hit</div>
  <div>hit</div>
</div>
```

### `element` \{#element\}
Use a type selector to target elements by tag name.
```html
<!-- @MARK span -->
<div class="bg:blue-60>span">
  <span>hit</span>
</div>
```
If a raw type selector is hard to read or conflicts with nearby syntax, wrap it with `:is()` or `:where()`.
```html
<!-- @MARK :is(span) -->
<span class="bg:blue-60:is(span)"></span>
```

### `.class` \{#class\}
Use an application class such as `.active`, `.selected`, or `.expanded` to represent state. The element must have both the utility class and the matching state class.
```html
<!-- @MARK .active -->
<div class="bg:blue-60.active active">...</div>
```

### `#id` \{#id\}
Use an ID selector when the state is tied to a unique element.
```html
<!-- @MARK #nav -->
<nav id="nav" class="bg:blue-60#nav">...</nav>
```

### `[attribute]` \{#attribute\}
Use attribute selectors for DOM state that already lives in markup, such as `[disabled]`, `[open]`, `aria-*`, and `data-*`.
```html
<!-- @MARK [disabled] -->
<button type="button" class="bg:blue-60[disabled]" disabled>Submit</button>
```

### `:pseudo-class` \{#pseudo-class\}
Use pseudo-classes for browser-managed states.
```html
<!-- @MARK :hover -->
<button type="button" class="bg:blue-60:hover">Submit</button>
```

### `::pseudo-element` \{#pseudo-element\}
Use pseudo-elements such as `::before` and `::after` when the style should target generated content.
```html
<!-- @MARK ::before -->
<div class="content:'“'::before">quotes</div>
```

## Combinators \{#combinators\}
Combinators target elements by their relationship to the element that owns the class. Use them when the declaration should style a child, sibling, or descendant instead of the element itself.

| Selector          | Description               |
|-------------------|---------------------------|
| `A B`             | Descendant selector (`_`) |
| `A > B`           | Child selector            |
| `A + B`           | Adjacent sibling selector |
| `A ~ B`           | General sibling selector  |

### `_` — Descendant \{#_--descendant\}
Use `_` as the descendant combinator. It stands in for the CSS space, because spaces split class names in HTML.
```html
<!-- @MARK _ -->
<div class="bg:blue-60_div">
  <div>hit</div>
  <div>hit
    <div>hit
      <div>hit</div>
    </div>
  </div>
</div>
```

### `>` — Child \{#--child\}
Use `>` when only direct children should match.
```html
<!-- @MARK >div -->
<div class="bg:blue-60>div">
  <div>hit</div>
</div>
```

### `+` — Adjacent sibling \{#--adjacent-sibling\}
Use `+` to style the next sibling when it appears immediately after the current element.
```html
<!-- @MARK +div -->
<div class="bg:blue-60+div"></div>
<div>hit</div>
```

### `~` — General sibling \{#--general-sibling\}
Use `~` to style later siblings that share the same parent.
```html
<!-- @MARK ~div -->
<div class="bg:blue-60~div"></div>
<div>hit</div>
<div>hit</div>
<div>hit</div>
```

## Selector groups \{#selector-groups\}
Use `,` when the same declaration should apply to several selectors.
```html
<!-- @MARK , -->
<div class="content:'“'::before,::after">quotes</div>
```

## Pseudo-classes \{#pseudo-classes\}
### `:hover`, `:active`, `:focus` \{#hover--active--focus\}
Use interaction pseudo-classes to give controls feedback as people hover, press, focus, or navigate with a keyboard.

Hover or press the button to match the corresponding state. Include an explicit keyboard focus treatment.
```html
<!-- @MARK :hover --><!-- @MARK :active --><!-- @MARK :focus-visible -->
<button type="button" class="bg:blue-60 fg:white bg:blue-70:hover outline:2px|solid|blue:focus-visible bg:blue-80:active">Preview</button>
```

Use `:focus-visible` when the browser should decide whether to show a focus ring, including keyboard navigation. Keep focus visible instead of removing outlines without a replacement.
```html
<!-- @MARK :focus-visible -->
<button type="button" class="outline:2px|solid|blue:focus-visible">Submit</button>
```

### `:first`, `:last`, `:odd`, `:even` \{#first--last--odd--even\}
Use structural shorthands such as `:first`, `:last`, `:odd`, and `:even` to style list items by position. Write native selectors such as `:nth-child(N)` directly when they are clearer.
```html
<ul>
  <li class="surface:muted:even">Draft</li>
  <li class="surface:muted:even">In review</li>
  <li class="surface:muted:even">Published</li>
</ul>
```

`:odd` maps to `:nth-child(odd)`; `:even` maps to `:nth-child(2n)`. Positions count all element siblings, not only siblings that carry the same class.

<Class2CSS>{['surface:muted:even', 'mt:sm:odd']}</Class2CSS>

### `:valid`, `:invalid`, `:required` \{#valid--invalid--required\}
Use form validation pseudo-classes to reflect native validity without writing JavaScript state.

The required field is invalid while empty or while its value fails native email validation. The visible label supplies its accessible name.
```html
<!-- @MARK :valid --><!-- @MARK :invalid --><!-- @MARK :required -->
<label for="contact-email">Email</label>
<input id="contact-email" type="email" required
  class="b:1px|solid b:green:valid b:red:invalid outline:2px|solid|blue:focus-visible" />
```

Use `:required` to select required controls regardless of whether their current value is valid. Avoid communicating validation through color alone; production forms should also explain the error in text.

### `:disabled` \{#disabled\}
Use `:disabled` for controls that cannot be interacted with.
```html
<!-- @MARK :disabled -->
<button type="button" class="opacity:.5:disabled" disabled>Submit</button>
```

### `:checked`, `:indeterminate` \{#checked--indeterminate\}
Use `:checked` and `:indeterminate` for checkboxes, radio buttons, switches, and custom controls backed by native inputs.
```html
<!-- @MARK :checked -->
<label>
  <input class="outline:2px|solid|blue:checked" type="checkbox" checked />
  Include archived items
</label>
```

`indeterminate` is a DOM property, not an HTML attribute. Set it from JavaScript when a checkbox represents a partially selected group; style that state with `:indeterminate`. It does not change the checkbox's submitted checked value.

```html
<label><input id="select-all" type="checkbox" class="outline:2px|solid|blue:indeterminate" /> Select all</label>
```
```js
document.querySelector('#select-all').indeterminate = true
```

### `:rtl`, `:ltr` \{#rtl--ltr\}
Use `:rtl` and `:ltr` to react to text direction. They map to `:dir(rtl)` and `:dir(ltr)`.
```html
<!-- @MARK :rtl -->
<div dir="rtl" class="mr:xs:rtl">مرحبا</div>
```

### `:has()` \{#has\}
Use `:has()` when the current element should change because it contains a matching child or descendant.
```html
<!-- @MARK :has(.active) -->
<div class="bg:blue-60:has(.active)">
  <div>Item 1</div>
  <div class="active">Item 2</div>
  <div>Item 3</div>
</div>
```

### `:not()` \{#not\}
Use `:not()` to exclude a selector from the match.
```html
<!-- @MARK :not(.active) -->
<div class="fg:green-60:not(.active) active">...</div>
```

### `:of()` \{#of\}
`:of()` is the only proprietary selector introduced by Master CSS. It lets the current element respond to a parent, ancestor, or previous sibling. Use native selectors first when they can express the relationship; use `:of()` when you need to style the current element from outside-in context.

Style the element when an ancestor matches.
```html
<!-- @MARK active -->
<div class="active">
  <div>
    <!-- @MARK :of(.active) -->
    <div class="hidden:of(.active)">hidden</div>
  </div>
</div>
```
Style the element when its parent matches.
```html
<!-- @MARK active -->
<div class="active">
  <!-- @MARK :of(.active>) -->
  <div class="hidden:of(.active>)">hidden</div>
</div>
```
Style the element when its previous adjacent sibling matches.
```html
<!-- @MARK active -->
<div class="active"></div>
<!-- @MARK :of(.active+) -->
<div class="hidden:of(.active+)">hidden</div>
```
Style the element when one of its preceding siblings matches.
```html
<!-- @MARK active -->
<div class="active"></div>
<div></div>
<!-- @MARK :of(.active~) -->
<div class="hidden:of(.active~)">hidden</div>
```
Do not put combinators or pseudo-elements before `:of()`. The following order is unsupported:
```html
<div class="hidden_div::before:of(.active)">hidden</div>
```

## Pseudo-elements \{#pseudo-elements\}
### `::before`, `::after` \{#before--after\}
Use `::before` and `::after` to style generated content attached to the element.
```html
<!-- @MARK ::before --><!-- @MARK ::after -->
<span class="content:close-quote::after content:open-quote::before">
  Keep the interface clear.
</span>
```

### `::scrollbar` \{#scrollbar\}
Style common scrollbar surfaces with `::scrollbar`, `::scrollbar-thumb`, and `::scrollbar-track` shorthands. Write native vendor selectors such as `::-webkit-scrollbar-corner` directly for less common parts.

These aliases generate `::-webkit-scrollbar*` selectors. Their effect depends on browser support and the platform scrollbar settings; overlay scrollbars may remain hidden until scrolling.
```html
<!-- @MARK scrollbar --><!-- @MARK ::scrollbar-thumb -->
<div tabindex="0" role="region" aria-label="Scrollable schedule"
  class="overflow-x:auto max-w:full size:0.375rem::scrollbar bg:neutral-50/.2::scrollbar-thumb">
  <p class="w:7xl">Monday · Tuesday · Wednesday · Thursday · Friday</p>
</div>
```

## Attribute selectors \{#attribute-selectors\}
### `[open]` \{#open\}
Use `[open]` to style a `<details>` element while it is expanded. The browser updates the attribute when the user toggles its summary.
```html
<!-- @MARK [open] -->
<details class="surface:raised[open]" open>
  <summary>Details</summary>
  <p>Details content goes here.</p>
</details>
```

### `[aria-<key>=<value>]` \{#aria-keyvalue\}
Use [ARIA](https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA) attributes when accessible state is already present in the DOM.
```html
<!-- @MARK [aria-pressed=true] -->
<button type="button" class="bg:blue-60[aria-pressed=true] fg:white[aria-pressed=true]" aria-pressed="true">Bold</button>
```

Choose an attribute that is valid for the control, and update it as part of the control behavior. A selector only reads state; it does not implement the interaction or make an arbitrary element accessible.

### `[data-<key>=<value>]` \{#data-keyvalue\}
Use `data-*` attributes for component state that is not covered by native attributes or ARIA.
```html
<!-- @MARK [data-active] -->
<div class="bg:blue-60[data-active]" data-active>...</div>
```

### `[<attr>=<value>]` \{#attrvalue\}
Match an exact attribute value. Pseudo aliases only expand at actual pseudo selectors: `[data-state=":first"]:first` keeps the attribute value `:first` and expands the final `:first` to `:first-child`. Escaped identifier characters also remain literal.
```html
<!-- @MARK [type=checkbox] -->
<label><input class="accent-color:blue[type=checkbox]" type="checkbox" /> Enable alerts</label>
```

### `[<attr>^=<value>]` \{#attrvalue-1\}
Match values that start with a specific string.

This matches links whose attribute starts with `http`; it does not distinguish same-origin from external links.
```html
<!-- @MARK [href^=http] -->
<a class="content:'↗'[href^=http]::after" href="https://example.com">External</a>
```

### `[<attr>$=<value>]` \{#attrvalue-2\}
Match values that end with a specific string.
```html
<!-- @MARK [href$='.pdf'] -->
<a class="content:'⬇'[href$='.pdf']::after" href="https://example.com/report.pdf">PDF</a>
```

### `[<attr>*=<value>]` \{#attrvalue-3\}
Match values that contain a specific string.
```html
<!-- @MARK [title*=master] -->
<div class="bg:blue-60[title*=master]" title="mastercss">...</div>
```

### `[<attr>|=<value>]` \{#attrvalue-4\}
Match a value exactly or followed by a hyphen, which is common for language codes.
```html
<!-- @MARK [lang|=en] -->
<div class="bg:blue-60[lang|=en]" lang="en-US">...</div>
```

### `[<attr>~=<value>]` \{#attrvalue-5\}
Match one word inside a whitespace-separated attribute value.
```html
<!-- @MARK [title~=css] -->
<div class="bg:blue-60[title~=css]" title="master css">...</div>
```
