## Start with the element that owns the state

CSS selectors decide which element receives a declaration. To change a button's text color while it is hovered, append `:hover` to the color class:

```html
<button class="fg:blue-60:hover">Save</button>
```

<Class2CSS>{['fg:blue-60:hover']}</Class2CSS>

First inspect the selector in the output. It should target the same button that owns the class. The [selector overview](/reference/rules/selectors#basic-selectors) maps native selector forms to their targets.

## Choose the target before combining selectors

1. Identify the element that owns the state and the element that should receive the style.
2. Check one selector before adding a combinator or a selector group.
3. Test the actual interaction. Hover styling alone does not provide keyboard focus feedback or disabled behavior.
4. When the style also needs a breakpoint, place its [condition after the selector](/reference/rules/conditions#composition).

Use the [Selectors reference](/reference/rules/selectors) to look up pseudo-classes, attributes, combinators and aliases.
