## Overview [sr-only]

```html
<!-- @MARK :hover -->
<div class="fg:accent:hover"></div>
<!-- @MARK :invalid -->
<input class="border:red:invalid" />
<!-- @MARK [open] -->
<details class="bg:white[open]" open></details>
```
State selectors let one declaration apply only when a selector matches. Append the selector after the declaration value:

```txt
property:value<selector>
```

Common examples include interaction states such as `:hover`, validation states such as `:invalid`, and attributes such as `[disabled]` or `[open]`.

```html
<!-- @MARK :hover --><!-- @MARK :active -->
<h2 class="font:lg font:2xl:hover font:3xl:active …">
```
Selectors can be stacked when the CSS selector itself needs more detail.
```html
<!-- @MARK :hover:not(.active) -->
<div class="bg:blue-20:hover:not(.active) …">
```
If you also need a breakpoint, mode, or other condition, put the [conditional query](/guide/conditional-queries) after the selector.

```html
<!-- @MARK :hover@md -->
<button class="bg:accent:hover@md">Save</button>
```

For readability, Master CSS can use [selector variants](/guide/theme#selector-variants) to name selectors that appear often.
```html
<div class="mt:sm:first"><!-- [!code highlight] -->
<div class="mt:sm:first-child">
<div class="mt:sm:odd"><!-- [!code highlight] -->
<div class="mt:sm:nth-child(2n)">
<div class="mt:sm:rtl"><!-- [!code highlight] -->
<div class="mt:sm:dir(rtl)">
```
You can also create project-specific selector variants for longer selectors.
```html
<div class="font:semibold_:headings"><!-- [!code highlight] -->
<div class="font:semibold_:is(h1,h2,h3,h4,h5,h6)">
```

## Basic selectors
Master CSS accepts native selector syntax. The selector is relative to the element that owns the class unless a combinator points to another element.

| Selector              | Description                                           | Preview CSS                               |
|-----------------------|-------------------------------------------------------|-------------------------------------------|
| `*`                   | Universal selector                                    | `css * { margin: 0; }`                    |
| `element`             | Type selector                                         | `css p { color: red; }`                   |
| `.class`              | Class selector                                        | `css .box { padding: 1rem; }`             |
| `#id`                 | ID selector                                           | `css #header { background: blue; }`       |
| `[attribute]`         | Attribute selector                                    | `css [disabled] { opacity: 0.5; }`        |
| `:pseudo-class`       | Pseudo-class selector                                 | `css a:hover { color: blue; }`            |
| `::pseudo-element`    | Pseudo-element selector                               | `css p::first-letter { font-size: 2em; }` |

### `*` — Universal
Use `*` as a wildcard. In `>*`, every direct child matches.
```html
<!-- @MARK * -->
<div class="bg:accent>*">
    <div>hit</div>
    <div>hit</div>
    ...
</div>
```

### `element`
Use a type selector to target elements by tag name.
```html
<!-- @MARK span -->
<div class="bg:accent>span">
    <span>hit</span>
</div>
```
(i) If a raw type selector is hard to read or conflicts with nearby syntax, wrap it with `:is()` or `:where()`.
```html
<!-- @MARK :is(span) -->
<span class="bg:accent:is(span)"></span>
```

### `.class`
Use a class selector for custom application state, such as `.active`, `.selected`, or `.expanded`.
```html
<!-- @MARK .active -->
<div class="bg:accent.active active">...</div>
```

### `#id`
Use an ID selector when the state is tied to a unique element.
```html
<!-- @MARK #nav -->
<nav id="nav" class="bg:accent#nav">...</nav>
```

### `[attribute]`
Use attribute selectors for DOM state that already lives in markup, such as `[disabled]`, `[open]`, `aria-*`, and `data-*`.
```html
<!-- @MARK [disabled] -->
<button class="bg:accent[disabled]" disabled>Submit</button>
```

### `:pseudo-class`
Use pseudo-classes for browser-managed states.
```html
<!-- @MARK :hover -->
<button class="bg:accent:hover">Submit</button>
```

### `::pseudo-element`
Use pseudo-elements such as `::before` and `::after` when the style should target generated content.
```html
<!-- @MARK ::before -->
<div class="content:'“'::before">quotes</div>
```

## Combinators
Combinators target elements by their relationship to the element that owns the class. Use them when the declaration should style a child, sibling, or descendant instead of the element itself.

| Selector          | Description               | Preview CSS                 |
|-------------------|---------------------------|-----------------------------|
| `A B`             | Descendant selector (`_`) | `css nav a { color: white; }`   |
| `A > B`           | Child selector            | `css ul > li { list-style: none; }` |
| `A + B`           | Adjacent sibling selector | `css h1 + p { margin-top: 0; }` |
| `A ~ B`           | General sibling selector  | `css h1 ~ p { color: gray; }`   |

### `_` — Descendant
Use `_` as the descendant combinator. It stands in for the CSS space, because spaces split class names in HTML.
```html
<!-- @MARK _ -->
<div class="bg:accent_div">
    <div>hit</div>
    <div>hit
        <div>hit
            <div>hit</div>
        </div>
    </div>
</div>
```

### `>` — Child
Use `>` when only direct children should match.
```html
<!-- @MARK >div -->
<div class="bg:accent>div">
    <div>hit</div>
</div>
```

### `+` — Adjacent sibling
Use `+` to style the next sibling when it appears immediately after the current element.
```html
<!-- @MARK +div -->
<div class="bg:accent+div"></div>
<div>hit</div>
```

### `~` — General sibling
Use `~` to style later siblings that share the same parent.
```html
<!-- @MARK ~div -->
<div class="bg:accent~div"></div>
<div>hit</div>
<div>hit</div>
<div>hit</div>
```

## Selector groups
Use `,` when the same declaration should apply to several selectors.
```html
<!-- @MARK , -->
<div class="content:'“'::before,::after">quotes</div>
```
<details>
  <summary>Generated CSS</summary>
  <Class2CSS>
    {[`content:'“'::before,::after`]}
  </Class2CSS>
</details>
Selector groups also work with combinators. In this example, the declaration applies to direct `div` and `span` children.
```html
<!-- @MARK , -->
<div class="block>div,>span">hit</div>
```
<details>
  <summary>Generated CSS</summary>
  <Class2CSS>
    {['block>div,>span']}
  </Class2CSS>
</details>

## Pseudo-classes
### `:hover`, `:active`, `:focus`
Use interaction pseudo-classes to give controls feedback as people hover, press, focus, or navigate with a keyboard.

(click) Try clicking the button to see states change
<Demo>
    <button className="bg:accent bg:accent-hover:hover bg:accent-pressed:active px:md h:10x font:sm font:medium fg:on-accent r:sm inline-flex align-items:center">Submit</button>
</Demo>
```html
<!-- @MARK :hover --><!-- @MARK :active -->
<button class="bg:accent fg:on-accent bg:accent-hover:hover bg:accent-pressed:active">Submit</button>
```

Use `:focus-visible` for keyboard focus rings when you want to avoid showing the focus style after every pointer click.
```html
<!-- @MARK :focus-visible -->
<button class="outline:2|solid|blue:focus-visible">Submit</button>
```

### `:first`, `:last`, `:odd`, `:even`
Use structural shorthands such as `:first`, `:last`, `:odd`, `:even`, and `:nth(N)` to style list items by position.
<Demo $py={0}>
    <DemoPanel $p={0} className="w:full max-w:90x">
        <ul className="list-style:none py:lg px:0 m:0">
            {furnitures.map((furniture, index) =>
                <li className="bb:0:last bg:slate-5:even@light bg:gray-90:even@dark bb:1|subtle px:lg flex align-items:center my:0 gap:sm" key={index}>
                    <img className="round object:cover" src={furniture.url} width="56" height="56" alt="avatar" quality={'0'} />
                    <div className="flex flex-col flex:1 py:xs">
                        <div className="flex align-items:center">
                            <div className="text:sm capitalize fg:strong">{furniture.name}</div>
                        </div>
                        <div className="text:xs m:0 fg:text">{furniture.intro}</div>
                    </div>
                </li>
            )}
        </ul>
    </DemoPanel>
</Demo>
```html
<ul class="…">
    <!-- @MARK :even --><!-- @MARK :even -->
    <li class="bg:slate-5:even@light bg:gray-90:even@dark …">…</li>
</ul>
```

### `:valid`, `:invalid`, `:required`
Use form validation pseudo-classes to reflect native validity without writing JavaScript state.

(type) Try typing `co` as a valid email address
<Demo>
    <input type="email" className="b:danger:invalid b:success:valid b:1|subtle outline:0 h:12x font:sm px:md bg:panel r:md max-w:75x" defaultValue="aron@master." />
</Demo>
```html
<!-- @MARK :invalid --><!-- @MARK :invalid -->
<input class="b:danger:invalid b:success:valid b:1|solid …" type="email" />
```

### `:disabled`
Use `:disabled` for controls that cannot be interacted with.
```html
<!-- @MARK :disabled -->
<button class="opacity:.5:disabled" disabled>Submit</button>
```

### `:checked`, `:indeterminate`
Use `:checked` and `:indeterminate` for checkboxes, radio buttons, switches, and custom controls backed by native inputs.
<Demo>
    <input type="checkbox" className="appearance:none bg:accent:checked b:1|line r:sm size:5x" defaultChecked />
</Demo>
```html
<!-- @MARK :checked -->
<input class="bg:accent:checked …" type="checkbox" checked />
```

### `:rtl`, `:ltr`
Use `:rtl` and `:ltr` to react to text direction. They map to `:dir(rtl)` and `:dir(ltr)`.
```html
<!-- @MARK :rtl -->
<div class="mr:xs:rtl">...</div>
```

### `:has()`
Use `:has()` when the current element should change because it contains a matching child or descendant.
```html
<!-- @MARK :has(.active) -->
<div class="bg:accent:has(.active)">
    <div>Item 1</div>
    <div class="active">Item 2</div>
    <div>Item 3</div>
</div>
```

### `:not()`
Use `:not()` to exclude a selector from the match.
```html
<!-- @MARK :not(.active) -->
<div class="fg:success:not(.active) active">...</div>
```

### `:of()`
`:of()` is the only proprietary selector introduced by Master CSS. It lets the current element respond to a parent, ancestor, or previous sibling. Use native selectors first when they can express the relationship; use `:of()` when you need to style the current element from outside-in context.

(i) Style the element when an ancestor matches.
```html
<!-- @MARK active -->
<div class="active">
    <div>
        <!-- @MARK :of(.active) -->
        <div class="hidden:of(.active)">hidden</div>
    </div>
</div>
```
(i) Style the element when its parent matches.
```html
<!-- @MARK active -->
<div class="active">
    <!-- @MARK :of(.active>) -->
    <div class="hidden:of(.active>)">hidden</div>
</div>
```
(i) Style the element when its previous adjacent sibling matches.
```html
<!-- @MARK active -->
<div class="active"></div>
<!-- @MARK :of(.active+) -->
<div class="hidden:of(.active+)">hidden</div>
```
(i) Style the element when one of its preceding siblings matches.
```html
<!-- @MARK active -->
<div class="active"></div>
<div></div>
<!-- @MARK :of(.active~) -->
<div class="hidden:of(.active~)">hidden</div>
```
(x) Do not put combinators or pseudo-elements before `:of()`.
```html
<div class="hidden_div::before:of(.active)">hidden</div>
```

## Attribute selectors
### `[open]`
Use `[open]` to style a `<details>` element while it is expanded.
```html
<!-- @MARK [open] -->
<details class="bg:white[open]" open>
    <summary>Details</summary>
    <p>Details content goes here.</p>
</details>
```

### `[aria-<key>=<value>]`
Use [ARIA](https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA) attributes when accessible state is already present in the DOM.
```html
<!-- @MARK [aria-checked] -->
<div class="bg:accent[aria-checked=true]" aria-checked="true">...</div>
```

### `[data-<key>=<value>]`
Use `data-*` attributes for component state that is not covered by native attributes or ARIA.
```html
<!-- @MARK [data-active] -->
<div class="bg:accent[data-active]" data-active>...</div>
```

### `[<attr>=<value>]`
Match an exact attribute value.
```html
<!-- @MARK [type=checkbox] -->
<input class="b:accent[type=checkbox]" type="checkbox" />
```

### `[<attr>^=<value>]`
Match values that start with a specific string.

(i) Links that start with `http`.
<Demo>
    <a className="{content:'↗';ml:3xs}[href^=http]::after" href="https://css.master.co" target="_blank">External</a>
</Demo>
```html
<!-- @MARK [href^=http] -->
<a class="content:'↗'[href^=http]::after" href="https://…">External</a>
```

### `[<attr>$=<value>]`
Match values that end with a specific string.
<Demo>
    <a className="{content:'⬇';ml:3xs}[href$='.pdf']::after" href="https://….pdf">PDF</a>
</Demo>
```html
<!-- @MARK [href$='.pdf'] -->
<a class="content:'⬇'[href$='.pdf']::after" href="https://….pdf">PDF</a>
```

### `[<attr>*=<value>]`
Match values that contain a specific string.
```html
<!-- @MARK [title*=master] -->
<div class="bg:accent[title*=master]" title="mastercss">...</div>
```

### `[<attr>|=<value>]`
Match a value exactly or followed by a hyphen, which is common for language codes.
```html
<!-- @MARK [lang|=en] -->
<div class="bg:accent[lang|=en]" lang="en-US">...</div>
```

### `[<attr>~=<value>]`
Match one word inside a whitespace-separated attribute value.
```html
<!-- @MARK [title~=css] -->
<div class="bg:accent[title~=css]" title="master css">...</div>
```
