```css name=index.css
@master {
    @custom-at landscape @media (orientation: landscape);
}
```
Employ concise yet semantically meaningful markup.
```html
<!-- @MARK @landscape -->
<div class="aspect:2/1@landscape">…</div>
```
(!) You usually do not want to write full conditions in markup.
```html
<!-- @MARK @media(orientation:landscape) -->
<div class="aspect:2/1@media(orientation:landscape)">…</div>
```
