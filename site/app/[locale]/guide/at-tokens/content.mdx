## Overview [sr-only]
<Default />
Native CSS cannot store full `@media`, `@supports`, or `@container` rules in CSS variables. Master CSS uses at tokens to name reusable conditional rules and apply them from markup or from `@master` definitions.
<Overview />

---

## Define an at token
Define custom at tokens inside the root `@master` block with `@custom-at`.

```css name=index.css
@master {
    @custom-at motion-safe @media (prefers-reduced-motion: no-preference);
    @custom-at supports-backdrop @supports (backdrop-filter: blur(0));
    @custom-at card-wide @container card (width >= 42rem);
    @custom-at start @starting-style;
}
```

The token name is written without a leading `@` in the definition. Use the token as an `@` suffix in markup:

```html
<!-- @MARK @motion-safe -->
<div class="animation:fade-in|fast@motion-safe">…</div>

<!-- @MARK @supports-backdrop -->
<div class="bg:white/.8@supports-backdrop">…</div>
```

Generated CSS:

```css
@media (prefers-reduced-motion: no-preference) {
    .animation\:fade-in\|fast\@motion-safe {
        animation: fade-in 150ms;
    }
}

@supports (backdrop-filter: blur(0)) {
    .bg\:white\/\.8\@supports-backdrop {
        background-color: rgb(255 255 255 / .8);
    }
}
```

## Use at tokens in managed definitions
Inside `@layer components` and `@layer utilities`, use `@at` blocks instead of putting conditional suffixes inside `@compose`. This keeps the composed utility list plain and lets the surrounding CSS structure describe the condition.

```css name=index.css
@master {
    @custom-at motion-safe @media (prefers-reduced-motion: no-preference);
}

@layer components {
    .card {
        @compose "p:md r:xl";

        @at motion-safe {
            @compose "animation:fade-in|fast";
        }
    }
}
```

`@at` accepts custom at tokens, screen tokens such as `md`, mode names such as `dark`, and raw Master CSS at syntax such as `<sm`.

```css name=index.css
@master {
    mode-trigger: class;
}

@layer components {
    .btn {
        @compose "inline-flex";

        @at dark {
            @compose "bg:neutral-90";
        }

        @at <sm {
            @compose "block";
        }
    }
}
```

With `mode-trigger: class`, `@at dark` becomes a selector wrapper such as `.dark &`. With `mode-trigger: media`, it becomes `@media (prefers-color-scheme: dark)`.

## Built-in tokens and conflicts
Screen variables automatically create at tokens such as `@md`, and modes automatically create at tokens such as `@dark`.

```css name=index.css
@master {
    --screen-md: 768;

    dark {
        --color-primary: #000;
    }
}
```

Custom at token names cannot start with `@`, cannot start with `:` or `::`, and cannot conflict with screen or mode names. Use [selector tokens](/guide/selector-tokens) for selector aliases.
