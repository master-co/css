## Using shadows [sr-only]
[CSS box shadows](https://developer.mozilla.org/en-US/docs/Web/CSS/box-shadow) create visual depth by drawing one or more shadows around an element. Master CSS maps elevation to the `shadow` variable namespace, so product surfaces can use stable size tokens instead of repeating raw shadow values.

The default scale runs from `xs` to `2xl`. Each step increases offset, blur, and shadow opacity while staying practical for application UI.

Use elevation tokens to answer three interface questions:

* How close is the surface to the page? Use `shadow:xs` or `shadow:sm` for low separation.
* Is the surface floating above nearby content? Use `shadow:md` or `shadow:lg`.
* Does the surface interrupt the workflow? Use `shadow:xl` or `shadow:2xl`.

Use the scale by surface role:

* `shadow:xs` is for tiny separation, such as compact controls or subtle rows.
* `shadow:sm` is the default card elevation.
* `shadow:md` is for floating controls and hover lift.
* `shadow:lg` is for dropdowns, popovers, and toast surfaces.
* `shadow:xl` and `shadow:2xl` are for dialogs, drawers, modals, and blocking overlays.

---

## Namespace for elevation
Elevation tokens are defined in `variables.shadow`. The `box-shadow` rule references this namespace, so both `shadow:<token>` and `box-shadow:<token>` resolve the same values.

```css name=index.css
@master {
    --shadow-sm: 0 1px 2px oklch(0% 0 none / .06), 0 2px 4px oklch(0% 0 none / .06);
    --shadow-md: 0 2px 4px -1px oklch(0% 0 none / .08), 0 6px 12px -2px oklch(0% 0 none / .08);
    --shadow-lg: 0 4px 8px -2px oklch(0% 0 none / .08), 0 12px 24px -4px oklch(0% 0 none / .10);
}
```

Apply the custom tokens in markup:

```html
<!-- @MARK shadow:sm --><!-- @MARK box-shadow:lg -->
<article class="shadow:sm">...</article>
<div class="box-shadow:lg">...</div>
```

## Layer surfaces consistently
Elevation works best when it supports a clear surface hierarchy. Start with the lowest token that separates the element, then move up only when the surface overlays or interrupts surrounding content.

Use outlines and background tokens with shadows. An `outline:1|lightest` outline keeps low elevations visible on light surfaces, while `bg:base` or `bg:surface` keeps the elevated area distinct from the page ground.

## Customize shadow tokens
Override `shadow` variables when your product needs a softer, sharper, or more branded elevation scale. Keep the keys size-based so markup remains portable across components.

```css name=index.css
@master {
    --shadow-xs: 0 1px 1px oklch(0% 0 none / .06);
    --shadow-sm: 0 2px 4px oklch(0% 0 none / .08);
    --shadow-md: 0 6px 16px oklch(0% 0 none / .10);
    --shadow-lg: 0 12px 32px oklch(0% 0 none / .12);
    --shadow-xl: 0 20px 48px oklch(0% 0 none / .14);
    --shadow-2xl: 0 32px 80px oklch(0% 0 none / .18);
}
```
