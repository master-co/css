## Guide status [sr-only]
This CSS migration guide is being rebuilt. Use the [quick start](/guide/migration) to direct your local coding agent, then ask it to inspect existing CSS before converting anything.

## Inspect first
- Global stylesheets, reset files, layout files, and component CSS.
- CSS modules, framework style blocks, and files imported by app entry points.
- Custom properties, theme values, cascade layers, and media queries.
- Vendor CSS, generated CSS, animations, and one-off rules that should stay in regular CSS.
