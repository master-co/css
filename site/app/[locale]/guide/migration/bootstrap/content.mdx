## Guide status [sr-only]
This Bootstrap migration guide is being rebuilt. Use the [quick start](/guide/migration) to direct your local coding agent, then ask it to inspect Bootstrap-specific styling before changing code.

## Inspect first
- Bootstrap package imports, CSS entry files, Sass variable overrides, and compiled output.
- Grid, spacing, display, typography, and utility classes used in templates.
- JavaScript-driven components, data attributes, and third-party markup that should remain compatible.
- Custom overrides that depend on Bootstrap selectors or cascade order.
