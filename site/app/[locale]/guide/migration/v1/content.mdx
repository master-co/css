## Guide status [sr-only]
This Master CSS v1 migration guide is being rebuilt. Use the [quick start](/guide/migration) to direct your local coding agent, then ask it to inspect v1-specific setup before changing code.

## Inspect first
- Installed `@master/*` package versions and old runtime or server initialization code.
- Project CSS entries, imported Master CSS files, and any legacy config files.
- Custom theme values, breakpoints, queries, classes, and selector syntax.
- Color shades, variable references, and component abstractions that may need current syntax.
