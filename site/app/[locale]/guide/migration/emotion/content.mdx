This Emotion migration guide is being rebuilt. Use the [quick start](/guide/migration) to direct your local coding agent, then ask it to inspect Emotion-specific styling before changing code.

## Inspect first
- `@emotion/react`, `@emotion/styled`, `css` prop usage, and object style helpers.
- Theme providers, `Global` styles, shared fragments, and variant props.
- Components where static class strings would be clearer than runtime style objects.
- Dynamic styles that should stay in component logic until there is a simpler Master CSS form.
