This Tailwind CSS migration guide is being rebuilt. Use the [quick start](/guide/migration) to direct your local coding agent, then ask it to inspect Tailwind-specific styling before changing code.

## Inspect first
- `tailwind.config.*`, preset files, plugins, and theme extensions.
- CSS entries with `@tailwind`, `@layer`, or `@apply`.
- Markup class strings, helper functions, and component props that compose Tailwind classes.
- Custom utilities, design tokens, and third-party classes that should stay in place.
