## Change a component at the right boundary

Choose a condition from the component's requirement: viewport width for page layout, container width for a reusable component, and state selectors for interaction. For example, this text color applies while the element is hovered at the current preset's `sm` breakpoint and above:

```html
<button class="fg:red:hover@sm">Save</button>
```

<Class2CSS>{['fg:red:hover@sm']}</Class2CSS>

Read the media condition in the generated CSS instead of assuming a breakpoint value from another project. The output also includes the color token's mode dependencies.

## Check one condition at a time

1. Start with the unqualified style and verify its value.
2. Add the interaction state and test that state.
3. Add the viewport or container condition and test on both sides of its boundary.
4. If the result still differs, inspect the active mode and competing cascade layers.

The [composition contract](/reference/rules/conditions#composition) explains these dependencies together. Use the [Conditions reference](/reference/rules/conditions) for exact forms and combinations.
