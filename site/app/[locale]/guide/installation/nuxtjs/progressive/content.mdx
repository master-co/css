<StepSection>
  <Step $row>

      ### <StepNum />Create a project
      If you don't have a Nuxt project, create one first.
    </StepL>
    <StepR>
      ```bash name=Terminal
      npx nuxi@latest init my-app
      cd my-app
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### <StepNum />Add Master CSS
      Run the installer with `--mode progressive` from the project root. Pre-rendered pages receive first-response CSS and a runtime handoff for later class names.
    </StepL>
    <StepR>
      ```bash name=Terminal
      npm create @master/css@rc -- --framework nuxt --mode progressive --yes
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### <StepNum />Launch server
      Run the development server.
    </StepL>
    <StepR>
      ```bash name=Terminal&action=run
      dev
      ```
    </StepR>
  </Step>
  <Step>
    ### <StepNum />Start using Master CSS

  </Step>
