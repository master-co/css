## Installation [sr-only]
Add Master CSS to an existing project with the installer. It detects common frameworks, applies the matching setup, and can install the required packages.

<StepSection>
    <Step $row>
        <StepL>
            ### <StepNum />Create a project
            Start from a Vite project when you do not have an app yet.
        </StepL>
        <StepR>
            ```bash name=Terminal
            npm create vite@latest my-app
            cd my-app
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Add Master CSS
            Run the installer from the project root. It updates the project setup and installs the packages with the detected package manager.
        </StepL>
        <StepR>
            ```bash name=Terminal
            npm create @master/css@rc -- --framework vite --yes
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Run and style
            Start the dev server, then use Master CSS classes in your markup.
        </StepL>
        <StepR>
            ```bash name=Terminal&action=run
            dev
            ```

            ```html name=index.html
            <h1 class="italic m:2xl text:neutral font:5xl font:heavy">
                Hello World
            </h1>
            ```
        </StepR>
    </Step>
    <HelloWorld url="localhost:5173" />
</StepSection>
