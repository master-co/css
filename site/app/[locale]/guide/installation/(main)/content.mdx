## Installation [sr-only]
Start with Vite and the official plugin. This quick start uses [static rendering](/guide/rendering-modes#static-rendering) for generated CSS.

<StepSection>
    <Step $row>
        <StepL>
            ### <StepNum />Create a Vite project
            Create an app and enter the project directory.
        </StepL>
        <StepR>
            ```bash name=Terminal
            npm create vite@latest my-app
            cd my-app
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Install Master CSS
            Add the Vite plugin.
        </StepL>
        <StepR>
            ```bash action=install
            @master/css.vite@rc
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Configure Vite
            Register `masterCSS()` in static mode.
        </StepL>
        <StepR>
            ```js name=vite.config.js
            import { defineConfig } from 'vite'
            import masterCSS from '@master/css.vite' // [!code highlight]

            export default defineConfig({
                plugins: [
                    masterCSS({ // [!code highlight]
                        mode: 'static' // [!code highlight]
                    }) // [!code highlight]
                ]
            })
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Import stylesheets
            Import Master CSS once from the CSS file your app already loads. This stylesheet is also the project CSS entry.
        </StepL>
        <StepR>
            ```css name=src/style.css
            @import '@master/css';
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Run and style
            Start the dev server, then add Master CSS classes.
        </StepL>
        <StepR>
            ```bash name=Terminal&action=run
            dev
            ```

            ```html name=index.html
            <h1 class="italic m:2xl text:strong font:5xl font:heavy">
                Hello World
            </h1>
            ```
        </StepR>
    </Step>
    <HelloWorld url="localhost:5173" />
</StepSection>
