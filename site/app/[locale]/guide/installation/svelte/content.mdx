## Manual setup

Use this path when `sv add` is not available for the project. The Svelte integration uses `progressive` mode by default, and the scanner extracts classes from `.svelte` files automatically.

```bash name=Terminal
npm install @master/css@rc @master/css.svelte@rc
```

```js name=vite.config.js
import { sveltekit } from '@sveltejs/kit/vite'
import { defineConfig } from 'vite'
import masterCSS from '@master/css.svelte/vite' // [!code highlight]

export default defineConfig({
    plugins: [
        sveltekit(),
        masterCSS() // [!code highlight]
    ]
})
```

Import Master CSS from a global stylesheet and load it from the root layout. This stylesheet is also the project CSS entry.

```css name=src/routes/styles.css
@import '@master/css';
```

```svelte name=src/routes/+layout.svelte
<script lang="ts">
    import './styles.css'
</script>
```

Create or update `src/hooks.server.ts` with the Master CSS handle. It injects early streamed CSS before `</head>`, while the client runtime hydrates classes discovered after the head is flushed.

```ts name=src/hooks.server.ts
export { default as handle } from '@master/css.svelte/hooks.server'
```

If the project already has a server `handle`, compose it with SvelteKit's `sequence()` and keep Master CSS first.

```ts name=src/hooks.server.ts
import masterCSSHandle from '@master/css.svelte/hooks.server'
import { sequence } from '@sveltejs/kit/hooks'

const userHandle = async ({ event, resolve }) => {
    return resolve(event)
}

export const handle = sequence(masterCSSHandle, userHandle)
```
