<StepSection>
    <Step $row>
        <StepL>
            ### <StepNum />Create a project
            If you don't have a Svelte project, create one first. It's recommended to refer to [Svelte Kit](https://kit.svelte.dev/).
        </StepL>
        <StepR>
            ```bash name=Terminal
            npm create svelte@latest my-app
            cd my-app
            npm install
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Install Master CSS
            Install `@master/css.svelte` into your project.
        </StepL>
        <StepR>
            ```bash action=install
            @master/css.svelte@rc
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Set up Master CSS
            Add the Master CSS Svelte Vite plugin in `vite.config.js`. The Svelte integration uses `progressive` mode by default.
        </StepL>
        <StepR>
            ```js name=vite.config.js
            import { sveltekit } from '@sveltejs/kit/vite'
            import { defineConfig } from 'vite'
            import masterCSS from '@master/css.svelte/vite' // [!code highlight]

            export default defineConfig({
                plugins: [
                    sveltekit(),
                    masterCSS() // [!code highlight]
                ]
            })
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Import the default stylesheet
            Import Master CSS from a global stylesheet and load it from the root layout. This stylesheet is also the project CSS entry.
        </StepL>
        <StepR>
            ```css name=src/routes/styles.css
            @import '@master/css';
            ```

            ```svelte name=src/routes/+layout.svelte
            <script lang="ts">
                import './styles.css'
            </script>
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Set up Master CSS renderer
            Create a `src/hooks.server.ts` and export the Master CSS handle. It injects early streamed CSS before `</head>`, while the client runtime hydrates classes discovered after the head is flushed.

            If the project already has a server `handle`, compose it with SvelteKit's `sequence()`.
        </StepL>
        <StepR>
            ```ts name=src/hooks.server.ts
            export { default as handle } from '@master/css.svelte/hooks.server'
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Launch server
            Run `npm run dev -- --open` to start your Svelte development server
        </StepL>
        <StepR>
            ```bash name=Terminal
            npm run dev -- --open
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Start using Master CSS
            Now style your first element using Master CSS syntax!
        </StepL>
        <StepR>
            ```svelte name=src/routes/%2Bpage.svelte
            <h1 class="italic m:2xl fg:strong font:5xl font:heavy">
                Hello World
            </h1>
            ```
        </StepR>
    </Step>
    <HelloWorld url="localhost:5173" />
</StepSection>
