        <StepL>
            ### <StepNum />Create a Vite project
            If you don't have a Vite project, create one first.
        </StepL>
        <StepR>
            ```bash name=Terminal
            npm create vite@latest my-app
            cd my-app
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Add Master CSS
            Run the installer in static mode from the Vite project root. Static mode scans complete class strings and emits generated CSS at build time.
        </StepL>
        <StepR>
            ```bash name=Terminal
            npm create @master/css@rc -- --framework vite --mode static --yes
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Start dev server
            Run the command to start the Vite dev server.
        </StepL>
        <StepR>
            ```bash name=Terminal&action=run
            dev
            ```
        </StepR>
    </Step>
    <Step>
        ### <StepNum />Start using Master CSS
        Now style your first element using Master CSS syntax.
    </Step>
    <HelloWorld url="localhost:5173" />
