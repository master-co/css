<StepSection>
    <Step $row>
        <StepL>
            ### <StepNum />Create a Vite project
            If you don't have a Vite project, create one first. Vite treats the project root `index.html` as the entry point and the default templates usually load source files from `src/`.
        </StepL>
        <StepR>
            ```bash name=Terminal
            npm create vite@latest my-app
            cd my-app
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Install Master CSS
            Install [`@master/css.vite`](/reference/vite) plugin into your project.
        </StepL>
        <StepR>
            ```bash action=install
            @master/css.vite@rc
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Create a configuration file
            Run the command to create a [master.css](/guide/configuration) file.
        </StepL>
        <StepR>
            ```bash action=create
            @master/css@rc
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Set up Master CSS
            Add a `masterCSS` vite plugin in `vite.config.js`.

            This example uses static extraction. Use `masterCSS()` without options when you want runtime rendering instead.
        </StepL>
        <StepR>
            ```js name=vite.config.js
            import { defineConfig } from 'vite'
            import masterCSS from '@master/css.vite' // [!code highlight]

            export default defineConfig({
                plugins: [
                    masterCSS({ // [!code highlight]
                        mode: 'extract' // [!code highlight]
                    }) // [!code highlight]
                ]
            })
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Import extracted CSS
            In extract mode, import the virtual CSS module from the stylesheet your Vite entry already loads, such as `src/style.css`.

            (i) You can also import `virtual:master.css` from `src/main.js`. Use one import location for the generated stylesheet.
        </StepL>
        <StepR>
            ```css name=src/style.css
            @import 'virtual:master.css';
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Define local CSS
            Source stylesheets can contain ordinary CSS and `@master` definitions together. In extract mode, ordinary class selectors are kept only when the class appears in scanned source.

            (i) Import the stylesheet from `master.css` when you want its `@master {}` blocks to participate in the config graph.
        </StepL>
        <StepR>
            ```css name=src/style.css
            @import 'virtual:master.css';

            .native-card {
                border: 1px solid rgb(0 0 0 / 12%);
            }

            @master {
                .btn {
                    @compose "inline-flex ai:center px:md h:40 r:md bg:primary fg:white";
                }
            }
            ```

            ```css name=master.css
            @import './src/style.css';
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Add client types
            If TypeScript source files import the Master CSS config object, add the Vite client types and Master CSS Vite client types to your environment file.
        </StepL>
        <StepR>
            ```ts name=src/vite-env.d.ts
            /// <reference types="vite/client" />
            /// <reference types="@master/css.vite/client" />
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Start dev server
            Run the command to start the Vite dev server.
        </StepL>
        <StepR>
            ```bash name=Terminal&action=run
            dev
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Start using Master CSS
            Now style your first element using Master CSS syntax!
        </StepL>
        <StepR>
            ```html name=index.html
            <h1 class="btn native-card m:2xl">Hello World</h1>
            ```
        </StepR>
    </Step>
    <HelloWorld url="localhost:5173" />
</StepSection>
