<StepSection>
    <Step $row>
        <StepL>
            ### <StepNum />Create a project
            If you don't have a Webpack project, create one first. This guide uses a small app with `src/index.js`, `src/style.css`, and `src/index.html`.
        </StepL>
        <StepR>
            ```bash name=Terminal
            mkdir my-app
            cd my-app
            npm init -y
            npm install webpack webpack-cli webpack-dev-server html-webpack-plugin css-loader style-loader --save-dev
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Create a configuration file
            Run the command to create a [project CSS entry](/guide/configuration).
        </StepL>
        <StepR>
            ```bash action=create
            @master/css@rc
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Install Master CSS Extractor
            Install the Master CSS extractor into your project via package managers.
        </StepL>
        <StepR>
            ```bash action=install
            @master/css.webpack@rc
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Add client types
            If your source files are type-checked, add the Webpack client types before importing Master CSS config modules.
        </StepL>
        <StepR>
            ```ts name=src/master-css-env.d.ts
            /// <reference types="@master/css.webpack/client" />
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Create a Webpack config file
            Create and configure the `webpack.config.mjs` file. The extractor scans `src/index.html` and your JavaScript modules, then writes generated CSS into the stylesheet that imports `@master/css`.
        </StepL>
        <StepR>
            ```js name=webpack.config.mjs
            import path from 'node:path'
            import HtmlWebpackPlugin from 'html-webpack-plugin'
            import MasterCSSPlugin from '@master/css.webpack'

            export default {
                entry: './src/index.js',
                output: {
                    filename: 'bundle.js',
                    path: path.resolve('dist')
                },
                plugins: [
                    new HtmlWebpackPlugin({
                        template: path.resolve('src/index.html')
                    }),
                    new MasterCSSPlugin({ sources: ['./src/index.html'] })
                ],
                devServer: {
                    static: './dist',
                    port: 8080,
                    watchFiles: ['src/**/*']
                },
                module: {
                    rules: [
                        { test: /\.css$/, use: ['style-loader', 'css-loader'] }
                    ]
                }
            }
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Configure a HTML file
            Create and configure the `src/index.html` template file.
        </StepL>
        <StepR>
            ```html name=src/index.html
            <!doctype html>
            <html lang="en">
            <head>
                <meta charset="utf-8" />
                <title>Master CSS Webpack</title>
            </head>
            <body>
                <h1 class="hero-title native-card">Hello World</h1>
            </body>
            </html>
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Import the app stylesheet
            Import your stylesheet from the JavaScript entry.
        </StepL>
        <StepR>
            ```js name=src/index.js
            import './style.css'
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Import stylesheets
            Import Master CSS from `src/style.css`. This import inserts the generated stylesheet and enables native CSS shaking for this stylesheet root.
        </StepL>
        <StepR>
            ```css name=src/style.css
            @import '@master/css';
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Author app CSS and config
            Source stylesheets can contain ordinary CSS and `@master` definitions together. Ordinary class selectors are kept only when they appear in scanned source. Add `@master no-shake;` only when native CSS must be preserved as written.

            (i) A stylesheet that imports `@master/css` is also a project CSS entry, so its `@master {}` blocks participate in the config graph.
        </StepL>
        <StepR>
            ```css name=src/style.css
            @import '@master/css';

            .native-card {
                border: 1px solid rgb(0 0 0 / 12%);
            }

            @master {
                .hero-title {
                    @compose "m:0 font:5xl font:heavy fg:strong";
                }
            }
            ```

            ```css name=index.css
            @master;
            @import './src/style.css';
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Add scripts to `package.json`
            Add `start` and `build` scripts to standardize the development process.
        </StepL>
        <StepR>
            ```js name=package.json
            {
                "scripts": {
                    "dev": "webpack serve --mode development",
                    "build": "webpack --mode production"
                }
            }
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Launch server
            Run the development server.
        </StepL>
        <StepR>
            ```bash name=Terminal
            npm run dev
            ```
        </StepR>
    </Step>
    <Step>
        ### <StepNum />Hello world!
        Now style your first element using Master CSS syntax!
        ```html name=src/index.html
        <!doctype html>
        <html lang="en">
        <head>
            <meta charset="utf-8" />
            <title>Master CSS Webpack</title>
        </head>
        <body>
            <h1 class="hero-title native-card">Hello World</h1>
        </body>
        </html>
        ```
        Open your browser to watch the changes.
        <HelloWorld url="localhost:8080" />
