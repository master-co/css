<StepSection>
    <Step $row>
        <StepL>
            ### <StepNum />Create a project
            If you don't have a Webpack project, create one first.
        </StepL>
        <StepR>
            ```bash name=Terminal
            mkdir my-app
            cd my-app
            npm init -y
            npm install -D webpack webpack-cli webpack-dev-server
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Add Master CSS
            Run the installer from the Webpack project root. It adds the packages and creates the Master CSS entry stylesheet.
        </StepL>
        <StepR>
            ```bash name=Terminal
            npm create @master/css@rc -- --framework webpack --yes
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Configure Webpack
            Register the Webpack plugin in static mode. Static mode scans complete class strings and emits generated CSS at build time.
        </StepL>
        <StepR>
            ```js name=webpack.config.mjs
            import MasterCSSPlugin from '@master/css.webpack'

            export default {
                plugins: [
                    new MasterCSSPlugin({ mode: 'static' })
                ]
            }
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Launch server
            Run your Webpack development command.
        </StepL>
        <StepR>
            ```bash name=Terminal
            npm run dev
            ```
        </StepR>
    </Step>
    <Step>
        ### <StepNum />Hello world
        Now style your first element using Master CSS syntax.
    </Step>
    <HelloWorld />
</StepSection>

```css name=src/index.css
@import '@master/css';
```

```html
<h1 class="m:2xl italic font:5xl font:heavy text:neutral">
    Hello World
</h1>
```
