    </StepL>
    <StepR>
      ```bash name=Terminal
      npm create vite@latest my-app -- --template react-ts
      cd my-app
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### <StepNum />Add Master CSS
      Run the installer with `--mode runtime` from the project root. The browser runtime generates rules for class names that appear after the build.
    </StepL>
    <StepR>
      ```bash name=Terminal
      npm create @master/css@rc -- --framework react --mode runtime --yes
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### <StepNum />Start dev server
      Run the command to start the Vite dev server.
    </StepL>
    <StepR>
      ```bash name=Terminal&action=run
      dev
      ```
    </StepR>
  </Step>
  <Step>
    ### <StepNum />Start using Master CSS
    Now style your first component using Master CSS syntax.
  </Step>
