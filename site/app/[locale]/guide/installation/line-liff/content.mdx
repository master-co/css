Use Vite static rendering for LINE LIFF apps so the stylesheet is generated before the app opens inside LINE's WebView. This reduces runtime startup work and avoids waiting for browser-side class generation.

<StepSection>
    <Step $row>
        <StepL>
            ### <StepNum />Create or open a LIFF app
            Start from a LIFF project that uses Vite, or create a Vite project for the LIFF frontend.
        </StepL>
        <StepR>
            ```bash name=Terminal
            npm create vite@latest my-liff-app
            cd my-liff-app
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Install Master CSS
            Install the Master CSS Vite integration.
        </StepL>
        <StepR>
            ```bash name=Terminal
            npm install -D @master/css.vite@rc
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Configure Vite
            Enable static rendering for the LIFF asset build.
        </StepL>
        <StepR>
            ```ts name=vite.config.ts
            import { defineConfig } from 'vite'
            import masterCSS from '@master/css.vite'

            export default defineConfig({
                plugins: [
                    masterCSS({ mode: 'static' })
                ]
            })
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Create the CSS entry
            Import Master CSS from the stylesheet loaded by your Vite app.
        </StepL>
        <StepR>
            ```css name=src/app.css
            @import "@master/css";
            ```

            ```ts name=src/main.ts
            import './app.css'
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Build for LIFF hosting
            Build the Vite app before deploying it to your LIFF endpoint.
        </StepL>
        <StepR>
            ```bash name=Terminal
            npm run build
            ```
        </StepR>
    </Step>
    <Step>
        ### <StepNum />Hello world
        Now style your first LIFF view using Master CSS syntax.
    </Step>
    <HelloWorld url="localhost:5173" />
</StepSection>

```html name=index.html
<h1 class="m:2xl italic font:5xl font:heavy text:neutral">
    Hello World
</h1>
```

Use the [Runtime CDN](/guide/installation/cdn) only for prototypes that can use the default preset and tolerate browser-side generation. For production LIFF pages, prefer static rendering in the Vite build.
