        <StepL>
            ### <StepNum />Set up project linting
            Add Master CSS linting to the project's ESLint flat config first. Use the setup step in the matching framework installation guide, or add the recommended config directly when the project already has parser support.
        </StepL>
        <StepR>
            ```js name=eslint.config.js
            import css from '@master/eslint-config-css'

            export default [
                css
            ]
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Enable sort on save
            Add `@master/css/sort-classes` to `eslint.codeActionsOnSave.rules` so Visual Studio Code applies the class sorting fix when the ESLint extension runs on save.
        </StepL>
        <StepR>
            ```json name=.vscode/settings.json
            {
                "eslint.codeActionsOnSave.rules": [
                    "@master/css/sort-classes"
                ]
            }
            ```
        </StepR>
        <StepEnd />
    </Step>
</StepSection>
