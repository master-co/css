Use Vite to build the browser runtime entry for a Blazor app. Vite owns the frontend assets, while Blazor and .NET still own the app host page, project files, and server/runtime lifecycle.

<StepSection>
  <Step $row>
    <StepL>
      ### <StepNum />Create a Blazor project
      If you don't have a Blazor project, create one first.
    </StepL>
    <StepR>
      ```bash name=Terminal
      dotnet new blazor -o my-app
      cd my-app
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### <StepNum />Install Vite and Master CSS
      Install Vite and the Master CSS Vite integration in the Blazor project root.
    </StepL>
    <StepR>
      ```bash name=Terminal
      npm init -y
      npm install @master/css@rc @master/css-runtime@rc
      npm install -D vite @master/css-vite@rc
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### <StepNum />Configure Vite
      Build the runtime entry and base stylesheet into `wwwroot/assets` so the Blazor host page can load them as static assets.
    </StepL>
    <StepR>
      ```ts name=vite.config.ts
      import { defineConfig } from 'vite'
      import { createMasterCSSVitePlugin } from '@master/css-vite'

      export default defineConfig({
        plugins: [
          createMasterCSSVitePlugin({ mode: 'runtime', runtime: false })
        ],
        build: {
          outDir: 'wwwroot/assets',
          emptyOutDir: true,
          rollupOptions: {
            input: 'src/main.ts',
            output: {
              entryFileNames: 'app.js',
              assetFileNames: 'app[extname]'
            }
          }
        }
      })
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### <StepNum />Create the asset entry
      Import the Vite-managed runtime and the Master CSS stylesheet from the browser entry.
    </StepL>
    <StepR>
      ```ts name=src/main.ts
      import { MasterCSSRuntime } from '@master/css-runtime'
      import manifest from 'virtual:master-css-manifest'
      import emittedGlobals from 'virtual:master-css-emitted-globals'
      import './app.css'

      const runtime = await MasterCSSRuntime.start({ manifest, emittedGlobals })
      runtime.observe()
      ```

      ```css name=src/app.css
      @import "@master/css";
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### <StepNum />Add build scripts
      Run Vite before serving the app, or keep it watching while the .NET dev server runs.
    </StepL>
    <StepR>
      ```json name=package.json
      {
        "scripts": {
          "build:assets": "vite build",
          "watch:assets": "vite build --watch"
        },
        "devDependencies": {
          "@master/css-vite": "rc",
          "vite": "latest"
        }
      }
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### <StepNum />Load the built assets
      Reference the Vite output from the Blazor host page your project uses, such as `Components/App.razor`, `wwwroot/index.html`, or `Pages/_Host.cshtml`. Add `hidden` to the root document so the runtime can avoid a flash of unstyled content before it injects class rules.
    </StepL>
    <StepR>
      ```html name=Components/App.razor
      <html lang="en" hidden>
      <head>
        <link rel="stylesheet" href="/assets/app.css">
      </head>
      <body>
        <Routes />
        <script type="module" src="/assets/app.js"></script>
      </body>
      </html>
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### <StepNum />Launch the app
      Build or watch the frontend assets, then run the Blazor app.
    </StepL>
    <StepR>
      ```bash name=Terminal
      npm run build:assets
      dotnet run
      ```
    </StepR>
  </Step>
  <Step>
    ### <StepNum />Start using Master CSS
    Now style your first Razor component using Master CSS syntax.
  </Step>
  <HelloWorld url="localhost:5000" />
</StepSection>

```html name=Components/Pages/Home.razor
<h1 class="m:2xl italic font:5xl font:heavy text:neutral">
  Hello World
</h1>
```

Runtime rendering generates CSS in the browser as Blazor renders and updates elements. Use [Blazor static rendering](/guide/installation/blazor/static-rendering) when classes are statically visible and you need build-time CSS output.
