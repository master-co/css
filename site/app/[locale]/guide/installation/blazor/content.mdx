## Blazor setup
Blazor is not automated by `@master/create-css` yet because a complete setup spans .NET project files, static asset bundling, and runtime script loading outside a normal JavaScript app root.

For Blazor projects, use one of the lower-level integration paths:

- Use [runtime rendering](/guide/rendering-modes#runtime-rendering) when classes should be generated in the browser.
- Use the [CLI guide](/guide/installation/cli) when you want to scan source files and generate a CSS file from a Node toolchain.
- Use the [Webpack guide](/guide/installation/webpack) if your Blazor app already owns a Webpack asset pipeline.

Keep the setup in the JavaScript asset workspace that owns package installation and build scripts.
