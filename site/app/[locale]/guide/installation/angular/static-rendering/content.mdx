Generate ordinary CSS with the CLI before Angular builds the application. This
works with Angular’s existing builder and does not require a browser runtime.

## Install

```bash
npm create @master/css@rc -- --framework angular --mode static --yes
```

The installer creates a separate source entry and imports the generated output:

```css name=master.css
@import '@master/css';
```

```css name=src/styles.css
@import './master.generated.css';
```

Keep `src/styles.css` in the application’s existing global styles configuration.
The generated file is output, so do not edit it or import it from `master.css`.

## Generate and build

Run from the project root before each production build:

```bash
npx master-css generate --output src/master.generated.css
npm run build
```

During development, keep the CLI watcher in a separate terminal:

```bash
npx master-css generate --output src/master.generated.css --watch
```

Then run `npm start`. Keep complete class names in Angular templates or an explicit
safelist. Bind CSS custom properties for dynamic values; static mode does not
compile newly assembled class names in the browser.

```html name=src/app/app.component.html
<div class="width:var(--progress)" [style.--progress]="progress + '%'">Progress</div>
```

For browser generation, select `--mode runtime` explicitly and follow the
[runtime guide](/guide/installation/angular/runtime-rendering).
