Use the CLI when Express renders EJS, Handlebars, or Pug templates on the server. Master CSS scans template files, then Express serves the generated stylesheet as a static asset.

<StepSection>
    <Step $row>
        <StepL>
            ### <StepNum />Open your project
            Start from an Express project root.
        </StepL>
        <StepR>
            ```bash name=Terminal
            cd my-express-app
            npm init -y
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Install Master CSS
            Install the CLI as a development dependency.
        </StepL>
        <StepR>
            ```bash name=Terminal
            npm install -D @master/css-cli@rc
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Create your CSS entry
            Include the server templates where classes are written.
        </StepL>
        <StepR>
            ```css name=src/master.css
            @import "@master/css";

            @source "../views/**/*.{ejs,hbs,pug}";
            @source "../public/**/*.html";
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Build the stylesheet
            Scan the server templates and write CSS into the public directory.
        </StepL>
        <StepR>
            ```bash name=Terminal
            npx @master/css-cli "views/**/*.{ejs,hbs,pug}" "public/**/*.html" --output public/master.css --watch
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Serve the asset
            Serve `public` from Express and link the generated stylesheet from your layout.
        </StepL>
        <StepR>
            ```js name=app.js
            app.use(express.static('public'))
            ```

            ```html name=views/layout.ejs
            <link rel="stylesheet" href="/master.css">
            ```
        </StepR>
    </Step>
    <Step>
        ### <StepNum />Hello world
        Now style your first server-rendered template using Master CSS syntax.
    </Step>
    <HelloWorld url="localhost:3000" />
</StepSection>

```html name=views/index.ejs
<h1 class="m:2xl italic font:5xl font:heavy text:neutral">
    Hello World
</h1>
```

If the Express app already serves Vite-built assets, install `vite @master/css.vite@rc`, use `masterCSS({ mode: 'static' })`, and keep `@source "./views/**/*.{ejs,hbs,pug}"` in the CSS entry.
