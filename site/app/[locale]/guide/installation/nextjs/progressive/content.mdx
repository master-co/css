Progressive rendering adds pre-rendered CSS and a hydration manifest to static or pre-rendered Next.js pages. The runtime then adopts those rules and can generate CSS for class names added later in the browser. Request-time dynamic SSR responses are outside the build adapter's pre-rendered output.

```tsx name=app/page.tsx
export default function Home() {
  return (
    <h1 className="m-2xl italic font-5xl font-heavy text-neutral">
      Hello World
    </h1>
  )
}
```

(!) Turbopack cannot currently compile Master CSS directives inside CSS Modules. Use a page-imported ordinary CSS file with `@reference` for local project-token styles, and scope its classes to the page. Native CSS Modules without Master directives still work; the Next.js Webpack path can compile directive-bearing CSS Modules.
