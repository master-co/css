<StepSection>
    <Step $row>
        <StepL>
            ### <StepNum />Create a Next.js project
            If you don't have a Next.js project, create one first. It's recommended to refer to [Create Next App](https://nextjs.org/docs/app/api-reference/cli/create-next-app).
        </StepL>
        <StepR>
            ```bash name=Terminal
            npx create-next-app@latest my-app --ts --app --no-tailwind
            cd my-app
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Create a configuration file
            Run the command to create a [master.css](/guide/configuration) file.
        </StepL>
        <StepR>
            ```bash action=create
            @master/css@rc
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Install Master CSS
            Install the Master CSS Next.js integration into your project via package managers.
        </StepL>
        <StepR>
            ```bash action=install
            @master/css.next@rc
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Set up extract mode
            Register the Master CSS Next.js integration in `extract` mode. This creates the generated stylesheet and wires `virtual:master.css` into Turbopack CSS processing.

            (i) Extract mode scans source files as the correctness baseline. During Turbopack builds, a scanner loader also feeds visited JavaScript and TypeScript modules into the extractor for incremental updates.
        </StepL>
        <StepR>
            ```js name=next.config.mjs
            import { withMasterCSS } from '@master/css.next' // [!code ++]

            /** @type {import('next').NextConfig} */
            const nextConfig = await withMasterCSS({ // [!code ++]
                /* your Next.js config */ // [!code ++]
            }, { // [!code ++]
                mode: 'extract' // [!code ++]
            }) // [!code ++]

            export default nextConfig
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Import virtual CSS module
            Import the generated CSS module from `app/globals.css`.

            (i) Use `virtual:master.css` for the generated stylesheet. Ordinary class selectors in this stylesheet are pruned against detected source classes.
        </StepL>
        <StepR>
            ```css name=app/globals.css
            @import 'virtual:master.css';

            .main {
                background-color: var(--color-primary);
            }

            @master {
                --color-primary: #ff0000;

                .hero-title {
                    @compose "m:0 font:5xl font:heavy fg:strong";
                }
            }
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Author CSS config
            Use `master.css` as the workspace entry for the CSS config graph.

            (i) `@master {}` blocks can live in imported CSS files such as `app/globals.css`. The config compiler reads those blocks and ignores ordinary CSS outside `@master`.
        </StepL>
        <StepR>
            ```css name=master.css
            @import './app/globals.css';
            ```
        </StepR>
    </Step>
    <Step $row>
        <StepL>
            ### <StepNum />Launch server
            Run `npm run dev` to start your Next.js development server
        </StepL>
        <StepR>
            ```bash name=Terminal
            npm run dev
            ```
        </StepR>
    </Step>
    <Step>
        ### <StepNum />Start using Master CSS
        Now style your first element using Master CSS syntax!
        ```tsx name=app/page.tsx
        export default function Home() {
            return (
                <h1 className="hero-title main m:2xl">Hello World</h1>
            )
        }
        ```
        Open your browser to watch the changes.
        <HelloWorld url="localhost:3000" />
    </Step>
</StepSection>
