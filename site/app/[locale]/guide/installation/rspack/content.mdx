The installer registers the Webpack-compatible plugin in `rspack.config.*` and creates `src/index.css` as the Master CSS entry.

```js name=rspack.config.mjs
import MasterCSSPlugin from '@master/css.webpack'

export default {
    module: {
        rules: [
            {
                test: /\.css$/i,
                type: 'css/auto'
            }
        ]
    },
    plugins: [
        new MasterCSSPlugin()
    ]
}
```

```css name=src/index.css
@import '@master/css';
```

```html
<h1 class="italic m:2xl text:neutral font:5xl font:heavy">
    Hello World
</h1>
```
