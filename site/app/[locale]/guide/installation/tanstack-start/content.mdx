TanStack Start supports Vite and Rsbuild. This guide uses the Vite setup path.

<StepSection>
  <Step $row>
    <StepL>
      ### <StepNum />Create a project
      If you don't have a TanStack Start project, create one first.
    </StepL>
    <StepR>
      ```bash name=Terminal
      npx @tanstack/cli@latest create
      cd my-app
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### <StepNum />Add Master CSS
      Run the installer from the TanStack Start project root. The default TanStack Start setup uses runtime rendering.
    </StepL>
    <StepR>
      ```bash name=Terminal
      npm create @master/css@rc -- --framework tanstack-start --yes
      ```
    </StepR>
  </Step>
  <Step $row>
    <StepL>
      ### <StepNum />Start dev server
      Run the command to start the TanStack Start dev server.
    </StepL>
    <StepR>
      ```bash name=Terminal&action=run
      dev
      ```
    </StepR>
  </Step>
  <Step>
    ### <StepNum />Start using Master CSS
    Now style your first route using Master CSS syntax.
  </Step>
  <HelloWorld url="localhost:3000" />
</StepSection>

The installer registers `@master/css-vite` in runtime mode, creates `src/styles/app.css`, and imports it from `src/routes/__root.tsx`.

```tsx name=src/routes/index.tsx
import { createFileRoute } from '@tanstack/react-router'

export const Route = createFileRoute('/')({
  component: Home
})

function Home() {
  return (
    <h1 className="m:2xl italic font:5xl font:heavy text:neutral">
      Hello World
    </h1>
  )
}
```
