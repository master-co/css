## Using colors [sr-only]
Master CSS provides a P3-compatible raw palette, mode-aware base hue aliases, and a small set of text and line roles. Use palette tokens such as `bg:blue-60` for direct swatches, hue aliases such as `bg:blue` for common color choices, and retained roles such as `fg:text` or `b:1px|solid|subtle` for basic foreground and separator color.

Product roles such as `surface`, `accent`, `success`, `warning`, and `danger`, plus expanded hue roles such as `blue-hover`, `blue-surface`, or `on-blue`, belong in your project theme or in a UI layer such as Master UI. Define them with `@theme` when the name represents a product decision.

### Default color palette [sr-only]
<ColorPalette />
Each preset color family ranges from `0`, `5`, `10`, and then by tens through `100`. Choose a palette step directly for swatches, illustrations, and intentional brand or status accents.

```html
<!-- @MARK bg:blue-5 --><!-- @MARK fg:blue-60 -->
<div class="bg:blue-5 fg:blue-60">…</div>
```

### Adapting default colors
You can adapt the default color palette to your brand color by defining color variables in the project CSS entry.
```css name=index.css
@theme {
    --color-brand: #4f46e5; /* [!code highlight] */
    --color-brand-10: #eef2ff; /* [!code highlight] */
    --color-brand-60: #4f46e5; /* [!code highlight] */
}
```
Apply them using the color-related syntax:
```html
<!-- @MARK bg:brand-10 --><!-- @MARK fg:brand-60 -->
<div class="bg:brand-10 fg:brand-60">…</div>
```
See [theme color tokens](/guide/theme#theme-tokens) for more details on how to add custom colors.

### With variable modes
Use [variable modes](/guide/theme#modes) to define color roles for light and dark modes. Keep mode-specific color decisions in theme variables when the same role repeats across the product.

(x) Markup owns the light and dark color choice.

```html
<div class="fg:white@dark fg:black@light">...</div>
```

(o) The theme owns the mode-specific role.

```html
<div class="fg:text">...</div>
```

Use conditional color classes when a one-off interaction genuinely differs by mode. For shared text, surface, line, brand, and status color, prefer a named token that can resolve differently per mode.

## Product color roles
Surface, accent, and status roles are product tokens. Define them in your project CSS entry, or consume them from a UI package that owns those decisions.

```css name=index.css
@theme light {
    --color-canvas: $color-white;
    --color-surface: $color-white;
    --color-surface-muted: $color-neutral-5;
    --color-accent: $color-blue-60;
    --color-on-accent: $color-white;
    --color-danger: $color-red-60;
    --color-on-danger: $color-white;
}

@theme dark {
    --color-canvas: $color-gray-95;
    --color-surface: $color-gray-90;
    --color-surface-muted: $color-gray-95;
    --color-accent: $color-blue-40;
    --color-on-accent: $color-blue-95;
    --color-danger: $color-red-40;
    --color-on-danger: $color-red-95;
}
```

| Role | Example | Use |
|------|---------|-----|
| `canvas` | <Bg className="bg:canvas" /> | Page and application background |
| `surface` | <Bg className="bg:surface" /> | Cards, panels, controls, and plain containers |
| `surface-muted` | <Bg className="bg:surface-muted" /> | Recessed or secondary surfaces |
| `accent` | <Bg className="bg:accent" /> | Primary product action or brand emphasis |
| `danger` | <Bg className="bg:danger" /> | Destructive actions and errors |

Semantic roles are useful for product UI when the color represents a role instead of a specific hue. They are not part of the cleaned default preset.

## Text colors
<ExpandContent>
| Token                                             | Descriptions                                                              |
|---------------------------------------------------|---------------------------------------------------------------------------|
| <Aa className="fg:strong" />`strong` | Titles, headings, and emphasized fields |
| <Aa className="fg:text" />`text` | Body text and default content |
| <Aa className="fg:muted" />`muted` | Secondary labels, descriptions, and icons |
| <Aa className="fg:subtle" />`subtle` | Tertiary text and low-emphasis metadata |
| <Aa className="fg:disabled" />`disabled` | Disabled text and unavailable controls |
| <Aa className="fg:placeholder" />`placeholder` | Input placeholders |
| <Aa className="fg:inverse" />`inverse` | Text on inverse surfaces |
| <Aa className="fg:link" />`link` | Links |
</ExpandContent>

By default, theme modes [drive](/guide/theme#modes) text variables for light and dark foreground contrast.
