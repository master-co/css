## Using colors [sr-only]
Master CSS provides a P3-compatible raw palette, mode-aware base hue aliases, text hue aliases, and a small set of text and line roles. Use palette tokens such as `bg:blue-60` for direct swatches, hue aliases such as `bg:blue` for common color choices, `text:blue` for readable hue text, and roles such as `text:text` or `b:1px|solid|subtle` for basic foreground and separator color.

### Default color palette [sr-only]
<ColorPalette />
Each preset color family ranges from `0`, `5`, `10`, and then by tens through `100`. Choose a palette step directly for swatches, illustrations, and intentional brand or status accents.

```html
<!-- @MARK bg:blue-5 --><!-- @MARK text:blue-60 -->
<div class="bg:blue-5 text:blue-60">…</div>
```

### Adapting default colors
You can adapt the default color palette to your brand color by defining color variables in the project CSS entry.
```css name=index.css
@theme {
    --color-brand: #4f46e5; /* [!code highlight] */
    --color-brand-10: #eef2ff; /* [!code highlight] */
    --color-brand-60: #4f46e5; /* [!code highlight] */
}
```
Apply them using the color-related syntax:
```html
<!-- @MARK bg:brand-10 --><!-- @MARK text:brand-60 -->
<div class="bg:brand-10 text:brand-60">…</div>
```
See [theme color tokens](/guide/theme#theme-tokens) for more details on how to add custom colors.

### With variable modes
Use [variable modes](/guide/theme#modes) to define color roles for light and dark modes. Keep mode-specific color decisions in theme variables when the same role repeats across the product.

(x) Markup owns the light and dark color choice.

```html
<div class="text:white@dark text:black@light">...</div>
```

(o) The theme owns the mode-specific role.

```html
<div class="text:text">...</div>
```

Use conditional color classes when a one-off interaction genuinely differs by mode. For shared foreground or separator color, prefer a named token that can resolve differently per mode.

## Text colors
<ExpandContent>
| Token                                             | Descriptions                                                              |
|---------------------------------------------------|---------------------------------------------------------------------------|
| <Aa className="text:strong" />`strong` | Titles, headings, and emphasized fields |
| <Aa className="text:text" />`text` | Body text and default content |
| <Aa className="text:muted" />`muted` | Secondary labels, descriptions, and icons |
| <Aa className="text:subtle" />`subtle` | Tertiary text and low-emphasis metadata |
| <Aa className="text:disabled" />`disabled` | Disabled text and unavailable controls |
| <Aa className="text:placeholder" />`placeholder` | Input placeholders |
| <Aa className="text:inverse" />`inverse` | Text on inverse surfaces |
| <Aa className="text:link" />`link` | Links |
</ExpandContent>

By default, theme modes [drive](/guide/theme#modes) text variables for light and dark foreground contrast.
<Demo $py={0} $px={0}>
    <DemoLight>
        <div className="text:yellow font:heavy font:9xl">M</div>
    </DemoLight>
    <DemoDark>
        <div className="text:yellow font:heavy font:9xl">M</div>
    </DemoDark>
</Demo>
```html
<div class="light">
    <!-- @MARK text:yellow -->
    <span class="text:yellow">M</span>
</div>
<div class="dark">
    <!-- @MARK text:yellow -->
    <span class="text:yellow">M</span>
</div>
```

See the [color](/reference/color#use-custom-text-colors) reference for more details on how to add custom text colors.

## Line colors
| Token                                                   | Descriptions                                                              |
|---------------------------------------------------------|---------------------------------------------------------------------------|
| <Bg className="outline:line" />`line` | Default borders and separators |
| <Bg className="outline:strong" />`strong` | High-contrast borders |
| <Bg className="outline:muted" />`muted` | Quiet borders inside dense UI |
| <Bg className="outline:subtle" />`subtle` | Dividers, layout chrome, and soft outlines |

By default, theme modes [drive](/guide/theme#modes) line variables for light and dark separators.
