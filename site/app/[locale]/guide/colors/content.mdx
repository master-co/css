## Using colors [sr-only]
Master CSS provides a P3-compatible raw palette, mode-aware base hue aliases, text hue aliases, and the `inverse` text role. Use palette tokens such as `bg:blue-60` for direct swatches, hue aliases such as `bg:blue` for common color choices, and text aliases such as `text:blue` or `text:neutral` for readable foreground color. Define project role tokens when foreground or separator color needs a semantic name.

### Default color palette [sr-only]
<ColorPalette />
Each preset color family ranges from `0`, `5`, `10`, and then by tens through `100`. Choose a palette step directly for swatches, illustrations, and intentional brand or status accents.

```html
<!-- @MARK bg:blue-5 --><!-- @MARK fg:blue-60 -->
<div class="bg:blue-5 fg:blue-60">…</div>
```

### Adapting default colors
You can adapt the default color palette to your brand color by defining color variables in the project CSS entry.
```css name=index.css
@theme {
    --color-brand: #4f46e5; /* [!code highlight] */
    --color-brand-10: #eef2ff; /* [!code highlight] */
    --color-brand-60: #4f46e5; /* [!code highlight] */
}
```
Apply them using the color-related syntax:
```html
<!-- @MARK bg:brand-10 --><!-- @MARK fg:brand-60 -->
<div class="bg:brand-10 fg:brand-60">…</div>
```
See [theme color tokens](/guide/theme#theme-tokens) for more details on how to add custom colors.

### With variable modes
Use [variable modes](/guide/theme#modes) to define color roles for light and dark modes. Keep mode-specific color decisions in theme variables when the same role repeats across the product.

(x) Markup owns the light and dark color choice.

```html
<div class="fg:white@dark fg:black@light">...</div>
```

(o) The theme owns the mode-specific role.

```css name=index.css
@theme light {
    --color-text-body: $color-neutral-70;
    --color-line-divider: oklch(0% 0 none / 0.12);
}

@theme dark {
    --color-text-body: $color-gray-30;
    --color-line-divider: oklch(100% 0 none / 0.12);
}
```

```html
<div class="text:body b:1px|solid|divider">...</div>
```

Use conditional color classes when a one-off interaction genuinely differs by mode. For shared foreground or separator color, prefer a named token that can resolve differently per mode.

## Border and line colors
Preset border and outline colors resolve palette and color tokens by default. Define project `color-line-*` tokens when separators need semantic, mode-aware names.

```css name=index.css
@theme light {
    --color-line-divider: oklch(0% 0 none / 0.12);
}

@theme dark {
    --color-line-divider: oklch(100% 0 none / 0.12);
}
```

```html
<div class="b:1px|solid|divider">...</div>
```

Palette border colors are available without adding custom line tokens.

<Demo $py={0} $px={0}>

    <div class="b:3x|solid|gray-20 size:24x"></div>

See the [border color](/reference/border-color#use-custom-border-colors) reference for more details on how to add custom border colors.
