## Default color palette [sr-only]

Master CSS provides a P3-compatible raw palette, preset light and dark color aliases, canvas and surface roles, line roles, text roles, and text hue aliases.

<ColorPalette />

Each preset color family ranges from `0`, `5`, `10`, and then by tens through `100`. Choose a palette step directly for swatches, illustrations, and intentional brand or status accents.

```html
<!-- @MARK bg:blue-5 --><!-- @MARK fg:blue-60 -->
<div class="bg:blue-5 fg:blue-60">…</div>
```

## Preset mode-aware colors
The default preset ships mode-aware aliases for foundational UI color decisions. Palette steps such as `blue-60` stay fixed, while aliases such as `blue`, `text:body`, `text:blue`, `canvas`, `line`, and `surface:base` resolve to different preset references in light and dark modes.

```html
<!-- @MARK bg:canvas --><!-- @MARK text:body --><!-- @MARK surface:base --><!-- @MARK b:1px|solid|line --><!-- @MARK text:strong --><!-- @MARK text:muted --><!-- @MARK text:link -->
<main class="bg:canvas text:body">
    <section class="surface:base b:1px|solid|line">
        <h2 class="text:strong">Project updates</h2>
        <p class="text:muted">Three milestones changed this week.</p>
        <a class="text:link" href="#">Continue</a>
    </section>
</main>
```

### Line roles
Line tokens are for borders, dividers, outlines, and strokes. Border and outline utilities search the `color-line` namespace before the general `color` namespace.

## With variable modes
Use [variable modes](/guide/theme#modes) to adjust preset color roles for light and dark modes. Keep mode-specific decisions in theme variables when the same role repeats across the product.

(x) Markup owns the light and dark color choice.

```html
<div class="fg:white@dark fg:black@light">...</div>
```

(o) The theme owns the mode-specific role.

```css name=index.css
@theme light {
    --color-canvas: $color-white;
}

@theme dark {
    --color-canvas: $color-gray-100;
}
```

```html
<main class="bg:canvas">...</main>
```

Use conditional color classes when a one-off interaction genuinely differs by mode. For shared product color decisions, prefer a named token that can resolve differently per mode.
