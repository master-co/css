## Using colors [sr-only]
Master CSS provides a P3-compatible color palette, semantic product roles, and mode-aware variables. Use role tokens such as `bg:canvas`, `bg:surface`, `fg:strong`, `fg:muted`, and `b:subtle` for product surfaces; use palette steps when a design intentionally needs a swatch, illustration, or one-off brand color.

### Default color palette [sr-only]
<ColorPalette />
Each preset color family ranges from `0`, `5`, `10`, and then by tens through `100`. Choose a palette step directly for swatches, illustrations, and intentional brand or status accents.

```html
<!-- @MARK bg:blue-5 --><!-- @MARK fg:blue-60 -->
<div class="bg:blue-5 fg:blue-60">…</div>
```

### Adapting default colors
You can adapt the default color palette to your brand color by defining color variables in the project CSS entry.
```css name=index.css
@theme {
    --color-brand: #4f46e5; /* [!code highlight] */
    --color-brand-10: #eef2ff; /* [!code highlight] */
    --color-brand-60: #4f46e5; /* [!code highlight] */
}
```
Apply them using the color-related syntax:
```html
<!-- @MARK bg:brand-10 --><!-- @MARK fg:brand-60 -->
<div class="bg:brand-10 fg:brand-60">…</div>
```
See [theme color tokens](/guide/theme#theme-tokens) for more details on how to add custom colors.

### With variable modes
Use [variable modes](/guide/theme#modes) to define color roles for light and dark modes. Keep mode-specific color decisions in theme variables when the same role repeats across the product.

(x) Markup owns the light and dark color choice.

```html
<div class="fg:white@dark fg:black@light">...</div>
```

(o) The theme owns the mode-specific role.

```html
<div class="fg:text">...</div>
```

Use conditional color classes when a one-off interaction genuinely differs by mode. For shared text, surface, line, brand, and status color, prefer a named token that can resolve differently per mode.

## Color roles
| Role | Example | Use |
|------|---------|-----|
| `canvas` | <Bg className="bg:canvas" /> | Page and application background |
| `surface` | <Bg className="bg:surface" /> | Cards, panels, controls, and plain containers |
| `surface-muted` | <Bg className="bg:surface-muted" /> | Recessed or secondary surfaces |
| `surface-raised` | <Bg className="bg:surface-raised" /> | Elevated cards and sticky regions |
| `surface-overlay` | <Bg className="bg:surface-overlay" /> | Popovers, dialogs, and floating layers |
| `surface-inverse` | <Bg className="bg:surface-inverse" /> | High-contrast inverted surfaces |

By default, theme modes [drive](/guide/theme#modes) these role variables for light and dark surfaces.
<Demo $py={0} $px={0}>
    <DemoLight>
        <div className="bg:surface-raised b:1|subtle aspect:2/1 size:full|12x r:sm shadow:card"></div>
    </DemoLight>
    <DemoDark>
        <div className="bg:surface-raised b:1|subtle aspect:2/1 size:full|12x r:sm shadow:card"></div>
    </DemoDark>
</Demo>
```html
<div class="light">
    <!-- @MARK bg:surface-raised --><!-- @MARK b:1|subtle -->
    <div class="bg:surface-raised b:1|subtle"></div>
</div>
<div class="dark">
    <!-- @MARK bg:surface-raised --><!-- @MARK b:1|subtle -->
    <div class="bg:surface-raised b:1|subtle"></div>
</div>
```
Add a project color role when your product has a named brand decision.
```css name=index.css
@theme {
    --color-brand: #4f46e5; /* [!code ++] */
    --color-brand-surface: #eef2ff; /* [!code ++] */
    --color-brand-text: #ffffff; /* [!code ++] */
}
```
Apply the custom color:
```html
<!-- @MARK bg:brand --><!-- @MARK fg:brand-text -->
<button class="bg:brand fg:brand-text"></button>
```

## Text colors
<ExpandContent>
| Token                                             | Descriptions                                                              |
|---------------------------------------------------|---------------------------------------------------------------------------|
| <Aa className="fg:strong" />`strong` | Titles, headings, and emphasized fields |
| <Aa className="fg:text" />`text` | Body text and default content |
| <Aa className="fg:muted" />`muted` | Secondary labels, descriptions, and icons |
| <Aa className="fg:subtle" />`subtle` | Tertiary text and low-emphasis metadata |
| <Aa className="fg:disabled" />`disabled` | Disabled text and unavailable controls |
| <Aa className="fg:placeholder" />`placeholder` | Input placeholders |
| <Aa className="fg:inverse" />`inverse` | Text on inverse surfaces |
| <Aa className="fg:link" />`link` | Links |
| <Aa className="fg:accent" />`accent` | Accent text |
| <Aa className="fg:success" />`success` | Success messages |
| <Aa className="fg:warning" />`warning` | Warnings |
| <Aa className="fg:danger" />`danger` | Errors and destructive actions |
| <Aa className="fg:info" />`info` | Informational messages |
</ExpandContent>

By default, theme modes [drive](/guide/theme#modes) text variables for light and dark foreground contrast.
<Demo $py={0} $px={0}>
    <DemoLight>
        <div className="fg:accent font:heavy font:9xl">M</div>
    </DemoLight>
    <DemoDark>
        <div className="fg:accent font:heavy font:9xl">M</div>
    </DemoDark>
</Demo>
```html
<div class="light">
    <!-- @MARK fg:accent -->
    <span class="fg:accent">M</span>
</div>
<div class="dark">
    <!-- @MARK fg:accent -->
    <span class="fg:accent">M</span>
</div>
```
See the [color](/reference/color#use-custom-text-colors) reference for more details on how to add custom text colors.

## Line colors
| Token                                                   | Descriptions                                                              |
|---------------------------------------------------------|---------------------------------------------------------------------------|
| <Bg className="outline:line" />`line` | Default borders and separators |
| <Bg className="outline:strong" />`strong` | High-contrast borders |
| <Bg className="outline:muted" />`muted` | Quiet borders inside dense UI |
| <Bg className="outline:subtle" />`subtle` | Dividers, layout chrome, and soft outlines |
| <Bg className="outline:accent" />`accent` | Accent borders |
| <Bg className="outline:danger" />`danger` | Error borders |

By default, theme modes [drive](/guide/theme#modes) line variables for light and dark separators.
