## Namespaces for typography
Typography is built from [theme tokens](/guide/theme) organized into focused namespaces.

`text-` applies a size, line height and tracking treatment. `font-size-`, `leading-` and `tracking-` change one property. See the [complete family index](/reference/tokens/families).

Utilities search the relevant namespace, so `font-size-lg`, `leading-md`, and `tracking-tight` can use short token names without the full custom property prefix.

---

## All-in-one text scale
At its core, the system is powered by a semantic type scale from `text-3xs` to `text-10xl`. These values are calibrated as complete text treatments, not just mathematically scaled font sizes.

Use `text-<token>` to apply the tuned font size, line height, and letter spacing with one class.

* `text-3xs ~ text-xs` — For fine print, annotations, captions, or table labels
* `text-sm ~ text-lg` — Standard text sizes for body copy, paragraphs, and buttons
* `text-xl ~ text-3xl` — Ideal for subheadings, lead paragraphs, or callouts
* `text-4xl ~ text-10xl` — Reserved for large headings, page titles, and hero sections

Use `font-size-<token>` when you only want the font-size token. Use `line-height:*` and `letter-spacing:*` when the design intentionally adjusts line height or letter spacing separately.

### Without vs with `text-<token>`
Manually configuring typography often requires juggling `font-size`, `line-height`, and `letter-spacing`. This becomes inconsistent when the same heading or paragraph style appears across components.

(x) The type treatment is assembled manually.

```html
<h1 class="font-size-3xl line-height:2.4rem letter-spacing:-0.048em">...</h1>
```

(o) The type treatment uses the shared text scale.

```html
<h1 class="text-3xl">...</h1>
```

Prefer `text-<token>` for repeated body, heading, and display styles. Reach for lower-level typography utilities only when the design intentionally departs from the text scale.

## Font families
Choose `font-family-sans` for interface text and `font-family-mono` for code or aligned numeric specimens. Load the chosen font files separately; the token only declares a fallback stack.

<FoundationTokens namespace="font-family" keys={["sans", "mono"]} />
See the [font family](/reference/tokens/font-family) reference for more details on how to add custom fonts.

---

## Font weights
Use `font-weight-regular` for body copy and `font-weight-semibold` for headings or labels that need emphasis. Check that the loaded face supports the requested weight.

<FoundationTokens namespace="font-weight" keys={["regular", "semibold"]} />

See the complete [values and consumers](/reference/tokens/font-weight) in Reference.

---

## Line height
Give paragraphs more breathing room than short headings. A complete `text-md` treatment already supplies leading; use `leading-lg` only when the content needs a deliberate override.

See the complete [values and consumers](/reference/tokens/leading) in Reference.

---

## Letter spacing
Use `tracking-widest` with short uppercase labels sparingly, and check the result in the actual font. Keep body text on the treatment’s default tracking.

See the complete [values and consumers](/reference/tokens/tracking) in Reference.
