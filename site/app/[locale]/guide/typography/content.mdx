## All-in-one text scale
At its core, the system is powered by a semantic type scale from `text-3xs` to `text-10xl`. These values are calibrated as complete text treatments, not just mathematically scaled font sizes.

Use `text-<token>` to apply the tuned font size, line height, and letter spacing with one class.

* `text-3xs ~ text-xs` — For fine print, annotations, captions, or table labels
* `text-sm ~ text-lg` — Standard text sizes for body copy, paragraphs, and buttons
* `text-xl ~ text-3xl` — Ideal for subheadings, lead paragraphs, or callouts
* `text-4xl ~ text-10xl` — Reserved for large headings, page titles, and hero sections

Use `font-<token>` when you only want the font-size token. Use `line-height:*` and `letter-spacing:*` when the design intentionally adjusts line height or letter spacing separately.

### Without vs with `text-<token>`
Manually configuring typography often requires juggling `font-size`, `line-height`, and `letter-spacing`. This becomes inconsistent when the same heading or paragraph style appears across components.

<Demo $py={0}>
  <DemoPanel className="display:flex flex-direction:column gap-xl width:100%">
    <div className="width:100%">
      <DemoLabel className="fg-text-red">font-size-5xl</DemoLabel>
      <DemoP className="font-size-5xl font-weight-regular line-height:1 text-wrap:pretty">Designing for consistency across every platform.</DemoP>
    </div>
    <div className="width:100%">
      <DemoLabel className="fg-text-green">text-5xl</DemoLabel>
      <DemoP className="text-5xl font-weight-regular text-wrap:pretty">Designing for consistency across every platform.</DemoP>
    </div>
  </DemoPanel>
</Demo>

(x) The type treatment is assembled manually.

```html
<h1 class="font-size-3xl line-height:2.4rem letter-spacing:-0.048em">...</h1>
```

(o) The type treatment uses the shared text scale.

```html
<h1 class="text-3xl">...</h1>
```

The `text-3xl` token applies a finely tuned combination:

<Class2CSS>{'text-3xl'}</Class2CSS>

Prefer `text-<token>` for repeated body, heading, and display styles. Reach for lower-level typography utilities only when the design intentionally departs from the text scale.

## Font weights
Our typography system defines a semantic range of font weight tokens, from `font-weight-thin` to `font-weight-heavy`, providing clear naming for visual emphasis and typographic hierarchy.

* `font-weight-thin` extra-light strokes for subtle or elegant UI elements
* `font-weight-light` light weight, ideal for large headings or minimalist design
* `font-weight-regular` default weight for body text and general readability
* `font-weight-medium` slightly bolder for subheadings or emphasis
* `font-weight-bold` strong emphasis, often used in call-to-action or UI labels
* `font-weight-heavy` maximum weight for impact, branding, or visual anchors
