## Overview [sr-only]
Use motion to explain a state change or show progress. Choose a short duration for feedback and reserve continuous motion for status indicators.

## Choose motion tokens
### Animation tokens
Each `--animate-*` token contains a complete native `animation` shorthand. The matching `animate-*` class emits one declaration, such as `animation: var(--animate-fade)`.

Use `animate-fade` for a brief appearance and `animate-rotate` for ongoing progress. See [all animation values and their contract](/reference/tokens/animate).

### Duration scale
Share duration tokens across animation and transition properties.

<FoundationTokens namespace="duration" keys={["fast", "normal"]} />

See the complete [values and consumers](/reference/tokens/duration) in Reference.

### Easing scale
Choose easing tokens for repeated motion decisions, or use explicit CSS curves such as `linear`, `steps()` and `cubic-bezier()`.

<FoundationTokens namespace="easing" keys={["smooth"]} />

See the complete [values and consumers](/reference/tokens/easing) in Reference.

## Namespaces for motion
`animation-duration-` and `transition-duration-` share duration tokens; `transition-timing-function-` reads easing tokens. See [all consumers](/reference/tokens/families).

## Use motion tokens
Use a named animation token and override individual settings with full-property declarations when needed. Preset animations repeat indefinitely by default; set an iteration count for a single entrance.

```html
<div class="animate-fade animation-duration:var(--duration-fast) animation-iteration-count:1">Ready</div>
<svg class="animate-rotate@motion-safe animation-duration:var(--duration-slowest)@motion-safe">...</svg>
```

<Class2CSS>{['animate-fade', 'animation-duration:var(--duration-fast)', 'animation-iteration-count:1', 'animate-rotate@motion-safe', 'animation-duration:var(--duration-slowest)@motion-safe']}</Class2CSS>

Token classes follow the general declaration order. At the same layer and conditions, `animation-duration-fast` sorts before `animate-fade`, so the shorthand resets that duration. Use `animation-duration:var(--duration-fast)` as above, or customize the complete `--animate-fade` value. Match condition suffixes when combining classes.

## Transition properties

<FoundationTransition />
Select the property, duration and timing function independently. A transition runs when the selected property's value changes.

```html
<button class="opacity:.7 opacity:1:hover transition-property:opacity transition-duration-fast transition-timing-function-smooth">Save</button>
```

<Class2CSS>{['opacity:.7', 'opacity:1:hover', 'transition-property:opacity', 'transition-duration-fast', 'transition-timing-function-smooth']}</Class2CSS>

## Respect motion preference
Use `@motion-safe` so nonessential motion only runs when the user has not requested reduced motion. Keep status text visible in either state.

```html
<span class="animate-pulse@motion-safe">Loading…</span>
```

<Class2CSS>{'animate-pulse@motion-safe'}</Class2CSS>

## Customize motion tokens

<FoundationDialog />
Store the keyframe name and playback settings together in one shorthand token. Duration and easing tokens can be referenced with `var()`. Omitted fields use native CSS defaults; this entrance runs once and keeps both fill states.

```css name=index.css
@theme {
    --duration-enter: 180ms;
    --easing-emphasized: cubic-bezier(.16, 1, .3, 1);
    --animate-dialog-in: dialog-in var(--duration-enter) var(--easing-emphasized) both;

  @keyframes dialog-in {
    from { translate: 0 0.5rem; opacity: 0; }
    to { translate: 0; opacity: 1; }
  }
}
```

```html
<dialog class="animate-dialog-in@motion-safe">...</dialog>
```

Managed keyframes are generated when an animation declaration references them. Static names, token references, native overrides and fallbacks are tracked. Unresolved dynamic names retain all managed keyframes. Put always-delivered keyframes outside `@theme`; JavaScript-only names need native keyframes or `@safelist "animation-name:dialog-in";`. See the [keyframe contract](/reference/directives/theme#theme-keyframes).

## Avoid motion noise
Keep persistent controls still until feedback is needed. Reuse duration and easing tokens so related interactions share a rhythm.
