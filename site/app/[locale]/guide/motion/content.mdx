## Overview [sr-only]
Use motion to explain a state change or show progress. Choose a short duration for feedback and reserve continuous motion for status indicators.

## Use motion tokens
Use a named recipe and override individual settings when needed. Preset animations repeat indefinitely by default; set an iteration count for a single entrance.

```html
<div class="animate-fade animation-duration-fast animation-iteration-count:1">Ready</div>
<svg class="animate-rotate@motion-safe animation-duration-slowest@motion-safe">...</svg>
```

<Class2CSS>{['animate-fade', 'animation-duration-fast', 'animation-iteration-count:1', 'animate-rotate@motion-safe', 'animation-duration-slowest@motion-safe']}</Class2CSS>

## Transition properties
Select the property, duration and timing function independently. A transition runs when the selected property's value changes.

```html
<button class="opacity:.7 opacity:1:hover transition-property:opacity transition-duration-fast transition-timing-function-smooth">Save</button>
```

<Class2CSS>{['opacity:.7', 'opacity:1:hover', 'transition-property:opacity', 'transition-duration-fast', 'transition-timing-function-smooth']}</Class2CSS>

## Respect motion preference
Use `@motion-safe` so nonessential motion only runs when the user has not requested reduced motion. Keep status text visible in either state.

```html
<span class="animate-pulse@motion-safe">Loading…</span>
```

<Class2CSS>{'animate-pulse@motion-safe'}</Class2CSS>

## Customize motion tokens
Define the keyframe name and each playback setting explicitly. Companion tokens customize a recipe without creating additional class names.

```css name=index.css
@theme {
  :root, :host {
    --duration-enter: 180ms;
    --easing-emphasized: cubic-bezier(.16, 1, .3, 1);
    --animate-dialog-in: dialog-in;
    --animate-dialog-in--duration: var(--duration-enter);
    --animate-dialog-in--timing-function: var(--easing-emphasized);
    --animate-dialog-in--iteration-count: 1;
    --animate-dialog-in--fill-mode: both;
  }
  @keyframes dialog-in {
    from { translate: 0 0.5rem; opacity: 0; }
    to { translate: 0; opacity: 1; }
  }
}
```

```html
<dialog class="animate-dialog-in@motion-safe">...</dialog>
```

Managed keyframes are generated when an animation declaration references them. Static names, token scopes and fallbacks are tracked. Unresolved dynamic names retain all managed keyframes. Put always-delivered keyframes outside `@theme`; JavaScript-only names need native keyframes or `@safelist "animation-name:dialog-in";`. See the [keyframe contract](/guide/directives#theme-static).

## Avoid motion noise
Keep persistent controls still until feedback is needed. Reuse duration and easing tokens so related interactions share a rhythm.
