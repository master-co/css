```css name=index.css
@master {
    @layer utilities {
        .round { /* [!code highlight] */
            border-radius: 50%; /* [!code highlight] */
            aspect-ratio: 1 / 1; /* [!code highlight] */
        } /* [!code highlight] */
    }
}
```
Apply a static utility:
```html
<!-- @MARK round -->
<div class="round">o</div>
```
Generated CSS:
```css
.round {
    border-radius: 50%;
    aspect-ratio: 1 / 1;
}
```
Use utilities with selectors and at-rules:
```html
<!-- @MARK round:hover@sm -->
<div class="round:hover@sm">o</div>
```
