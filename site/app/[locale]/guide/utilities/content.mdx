## Overview [sr-only]
Master CSS utilities are the class syntax definitions that map class names to CSS declarations. Some utilities are fixed class names like `block` and `round`; others are value-based syntax like `font:16`, `bg:primary`, or `grid-cols:3`.

Utilities work with [selectors](/guide/selectors), [at-rules](/guide/at), modes, functions, and variables. Use them for reusable styling primitives. If you are defining semantic classes such as `.btn` or `.card`, use [components](/guide/reusing-styles) instead.

---

## Add a custom utility
Use `config.utilities` only when your design system needs a reusable primitive that cannot be represented cleanly by existing utilities or components.
