## Overview [sr-only] \{#overview\}
Master CSS classes are CSS declarations written directly in markup. Read each class from left to right: start with the style you want, then add optional [state selectors](/reference/rules/selectors) and optional [conditional queries](/reference/rules/conditions).

```html
<!-- @MARK fg:white --><!-- @MARK :hover --><!-- @MARK @md -->
<button type="button" class="fg:white:hover@md">Save</button>
```

The examples in this reference start with explicit CSS-like declarations, then show how to shorten them with utilities, shorthands, abbreviations, variables, and explicit units. Common native properties such as spacing, sizing, radius, color, and timing can still use Master CSS tokens and multiplier units, while rare CSS properties can use valid native declaration syntax directly. When you are learning a new class, write the explicit form first. Once the output is clear, use the shorter form that still reads well to your team.



## Combine with states and queries \{#combine-with-states-and-queries\}
After the declaration itself is clear, you can attach selectors and conditions without changing the declaration syntax.

```html
<!-- @MARK bg:blue-60 --><!-- @MARK bg:blue-70:hover@md --><!-- @MARK transition:background-color|.2s -->
<button type="button" class="bg:blue-60 transition:background-color|.2s bg:blue-70:hover@md">
  Save
</button>
```

This means:

- `bg:blue-60` applies by default.
- `bg:blue-70:hover@md` applies only when the button is hovered and the viewport matches `@md`.
- `transition:background-color|.2s` adds a `background-color` transition.

Continue with [selectors](/reference/rules/selectors) for element states and relationships, or [conditions](/reference/rules/conditions) for viewport, media, container, and layer suffixes. The [syntax tutorial](/guide/syntax-tutorial) introduces the authoring workflow.
