## Write one declaration

Start with the CSS property you need. For a button with space around its label, add a padding class:

```html
<button class="p:md">Save</button>
```

<Class2CSS>{['p:md']}</Class2CSS>

The [padding reference](/reference/padding) shows the full property name, shorter forms and current token values. Read the generated declaration first; then choose the form your team finds clearest.

## Add behavior in small steps

1. Confirm the unqualified class produces the intended declaration.
2. Add a [state selector](/guide/state-selectors) when the change depends on interaction.
3. Add a [condition](/guide/conditional-queries) when the change depends on the viewport, container or mode.
4. Inspect the full combination in your project when its values depend on custom settings.

Use [Declarations & values](/reference/rules/declarations) to check accepted forms, units and native property fallback.
