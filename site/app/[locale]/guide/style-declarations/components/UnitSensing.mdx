Some properties have an obvious default unit. Master CSS can infer that unit from the property instead of requiring you to type it every time.
<Code lang="html">
    {code1}
</Code>

(o) Omit the unit when the property can infer it clearly. <Dropped p1={code1} p2={code2} target="class" />
<Code lang="html">
    {code2}
</Code>

When a rotation value is written without a unit, it is interpreted as `deg` instead of invalid `px`.

Similarly, time properties without units are interpreted as `ms`. You can still write explicit values such as `.2s` when seconds read better.
