(x) Inline styles can declare CSS variables, but they cannot respond to selectors or queries.
```html
<div style="--color: red; --size: 5rem">
```

(o) Use `--<name>:<value>` when a variable needs the same selector and query power as any other Master CSS declaration.
```html
<!-- @MARK --color:red:hover --><!-- @MARK --size:5rem@sm -->
<div class="--color:red:hover --size:5rem@sm">
```
Generated CSS:
<Class2CSS>
    {['--color:red:hover', '--size:5rem@sm']}
</Class2CSS>

Use the variable from another declaration with native CSS `var()`.
```html
<!-- @MARK --button-bg:red-60 --><!-- @MARK bg:var(--button-bg) -->
<button class="--button-bg:red-60 bg:var(--button-bg)">
    Save
</button>
```

This is useful for component internals: set a variable in one state, then let child declarations, shadow parts, or native component CSS consume the same custom property.
```css
.button {
    background: var(--button-bg);
}
```
