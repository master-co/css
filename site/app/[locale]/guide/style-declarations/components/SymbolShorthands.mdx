  <div class="transition-property:opacity animation-duration:1s animation-name:fade">

Animation and transition longhand declarations use their CSS property keys.
<Code lang="html">
  {code1}
</Code>

Animation and transition shorthand declarations also keep the explicit property key:
```html
<!-- @MARK animation:fade|1s|ease --><!-- @MARK transition:opacity|3s -->
<div class="transition:opacity|3s animation:fade|1s|ease">
```

To learn more, check out the [animation](/reference/animation) and [transition](/reference/transition) documentation.
