Use full native property names for direct values, canonical token families for theme values, and mixins for reusable recipes.

```html
<div class="display:block position:absolute border-radius:50%"></div>
```

A declaration describes its native CSS property and value; a named token such as `p-md` reads a theme value.

Recipes express a reusable combination or static parameter operation. The preset includes `sr-only`, `font-antialiased`, `grid-cols(3)`, `text-sm`, and `animate-fade`. Projects may define their own names with `@mixin`.

```html
<div class="grid-cols(3) gap-md"></div>
```

Complete native shorthand properties remain supported. Documentation examples prefer independent styling decisions; this authoring preference does not remove native CSS shorthand syntax or expand native CSS declarations into resets.

For project-specific recipes, see [mixins](/reference/directives/definitions#utilities).
