Master CSS ships with predefined theme tokens for common primitive values. You can also define [theme tokens](/guide/theme#theme-tokens) for your own design system, then use semantic values instead of repeating raw CSS values.

```css name=index.css
@theme {
  --spacing-sm: 0.625rem;
  --color-primary: #000000;
}
```

Apply custom tokens using contextual shorthand:

```html
<!-- @MARK m:sm --><!-- @MARK bg:primary -->
<div class="m:sm bg:primary">...</div>
```
