Class attributes use whitespace to separate class names, so a value like `10 20 30 40` must be written with a delimiter.

(o) Use `|` delimiters instead of whitespaces between CSS parameter values.
```html
<div class="m:10|20|30|40"></div>
```
Review native CSS:
```css
div {
    margin: 0.625rem 1.25rem 1.875rem 2.5rem
}
```
The delimiter does not change the CSS shorthand rules. Keep the same top, right, bottom, and left order you would use in CSS.

[Master CSS syntax highlighting](/guide/language-service) uses low-contrast styling for `|`, so shorthand values stay close to the feel of native CSS whitespace.
