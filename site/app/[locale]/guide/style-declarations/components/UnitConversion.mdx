The unitless `48` is interpreted as pixels for `font` and converted to `3rem` when CSS is generated.

Master CSS defines [practical unit and conversion behavior](/guide/utilities#syntax-reference) by utility. Many size values convert from pixels to `rem`, while other properties keep or infer a different unit.

Use explicit units when you need to preserve a value exactly as written.
