Supported native CSS declarations can be written directly as `property:value`, even when they are not listed as built-in utilities.
Use arbitrary properties when you need to force a raw CSS property/value pair or group declarations inside one class.
```html
<!-- @MARK float:left --><!-- @MARK {block-size:5rem} -->
<div class="float:left {block-size:5rem}">
```
Generated CSS:
```css
.float\:left {
    float: left;
}

.\{block-size\:5rem\} {
    block-size: 5rem;
}
```

Prefer built-in utilities when they exist, because they can include token resolution, unit conversion, aliases, sorting, and shorthand behavior. Arbitrary properties are the escape hatch for raw declarations and one-off declaration groups.
