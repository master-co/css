Use arbitrary properties when you need a native CSS declaration that does not have a built-in utility yet. Wrap the declaration in `{}` so Master CSS treats it like a CSS property/value pair.
```html
<!-- @MARK {block-size:5rem} -->
<div class="{block-size:5rem}">
```
Generated CSS:
```css
.\{block-size\:5rem\} {
    block-size: 5rem;
}
```

Prefer built-in utilities when they exist, because they can include token resolution, unit conversion, sorting, and validation behavior. Arbitrary properties are the escape hatch for platform features, experiments, and one-off declarations.
