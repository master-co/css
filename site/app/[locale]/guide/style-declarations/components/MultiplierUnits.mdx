Use multiplier units when a value should follow the configured spacing and size rhythm.
```html
<!-- @MARK m:4x -->
<div class="m:4x"></div>
```
Generated CSS:
```css
.m\:4x {
    margin: 1rem; /* 4x = 4*4 = 16px, 16px / 16 = 1rem */
}
```
By default, the multiplier [base unit](/guide/configuration#baseunit) is `4`, so `4x` means `16px` before conversion. This makes repeated spacing values consistent without forcing you to create a named token for every small step.
