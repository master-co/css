Use multiplier units when a value should follow the theme spacing and size rhythm.
{/* eslint-disable @master/css/prefer-canonical-classes -- intentional multiplier-unit source example */}
```html
<!-- @MARK m:4x -->
<div class="m:4x"></div>
```
{/* eslint-enable @master/css/prefer-canonical-classes */}
Generated CSS:
```css
.m\:4x {
    margin: 1rem; /* 4x = 4*4 = 16px, 16px / 16 = 1rem */
}
```
By default, the multiplier [base unit](/guide/theme#project-settings) is `4`, so `4x` means `16px` before conversion. This makes repeated spacing values consistent without forcing you to create a named token for every small step.
