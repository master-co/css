```css name=index.css
@master {
    slide-in-up {
        from {
            transform: translateY(100%);
        }

        to {
            transform: translateY(0);
        }
    }
}
```
You can also write native `@keyframes` inside `@master`:
```css name=index.css
@master {
    @keyframes slide-in-up {
        from { transform: translateY(100%); }
        to { transform: translateY(0); }
    }
}
```
Apply the custom animation using [animation](/reference/animation) syntax:
```html
<!-- @MARK animation:slide-in-up|slower -->
<div class="animation:slide-in-up|slower"></div>
```
