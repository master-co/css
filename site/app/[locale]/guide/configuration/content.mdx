## Setup [sr-only]
```bash action=create
@master/css@rc
```
If you don't have a configuration file, [create](/reference/create-app) one first. The primary configuration format is `master.css`.

```css name=master.css
@master {
    root-size: 16;
    base-unit: 4;
    default-mode: light;
    mode-trigger: media;
    scope: #app;

    --color-primary: #4f46e5;
    --screen-md: 768;

    dark {
        --color-primary: #818cf8;
    }

    @custom-at motion-safe @media (prefers-reduced-motion: no-preference);
    @custom-selector :headings :is(h1, h2, h3, h4, h5, h6);
}

@master components {
    .btn {
        @compose "inline-flex ai:center jc:center px:1rem py:.625rem r:.5rem";
        background: var(--color-primary);
        color: white;
    }
}

@master utilities {
    .content-auto {
        content-visibility: auto;
        contain-intrinsic-size: auto 32rem;
    }
}

@master animations {
    fade-in {
        from { opacity: 0; }
        to { opacity: 1; }
    }
}
```

`@master` blocks are converted into runtime/build config. They are not emitted as CSS by themselves, and component definitions are still generated only when the component class is used in markup or extracted from source.

---

## CSS config graph
Use native CSS `@import` to split a CSS config into files. Local relative `.css` imports are resolved into one config graph before compilation.

```css name=master.css
@import './styles/theme.css';
@import './styles/button.css';

@master components {
    .btn {
        display: block;
    }
}
```

```css name=styles/button.css
@master components {
    .btn {
        font-size: 1rem;
    }
}
```

For repeated component definitions with the same selector, at-rules, and layer, declarations are merged in import/source order. In the example above, `.btn` becomes one component definition with both `font-size: 1rem` and `display: block`.

Root options, variables, animations, `@custom-at`, and `@custom-selector` are last-write-wins when repeated. Package imports and regular CSS outside `@master` stay as normal CSS output.

### `.important`
Make all generated CSS declarations `!important`.

<DocProp defaultValue="false" types={['boolean']} />

(!|) Global important output should be a last option because it changes the whole cascade contract.
```css name=master.css
@master {
    important; /* [!code ++] */
}
```
You can also write the flag as `!important;`.

Generated CSS:
```css
.hidden {
    /* @MARK !important */
    display: none !important;
}

.full {
    /* @MARK !important */
    width: 100% !important;
    /* @MARK !important */
    height: 100% !important;
}
```

### `.rootSize`
Specify the conversion factor for `rem` and `em`.

<DocProp defaultValue="16" types={['number']} />

Here's a common use case with `rootSize: 10`:
```css name=master.css
@master {
    root-size: 10; /* [!code ++] */
}
```

Generated CSS rules:
```css
.font\:16 {
    font-size: 1rem;   /* rootSize: 16 */ /* [!code --] */
    font-size: 1.6rem; /* rootSize: 10 */ /* [!code ++] */
}
```

And you will set the font size of the root to `62.5%`:
```html
<html class="font:62.5%">
```

### `.baseUnit`
This base unit determines the size scale and ensures visual consistency across products.
<DocProp defaultValue="4" types={['number']} />
For example, with the default `baseUnit: 4`, the size scale `1x, 2x, …` will be `4, 8, …`.
```html
<div class="m:4x"></div>
```
Generated CSS:
```css
.m\:4x {
    margin: 1rem; /* 4x = 4*4 = 16px, 16px / 16 = 1rem */
}
```

### `.scope`
Limit the generated CSS rules to a specific scope with CSS selectors.
<DocProp defaultValue="''" types={['string']} />

(!|) Don't make it part of your coding style, but as a last resort to solve problems.
```css name=master.css
@master {
    scope: #app; /* [!code ++] */
}
```
All Master CSS syntax will only be applied if the `<body id="app">`.
```html
<html>
<!-- @MARK app -->
<body id="app">
    <!-- @MARK mt:1 text:center -->
    <div class="mt:1 text:center"></div>
</body>
</html>
```
Generated CSS:
```css
/* @MARK #app */
#app .mt\:1 {
    margin-top: 0.0625rem
}

/* @MARK #app */
#app .text\:center {
    text-align: center
}
```
