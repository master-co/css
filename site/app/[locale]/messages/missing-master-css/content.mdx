## Causes [sr-only]
### Why this warning occurred

An integration started without finding a project CSS entry in the current project directory.

```txt
[@master/css.vite] Master CSS entry was not found in /path/to/project.
Create /path/to/project/index.css and mark it as the project entry, for example:
  @master;
  @import "./src/globals.css";
Master CSS uses this entry graph for integrations, language service, and VS Code. Imported CSS config blocks participate in the graph.
```

Master CSS can still generate utility CSS without custom config, but integrations and editor tooling use the project CSS entry to find shared tokens, component definitions, animations, and workspace behavior.

`@theme`, `@master`, `@custom-at`, and `@custom-selector` directives do not have to be written directly in the entry file. They can live in ordinary CSS files such as `src/globals.css` or `app/globals.css`, as long as the entry imports those files with a relative CSS import. The entry itself is recognized by `@master;` or `@import '@master/css'`.

---

## Solutions
### Create a workspace entry

Create `index.css` at the project root and import your stylesheet entry.

```css name=index.css
@master;
@import './src/globals.css';
```

Then keep tokens, component rules, animations, or other Master CSS config in that imported stylesheet or in files imported by it.

```css name=src/globals.css
@theme {
    color-primary: #4f46e5;
}

@components {
    btn {
        @compose "inline-flex ai:center px:md h:40 r:md bg:primary fg:white";
    }
}
```

Ordinary CSS outside Master CSS directives stays native CSS and follows the integration's stylesheet behavior.

### Pass an explicit config object

If your integration should not use the discovered project CSS entry, pass an explicit config object.

```js name=vite.config.js
import masterCSS from '@master/css.vite'

export default {
    plugins: [
        masterCSS({
            config: {
                variables: {
                    color: {
                        primary: '#4f46e5'
                    }
                }
            }
        })
    ]
}
```

### Ignore the warning

You can ignore this warning when the current project intentionally has no Master CSS config and does not need shared tokens, component definitions, animations, language-service workspace detection, or editor integration behavior.
