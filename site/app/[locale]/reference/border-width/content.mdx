## Examples \{#examples\}
### Set border width \{#set-border-width\}
Use `b:*` with a size value to set `border-width`.
```html
<!-- @MARK b:1px -->
<div class="b-solid b:1px">
  ...
</div>
```

### Set one side or axis \{#set-one-side-or-axis\}
Use `bt:*`, `br:*`, `bb:*`, and `bl:*` for physical sides. Use `bx:*` and `by:*` for logical axes.
```html
<!-- @MARK bt:2px --><!-- @MARK by:1px -->
<div class="by:1px bt:2px">...</div>
```

Use [border](/reference/border) when width, style, and color should be declared together.

### Apply conditionally \{#apply-conditionally\}
Apply styles based on different states using [selectors](/reference/rules/selectors) and [conditional queries](/reference/rules/conditions).
```html
<div class="b:0 b:0@print b:1px@sm">...</div>
```

Remember that a border is not visible unless its style is not `none`.
