## Examples \{#examples\}

### Set border width \{#set-border-width\}
`border-width:<size>` changes only border width. Both panels below have the same 240 × 96 border box. A thicker border leaves less room for content and padding inside that fixed outer size.

<DemoExample page="border-width" section="set-border-width" />

```html
<!-- 2px border · fixed outer box -->
<div id="target"
  class="display:flex align-items:center justify-content:center height:96px
         width:240px max-width:100% p-md border-style:solid border-width:2px b-blue
         font-size-md bg-surface-inset fg-text-body
         box-sizing:border-box">
  Preview panel
</div>
```

```html
<!-- 8px border · same outer box -->
<div id="target"
  class="display:flex align-items:center justify-content:center height:96px
         width:240px max-width:100% p-md border-style:solid border-width:8px b-blue
         font-size-md bg-surface-inset fg-text-body
         box-sizing:border-box">
  Preview panel
</div>
```

<details>
  <summary>Generated CSS</summary>
  <Class2CSS>
    {['border-width:2px']}
  </Class2CSS>
</details>

With `box-content`, border widths add outside the declared content dimensions instead. A `none` or `hidden` border style produces zero used width.

### Set one side or axis \{#set-one-side-or-axis\}
Physical aliases such as `bt` always address the named edge. `by` changes the block-axis pair, which becomes the left and right edges in vertical writing.

<DemoExample page="border-width" section="set-one-side-or-axis" />

```html
<!-- Top edge · physical -->
<div id="target"
  class="display:flex align-items:center justify-content:center height:96px
         width:240px max-width:100% p-md border-style:solid b-blue border-bottom-width:0
         border-left-width:0 border-right-width:0 border-top-width:6px font-size-md bg-surface-inset
         fg-text-body box-sizing:border-box">
  Top: 6px
</div>
```

```html
<!-- Block edges · horizontal writing -->
<div id="target"
  class="display:flex align-items:center justify-content:center height:96px
         width:240px max-width:100% p-md border-style:solid border-width:0 b-blue
         border-block-width:6px font-size-md bg-surface-inset fg-text-body
         box-sizing:border-box">
  Top and bottom: 6px
</div>
```

```html
<!-- Block edges · vertical writing -->
<div id="target"
  class="display:flex align-items:center justify-content:center height:96px
         width:240px max-width:100% p-md border-style:solid border-width:0 b-blue
         border-block-width:6px font-size-md bg-surface-inset fg-text-body
         box-sizing:border-box writing-mode:vertical-rl">
  Left and right: 6px
</div>
```

`bx` sets inline-axis widths. Keep a visible style and color when adjusting width independently.

### Apply conditionally \{#apply-conditionally\}
Widen to `sm` to add a 6px border. The explicitly fixed border-box dimensions remain unchanged; the content area becomes smaller. Print returns to zero width.

<DemoExample page="border-width" section="apply-conditionally" />

```html
<!-- 0 → 6px at sm · fixed outer geometry -->
<div id="target"
  class="display:flex align-items:center justify-content:center height:96px
         width:240px max-width:100% p-md border-style:solid border-width:0 b-blue
         font-size-md bg-surface-inset fg-text-body
         box-sizing:border-box border-width:0@media(print) border-width:6px@media(screen)@sm">
  Preview panel
</div>
```

The screen-qualified condition does not override the print reset. Set border width, [style](/reference/border-style) and [color](/reference/border-color) independently.
