## Examples
### Set border width
Use `b:*` with a size value to set `border-width`.
```html
<!-- @MARK b:1 -->
<div class="b:1 b-solid">
    ...
</div>
```

<details>
    <summary>Generated CSS</summary>
    <Class2CSS>
        {['b:1']}
    </Class2CSS>
</details>

### Set one side or axis
Use `bt:*`, `br:*`, `bb:*`, and `bl:*` for physical sides. Use `bx:*` and `by:*` for horizontal or vertical sides.
```html
<!-- @MARK bt:2 --><!-- @MARK by:1 -->
<div class="bt:2 by:1">...</div>
```

Use [border](/reference/border) when width, style, and color should be declared together.

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="b:0 b:1@sm b:0@print">...</div>
```

Remember that a border is not visible unless its style is not `none`.
