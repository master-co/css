## Installation [sr-only]
```bash action=install
@master/css.vite@rc
```
```js name=vite.config.js
import { defineConfig } from 'vite'
import masterCSS from '@master/css.vite' // [!code highlight]

export default defineConfig({
    plugins: [
        masterCSS(options) // [!code highlight]
    ]
})
```

### Client types
Add `@master/css.vite/client` to the project environment file when TypeScript source files import `virtual:master-css-config` or `*.css?master-css-config`.

```ts name=src/vite-env.d.ts
/// <reference types="vite/client" />
/// <reference types="@master/css.vite/client" />
```

### Virtual CSS imports
In extract mode, import the generated stylesheet from JavaScript or from a source stylesheet.

```js name=src/main.js
import 'virtual:master.css'
```

```css name=src/style.css
@import 'virtual:master.css';
```

Source stylesheets that import the virtual module are treated as extractable CSS entries. Ordinary CSS outside `@master` is pruned against detected classes. If the same stylesheet contains `@master {}` config, import it from `master.css` so the config graph can read those definitions.
