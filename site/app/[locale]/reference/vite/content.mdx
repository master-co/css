## Installation [sr-only]
```bash action=install
@master/css.vite@rc
```
```js name=vite.config.js
import { defineConfig } from 'vite'
import masterCSS from '@master/css.vite' // [!code highlight]

export default defineConfig({
    plugins: [
        masterCSS(options) // [!code highlight]
    ]
})
```

### Client types
Add `@master/css.vite/client` to the project environment file when TypeScript source files import `virtual:master-css-config`.

```ts name=src/vite-env.d.ts
/// <reference types="vite/client" />
/// <reference types="@master/css.vite/client" />
```

### Master CSS imports
In extract mode, import the generated stylesheet from a source stylesheet.

```css name=src/style.css
@import '@master/css';
```

Source stylesheets that import `@master/css` are treated as native CSS shaking roots by default. Ordinary CSS outside `@master` is pruned against detected classes, and the import inserts generated Master CSS. Add `@master no-shake;` when native CSS must be preserved. If the same stylesheet contains `@master {}` config, that stylesheet can also serve as the project CSS entry because `@import '@master/css'` is an entry marker.

### Config imports
The plugin exposes the canonical project-level config module:

```ts
import config from 'virtual:master-css-config'
```

Use the virtual module when application code should receive the same config graph that the plugin discovered from the project CSS entry. It is backed by [`@master/css-configer`](/reference/configer).
