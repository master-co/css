## Examples \{#examples\}
### Align tabular numbers \{#align-tabular-numbers\}
Use `tabular-nums` for tables, timers, and dashboards where digits should line up across rows.
```html
<!-- @MARK tabular-nums -->
<td class="tabular-nums">12,480.00</td>
```

### Show slashed zeroes \{#show-slashed-zeroes\}
Use `slashed-zero` when zeroes need to be visually distinct from the letter O.
```html
<!-- @MARK slashed-zero -->
<code class="slashed-zero">OID-00042</code>
```

### Reset numeric variants \{#reset-numeric-variants\}
Use `font-variant-numeric:normal` to remove numeric variant features from a nested element.
```html
<!-- @MARK font-variant-numeric:normal -->
<span class="tabular-nums">
  <span class="font-variant-numeric:normal">Normal numbers</span>
</span>
```

### Apply conditionally \{#apply-conditionally\}
Apply styles based on different states using [selectors](/reference/rules/selectors) and [conditional queries](/reference/rules/conditions).
```html
<span class="tabular-nums:hover font-variant-numeric:normal@print font-variant-numeric:normal@sm">...</span>
```
