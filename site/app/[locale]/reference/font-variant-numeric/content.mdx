## Examples \{#examples\}

### Align tabular numbers \{#align-tabular-numbers\}
Tabular digits have equal advance widths, which helps align equally formatted values. Geist is proportional by default; this comparison uses identical strings and no padding between digits.

<DemoExample page="font-variant-numeric" section="align-tabular-numbers" />

```html
<!-- proportional-nums -->
<div id="target" class="font-variant-numeric:proportional-nums font-size-3xl leading-sm"><span id="ones" class="display:inline-block">11111</span><br><span id="eights" class="display:inline-block">88888</span></div>
```

```html
<!-- tabular-nums -->
<div id="target" class="font-variant-numeric:tabular-nums font-size-3xl leading-sm"><span id="ones" class="display:inline-block">11111</span><br><span id="eights" class="display:inline-block">88888</span></div>
```

Decimal points, signs and different digit counts still need an appropriate table or alignment strategy.

### Show slashed zeroes \{#show-slashed-zeroes\}
`slashed-zero` selects the font’s alternate zero when available. This example loads the site’s JetBrains Mono face, where the dotted default zero changes to a slashed form.

<DemoExample page="font-variant-numeric" section="show-slashed-zeroes" />

```css name=index.css
@font-face {
  font-family: 'JetBrains Mono';
  font-style: normal;
  font-weight: 100 800;
  font-display: swap;
  src: url('/fonts/JetBrainsMono[wght].ttf') format('truetype');
}
@theme { :root, :host {
  --font-family-code-demo: 'JetBrains Mono', monospace;
} }

```

```html
<!-- font-variant-numeric:normal -->
<p id="target" class="margin:0 font-variant-numeric:normal font-size-3xl leading-sm font-family-code-demo">0O 00 2026</p>
```

```html
<!-- slashed-zero -->
<p id="target" class="margin:0 font-variant-numeric:slashed-zero font-size-3xl leading-sm font-family-code-demo">0O 00 2026</p>
```

An unsupported OpenType feature is ignored. The computed property alone does not prove that the glyph changed.

### Reset numeric variants \{#reset-numeric-variants\}
`font-variant-numeric:normal` resets inherited numeric variants on the child. It does not cancel a separate raw `font-feature-settings` override.

<DemoExample page="font-variant-numeric" section="reset-numeric-variants" />

```html
<!-- Tabular parent · proportional child -->
<div id="context" class="font-variant-numeric:tabular-nums font-size-3xl leading-sm">
  <p class="margin:0"><span id="inherited" class="display:inline-block">11111</span></p>
  <p id="target" class="margin:0 font-variant-numeric:normal"><span id="ones" class="display:inline-block">11111</span><br><span id="eights" class="display:inline-block">88888</span></p>
</div>
```

### Apply conditionally \{#apply-conditionally\}
Focus the sample with the keyboard or hover it to enable tabular digits. Read the actual glyph-run widths below.

<DemoExample page="font-variant-numeric" section="apply-conditionally" />

```html
<!-- A real state change -->
<div id="target" tabindex="0" role="group" aria-label="Numeric variant sample" class="font-variant-numeric:proportional-nums font-size-3xl leading-sm font-variant-numeric:tabular-nums:hover font-variant-numeric:tabular-nums:focus-visible"><span id="ones" class="display:inline-block">11111</span><br><span id="eights" class="display:inline-block">88888</span></div>
```
