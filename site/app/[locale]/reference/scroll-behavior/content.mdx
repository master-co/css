## Examples
### Enable smooth anchor scrolling
Use `scroll-behavior:smooth` on the scrolling container or root element when anchor navigation should animate.
```html
<!-- @MARK scroll-behavior:smooth -->
<main class="scroll-behavior:smooth">
  ...
</main>
```

<details>
  <summary>Generated CSS</summary>
  <Class2CSS>
    {['scroll-behavior:smooth']}

</details>

### Keep static output immediate
Use `scroll-behavior:auto` when a context should jump directly, such as print or automated layout measurement.
```html
<!-- @MARK scroll-behavior:auto -->
<main class="scroll-behavior:smooth scroll-behavior:auto@print">
  ...
</main>
```

### Combine with scroll offsets
Smooth scrolling pairs well with `scroll-mt:*` on the destination element or `scroll-pt:*` on the container.
```html
<main class="scroll-pt:3xl scroll-behavior:smooth">
  <section id="details" class="scroll-mt:3xl">Details</section>
</main>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<main class="scroll-behavior:smooth scroll-behavior:auto@print">...</main>
```
