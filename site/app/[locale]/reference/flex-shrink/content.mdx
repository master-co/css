## Examples \{#examples\}
### Allow an item to shrink \{#allow-an-item-to-shrink\}
`flex-shrink` distributes a shortage of space relative to each item’s basis. These 192px and 96px bases, plus the 16px gap, exceed the 280px row. With equal shrink factors, the larger basis loses twice as much width.

<DemoExample page="flex-shrink" section="allow-an-item-to-shrink" />

```html
<div id="layout" class="display:flex gap-md width:17.5rem max-width:100%">
  <div id="target" class="flex-basis:12rem flex-shrink:1 height:6rem min-width:0"><span class="display:block p-sm">192px basis</span></div>
  <div id="peer" class="flex-basis:6rem flex-shrink:1 height:6rem min-width:0"><span class="display:block p-sm">96px basis</span></div>
</div>
```

<details>
  <summary>Generated CSS</summary>
  <Class2CSS>
    {['flex-shrink:1', 'min-width:0']}
  </Class2CSS>
</details>

At the full 280px row width, the items settle at 176px and 88px. `min-width:0` removes their automatic content minimum so the shrink calculation can fit the row.

### Prevent fixed media from shrinking \{#prevent-fixed-media-from-shrinking\}
`flex-shrink:0` keeps a fixed avatar from losing width when a long text sibling needs space. The 48px avatar stays square; the text box can shrink and wrap inside the 280px row.

<DemoExample page="flex-shrink" section="prevent-fixed-media-from-shrinking" />

```html
<div id="layout" class="display:flex align-items:center gap-md width:17.5rem max-width:100%">
  <span id="target" class="display:grid flex-shrink:0 place-items:center width:3rem height:3rem" aria-hidden="true">AL</span>
  <div id="peer" class="overflow-wrap:anywhere flex-basis-xs min-width:0 p-sm">Alexandra Lee<br>alexandra.lee@collaborative.design.example</div>
</div>
```

Removing the minimum-width constraint changes the box’s sizing. A separate wrapping rule handles an unbroken address that would otherwise paint outside it.

### Apply conditionally \{#apply-conditionally\}
Use [conditional queries](/reference/rules/conditions) to preserve the blue item’s 192px basis from `sm`. The row remains 280px wide so resizing isolates the change in shrink behavior; the violet item absorbs the remaining shortage.

<DemoExample page="flex-shrink" section="apply-conditionally" />

```html
<div id="layout" class="display:flex gap-md width:17.5rem max-width:100%">
  <div id="target" class="flex-basis:12rem flex-shrink:1 height:6rem min-width:0 flex-shrink:0@sm"><span class="display:block p-sm">Target</span></div>
  <div id="peer" class="flex-basis:6rem flex-shrink:1 height:6rem min-width:0"><span class="display:block p-sm">Peer</span></div>
</div>
```

Set [growth](/reference/flex-grow) and the [basis](/reference/flex-basis) independently from shrinkage.
