## Examples \{#examples\}
### Balance short headings \{#balance-short-headings\}
Use `text-balance` for headings, cards, and callouts where balanced line lengths are more important than fitting as much text as possible on each line.
```html
<!-- @MARK text-balance -->
<h1 class="text-balance">
  Build interfaces that stay readable across narrow and wide containers
</h1>
```

### Prefer pretty wrapping for prose \{#prefer-pretty-wrapping-for-prose\}
Use `text-pretty` for paragraphs where the browser should avoid awkward last lines when it can.
```html
<!-- @MARK text-pretty -->
<p class="text-pretty">
  Master CSS keeps text wrapping decisions in markup while still using native CSS behavior.
</p>
```

### Prevent wrapping \{#prevent-wrapping\}
Use `text-nowrap` when a label, tab, or inline control must stay on one line.
```html
<!-- @MARK text-nowrap --><!-- @MARK overflow:hidden --><!-- @MARK text-ellipsis -->
<span class="overflow:hidden text-ellipsis text-nowrap">
  Very long file name
</span>
```

Only use no-wrap when the container has an overflow strategy. Otherwise the text can force the layout wider than intended.

### Apply conditionally \{#apply-conditionally\}
Apply styles based on different states using [selectors](/reference/rules/selectors) and [conditional queries](/reference/rules/conditions).
```html
<div class="text-wrap text-wrap@print text-balance@sm text-pretty@lg">...</div>
```

Use [white-space](/reference/white-space) when the requirement is preserving spaces or line breaks.
