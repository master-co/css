## Examples \{#examples\}
### Balance short headings \{#balance-short-headings\}
Compare ordinary wrapping with `text-balance` at the same width. Balancing redistributes short lines; the exact breaks depend on the available font and browser.

<DemoExample page="text-wrap" section="balance-short-headings" />

```html
<!-- text-wrap -->
<h2 id="target" class="w:240px max-w:100% m:0 font:md leading:24px text-wrap">Good tools make room for clear thinking.</h2>
```

```html
<!-- text-balance -->
<h2 id="target" class="w:240px max-w:100% m:0 font:md leading:24px text-balance">Good tools make room for clear thinking.</h2>
```

### Prefer pretty wrapping for prose \{#prefer-pretty-wrapping-for-prose\}
`text-pretty` asks the browser to improve line breaking, such as avoiding a very short final line. It is an algorithm choice; it does not guarantee a particular final word count.

<DemoExample page="text-wrap" section="prefer-pretty-wrapping-for-prose" />

```html
<!-- text-wrap -->
<p id="target" class="w:240px max-w:100% m:0 font:md leading:24px text-wrap">A clear reading rhythm gives each idea room to breathe. Keep the measure comfortable and let the content set the pace.</p>
```

```html
<!-- text-pretty -->
<p id="target" class="w:240px max-w:100% m:0 font:md leading:24px text-pretty">A clear reading rhythm gives each idea room to breathe. Keep the measure comfortable and let the content set the pace.</p>
```

### Prevent wrapping \{#prevent-wrapping\}
`text-nowrap` suppresses soft line breaks. This complete example gives the label a block box, a limited width and an ellipsis for hidden overflow.

<DemoExample page="text-wrap" section="prevent-wrapping" />

```html
<!-- One line · explicit overflow handling -->
<span id="target" class="block overflow:hidden w:200px max-w:100% m:0 font:md leading:24px text-ellipsis text-nowrap">quarterly-roadmap-final-version.pdf</span>
```

Keep the full label available in the surrounding UI when readers need it.

### Apply conditionally \{#apply-conditionally\}
Resize the viewport to switch from normal wrapping to balance at `sm`, then pretty at `lg`. Print uses ordinary wrapping.

<DemoExample page="text-wrap" section="apply-conditionally" />

```html
<!-- One heading · native viewport conditions -->
<h2 id="target" class="w:240px max-w:100% m:0 font:md leading:24px text-wrap text-wrap@print text-balance@screen&sm text-pretty@screen&lg">Good tools make room for clear thinking.</h2>
```

Use [white-space](/reference/white-space) to control preserved spaces and explicit line breaks.
