## Basic usage
### Play animation
Set it to run when the animation is paused.
<Basic className="animation-play-state:running" />

### Pause animation
Pauses the running animation.
<Basic className="animation-play-state:paused" />

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="animation-play-state:paused:hover animation-play-state:paused@sm animation-play-state:paused@dark animation-play-state:paused@print">…</div>
```
