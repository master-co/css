## Examples
### Run an animation
Use `animation-play-state:running` to ensure an animation is active when another state may pause it.
```html
<!-- @MARK animation-play-state:running -->
<div class="animation-duration:1s animation-iteration-count:infinite animation-name:rotate animation-play-state:running">
  Running
</div>
```

<details>
  <summary>Generated CSS</summary>
  <Class2CSS>
    {['animation-play-state:running']}
  </Class2CSS>
</details>

### Pause animation
Use `animation-play-state:paused` when an animation should stop without resetting its current frame.
```html
<!-- @MARK animation-play-state:paused -->
<button class="animation-duration:1s animation-iteration-count:infinite animation-name:rotate animation-play-state:paused:hover">
  Pause on hover
</button>
```

### Pause nonessential motion
Pause decoration when the user is interacting with the control or when the motion would compete with a more important state.
```html
<div class="animation-play-state:running animation-play-state:paused:focus-within">
  Interactive panel
</div>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="animation-play-state:paused:hover animation-play-state:paused@print animation-play-state:running@sm">...</div>
```
