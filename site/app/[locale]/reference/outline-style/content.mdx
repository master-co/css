## Examples \{#examples\}

### Set outline style \{#set-outline-style\}
Use `outline-solid` or `outline-dashed` to change only `outline-style`. These dedicated style utilities preserve the separately declared width and color.

<DemoExample page="outline-style" section="set-outline-style" />

```html
<!-- Solid · dedicated style utility -->
<button id="target" type="button"
  class="display:inline-flex align-items:center justify-content:center
         min-height:44px max-width:100% px-md py-sm
         border-width:1px border-style:solid b-line-divider r-sm outline-style:solid
         outline-offset-3xs outline-width:3px outline-blue
         font-md bg-surface-base fg-text-body box-sizing:border-box
         bg-surface-inset:focus-visible">
  Preview details
</button>
```

```html
<!-- Dashed · same width and color -->
<button id="target" type="button"
  class="display:inline-flex align-items:center justify-content:center
         min-height:44px max-width:100% px-md py-sm
         border-width:1px border-style:solid b-line-divider r-sm outline-style:dashed
         outline-offset-3xs outline-width:3px outline-blue
         font-md bg-surface-base fg-text-body box-sizing:border-box
         bg-surface-inset:focus-visible">
  Preview details
</button>
```

### Use dashed focus indicators \{#use-dashed-focus-indicators\}
Use Tab to focus the real skip link, then Enter to move to its destination. Its dashed outline is a keyboard focus treatment; the visible link remains available without focus.

<DemoExample page="outline-style" section="use-dashed-focus-indicators" />

```html
<!-- Native skip link · keyboard destination -->
<a id="target" href="#destination"
  class="display:inline-block outline-style:dashed
         outline-offset-3xs outline-width:3px
         outline-color:transparent
         text-decoration:underline fg-text-blue
         outline-blue:focus-visible">
  Skip to content
</a>
<section id="destination" tabindex="-1"
  class="mt-xl p-md bg-surface-inset fg-text-body">
  <h4 class="margin:0 font-lg">
    Preview content
  </h4>
  <p class="margin-inline:0 margin-bottom:0 mt-sm">
    The link moves keyboard focus here.
  </p>
</section>
```

Keep a real `href` and an appropriate destination. A decorative anchor with no destination is not a keyboard-operable skip link.

### Apply conditionally \{#apply-conditionally\}
The button has a solid resting outline. Keyboard focus changes only its style to dotted. Print removes the style and therefore the used outline width.

<DemoExample page="outline-style" section="apply-conditionally" />

```html
<!-- Solid → dotted on keyboard focus -->
<button id="target" type="button"
  class="display:inline-flex align-items:center justify-content:center
         min-height:44px max-width:100% px-md py-sm
         border-width:1px border-style:solid b-line-divider r-sm outline-style:solid
         outline-offset-3xs outline-width:3px outline-blue
         font-md bg-surface-base fg-text-body box-sizing:border-box
         bg-surface-inset:focus-visible
         outline-style:none@media(print)
         outline-style:dotted:focus-visible@media(screen)">
  Preview details
</button>
```

Set [outline width](/reference/outline-width) and [color](/reference/outline-color) independently.
