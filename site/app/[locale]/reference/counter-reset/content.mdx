## Basic usage
### Create a section counter
Use `counter-reset` to create a named counter and set its initial value. Regular counters default to `0`, so the first `counter-increment:section` produces `1`.
<Demo $py={0}>
  <DemoPanel>
    <article className="grid gap:2xl counter-reset:section">
      <h2 className="m:0 p:14x r:lg font-weight:560 font:xl bg:blue-5 text:neutral counter-increment:section font:semibold::before font:sm::before fg:blue-60::before content:'Section\00a0'counter(section)'.\00a0'::before bg:blue-95@dark">Setup</h2>
      <h2 className="m:0 p:14x r:lg font-weight:560 font:xl bg:blue-5 text:neutral counter-increment:section font:semibold::before font:sm::before fg:blue-60::before content:'Section\00a0'counter(section)'.\00a0'::before bg:blue-95@dark">Usage</h2>
    </article>
  </DemoPanel>
</Demo>
```html
<!-- @MARK counter-reset:section -->
<article class="counter-reset:section">
  <!-- @MARK counter-increment:section -->
  <!-- @MARK content:'Section\00a0'counter(section)'.\00a0'::before -->
  <h2 class="counter-increment:section content:'Section\00a0'counter(section)'.\00a0'::before">Setup</h2>
  <h2 class="counter-increment:section content:'Section\00a0'counter(section)'.\00a0'::before">Usage</h2>
</article>
```

### Start from another number
Add an integer after the counter name to choose its initial value.
<Demo $py={0}>
  <DemoPanel>
    <article className="counter-reset:chapter|4">
      <h2 className="m:0 p:3xl b:1px|solid|base r:lg font-weight:560 font:xl text:neutral counter-increment:chapter font:semibold::before font:sm::before fg:blue-60::before content:'Chapter\00a0'counter(chapter)':\00a0'::before">Advanced topics</h2>
    </article>
  </DemoPanel>
</Demo>
```html
<!-- @MARK counter-reset:chapter|4 -->
<article class="counter-reset:chapter|4">
  <!-- @MARK counter-increment:chapter -->
  <!-- @MARK content:'Chapter\00a0'counter(chapter)':\00a0'::before -->
  <h2 class="counter-increment:chapter content:'Chapter\00a0'counter(chapter)':\00a0'::before">Advanced topics</h2>
</article>
```

### Create a reversed counter
Use `reversed()` when a counter should count down from the number of items. Adjust the step with [`counter-increment`](/reference/counter-increment).
<Demo $py={0}>
  <DemoPanel>
    <ol className="grid-cols:3 gap:xl m:0 p:0 list-style:none counter-reset:reversed(step)">
      <li className="p:2xl r:lg text-center bg:gray-5 counter-increment:step|-1 block::before mb:xs::before font:2xl::before font:bold::before fg:blue-60::before content:counter(step)::before bg:gray-90@dark">
        <span className="font:sm">Final review</span>
      </li>
      <li className="p:2xl r:lg text-center bg:gray-5 counter-increment:step|-1 block::before mb:xs::before font:2xl::before font:bold::before fg:blue-60::before content:counter(step)::before bg:gray-90@dark">
        <span className="font:sm">Deploy</span>
      </li>
      <li className="p:2xl r:lg text-center bg:gray-5 counter-increment:step|-1 block::before mb:xs::before font:2xl::before font:bold::before fg:blue-60::before content:counter(step)::before bg:gray-90@dark">
        <span className="font:sm">Monitor</span>
      </li>
    </ol>
  </DemoPanel>
</Demo>
```html
<!-- @MARK counter-reset:reversed(step) -->
<ol class="list-style:none counter-reset:reversed(step)">
  <!-- @MARK counter-increment:step|-1 -->
  <!-- @MARK content:counter(step)::before -->
  <li class="counter-increment:step|-1 block::before content:counter(step)::before">Final review</li>
  <li class="counter-increment:step|-1 block::before content:counter(step)::before">Deploy</li>
  <li class="counter-increment:step|-1 block::before content:counter(step)::before">Monitor</li>
</ol>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="counter-reset:section:hover counter-reset:section@dark counter-reset:section@print counter-reset:section@sm">…</div>
```
