## Basic usage \{#basic-usage\}
### Create a section counter \{#create-a-section-counter\}
Create `section` with an initial value of zero. The first increment occurs on the first heading, so the displayed values begin at 1.

<DemoExample page="counter-reset" section="create-a-section-counter" />

```html
<!-- Scope · this article -->
<article id="target" class="counter-reset:section">
  <h2 class="margin-inline:0 mb-2xs margin-top:0 font-size-md font-weight-medium leading-lg
    counter-increment:section fg-text-blue::before
    content:counter(section)'.\00a0'::before">Setup</h2>
  <h2 class="margin-inline:0 mb-2xs margin-top:0 font-size-md font-weight-medium leading-lg
    counter-increment:section fg-text-blue::before
    content:counter(section)'.\00a0'::before">Usage</h2>
</article>
```

Resetting a counter creates a new instance at that element. Descendants use that instance; use [counter-set](/reference/counter-set) when you want to update the current value in the flow.

### Start from another number \{#start-from-another-number\}
Specify an integer after the counter name. This article initializes `chapter` to 4, then its headings increment to 5 and 6.

<DemoExample page="counter-reset" section="start-from-another-number" />

```html
<!-- Initial 4 · first heading 5 -->
<article id="target" class="counter-reset:chapter|4">
  <h2 class="margin-inline:0 mb-2xs margin-top:0 font-size-md font-weight-medium leading-lg
    counter-increment:chapter fg-text-blue::before
    content:counter(chapter)'.\00a0'::before">Advanced topics</h2>
  <h2 class="margin-inline:0 mb-2xs margin-top:0 font-size-md font-weight-medium leading-lg
    counter-increment:chapter fg-text-blue::before
    content:counter(chapter)'.\00a0'::before">Deployment</h2>
</article>
```

### Create a reversed counter \{#create-a-reversed-counter\}
Where supported, `reversed(step)` derives an initial value from the elements that decrement that counter. This three-item example counts 3, 2, 1. The base rule explicitly starts at 4, so unsupported browsers show the same countdown using the authored −1 step.

<DemoExample page="counter-reset" section="create-a-reversed-counter" />

```html
<!-- Native support · explicit countdown fallback -->
<p class="margin-inline:0 mb-2xs margin-top:0 font-size-sm display:none@supports((counter-reset:reversed(step)))">Explicit fallback · starts at 4</p>
<p class="display:none margin-inline:0 mb-2xs margin-top:0 font-size-sm
    display:block@supports((counter-reset:reversed(step)))">Native reversed() · item-derived start</p>
<ol id="target" role="list" reversed class="margin:0 padding:0 font-size-md leading-lg list-style:none counter-reset:step|4
    counter-reset:reversed(step)@supports((counter-reset:reversed(step)))">
  <li class="mb-2xs counter-increment:step|-1 fg-text-blue::before
    content:counter(step)'.\00a0'::before">Final review</li>
  <li class="mb-2xs counter-increment:step|-1 fg-text-blue::before
    content:counter(step)'.\00a0'::before">Deploy</li>
  <li class="mb-2xs counter-increment:step|-1 fg-text-blue::before
    content:counter(step)'.\00a0'::before">Monitor</li>
</ol>
```

The visible status and computed reset identify which rule your browser uses. The fallback’s 4 is authored for these three items; it does not automatically track added items. Check support in your target browsers, or use `<ol reversed>` for an ordinary reversed list.

### Apply conditionally \{#apply-conditionally\}
Resize past `sm` to initialize this chapter counter at 4 on screen. The headings change from 1, 2 to 5, 6. Print resets the initial value to zero.

<DemoExample page="counter-reset" section="apply-conditionally" />

```html
<!-- Real viewport · initial 0 or 4 -->
<article id="target" class="counter-reset:chapter counter-reset:chapter@media(print)
    counter-reset:chapter|4@media(screen)@sm">
  <h2 class="margin-inline:0 mb-2xs margin-top:0 font-size-md font-weight-medium leading-lg
    counter-increment:chapter fg-text-blue::before
    content:counter(chapter)'.\00a0'::before">Setup</h2>
  <h2 class="margin-inline:0 mb-2xs margin-top:0 font-size-md font-weight-medium leading-lg
    counter-increment:chapter fg-text-blue::before
    content:counter(chapter)'.\00a0'::before">Usage</h2>
</article>
```

The readout reports the article’s initial value, before any heading increments it.
