## Examples
### Force a snap stop
Use `scroll-snap-stop:always` on an important snap item when fast scrolling should not skip over it.
```html
<!-- @MARK scroll-snap-stop:always -->
<section class="scroll-snap:start scroll-snap-stop:always">
    Required step
</section>
```

<details>
    <summary>Generated CSS</summary>
    <Class2CSS>
        {['scroll-snap-stop:always']}

</details>

### Keep normal scroll momentum
Use `scroll-snap-stop:normal` for ordinary items where the browser can skip a snap point during fast scrolling.
```html
<!-- @MARK scroll-snap-stop:normal -->
<section class="scroll-snap:start scroll-snap-stop:normal">
    Optional step
</section>
```

### Use sparingly
Reserve `always` for onboarding steps, paged experiences, or essential panels. Too many forced stops can make scroll feel heavy.
```html
<section class="scroll-snap:start scroll-snap-stop:always">
    Confirm details
</section>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<section class="scroll-snap-stop:normal scroll-snap-stop:always@sm scroll-snap-stop:normal@print">...</section>
```
