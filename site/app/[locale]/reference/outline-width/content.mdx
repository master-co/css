## Examples \{#examples\}

### Set outline width \{#set-outline-width\}
A length in `outline:<size>` changes the outline width independently. Compare 2px and 6px outlines around identical buttons; their layout size does not grow.

<DemoExample page="outline-width" section="set-outline-width" />

```html
<!-- 2px outline · same layout box -->
<button id="target" type="button"
  class="display:inline-flex align-items:center justify-content:center
         min-height:44px max-width:100% px-md py-sm
         border:1px|solid|var(--color-line-divider) r-sm outline-style:solid
         outline-offset-3xs outline-width:2px outline-blue
         font-md bg-surface-base fg-text-body box-sizing:border-box
         bg-surface-inset:focus-visible">
  Preview details
</button>
```

```html
<!-- 6px outline · paint grows outward -->
<button id="target" type="button"
  class="display:inline-flex align-items:center justify-content:center
         min-height:44px max-width:100% px-md py-sm
         border:1px|solid|var(--color-line-divider) r-sm outline-style:solid
         outline-offset-3xs outline-width:6px outline-blue
         font-md bg-surface-base fg-text-body box-sizing:border-box
         bg-surface-inset:focus-visible">
  Preview details
</button>
```

### Use keyword widths \{#use-keyword-widths\}
Use `outline-thin`, `outline-medium` and `outline-thick` for native keyword widths without resetting style or color. The explicit `outline-width:*` longhands are equivalent. Read the browser’s resolved pixel values below.

<DemoExample page="outline-width" section="use-keyword-widths" />

```html
<!-- Thin · native width keyword -->
<button id="target" type="button"
  class="display:inline-flex align-items:center justify-content:center
         min-height:44px max-width:100% px-md py-sm
         border:1px|solid|var(--color-line-divider) r-sm outline-style:solid
         outline-width:thin outline-offset-3xs outline-blue
         font-md bg-surface-base fg-text-body box-sizing:border-box
         bg-surface-inset:focus-visible">
  Preview details
</button>
```

```html
<!-- Medium · native width keyword -->
<button id="target" type="button"
  class="display:inline-flex align-items:center justify-content:center
         min-height:44px max-width:100% px-md py-sm
         border:1px|solid|var(--color-line-divider) r-sm outline-width:medium
         outline-style:solid outline-offset-3xs
         outline-blue font-md bg-surface-base
         fg-text-body box-sizing:border-box
         bg-surface-inset:focus-visible">
  Preview details
</button>
```

```html
<!-- Thick · native width keyword -->
<button id="target" type="button"
  class="display:inline-flex align-items:center justify-content:center
         min-height:44px max-width:100% px-md py-sm
         border:1px|solid|var(--color-line-divider) r-sm outline-style:solid
         outline-width:thick outline-offset-3xs
         outline-blue font-md bg-surface-base
         fg-text-body box-sizing:border-box
         bg-surface-inset:focus-visible">
  Preview details
</button>
```

These keywords resolve to lengths. `outline:thin` is instead a full shorthand with the style omitted; that resets the style to `none` and leaves no visible outline. A visible style must be supplied.

### Apply conditionally \{#apply-conditionally\}
Keyboard focus increases the outline from 2px to 4px. Width grows into the surrounding paint area without moving or resizing the button. Print removes the outline width.

<DemoExample page="outline-width" section="apply-conditionally" />

```html
<!-- 2px → 4px on keyboard focus -->
<button id="target" type="button"
  class="display:inline-flex align-items:center justify-content:center
         min-height:44px max-width:100% px-md py-sm
         border:1px|solid|var(--color-line-divider) r-sm outline-style:solid
         outline-offset-3xs outline-width:2px outline-blue
         font-md bg-surface-base fg-text-body box-sizing:border-box
         bg-surface-inset:focus-visible
         outline-width:0@print
         outline-width:4px:focus-visible@screen">
  Preview details
</button>
```

Use [outline-offset](/reference/outline-offset) to change the gap independently of thickness.
