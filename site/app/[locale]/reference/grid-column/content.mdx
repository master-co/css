## Basic usage
### Place an item by columns
Use `grid-column` to place an item between column grid lines.
<Demo $py={0}>
  <DemoPanel>
    <div className="grid grid-cols:4 grid-template-rows:64px gap:2x">
      <div className="grid-column:2/4 min-w:0 p:3x border:1px|solid|blue-20 r:8px bg:blue-5 border-color:blue-80@dark bg:blue-95@dark">
        <div className="overflow:hidden font-weight:700 font:11px text-ellipsis white-space:nowrap fg:blue-60">grid-column:2/4</div>
        <div className="font-weight:560 font:14px text:neutral">Item</div>
      </div>
    </div>
  </DemoPanel>
</Demo>
```html
<!-- @MARK grid-column:2/4 -->
<div class="grid-column:2/4">Item</div>
```

### Span columns
```html
<!-- @MARK grid-col-span:2 -->
<div class="grid-col-span:2">Spans two columns</div>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="grid-column:2/4:hover grid-column:2/4@dark grid-column:2/4@print grid-column:2/4@sm">…</div>
```
