## Examples \{#examples\}
### Apply filter functions \{#apply-filter-functions\}
Filter functions process the element’s painted result in their written order. Compare the complete source with blur followed by brightness, using the same image dimensions.

<DemoExample page="filter" section="apply-filter-functions" />

```html
<!-- Original · sharp source -->
<img id="target" src="/demo/landscape.svg"
  width="320" height="200"
  alt="Blue and violet mountains beneath a yellow sun"
  class="display:block height:137.5px width:220px max-width:100% m-md
         filter:none object-fit:cover" />
```

```html
<!-- Blur then dim · one filter list -->
<img id="target" src="/demo/landscape.svg"
  width="320" height="200"
  alt="Blue and violet mountains beneath a yellow sun"
  class="display:block height:137.5px width:220px max-width:100% m-md
         filter:blur(4px)|brightness(.8) object-fit:cover" />
```

<details>
  <summary>Generated CSS</summary>
  <Class2CSS>
    {['filter:blur(4px)|brightness(.8)']}
  </Class2CSS>
</details>

The margin leaves room for blur outside the layout box. A filter changes paint, including descendants, without changing the measured box. Replacing the filter value replaces the whole function list.

### Use drop shadow for transparent images \{#use-drop-shadow-for-transparent-images\}
Drop-shadow follows the source’s alpha silhouette. The same transparent SVG makes its difference from a rectangular box shadow visible.

<DemoExample page="filter" section="use-drop-shadow-for-transparent-images" />

```html
<!-- Drop shadow · follows the shapes -->
<svg id="target" role="img"
  aria-label="Circle and diamond"
  width="160" height="120" viewBox="0 0 160 120"
  class="display:block m-md
         filter:drop-shadow(0|4px|2px|#7c3aed)">
  <circle cx="48" cy="60" r="28" fill="#2563eb" />
  <path d="M100 30 140 60 100 90 60 60Z" fill="#7c3aed" />
</svg>
```

```html
<!-- Box shadow · follows the viewport box -->
<svg id="target" role="img"
  aria-label="Circle and diamond"
  width="160" height="120" viewBox="0 0 160 120"
  class="display:block m-md box-shadow:0|4px|2px|#7c3aed">
  <circle cx="48" cy="60" r="28" fill="#2563eb" />
  <path d="M100 30 140 60 100 90 60 60Z" fill="#7c3aed" />
</svg>
```

The empty SVG corners cast no drop-shadow. A box shadow follows the SVG element’s rectangular box, even where its contents are transparent. Both samples reserve the same margin around their paint.

### Reset filters \{#reset-filters\}
Use `filter:none` to remove the entire chain. Open print preview to restore this filtered image without changing its dimensions.

<DemoExample page="filter" section="reset-filters" />

```html
<!-- Filtered on screen · original in print -->
<img id="target" src="/demo/landscape.svg"
  width="320" height="200"
  alt="Blue and violet mountains beneath a yellow sun"
  class="display:block height:137.5px width:220px max-width:100% m-md
         filter:blur(4px)|brightness(.8) object-fit:cover
         filter:none@media(print)" />
```

The print rule resets blur and brightness together. To keep one effect, provide the desired complete filter list instead of none.

### Apply conditionally \{#apply-conditionally\}
Hover or keyboard-focus the native button to restore its colors. The filter includes the artwork and label; print always uses the unfiltered result.

<DemoExample page="filter" section="apply-conditionally" />

```html
<!-- Grayscale → color on hover or focus -->
<button id="target" type="button"
  class="display:block padding:0 border:1px|solid|var(--color-line-divider) r-sm
         bg-surface-base fg-text-body
         filter:grayscale(1) filter:none@media(print)
         filter:none:hover@media(screen)
         filter:none:focus-visible@media(screen)">
  <img src="/demo/landscape.svg"
  width="320" height="200"
  alt=""
  class="display:block height:137.5px width:220px max-width:100%
         object-fit:cover" />
  <span class="display:block p-sm font-md">
    Preview artwork
  </span>
</button>
```

The button keeps the accessible name “Preview artwork”; the image is decorative within it. The native focus ring remains visible. Evaluate large filtered areas in the actual interface rather than assuming a performance gain.
