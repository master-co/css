## Examples \{#examples\}
### Apply filter functions \{#apply-filter-functions\}
Use `filter:*` with functions such as `blur(...)`, `brightness(...)`, and `drop-shadow(...)` to apply CSS filters.
```html
<!-- @MARK filter:blur(4px)|brightness(.8) -->
<img class="filter:blur(4px)|brightness(.8)" src="..." alt="" />
```

### Use drop shadow for transparent images \{#use-drop-shadow-for-transparent-images\}
Use `filter:drop-shadow(...)` when the shadow should follow the alpha shape of an image or SVG.
```html
<!-- @MARK filter:drop-shadow(0|2px|4px|black/.2) -->
<img class="filter:drop-shadow(0|2px|4px|black/.2)" src="..." alt="" />
```

Use [box-shadow](/reference/box-shadow) for the element box instead.

### Reset filters \{#reset-filters\}
Use `filter:none` to remove filters at a breakpoint or state.
```html
<!-- @MARK filter:none -->
<img class="filter:none@print" src="..." alt="" />
```

### Apply conditionally \{#apply-conditionally\}
Apply styles based on different states using [selectors](/reference/rules/selectors) and [conditional queries](/reference/rules/conditions).
```html
<div class="filter:none filter:blur(4px):hover filter:none@print">...</div>
```

Filters can be expensive on large areas; use them where the visual benefit is clear.
