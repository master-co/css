## Examples \{#examples\}
### Set a fixed or fluid width \{#set-a-fixed-or-fluid-width\}
`width:*` sets the physical width. Compare a fixed `width:12rem` (192px with the default 4px unit) with `width:100%` inside the same 280px containing block. Percentages follow the parent; a fixed width does not.

<DemoExample page="width" section="set-a-fixed-or-fluid-width" />

```html
<!-- Fixed · 192px -->
<div id="layout" class="width:17.5rem max-width:100%" role="group" aria-label="Available space">
  <div id="target" class="width:12rem p-sm">Fixed width</div>
</div>
```

```html
<!-- Fluid · 100% -->
<div id="layout" class="width:17.5rem max-width:100%" role="group" aria-label="Available space">
  <div id="target" class="width:100% p-sm">Full width</div>
</div>
```

Widths use the configured [sizing scale](/guide/sizing), container tokens, native units or functions. These examples use border-box sizing, so the displayed width includes padding. See [box-sizing](/reference/box-sizing) for the content-box alternative.

### Use percentages for proportional layout \{#use-percentages-for-proportional-layout\}
`width:50%` takes half the containing block’s width. The same class resolves to 140px in a 280px parent and 100px in a 200px parent. No breakpoint is needed for this proportional behavior.

<DemoExample page="width" section="use-percentages-for-proportional-layout" />

```html
<!-- Parent · 280px -->
<div id="layout" class="width:17.5rem max-width:100%" role="group" aria-label="Available space">
  <div id="target" class="width:50% p-sm">50%</div>
</div>
```

```html
<!-- Parent · 200px -->
<div id="layout" class="width:12.5rem max-width:100%" role="group" aria-label="Available space">
  <div id="target" class="width:50% p-sm">50%</div>
</div>
```

### Use intrinsic width keywords \{#use-intrinsic-width-keywords\}
`width:min-content` uses the narrowest width allowed by the content’s normal wrap opportunities. `width:max-content` keeps the text on one unwrapped line. `width:fit-content` uses available space between those bounds. Compare the same words inside 112px parents.

<DemoExample page="width" section="use-intrinsic-width-keywords" />

```html
<!-- Minimum content -->
<div id="layout" class="width:7rem" role="group" aria-label="Available space">
  <div id="target" class="width:min-content p-sm font-md font-mono line-height:24px">Design systems</div>
</div>
```

```html
<!-- Fit content -->
<div id="layout" class="width:7rem" role="group" aria-label="Available space">
  <div id="target" class="width:fit-content p-sm font-md font-mono line-height:24px">Design systems</div>
</div>
```

```html
<!-- Maximum content -->
<div id="layout" class="width:7rem" role="group" aria-label="Available space">
  <div id="target" class="width:max-content p-sm font-md font-mono line-height:24px">Design systems</div>
</div>
```

An intrinsic width can exceed its parent when even the smallest unbreakable piece is too wide. Wrapping, clipping and scrolling are separate decisions.

### Use container widths for wrappers \{#use-container-widths-for-wrappers\}
Combine `width:100%` with a container-token maximum and automatic inline margins. This wrapper fills the available space until `max-w-3xs` caps it at 256px in the default theme; `margin-inline:auto` divides any remaining inline space equally.

<DemoExample page="width" section="use-container-widths-for-wrappers" />

```html
<div id="layout" class="width:100%" role="group" aria-label="Available space">
  <div id="target" class="width:100% max-w-3xs margin-inline:auto p-sm">Centered wrapper</div>
</div>
```

Use a larger container token for a full page. The small token here makes the cap visible in the documentation column; project theme declarations can change token values.

### Apply conditionally \{#apply-conditionally\}
Use [conditional queries](/reference/rules/conditions) to change the preferred width. Resize the real iframe past `sm`: the blue panel changes from its parent’s full 280px width to 50%, or 140px.

<DemoExample page="width" section="apply-conditionally" />

```html
<div id="layout" class="width:17.5rem max-width:100%" role="group" aria-label="Available space">
  <div id="target" class="width:100% p-sm width:50%@sm">Responsive panel</div>
</div>
```

For both physical axes, use [size](/reference/size). For bounds, use [min-width](/reference/min-width) and [max-width](/reference/max-width).
