## Examples
### Keep characters upright
Use `text:upright` with vertical writing when each character should remain upright instead of rotating sideways.
```html
<!-- @MARK text:upright -->
<p class="writing-mode:vertical-rl text:upright">2026</p>
```

<details>
    <summary>Generated CSS</summary>
    <Class2CSS>
        {['text:upright']}

### Use mixed orientation
Use `text:mixed` to let the browser rotate horizontal scripts while keeping vertical scripts upright.
```html
<!-- @MARK text:mixed -->
<p class="writing-mode:vertical-rl text:mixed">Label 2026</p>
```

### Use sideways orientation
Use `text:sideways` when text should rotate as a run inside a vertical flow.
```html
<!-- @MARK text:sideways -->
<p class="writing-mode:vertical-rl text:sideways">Side label</p>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<p class="text:upright:hover text:mixed@sm text:mixed@print">...</p>
```
