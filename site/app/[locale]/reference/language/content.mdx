```bash action=install
@master/css-language
```
It allows styling (syntax highlighting) and to make the text editor “smart” about which context the caret is in.

## Basic usage
### Import the textmate grammars
The `grammars` array object is compatible with [Shiki](https://shiki.matsu.io/guide/load-lang) `LanguageRegistration[]`.
```js
import { grammars } from '@master/css-language'
```
Or import the grammars module:
```js
import grammars from '@master/css-language/grammars'
```

### Static and dynamic highlighting
This package provides static [TextMate](https://macromates.com/manual/en/language_grammars) grammars. They are loaded by VS Code, Shiki, and other grammar consumers before any project configuration is known.

Static grammar highlighting is intentionally configuration-independent. It can recognize stable Master CSS syntax such as declarations, values, selectors, queries, groups, functions, and punctuation, but it cannot know whether a token such as `brand`, `btn`, or `surface` comes from your `master.css.*` configuration.

For configuration-aware highlighting, use the [language service](/reference/language-service#settingsrendersemantictokens) through the [language server](/reference/language-server#semantic-tokens). The language server loads the workspace configuration, creates a configured Master CSS engine, and returns LSP semantic tokens for custom variables, components, utilities, and other parsed class parts.

## Integrating
### Shiki
[Shiki](https://shiki.matsu.io/) is a beautiful syntax highlighter. It uses TextMate grammars to provide syntax highlighting for a wide range of languages. You can use the Master CSS TextMate grammars with Shiki to provide syntax highlighting for Master CSS.
```ts name=highlighter.ts
import { createHighlighterCore } from 'shiki/core'
import { createJavaScriptRegexEngine } from 'shiki/engine/javascript'
import masterCSSLangDeclaration from '@master/css-language/declaration'

export default function createHighlighter() {
    const langAlias: Record<string, string> = {}
    masterCSSLangDeclaration.aliases.forEach(alias => {
        langAlias[alias] = masterCSSLangDeclaration.id
    })
    return createHighlighterCore({
        langs: [
            import('@shikijs/langs/html'),
            import('@shikijs/langs/javascript'),
            ...,
            import('@master/css-language/grammars') // [!code highlight]
        ],
        themes: [
            import('@shikijs/themes/dracula'),
            ...
        ],
        langAlias,
        engine: createJavaScriptRegexEngine(),
    })
}

export const themes = {
    dark: 'dracula',
    light: 'min-light'
}
```
Highlight a string:
```ts
highlighter.codeToHtml('text:center font:32@md', { lang: 'mcss' })
```
```mcss
text:center font:32@md
```
Highlight a template:
```ts
highlighter.codeToHtml(html, { lang: 'html' })
```
```html
<div class="text:center font:32@md">
    <p>Master CSS</p>
</div>
```

Shiki uses the static grammar data from this package. It does not load project configuration or render LSP semantic tokens by itself.

Use the language service Shiki transformer when you need configuration-aware semantic token classes in Shiki output:
```ts
import { transformerMasterCSSSemanticTokens } from '@master/css-language-service/shiki'
import config from './master.css'

highlighter.codeToHtml(html, {
    lang: 'html',
    transformers: [
        transformerMasterCSSSemanticTokens({ config })
    ]
})
```
The transformer decorates Shiki spans with classes such as `mcss-semantic-class`, `mcss-semantic-class-declaration`, `mcss-semantic-property`, `mcss-semantic-variable`, `mcss-semantic-type`, and `mcss-semantic-modifier`. Style those classes in CSS, or use `semanticTokenStyles` when inline styles are required.

### Monaco Editor
The [Monaco Editor](https://github.com/microsoft/monaco-editor) is the fully featured code editor from VS Code. Integrate Monaco Editor based on the above [shiki](#shiki) setup.
```ts
import { shikiToMonaco } from '@shikijs/monaco'
import * as monaco from 'monaco-editor-core'
import highlighter from './highlighter'

// ...

shikiToMonaco(highlighter, monaco)
```
See the [@shikijs/monaco](https://shiki.matsu.io/packages/monaco) documentation.

If your Monaco integration also needs configuration-aware Master CSS highlighting, pair the static grammar with the [language service](/reference/language-service) semantic token API.
