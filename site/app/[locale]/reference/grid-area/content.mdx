## Basic usage
### Place an item by grid lines
Use `grid-area` to place a grid item by `row-start / column-start / row-end / column-end`.
<Demo $py={0}>
    <DemoPanel>
        <div className="grid grid-cols:3 grid-template-rows:64|88|88 gap:2x">
            <div className="grid-area:1/1/2/4 min-w:0 p:3x r:8px bg:blue-5 bg:blue-95@dark border:1px|solid|blue-20 border-color:blue-80@dark overflow:hidden">
                <div className="fg:blue-60 font:11px font-weight:700 mb:1x text-ellipsis overflow:hidden white-space:nowrap">grid-area:1/1/2/4</div>
                <div className="fg:strong font:16px font-weight:560 text-ellipsis overflow:hidden white-space:nowrap">Header</div>
            </div>
            <div className="grid-area:2/1/4/2 min-w:0 p:3x r:8px bg:gray-5 bg:gray-90@dark overflow:hidden">
                <div className="fg:muted font:11px font-weight:700 mb:1x text-ellipsis overflow:hidden white-space:nowrap">2/1/4/2</div>
                <div className="fg:strong font:14px font-weight:560 text-ellipsis overflow:hidden white-space:nowrap">Nav</div>
            </div>
            <div className="grid-area:2/2/4/4 min-w:0 p:3x r:8px bg:gray-5 bg:gray-90@dark overflow:hidden">
                <div className="fg:muted font:11px font-weight:700 mb:1x text-ellipsis overflow:hidden white-space:nowrap">2/2/4/4</div>
                <div className="fg:strong font:14px font-weight:560 text-ellipsis overflow:hidden white-space:nowrap">Content</div>
            </div>
        </div>
    </DemoPanel>
</Demo>
```html
<div class="grid grid-cols:3 grid-template-rows:64|88|88">
    <!-- @MARK grid-area:1/1/2/4 -->
    <header class="grid-area:1/1/2/4">Header</header>

    <!-- @MARK grid-area:2/1/4/2 -->
    <nav class="grid-area:2/1/4/2">Navigation</nav>

    <!-- @MARK grid-area:2/2/4/4 -->
    <main class="grid-area:2/2/4/4">Content</main>
</div>
```

### Span tracks
Use `span` values when the item should cover a number of rows or columns from its starting line.
<Demo $py={0}>
    <DemoPanel>
        <div className="grid grid-cols:4 grid-template-rows:64|64|64 gap:2x">
            <div className="grid-area:2/2/span|2/span|2 min-w:0 p:3x r:8px bg:blue-5 bg:blue-95@dark border:1px|solid|blue-20 border-color:blue-80@dark overflow:hidden">
                <div className="fg:blue-60 font:11px font-weight:700 mb:1x text-ellipsis overflow:hidden white-space:nowrap">2/2/span 2/span 2</div>
                <div className="fg:strong font:14px font-weight:560 text-ellipsis overflow:hidden white-space:nowrap">Featured</div>
            </div>
            <div className="grid-area:1/1/2/5 min-w:0 p:3x r:8px bg:gray-5 bg:gray-90@dark fg:muted font:13px text-ellipsis overflow:hidden white-space:nowrap">Toolbar</div>
            <div className="grid-area:2/1/4/2 min-w:0 p:3x r:8px bg:gray-5 bg:gray-90@dark fg:muted font:13px text-ellipsis overflow:hidden white-space:nowrap">Aside</div>
            <div className="grid-area:2/4/4/5 min-w:0 p:3x r:8px bg:gray-5 bg:gray-90@dark fg:muted font:13px text-ellipsis overflow:hidden white-space:nowrap">Notes</div>
        </div>
    </DemoPanel>
</Demo>
```html
<!-- @MARK grid-area:2/2/span|2/span|2 -->
<section class="grid-area:2/2/span|2/span|2">Featured panel</section>
```

### Use a named area
`grid-area` also accepts a custom identifier that matches a named area from [`grid-template-areas`](/reference/grid-template-areas).
```html
<!-- @MARK grid-area:hero -->
<section class="grid-area:hero">Hero</section>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="grid-area:auto:hover grid-area:auto@sm grid-area:auto@dark grid-area:auto@print">…</div>
```
