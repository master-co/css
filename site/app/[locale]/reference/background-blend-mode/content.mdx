## Examples
### Blend background layers
Use `background-blend-mode:*` when multiple background layers or a background image and color should blend together.
```html
<!-- @MARK bg:url(/hero.jpg) --><!-- @MARK bg:blue-60/.4 --><!-- @MARK background-blend-mode:multiply -->
<section class="background-blend-mode:multiply bg:blue-60/.4 bg:url(/hero.jpg)">
    ...
</section>
```

<details>
    <summary>Generated CSS</summary>
    <Class2CSS>
        {['bg:url(/hero.jpg)', 'bg:blue-60/.4', 'background-blend-mode:multiply']}
    </Class2CSS>
</details>

### Restore normal blending
Use `background-blend-mode:normal` to remove a blend mode at a breakpoint or state.
```html
<!-- @MARK background-blend-mode:normal -->
<section class="background-blend-mode:normal">...</section>
```

For blending the whole element with content behind it, use [mix-blend-mode](/reference/mix-blend-mode).

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="background-blend-mode:normal background-blend-mode:normal@print background-blend-mode:multiply@sm">...</div>
```

Check contrast after blending, especially when text sits on top of the background.
