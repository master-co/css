## Examples
### Set the full outline shorthand
Use `outline:*` when width, style, and color should be set together.
```html
<!-- @MARK outline:2px|solid|blue -->
<button class="outline:2px|solid|blue">
    Focused action
</button>
```

### Keep outlines for focus
Outlines do not affect layout and are important for keyboard focus. If you customize them, keep a visible focus style.
```html
<!-- @MARK outline:2px|solid|primary --><!-- @MARK outline-offset:2x -->
<button class="outline:2px|solid|primary outline-offset:2x:focus">
    Save
</button>
```

Use [outline-width](/reference/outline-width), [outline-style](/reference/outline-style), [outline-color](/reference/outline-color), and [outline-offset](/reference/outline-offset) for focused changes.

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="outline:0 outline:2px|solid|primary:focus outline:0@print">...</div>
```

Avoid removing focus outlines unless another visible focus indicator replaces them.
