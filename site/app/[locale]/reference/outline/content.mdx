## Examples \{#examples\}

### Set the full outline shorthand \{#set-the-full-outline-shorthand\}
Combine width, style and color in one outline shorthand. Compare an explicit 4px blue outline with `outline:solid`, which uses the native `medium` width and current foreground color.

<DemoExample page="outline" section="set-the-full-outline-shorthand" />

```html
<!-- Full shorthand · explicit components -->
<button id="target" type="button"
  class="display:inline-flex align-items:center justify-content:center
         min-height:44px max-width:100% px-md py-sm
         border:1px|solid|var(--color-line-divider) r-sm outline:4px|solid|var(--color-blue)
         outline-offset-3xs font-md bg-surface-base
         fg-text-body box-sizing:border-box
         bg-surface-inset:focus-visible">
  Preview details
</button>
```

```html
<!-- Style-only shorthand · other components reset -->
<button id="target" type="button"
  class="display:inline-flex align-items:center justify-content:center
         min-height:44px max-width:100% px-md py-sm
         border:1px|solid|var(--color-line-divider) r-sm outline:solid
         outline-offset-3xs font-md bg-surface-base
         fg-text-body box-sizing:border-box
         bg-surface-inset:focus-visible">
  Preview details
</button>
```

<details>
  <summary>Generated CSS</summary>
  <Class2CSS>
    {['outline:4px|solid|var(--color-blue)', 'outline:solid']}
  </Class2CSS>
</details>

The shorthand resets outline width, style and color. It does not reset `outline-offset`. The outline paints around the box without taking layout space.

### Keep outlines for focus \{#keep-outlines-for-focus\}
Use Tab to focus this button. Its transparent resting outline becomes blue on keyboard focus. The button and neighboring content keep their layout dimensions.

<DemoExample page="outline" section="keep-outlines-for-focus" />

```html
<!-- Keyboard focus · visible blue ring -->
<button id="target" type="button"
  class="display:inline-flex align-items:center justify-content:center
         min-height:44px max-width:100% px-md py-sm
         border:1px|solid|var(--color-line-divider) r-sm
         outline:2px|solid|transparent
         outline-offset-3xs font-md bg-surface-base
         fg-text-body box-sizing:border-box
         outline-blue:focus-visible
         bg-surface-inset:focus-visible">
  Save changes
</button>
```

A custom focus treatment must remain visible. The outline follows the real `:focus-visible` state; a pointer click does not necessarily trigger that state. Use [outline-offset](/reference/outline-offset) to leave space around the edge.

### Apply conditionally \{#apply-conditionally\}
Keyboard focus draws a 3px blue outline on screen. Print removes its width. The border and content remain unchanged.

<DemoExample page="outline" section="apply-conditionally" />

```html
<!-- Keyboard focus on screen · no printed ring -->
<button id="target" type="button"
  class="display:inline-flex align-items:center justify-content:center
         min-height:44px max-width:100% px-md py-sm
         border:1px|solid|var(--color-line-divider) r-sm outline:0|solid|var(--color-blue)
         outline-offset-3xs font-md bg-surface-base
         fg-text-body box-sizing:border-box
         bg-surface-inset:focus-visible
         outline-width:0@media(print)
         outline:3px|solid|var(--color-blue):focus-visible@media(screen)">
  Preview details
</button>
```

The screen qualification prevents the focus rule from overriding the print reset. Never remove the only visible keyboard focus indicator.
