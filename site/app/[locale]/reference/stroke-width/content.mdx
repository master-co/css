## Examples \{#examples\}
### Set SVG stroke width \{#set-svg-stroke-width\}
Use `stroke:*` with a size value to set `stroke-width`.
```html
<!-- @MARK stroke:2 -->
<svg class="stroke:2" viewBox="0 0 16 16" aria-hidden="true">
  <path d="M2 8h12" />
</svg>
```

<details>
  <summary>Generated CSS</summary>
  <Class2CSS>
    {['stroke:2']}
  </Class2CSS>
</details>

### Pair width with stroke color \{#pair-width-with-stroke-color\}
Use [stroke](/reference/stroke) for paint and `stroke:*` size values for thickness.
```html
<!-- @MARK stroke:current --><!-- @MARK stroke:1.5 -->
<svg class="stroke:current stroke:1.5" aria-hidden="true"></svg>
```

Very thick strokes may need adjusted SVG viewBox or line caps to avoid clipping.

### Apply conditionally \{#apply-conditionally\}
Apply styles based on different states using [selectors](/reference/rules/selectors) and [conditional queries](/reference/rules/conditions).
```html
<svg class="stroke:1 stroke:1@print stroke:2@sm">...</svg>
```
