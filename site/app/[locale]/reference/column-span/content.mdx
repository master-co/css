## Examples
### Span across all columns
Use `column-span:all` for headings, pull quotes, or media that should break out of a multi-column flow.
```html
<!-- @MARK column-span:all -->
<h2 class="column-span:all">
  Section heading
</h2>
```

### Does not span multiple columns
Use `column-span:none` to keep an element inside the current column.
```html
<!-- @MARK column-span:none -->
<p class="column-span:none">
  Regular column content
</p>
```

### Use inside multi-column layouts
Column spanning only matters in a multi-column formatting context.
```html
<article class="columns:3">
  <h2 class="column-span:all">Report</h2>
  <p>Column content</p>
</article>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<h2 class="column-span:none column-span:all@print column-span:all@sm">...</h2>
```
