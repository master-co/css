## Examples
### Span across all columns
Use `col-span:all` for headings, pull quotes, or media that should break out of a multi-column flow.
```html
<!-- @MARK col-span:all -->
<h2 class="col-span:all">
    Section heading
</h2>
```

<details>

### Does not span multiple columns
Use `col-span:none` to keep an element inside the current column.
```html
<!-- @MARK col-span:none -->
<p class="col-span:none">
    Regular column content
</p>
```

### Use inside multi-column layouts
Column spanning only matters in a multi-column formatting context.
```html
<article class="columns:3">
    <h2 class="col-span:all">Report</h2>
    <p>Column content</p>
</article>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<h2 class="col-span:none col-span:all@sm col-span:all@print">...</h2>
```
