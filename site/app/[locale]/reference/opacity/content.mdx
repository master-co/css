## Examples \{#examples\}
### Fade an entire element \{#fade-an-entire-element\}
Use `opacity:*` to change the opacity of the whole element, including its text, background, border, and children.
```html
<!-- @MARK opacity:.5 -->
<button class="opacity:.5">
  Preview
</button>
```

  <Class2CSS>
    {['opacity:.5']}
  </Class2CSS>

Opacity changes appearance; it does not disable a button or change its interaction behavior.

### Prefer color alpha for surfaces \{#prefer-color-alpha-for-surfaces\}
When only a color should be translucent, use the color alpha suffix instead of reducing the whole element opacity.
```html
<!-- @MARK bg:blue-60/.12 --><!-- @MARK fg:blue-60 -->
<span class="bg:blue-60/.12 fg:blue-60">Status</span>
```

This keeps text and child content fully opaque.

### Apply conditionally \{#apply-conditionally\}
Apply styles based on different states using [selectors](/reference/rules/selectors) and [conditional queries](/reference/rules/conditions).
```html
<div class="opacity:1 opacity:.72:hover opacity:1@print">...</div>
```

Use opacity transitions with care for content that must remain readable.
