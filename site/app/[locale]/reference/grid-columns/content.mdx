## Basic usage
### Create equal columns
Use `grid-cols` to create an equal-width column grid. It also sets `display:grid`.
<Demo $py={0}>
    <DemoPanel>
        <div className="grid-cols:3 gap:2x">
            <div className="min-w:0 p:3x r:8 bg:blue-5 bg:blue-95@dark border:1|solid|blue-20 border-color:blue-80@dark text:center">1</div>
            <div className="min-w:0 p:3x r:8 bg:gray-5 bg:gray-90@dark text:center">2</div>
            <div className="min-w:0 p:3x r:8 bg:gray-5 bg:gray-90@dark text:center">3</div>
        </div>
    </DemoPanel>
</Demo>
```html
<!-- @MARK grid-cols:3 -->
<div class="grid-cols:3">
    <div>1</div><div>2</div><div>3</div>
</div>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="grid-cols:3:hover grid-cols:3@sm grid-cols:3@dark grid-cols:3@print">…</div>
```
