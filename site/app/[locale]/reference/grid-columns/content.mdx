## Basic usage
### Create equal columns
Use `grid-cols` to create an equal-width column grid. It also sets `display:grid`.
<Demo $py={0}>
  <DemoPanel>
    <div className="grid-cols:3 gap:xs">
      <div className="min-w:0 p:sm b:1px|solid|blue-20 r:lg text-center bg:blue-5 b:blue-80@dark bg:blue-95@dark">1</div>
      <div className="min-w:0 p:sm r:lg text-center bg:gray-5 bg:gray-90@dark">2</div>
      <div className="min-w:0 p:sm r:lg text-center bg:gray-5 bg:gray-90@dark">3</div>
    </div>
  </DemoPanel>
</Demo>
```html
<!-- @MARK grid-cols:3 -->
<div class="grid-cols:3">
  <div>1</div><div>2</div><div>3</div>
</div>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="grid-cols:3:hover grid-cols:3@dark grid-cols:3@print grid-cols:3@sm">…</div>
```
