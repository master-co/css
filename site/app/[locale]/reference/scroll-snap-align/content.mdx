## Examples \{#examples\}
### Align a snap item to the start \{#align-a-snap-item-to-the-start\}
Use `snap-start` on child items inside a snapping scroll container.
```html
<!-- @MARK snap-start -->
<article class="snap-start">
  Slide
</article>
```

<details>
  <summary>Generated CSS</summary>

</details>

### Center snap items \{#center-snap-items\}
Use `snap-center` when cards should settle in the middle of the scroll viewport.
```html
<!-- @MARK snap-center -->
<article class="snap-center">
  Featured card
</article>
```

### Disable item snapping \{#disable-item-snapping\}
Use `scroll-snap-align:none` for an item inside a snapping container that should not become a stop.
```html
<!-- @MARK scroll-snap-align:none -->
<article class="scroll-snap-align:none">
  Spacer
</article>
```

### Apply conditionally \{#apply-conditionally\}
Apply styles based on different states using [selectors](/reference/rules/selectors) and [conditional queries](/reference/rules/conditions).
```html
<article class="snap-start scroll-snap-align:none@print snap-center@sm">...</article>
```
