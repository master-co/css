## Basic usage
### Set a counter on one item
Use `counter-set` to set an existing counter to a specific value on selected elements. MDN recommends [`counter-reset`](/reference/counter-reset) for creating counters and `counter-set` for changing a counter value in the flow.
<Demo $py={0}>
  <DemoPanel>
    <ol className="grid gap:xl m:0 p:0 list-style:none counter-reset:step">
      <li className="flex items-center p:10x r:lg bg:gray-5 counter-increment:step inline-flex::before flex-shrink:0::before items-center::before justify-center::before size:7x::before mr:md::before r:full::before font:0.813rem::before font:bold::before bg:gray-20::before content:counter(step)::before bg:gray-80::before@dark bg:gray-90@dark">
        <span>Install dependencies</span>
      </li>
      <li className="flex items-center p:10x b:1px|solid|blue-20 r:lg bg:blue-5 counter-increment:step counter-set:step|9 inline-flex::before flex-shrink:0::before items-center::before justify-center::before size:7x::before mr:md::before r:full::before font:0.813rem::before font:bold::before bg:blue-60::before fg:white::before content:counter(step)::before b:blue-80@dark bg:blue-95@dark">
        <span>Jump to the deployment checklist</span>
      </li>
      <li className="flex items-center p:10x r:lg bg:gray-5 counter-increment:step inline-flex::before flex-shrink:0::before items-center::before justify-center::before size:7x::before mr:md::before r:full::before font:0.813rem::before font:bold::before bg:gray-20::before content:counter(step)::before bg:gray-80::before@dark bg:gray-90@dark">
        <span>Verify production</span>
      </li>
    </ol>
  </DemoPanel>
</Demo>
```html
<!-- @MARK counter-reset:step -->
<ol class="list-style:none counter-reset:step">
  <!-- @MARK counter-increment:step -->
  <!-- @MARK content:counter(step)::before -->
  <li class="counter-increment:step inline-flex::before r:full::before content:counter(step)::before">Install dependencies</li>
  <!-- @MARK counter-set:step|9 -->
  <li class="counter-increment:step counter-set:step|9 inline-flex::before r:full::before content:counter(step)::before">Jump to the deployment checklist</li>
  <li class="counter-increment:step inline-flex::before r:full::before content:counter(step)::before">Verify production</li>
</ol>
```

### Set multiple counters
Separate counter names and values with `|` to set more than one counter in the same declaration.
<Demo $py={0}>
  <DemoPanel>
    <div className="p:3xl r:lg bg:gray-5 counter-set:chapter|2|section|4 bg:gray-90@dark">
      <div className="mb:md font:13px text:gray">Current position</div>
      <div className="font-weight:560 font:22px text:neutral font:1.375rem::before font:bold::before fg:blue-60::before content:'Chapter\00a0'counter(chapter)',\00a0section\00a0'counter(section)::before"></div>
    </div>
  </DemoPanel>
</Demo>
```html
<!-- @MARK counter-set:chapter|2|section|4 -->
<!-- @MARK content:'Chapter\00a0'counter(chapter)',\00a0section\00a0'counter(section)::before -->
<h2 class="counter-set:chapter|2|section|4 content:'Chapter\00a0'counter(chapter)',\00a0section\00a0'counter(section)::before">Resume point</h2>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="counter-set:section|4:hover counter-set:section|4@dark counter-set:section|4@print counter-set:section|4@sm">…</div>
```
