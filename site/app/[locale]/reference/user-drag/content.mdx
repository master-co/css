## Examples \{#examples\}
### Prevent dragging media \{#prevent-dragging-media\}
Use `user-drag:none` to prevent images, icons, and decorative media from being dragged out of the interface.
{/* eslint-disable @master/css/no-invalid-classes -- documented vendor property is not validated by the default runtime CSS validator */}
```html
<!-- @MARK user-drag:none -->
<img class="user-drag:none" src="/images/product.png" alt="Product preview">
```
{/* eslint-enable @master/css/no-invalid-classes */}

### Keep draggable elements explicit \{#keep-draggable-elements-explicit\}
Use `user-drag:element` only when the element is intended to participate in native drag behavior.
{/* eslint-disable @master/css/no-invalid-classes -- documented vendor property is not validated by the default runtime CSS validator */}
```html
<!-- @MARK user-drag:element -->
<div class="user-drag:element">
  Draggable asset
</div>
```
{/* eslint-enable @master/css/no-invalid-classes */}

### Reset to browser behavior \{#reset-to-browser-behavior\}
Use `user-drag:auto` when a component variant should restore the default drag behavior.
{/* eslint-disable @master/css/no-invalid-classes -- documented vendor property is not validated by the default runtime CSS validator */}
```html
<!-- @MARK user-drag:auto -->
<img class="user-drag:none user-drag:auto@sm" src="/images/file.png" alt="File">
```
{/* eslint-enable @master/css/no-invalid-classes */}

### Apply conditionally \{#apply-conditionally\}
Apply styles based on different states using [selectors](/reference/rules/selectors) and [conditional queries](/reference/rules/conditions).
{/* eslint-disable @master/css/no-invalid-classes -- documented vendor property is not validated by the default runtime CSS validator */}
```html
<div class="user-drag:none:hover user-drag:none@print user-drag:auto@sm">...</div>
```
{/* eslint-enable @master/css/no-invalid-classes */}
