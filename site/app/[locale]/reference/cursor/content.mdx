## Examples
### Show clickable affordance
Use `cursor:pointer` for custom controls that are not native buttons or links.
```html
<!-- @MARK cursor:pointer -->
<div role="button" tabindex="0" class="cursor:pointer">
  Open menu
</div>
```

### Mark disabled actions
Use `cursor:not-allowed` with a real disabled state or equivalent accessibility attributes.
```html
<!-- @MARK cursor:not-allowed -->
<button disabled class="opacity:.5 cursor:not-allowed">
  Unavailable
</button>
```

### Support drag handles
Use `cursor:grab` and `cursor:grabbing` to make draggable handles clearer.
```html
<!-- @MARK cursor:grab --><!-- @MARK cursor:grabbing:active -->
<button class="cursor:grab cursor:grabbing:active">
  Move
</button>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="cursor:pointer:hover cursor:auto@print cursor:default@sm">...</div>
```
