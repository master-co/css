## Basic usage

### Flexible multi-column layout
Use `mcss columns:count|width` to set the minimum width of each column to `width` and the maximum number of columns to `count` columns when creating a flexible multi-column layout.

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="columns:5:hover columns:5@dark columns:5@print columns:5@sm">…</div>
```
