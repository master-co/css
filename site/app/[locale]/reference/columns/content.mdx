## Basic usage \{#basic-usage\}
### Set column count \{#set-column-count\}
Use `columns:count` to flow content through a chosen number of columns. Reading order continues down one column, then into the next.

<DemoExample page="columns" section="set-column-count" />

```html
<!-- @MARK columns:3 -->
<div class="columns:3">
  <p>Start with a short introduction to the collection.</p>
  <p>Continue with the details readers need to compare each option.</p>
  <p>Finish with a clear next step.</p>
</div>
```

### Flexible multi-column layout \{#flexible-multi-column-layout\}
Combine a column count with a preferred width, such as `columns:4|100px`. The browser fits up to four columns into the available space. The width is a preference, not a strict minimum: a container narrower than one column can still shrink it.

<DemoExample page="columns" section="flexible-multi-column-layout" />

```html
<!-- @MARK columns:4|100px -->
<div class="columns:4|100px">
  <p>Start with a short introduction to the collection.</p>
  <p>Continue with the details readers need to compare each option.</p>
  <p>Finish with a clear next step.</p>
</div>
```

### Apply conditionally \{#apply-conditionally\}
Use one column for narrow layouts and introduce more columns when there is enough reading width. Resize this preview past `sm` to compare the flow. See [conditions](/reference/rules/conditions).

<DemoExample page="columns" section="apply-conditionally" />

```html
<div class="columns:1 columns:3@sm">
  <p>First part of the story.</p>
  <p>The next part follows in reading order.</p>
</div>
```
