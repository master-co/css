### Use a native list style type \{#use-a-native-list-style-type\}
Set `list-style-type` independently for native marker styles. Square suits this unordered feature list; lower-roman labels the ordered steps.

<DemoExample page="list-style-type" section="use-a-native-list-style-type" />

```html
<!-- Unordered · square -->
<ul id="target" class="width:260px max-width:100% margin:0 pl-lg font-md leading-lg
    list-style-type:disc list-style-position:outside list-style-image:initial list-style-type:square">
  <li class="mb-2xs">Collect references</li>
  <li class="mb-2xs">Compare the spacing across every screen size.</li>
  <li class="mb-2xs">Review the composition</li>
</ul>
```

```html
<!-- Ordered · lower-roman -->
<ol id="target" class="width:260px max-width:100% margin:0 pl-lg font-md leading-lg
    list-style-type:decimal list-style-position:outside list-style-image:initial list-style-type:lower-roman">
  <li class="mb-2xs">Collect references</li>
  <li class="mb-2xs">Compare the spacing across every screen size.</li>
  <li class="mb-2xs">Review the composition</li>
</ol>
```


### Apply conditionally \{#apply-conditionally\}
Resize past `sm` to replace decimal markers with lower-roman on screen. Position stays outside and the list remains ordered. Print uses decimal.

<DemoExample page="list-style-type" section="apply-conditionally" />

```html
<!-- Real viewport · type only -->
<ol id="target" class="width:260px max-width:100% margin:0 pl-lg font-md leading-lg
    list-style-type:decimal list-style-position:outside list-style-image:initial list-style-type:decimal@media(print)
    list-style-type:lower-roman@media(screen)@sm">
  <li class="mb-2xs">Collect references</li>
  <li class="mb-2xs">Compare the spacing across every screen size.</li>
  <li class="mb-2xs">Review the composition</li>
</ol>
```
