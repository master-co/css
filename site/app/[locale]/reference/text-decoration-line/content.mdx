## Examples
### Underline text
Use `text-decoration-line:underline` when the line property should be controlled explicitly.
```html
<!-- @MARK text-decoration-line:underline -->
<a class="text-decoration-line:underline">
    Underlined
</a>
```

<details>
    <summary>Generated CSS</summary>
    <Class2CSS>
        {['text-decoration-line:underline']}

</details>

### Combine line values
Separate multiple line values with `|` so they become space-separated CSS values.
```html
<!-- @MARK text-decoration-line:underline|overline -->
<span class="text-decoration-line:underline|overline">
    Marked
</span>
```

### Use shorthand aliases for common cases
The shorter `underline`, `line-through`, and `overline` aliases are useful when only the line matters.
```html
<span class="line-through">Removed</span>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<span class="text-decoration-line:underline:hover text-decoration-line:underline|overline@sm text-decoration:none@print">...</span>
```
