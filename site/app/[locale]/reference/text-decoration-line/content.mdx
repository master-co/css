### Combine line values \{#combine-line-values\}
Separate line values with `|` to emit a space-separated CSS value. Both decorations are painted on the same text run.

<DemoExample page="text-decoration-line" section="combine-line-values" />

```html
<!-- Underline + overline -->
<p id="target"
  class="display:inline-block max-width:100% margin:0 font-2xl leading-xl
         text-decoration-line:underline|overline
         text-decoration-thickness:2px text-decoration-blue-50"
>
  Design together
</p>
```

### Set one decoration line \{#set-one-decoration-line\}

<DemoExample page="text-decoration-line" section="set-one-decoration-line" />


```html
<!-- underline -->
<p id="target"
  class="display:inline-block max-width:100% margin:0 font-2xl leading-xl text-decoration-line:underline"
>
  Design together
</p>
```

```html
<!-- line-through -->
<p id="target"
  class="display:inline-block max-width:100% margin:0 font-2xl leading-xl text-decoration-line:line-through"
>
  Design together
</p>
```

```html
<!-- overline -->
<p id="target"
  class="display:inline-block max-width:100% margin:0 font-2xl leading-xl text-decoration:overline"
>
  Design together
</p>
```

A strike-through is a visual treatment. Use semantic `<s>` or `<del>` when the text is outdated or represents a document deletion.

### Apply conditionally \{#apply-conditionally\}

<DemoExample page="text-decoration-line" section="apply-conditionally" />

```html
<!-- Pointer and keyboard states -->
<button id="target" type="button"
  class="font-2xl leading-xl text-decoration-line:underline
         text-decoration-thickness:2px text-decoration-blue-50
         text-decoration-line:underline@media(print)
         text-decoration-line:underline|overline:hover@media(screen)
         text-decoration-line:underline|overline:focus-visible@media(screen)"
>
  Design together
</button>
```
