The built-in `min-size` utility and its named token form have been removed before Master CSS 2.0. This URL remains for existing links.

Use `min-width:20px min-height:20px` for direct values, or `min-w-sm min-h-sm` when both entries resolve to the intended container token. These are independent declarations; review competing dimensions when upgrading.

See the [Master CSS v2 RC migration guide](/guide/migration/v2-rc#sizing-and-resolution) for safe migration and sorting checks, and [sizing](/guide/sizing) for current usage. Projects may still define a custom `min-size` utility with `@mixin`.

Native page-size descriptors and logical properties such as `inline-size` and `block-size` remain available.
