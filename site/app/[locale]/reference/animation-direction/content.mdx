## Overview [sr-only]
<Overview/>

Use the native animation direction property directly.
```html
<div class="animation-direction:reverse">
```

---

## Basic usage
### Play forward
The animation plays forward in each cycle.
<Basic className="animation-direction:normal"/>

### Play backward
The animation plays backward in each cycle. For example, rotate counterclockwise.
<Basic className="animation-direction:reverse"/>

### Play alternately
The animation **reverses direction each cycle** and **the first iteration plays forward**.
<Basic className="animation-direction:alternate"/>

### Play alternately and reverse first
The animation **reverses direction each cycle** and **the first iteration plays backward**.
<Basic className="animation-direction:alternate-reverse"/>

### Fade out
Reverse a project-defined `fade` keyframe so that you don't need to define a new keyframe for `fade-out`.
<Demo>
    <IconCircle className="app-icon-primary stroke:.5 animation-name:fade animation-duration:1s animation-direction:reverse animation-iteration-count:infinite" width="48" height="48" />
</Demo>
```html
<!-- @MARK animation-name:fade --><!-- @MARK animation-direction:reverse -->
<svg class="animation-name:fade animation-duration:1s animation-direction:reverse animation-iteration-count:infinite">…</svg>
```
For one-shot animations, remove `infinite`.

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="animation-direction:normal:hover">…</div>
<div class="animation-direction:normal@sm">…</div>
<div class="animation-direction:normal@dark">…</div>
<div class="animation-direction:normal@print">…</div>
```
