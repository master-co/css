## Installation [sr-only]
```bash action=install
@master/css-runtime
```
To import and initialize the runtime engine in the entry file, such as `main.js`:
```js name=main.js
import { initCSSRuntime } from '@master/css-runtime'
import plan from 'virtual:master-css-plan.json'
import preloaded from 'virtual:master-css-preloaded'

initCSSRuntime({ plan, preloaded })
```

---

## API Reference
### `CSSRuntime`
The `Runtime` extends the [`MasterCSS`](/reference/core#mastercss) and only works in the browser environment.
```ts
import CSSRuntime from '@master/css-runtime'
import plan from 'virtual:master-css-plan.json'

const cssRuntime = new CSSRuntime(document, plan)
```
`CSSRuntime` uses the provided plan directly. Use `initCSSRuntime({ plan })` when the runtime should reuse an existing runtime for the same root.

### `initCSSRuntime()`
Initializes the Master CSS runtime rendering engine.
<DocFn>
    {[
        { name: 'options', type: 'CSSRuntimeInitOptions' },
        { name: 'return', type: 'CSSRuntime' },
    ]}
</DocFn>
```ts
import { initCSSRuntime } from '@master/css-runtime'
import plan from 'virtual:master-css-plan.json'
import preloaded from 'virtual:master-css-preloaded'

const css = initCSSRuntime({
    plan,
    preloaded,
    root: document,
    autoObserve: true
})
```
Equivalent to:
```ts
import CSSRuntime from '@master/css-runtime'
import plan from 'virtual:master-css-plan.json'

const cssRuntime = new CSSRuntime(document, plan).observe()
```

If a runtime already exists for the same root, `initCSSRuntime()` returns that instance instead of creating a second observer.

`preloaded` tells the runtime which variables and keyframes were already emitted by the project CSS entry, so future dynamic classes can reuse them without inserting duplicate global CSS.

### `resolveRuntimePlan()`
Returns the complete `MasterCSSPlan` passed to runtime refresh or initialization.
<DocFn>
    {[
        { name: 'plan', type: 'MasterCSSPlan' },
        { name: 'return', type: 'MasterCSSPlan' },
    ]}
</DocFn>
```ts
import { resolveRuntimePlan } from '@master/css-runtime'
import plan from 'virtual:master-css-plan.json'

cssRuntime.refresh(resolveRuntimePlan(plan))
```

React, Vue, and Svelte runtime providers use this helper when their `plan` prop changes.
