## Installation [sr-only]
```bash action=install
@master/css-runtime
```
To import and initialize the runtime engine in the entry file, such as `main.js`:
```js name=main.js
import { initCSSRuntime } from '@master/css-runtime'
import config from './master.css?master-css-config'

initCSSRuntime(config)
```

---

## API Reference
### `CSSRuntime`
The `Runtime` extends the [`MasterCSS`](/reference/core#mastercss) and only works in the browser environment.
```ts
import CSSRuntime from '@master/css-runtime'

const cssRuntime = new CSSRuntime(document, config)
```
`CSSRuntime` uses the provided config directly. Use `initCSSRuntime(config)` when the runtime should extend the default config with a project config and reuse an existing runtime for the same root.

### `CSSRuntime.instances`
Runtime instances keyed by `Document` or `ShadowRoot`.
<DocProp defaultValue="[]" types={['WeakMap<Document | ShadowRoot, CSSRuntime>']} />

### `cssRuntime.root`
Observe the root element.
<DocProp defaultValue="document" types={['Document', 'ShadowRoot']} />

### `cssRuntime.host`
Observe the root's host element, usually `js this.root.host` or `js document.documentElement`.
<DocProp defaultValue="auto" types={['Element']} readonly />

### `cssRuntime.container`
Container for inserting style `html <style>`.
<DocProp defaultValue="auto" types={['HTMLElement', 'ShadowRoot']} readonly />

### `cssRuntime.observing`
Observation state. `js true` after `js .observe()`; `js false` after `js .disconnect()`.
<DocProp defaultValue="auto" types={['boolean']} readonly />

### `initCSSRuntime()`
Initializes the Master CSS runtime rendering engine.
<DocFn>
    {[
        { name: 'config?', type: 'Config', defaultValue: 'undefined' },
        { name: 'root?', type: 'Document | ShadowRoot', defaultValue: 'document' },
        { name: 'autoObserve?', type: 'boolean', defaultValue: 'true' },
        { name: 'return', type: 'CSSRuntime' },
    ]}
</DocFn>
```ts
import { initCSSRuntime } from '@master/css-runtime'

const css = initCSSRuntime()
```
Equivalent to:
```ts
import CSSRuntime, { resolveRuntimeConfig } from '@master/css-runtime'

const cssRuntime = new CSSRuntime(document, resolveRuntimeConfig()).observe()
```

If a runtime already exists for the same root, `initCSSRuntime()` returns that instance instead of creating a second observer.

### `resolveRuntimeConfig()`
Merges the default Master CSS config with a project config before runtime refresh or initialization.
<DocFn>
    {[
        { name: 'config?', type: 'Config', defaultValue: 'undefined' },
        { name: 'return', type: 'Config' },
    ]}
</DocFn>
```ts
import { resolveRuntimeConfig } from '@master/css-runtime'

cssRuntime.refresh(resolveRuntimeConfig(config))
```

React, Vue, and Svelte runtime providers use this helper when their `config` prop changes, so provider refreshes keep built-in utilities and project config together.
