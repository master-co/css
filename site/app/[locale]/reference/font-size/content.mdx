### With line height \{#with-line-height\}
Pair `font:*` with [`line-height:*`](/reference/line-height) to control size and line height independently. Both paragraphs below use the same 16px type and line width.

<DemoExample page="font-size" section="with-line-height" />

```html
<!-- leading-xs -->
<p id="target" class="max-width:24ch margin:0 font-size-md leading-xs">Clear type gives each idea room to breathe. Keep the measure comfortable and let the content set the pace.</p>
```

```html
<!-- leading-lg -->
<p id="target" class="max-width:24ch margin:0 font-size-md leading-lg">Clear type gives each idea room to breathe. Keep the measure comfortable and let the content set the pace.</p>
```

Use [`text:*`](/reference/text-size) when you want the combined size, leading and tracking treatment.

### Use an explicit font size \{#use-an-explicit-font-size\}
A `clamp()` formula can respond to the viewport while keeping a minimum and maximum. Adjust this real viewport: at a 16px root size, the title grows from 20px to 32px between 1000px and 1600px.

<DemoExample page="font-size" section="use-an-explicit-font-size" />

```html
<!-- 20px minimum · 2vw preferred · 32px maximum -->
<h2 id="target" class="margin:0 font-size:clamp(1.25rem,2vw,2rem) font-weight-medium leading-xs">A clearer canvas</h2>
```

Prefer a named token when a value is reused across the interface.

### Apply conditionally \{#apply-conditionally\}
Resize the viewport to cross the `sm` and `lg` breakpoints. The print rule returns the type to `font-size-sm`; use Print preview to inspect the actual print layout.

<DemoExample page="font-size" section="apply-conditionally" />

```html
<!-- Responsive supporting text -->
<p id="target" class="margin:0 font-size-sm leading-md font-size-sm@media(print) font-size-md@media(screen)@sm font-size-lg@media(screen)@lg">Clear type gives each idea room to breathe. Keep the measure comfortable and let the content set the pace.</p>
```
