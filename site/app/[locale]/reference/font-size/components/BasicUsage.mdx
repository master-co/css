Use `font:*` size tokens to change font size without setting line height or letter spacing. These specimens share `leading-md`, so their line height scales with their size.

```html
<!-- font-size-xs -->
<p id="target" class="margin:0 font-size-xs leading-md">Design with clarity.</p>
```

```html
<!-- font-size-sm -->
<p id="target" class="margin:0 font-size-sm leading-md">Design with clarity.</p>
```

```html
<!-- font-size-md -->
<p id="target" class="margin:0 font-size-md leading-md">Design with clarity.</p>
```

```html
<!-- font-size-lg -->
<p id="target" class="margin:0 font-size-lg leading-md">Design with clarity.</p>
```

```html
<!-- font-size-xl -->
<p id="target" class="margin:0 font-size-xl leading-md">Design with clarity.</p>
```

```html
<!-- font-size-2xl -->
<p id="target" class="margin:0 font-size-2xl leading-md">Design with clarity.</p>
```
