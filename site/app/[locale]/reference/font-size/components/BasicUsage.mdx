Use `font:*` size tokens to change font size without setting line height or letter spacing. These specimens share `leading-md`, so their line height scales with their size.

```html
<!-- font-xs -->
<p id="target" class="m:0 font-xs leading-md">Design with clarity.</p>
```

```html
<!-- font-sm -->
<p id="target" class="m:0 font-sm leading-md">Design with clarity.</p>
```

```html
<!-- font-md -->
<p id="target" class="m:0 font-md leading-md">Design with clarity.</p>
```

```html
<!-- font-lg -->
<p id="target" class="m:0 font-lg leading-md">Design with clarity.</p>
```

```html
<!-- font-xl -->
<p id="target" class="m:0 font-xl leading-md">Design with clarity.</p>
```

```html
<!-- font-2xl -->
<p id="target" class="m:0 font-2xl leading-md">Design with clarity.</p>
```
