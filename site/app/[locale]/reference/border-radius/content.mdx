### Use a radius token \{#use-a-radius-token\}
`r-2xl` rounds the box’s own border and background. It does not, by itself, clip a child image. Compare the same child with and without explicit overflow clipping.

<DemoExample page="border-radius" section="use-a-radius-token" />

```html
<!-- Radius only · child corners stay square -->
<div id="target"
  class="width:240px max-width:100% r-2xl bg-surface-inset
         box-sizing:border-box">
  <img src="/demo/landscape.svg"
    alt="Blue and violet mountains"
    width="320" height="200"
    class="display:block height:auto width:100%" />
</div>
```

```html
<!-- Radius + overflow hidden · child is clipped -->
<div id="target"
  class="overflow:hidden width:240px max-width:100% r-2xl
         bg-surface-inset box-sizing:border-box">
  <img src="/demo/landscape.svg"
    alt="Blue and violet mountains"
    width="320" height="200"
    class="display:block height:auto width:100%" />
</div>
```

<details>

Clipping also affects overflowing content and descendant focus indicators. Add it only when that behavior is intended.

### Round individual corners \{#round-individual-corners\}
`rtl`, `rtr`, `rbl` and `rbr` address the physical top-left, top-right, bottom-left and bottom-right corners.

<DemoExample page="border-radius" section="round-individual-corners" />

```html
<!-- Top corners only -->
<div id="target"
  class="display:flex align-items:center justify-content:center height:96px
         width:240px max-width:100% p-md border-width:2px border-style:solid b-blue
         rtl-xl rtr-xl font-md bg-surface-inset
         fg-text-body box-sizing:border-box">
  Rounded top
</div>
```

```html
<!-- Opposite corners -->
<div id="target"
  class="display:flex align-items:center justify-content:center height:96px
         width:240px max-width:100% p-md border-width:2px border-style:solid b-blue
         rbl-xl rtr-xl font-md bg-surface-inset
         fg-text-body box-sizing:border-box">
  Diagonal corners
</div>
```

These corner aliases remain physical when writing direction changes.

### Apply conditionally \{#apply-conditionally\}
Widen to `sm` to increase the radius from `sm` to `xl`. Print restores square corners. The measured outer dimensions stay the same.

<DemoExample page="border-radius" section="apply-conditionally" />

```html
<!-- Small → large radius at sm -->
<div id="target"
  class="display:flex align-items:center justify-content:center height:96px
         width:240px max-width:100% p-md border-width:2px border-style:solid b-blue
         r-sm font-md bg-surface-inset fg-text-body
         box-sizing:border-box border-radius:0@media(print) r-xl@media(screen)@sm">
  Preview panel
</div>
```

Use [conditional queries](/reference/rules/conditions) to choose the radius without changing the box’s dimensions.

## Customization \{#customization\}
### Use custom border radius \{#use-custom-border-radius\}
Define project radius tokens in `@theme`, then use the same token key in the class. This example adds a named panel radius instead of replacing a preset size.

<DemoExample page="border-radius" section="use-custom-border-radius" />

```css name=index.css
@theme { :root, :host {
  --radius-panel: 1.125rem;
} }

```

```html
<!-- Configured panel radius · 18px -->
<div id="target"
  class="display:flex align-items:center justify-content:center height:96px
         width:240px max-width:100% p-md border-width:2px border-style:solid b-blue
         r-panel font-md bg-surface-inset fg-text-body
         box-sizing:border-box">
  Preview panel
</div>
```

The readout reports the browser’s resolved value. Here `1.125rem` becomes 18px at a 16px root size.
