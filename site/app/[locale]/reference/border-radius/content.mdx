### Use a radius token
Use `r:*` to apply a border radius token or size directly.
```html
<!-- @MARK r:md -->
<div class="r:md">
    Rounded panel
</div>
```

<details>
    <summary>Generated CSS</summary>
    <Class2CSS>
        {['r:md']}
    </Class2CSS>
</details>

### Round only one side
Use side and corner aliases when only part of the element should be rounded.
```html
<!-- @MARK rt:md -->
<div class="rt:md">
    Rounded top
</div>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="r:md:hover r:lg@sm r:0@print">...</div>
```

## Customization
### Use custom border radius
Customize your border radius tokens by defining [theme tokens](/guide/theme#theme-tokens).
```css name=index.css
@theme {
    --radius-xs: 0.125rem; /* [!code ++] */
    --radius-sm: 0.25rem; /* [!code ++] */
}
```
Apply the defined `radius` variables.
```html
<div class="r:sm">...</div>
```
