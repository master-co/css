### Use a radius token \{#use-a-radius-token\}
Use `r:*` to apply a border radius token or size directly.
```html
<!-- @MARK r:md -->
<div class="r:md">
  Rounded panel
</div>
```

### Round individual corners \{#round-individual-corners\}
Use CSS corner properties or corner shorthands when only part of the element should be rounded.
```html
<!-- @MARK rtl:md --><!-- @MARK rtr:md -->
<div class="rtl:md rtr:md">
  Rounded top
</div>
```

Use `rtl`, `rtr`, `rbl`, and `rbr` for individual corners.
```html
<!-- @MARK rtr:md --><!-- @MARK rbl:sm -->
<div class="rbl:sm rtr:md">
  Rounded corners
</div>
```

### Apply conditionally \{#apply-conditionally\}
Apply styles based on different states using [selectors](/reference/rules/selectors) and [conditional queries](/reference/rules/conditions).
```html
<div class="r:md:hover r:0@print r:lg@sm">...</div>
```

## Customization \{#customization\}
### Use custom border radius \{#use-custom-border-radius\}
Customize your border radius tokens by defining [theme tokens](/guide/theme).
```css name=index.css
@theme {
  --radius-xs: 0.125rem; /* [!code ++] */
  --radius-sm: 0.25rem; /* [!code ++] */
}
```
Apply the defined `radius` variables.
```html
<div class="r:sm">...</div>
```
