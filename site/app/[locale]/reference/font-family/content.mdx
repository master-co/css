### Set the font family
Set the typeface of an element using the `font-family:` syntax.
<Demo $py={0}>
  <DemoPanel className="flex flex-col gap:xl">
    <div className="w:full">
      <DemoP className="font-family:cursive">Heavy boxes perform quick waltzes and jigs.</DemoP>
    </div>
  </DemoPanel>
</Demo>
```html
<!-- @MARK font-family:cursive -->
<p class="font-family:cursive">Heavy boxes perform quick waltzes and jigs.</p>
```
In practice, you wouldn't arbitrarily set the font family within the template; instead, you would unify your fonts through [custom fonts](#use-custom-fonts).

### Apply fonts globally
Relying on the `font-family` inherited behavior, you can set the entire page font in `html <body>`.
```html
<!-- @MARK font:sans -->
<body class="font:sans">…</body>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="font:mono:hover font:mono@dark font:mono@print font:mono@sm">…</div>
```
### Apply fonts to specified elements
Use the `mcss _:is(code,pre)` to select specified elements and apply the font.
```html
<!-- @MARK font:mono_:is(code,pre) -->
<body class="font:mono_:is(code,pre)">…</body>
```

## Resolve whitespaces in the value
Whitespace is used in the class attribute of the template to separate different classes. To replace whitespaces ` ` with non-breaking spaces `\00a0`.
```html
<!-- @MARK font-family:'Open\00a0Sans' -->
<p class="font-family:'Open\00a0Sans'">…</p>
```
Is it not very kind to use `\00a0` in markup?

(o) Predefine your [font](/guide/theme) tokens without `\00a0`.
```css name=index.css
@theme {
  --font-family-open-sans: Open Sans; /* [!code ++] */
}
```
Apply your custom fonts:
```html
<!-- @MARK font:open-sans -->
<p class="font:open-sans">…</p>
```

## Customization
### Use custom fonts
Customize your font tokens by defining [theme tokens](/guide/theme). For example, add `Geist` as the general font and `Fira Code` as the code font.
```css name=index.css
@theme {
  --font-sans: "Geist"; /* [!code ++] */
  --font-mono: "Fira Code"; /* [!code ++] */
}
```
Apply the defined `font-family` variables. For example, presetting the global fonts in `html <body>`:
```html
<!-- @MARK font:sans --><!-- @MARK font:mono_:is(code,pre) -->
<body class="font-feature-settings:'ss01' font:sans font:mono_:is(code,pre)">…</body>
```
Don't forget to add the [font faces](/guide/fonts#font-faces).

### Google fonts
The fastest way to declare custom font faces is through [Google Fonts](https://fonts.google.com/).
```html name=index.html
<!DOCTYPE html>
<html lang="en">
<head>
  <link rel="preconnect" href="https://fonts.googleapis.com">
  <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
  <link href="https://fonts.googleapis.com/css2?family=Fira+Code&family=Roboto:wght@400;500;600;700;800&display=swap" rel="stylesheet"> <!-- [!code ++] -->
</head>
</html>
```

### Self-hosted fonts
You can also self-host the fonts via native CSS, as usual.
```css name=styles/fonts.css
@font-face {
  font-family: 'Geist';
  font-style: normal;
  font-weight: 100 900;
  font-display: swap;
  src: url("/fonts/GeistVariable.woff2") format("woff2");
}
```
Self-host the complete font build when you rely on advanced OpenType features such as `font-feature-settings:'ss01'`.
