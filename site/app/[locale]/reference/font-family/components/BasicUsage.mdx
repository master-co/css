`font-sans`, `font-serif` and `font-mono` select the preset family stacks. Their resolved typefaces depend on the available fonts and any project overrides.

```html
<!-- font-sans -->
<p id="target" class="m:0 font-sans font-xl leading-md">Design with clarity.</p>
```

```html
<!-- font-serif -->
<p id="target" class="m:0 font-serif font-xl leading-md">Design with clarity.</p>
```

```html
<!-- font-mono -->
<p id="target" class="m:0 font-mono font-xl leading-md">Design with clarity.</p>
```
