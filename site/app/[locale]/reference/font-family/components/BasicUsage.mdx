`font-family-sans`, `font-family-serif` and `font-family-mono` select the preset family stacks. Their resolved typefaces depend on the available fonts and any project overrides.

```html
<!-- font-family-sans -->
<p id="target" class="margin:0 font-family-sans font-size-xl leading-md">Design with clarity.</p>
```

```html
<!-- font-family-serif -->
<p id="target" class="margin:0 font-family-serif font-size-xl leading-md">Design with clarity.</p>
```

```html
<!-- font-family-mono -->
<p id="target" class="margin:0 font-family-mono font-size-xl leading-md">Design with clarity.</p>
```
