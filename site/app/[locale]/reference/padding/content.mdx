## Quick answer \{#quick-answer\}
Use `p:md` for padding on every side. The value comes from the active spacing namespace.

```html
<button class="p:md">Save</button>
```

## Values and tokens \{#values-and-tokens\}
Current preset examples:
<TokenValues namespace="spacing" keys={['sm', 'md', 'lg']} />

Project theme declarations can override these values. See the complete [spacing namespace](/reference/tokens/spacing).

`px` and `py` refer to inline and block directions. Their physical direction depends on writing mode; they are not always horizontal and vertical.

## Examples \{#examples\}
### Combine values and logical sides \{#multiple-values\}
Separate shorthand values with `|`. Use `pxs:*` when only the inline-start side needs padding.

```html
<div class="p:md|lg">Two spacing values</div>
<div class="pxs:md">Inline-start padding</div>
```

<Class2CSS>{['p:md|lg', 'pxs:md']}</Class2CSS>

### Add padding on every side \{#add-padding-on-every-side\}
Use `p:*` to create space inside an element on all four sides. Padding is part of the element box, so backgrounds and borders include the padded area.
```html
<!-- @MARK p:md -->
<section class="p:md b:1px|solid|gray-20 bg:white">
  Content with breathing room.
</section>
```

### Set one side \{#set-one-side\}
Use `pt:*`, `pr:*`, `pb:*`, and `pl:*` when only one physical side needs spacing.
```html
<!-- @MARK pt:lg --><!-- @MARK pr:md --><!-- @MARK pb:xl --><!-- @MARK pl:md -->
<article class="px:md pb:xl pt:lg">
  ...
</article>
```

Physical sides are useful for fixed component anatomy. For bidirectional layouts, check whether the design needs logical CSS properties before relying on left and right.

<a id="set-horizontal-or-vertical-padding"></a>

### Set inline or block padding \{#set-inline-or-block-padding\}
Use `px:*` for inline padding and `py:*` for block padding. This is the common pattern for buttons, cards, fields, and page gutters.
```html
<!-- @MARK px:md --><!-- @MARK py:sm -->
<button class="px:md py:sm r:md">
  Save changes
</button>
```

Use `p:0` to override component-level padding at a breakpoint or state.
```html
<!-- @MARK p:0@sm -->
<section class="p:md p:0@sm">
  ...
</section>
```

### Apply conditionally \{#apply-conditionally\}
Apply styles based on different states using [selectors](/reference/rules/selectors) and [conditional queries](/reference/rules/conditions).
```html
<div class="p:sm:hover p:lg@dark p:0@print p:md@sm">...</div>
```

Use spacing tokens for repeated component rhythm. Use raw values only when the padding is a measured local detail.
