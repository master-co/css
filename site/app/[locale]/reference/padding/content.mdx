## Quick answer \{#quick-answer\}
Use `p-md` for padding on every side. Its value comes from the active spacing namespace. This borderless button has a 32px-wide, 20px-high content span; the default 16px padding makes its border box 64 × 52px.

<DemoExample page="padding" section="quick-answer" />

```html
<div id="layout" class="width:17.5rem max-width:100%" role="group" aria-label="Available space">
  <button id="target" class="p-md border-width:0" type="button"><span id="item-3" class="display:block width:2rem line-height:20px">Save</span></button>
</div>
```

## Values and tokens \{#values-and-tokens\}
Current preset examples:
<TokenValues namespace="spacing" keys={['sm', 'md', 'lg']} />

Project theme declarations can override these values. See the complete [spacing namespace](/reference/tokens/spacing).

`px` and `py` refer to inline and block directions. Their physical direction depends on writing mode; they are not always horizontal and vertical.

### Add padding on every side \{#add-padding-on-every-side\}
`p-md` adds 16px between content and each edge of the box. The neutral content is 160 × 48px, so the blue box is 192 × 80px with no border. Its background also paints the padded area.

<DemoExample page="padding" section="add-padding-on-every-side" />

```html
<div id="layout" class="width:17.5rem max-width:100%" role="group" aria-label="Available space">
  <div id="target" class="width:fit-content p-md"><div id="item-3" class="display:grid place-items:center height:3rem width:10rem">Content</div></div>
</div>
```

With border-box sizing and an explicit width, padding uses space inside that width. Here the width is intrinsic, so the content and padding determine the final size together.

### Set one side \{#set-one-side\}
Use `padding-top:*`, `padding-right:*`, `padding-bottom:*` and `padding-left:*` for physical sides. This box uses 24px top, 16px right, 32px bottom and 12px left padding around 120 × 48px content. The result is 148 × 104px.

<DemoExample page="padding" section="set-one-side" />

```html
<div id="layout" class="width:17.5rem max-width:100%" role="group" aria-label="Available space">
  <div id="target" class="width:fit-content pb-xl pl-sm pr-md pt-lg"><div id="item-3" class="display:grid place-items:center height:3rem width:7.5rem">Content</div></div>
</div>
```

Physical sides stay physical in every writing mode. Prefer logical properties when the intended edge should follow the reader’s direction.

<a id="set-horizontal-or-vertical-padding"></a>

### Set inline or block padding \{#set-inline-or-block-padding\}
`padding-inline:*` sets inline padding and `padding-block:*` sets block padding. With `px-md py-sm`, horizontal writing gets 16px left/right and 12px top/bottom. Vertical writing swaps those physical directions while preserving the same logical values.

<DemoExample page="padding" section="set-inline-or-block-padding" />

```html
<!-- Horizontal writing -->
<div id="layout" class="width:17.5rem max-width:100%" role="group" aria-label="Available space">
  <div id="target" class="width:fit-content px-md py-sm"><div id="item-3" class="display:grid place-items:center height:3rem width:7.5rem">Content</div></div>
</div>
```

```html
<!-- Vertical writing -->
<div id="layout" class="width:17.5rem max-width:100%" role="group" aria-label="Available space">
  <div id="target" class="width:fit-content px-md py-sm writing-mode:vertical-rl"><div id="item-3" class="display:grid place-items:center height:3rem width:7.5rem">Content</div></div>
</div>
```

Use `padding:0` to remove padding at a breakpoint or state. The next example keeps the content fixed so this reset can be measured directly.

### Apply conditionally \{#apply-conditionally\}
Resize past `sm` to apply `padding:0`. The same 160 × 48px content remains; removing the 16px padding changes the border box from 192 × 80px to 160 × 48px.

<DemoExample page="padding" section="apply-conditionally" />

```html
<div id="layout" class="width:17.5rem max-width:100%" role="group" aria-label="Available space">
  <div id="target" class="width:fit-content p-md padding:0@sm"><div id="item-3" class="display:grid place-items:center height:3rem width:10rem">Content</div></div>
</div>
```

Use shared spacing tokens for repeated rhythm. Raw values are appropriate for a measured local detail, such as the fixed content dimensions used in this specimen.
