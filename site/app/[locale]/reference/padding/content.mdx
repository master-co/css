## Examples
### Add padding on every side
Use `p:*` to create space inside an element on all four sides. Padding is part of the element box, so backgrounds and borders include the padded area.
```html
<!-- @MARK p:md -->
<section class="p:md bg:surface b:1|lightest">
    Content with breathing room.
</section>
```

### Set one side
Use `pt:*`, `pr:*`, `pb:*`, and `pl:*` when only one physical side needs spacing.
```html
<!-- @MARK pt:lg --><!-- @MARK pr:md --><!-- @MARK pb:xl --><!-- @MARK pl:md -->
<article class="pt:lg pr:md pb:xl pl:md">
    ...
</article>
```

Physical sides are useful for fixed component anatomy. For bidirectional layouts, check whether the design needs logical CSS properties before relying on left and right.

### Set horizontal or vertical padding
Use `px:*` for left and right padding, and `py:*` for top and bottom padding. This is the common pattern for buttons, cards, fields, and page gutters.
```html
<!-- @MARK px:md --><!-- @MARK py:sm -->
<button class="px:md py:sm r:md">
    Save changes
</button>
```

Use `p:0` to remove inherited or component-level padding at a breakpoint or state.
```html
<!-- @MARK p:0@sm --><!-- @MARK px:lg@sm -->
<section class="p:md p:0@sm px:lg@sm">
    ...
</section>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="p:sm:hover p:md@sm p:lg@dark p:0@print">...</div>
```

Use spacing tokens for repeated component rhythm. Use raw values only when the padding is a measured local detail.
