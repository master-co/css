## Examples \{#examples\}
### Let an item grow \{#let-an-item-grow\}
Use `flex-grow:1` on a flex item that should absorb remaining free space.
```html
<!-- @MARK flex --><!-- @MARK flex-grow:1 -->
<div class="flex gap:md">
  <aside class="flex-grow:0 w:24x">...</aside>
  <main class="flex-grow:1 min-w:0">...</main>
</div>
```

<details>
  <summary>Generated CSS</summary>
  <Class2CSS>
    {['flex', 'flex-grow:1', 'flex-grow:0', 'min-w:0']}
  </Class2CSS>
</details>

### Keep an item at its basis \{#keep-an-item-at-its-basis\}
Use `flex-grow:0` when an item should keep its width or basis and leave free space to siblings.
```html
<!-- @MARK flex-grow:0 --><!-- @MARK flex-basis:24x -->
<aside class="flex-basis:24x flex-grow:0">...</aside>
```

Use the [flex](/reference/flex) shorthand when grow, shrink, and basis should be set together.

### Apply conditionally \{#apply-conditionally\}
Apply styles based on different states using [selectors](/reference/rules/selectors) and [conditional queries](/reference/rules/conditions).
```html
<div class="flex-grow:0 flex-grow:0@print flex-grow:1@sm">...</div>
```

The parent must be a flex container for `flex-grow` to affect layout.
