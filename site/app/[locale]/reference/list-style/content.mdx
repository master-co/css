## Examples \{#examples\}
### Set type and position together \{#set-type-and-position-together\}
Use `list-style:*|*` when list marker type and marker position belong together.
```html
<!-- @MARK list-style:disc|inside -->
<ul class="list-style:disc|inside">
  <li>Install</li>
  <li>Configure</li>
</ul>
```

<details>
  <summary>Generated CSS</summary>
  <Class2CSS>
    {['list-style:disc|inside']}
  </Class2CSS>
</details>

### Use an image marker \{#use-an-image-marker\}
Use `list-style-image:url(*)` when the marker should come from an image asset.
```html
<!-- @MARK list-style-image:url(/marker.svg) -->
<ul class="list-style-image:url(/marker.svg)">
  <li>Custom marker</li>
</ul>
```

### Split longhands when variants differ \{#split-longhands-when-variants-differ\}
Use the type, position, and image pages when only one part of the list style changes across states.
```html
<ul class="list-style:decimal list-style:inside@sm">
  <li>Step</li>
</ul>
```

### Apply conditionally \{#apply-conditionally\}
Apply styles based on different states using [selectors](/reference/rules/selectors) and [conditional queries](/reference/rules/conditions).
```html
<ul class="list-style:disc|inside:hover list-style:disc@print list-style:decimal@sm">...</ul>
```
