## Usage

Use a positive integer to set the number of columns. Use `column-gap:*` to control their separation and `column-width:*` to set a preferred width.

### Set the number of columns \{#set-the-number-of-columns\}

<DemoExample page="column-count" section="set-the-number-of-columns" />

```html
<article class="column-count:2 column-gap:1.5rem">
  <p>Design decisions become easier to follow when spacing, color and type share a consistent vocabulary.</p>
  <p>Readers follow each column from top to bottom, then continue at the top of the next column.</p>
  <p>The browser balances the content across the available columns. Resize the preview to see how the text responds.</p>
</article>
```
