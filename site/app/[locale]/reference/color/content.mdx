## Examples \{#examples\}
### With opacity \{#with-opacity\}
Add the suffix `/alpha` to change the opacity of any color.
<Basic className="fg:blue-60/.15" />

### Apply conditionally \{#apply-conditionally\}
Apply styles based on different states using [selectors](/reference/rules/selectors) and [conditional queries](/reference/rules/conditions).
```html
<div class="fg:slate-10:hover fg:slate-10@dark fg:slate-10@print fg:slate-10@sm">...</div>
```

## Customization \{#customization\}
### Use custom text colors \{#use-custom-text-colors\}
Add a color to the `color-text` namespace, then compile the theme together with the class that consumes it.

<ConfiguredExample source={'@theme { --color-text-primary: #000; }'} classes={['text:primary']} />

The current preset exposes this namespace through <TextHeirs />. These consumers are derived from the public native namespaces, aliases and manifest utilities.

Use `text:primary` for the contextual text color. Use [text fill color](/reference/text-fill-color) when you need the WebKit text fill property.

To request a particular CSS variable explicitly, use a native variable reference:

```html
<p class="fg:var(--color-blue)">Base blue token</p>
```
