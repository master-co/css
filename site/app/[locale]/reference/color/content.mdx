## Examples \{#examples\}

### With opacity \{#with-opacity\}
Append `/alpha` to a color to make its paint translucent. Compare the same blue at full opacity and at 40%; the element itself keeps `opacity:1`.

<DemoExample page="color" section="with-opacity" />

```html
<!-- Opaque foreground -->
<p id="target"
  class="m:0 font-2xl leading-lg text-blue"
>A shared design language.</p>
```

```html
<!-- 40% foreground alpha -->
<p id="target"
  class="m:0 font-2xl leading-lg text-blue/.4"
>A shared design language.</p>
```

The low-alpha sample intentionally has reduced contrast. Choose sufficient contrast against the final surface for meaningful text. A color’s alpha differs from [element opacity](/reference/opacity), which composites the whole element and its descendants.

### Apply conditionally \{#apply-conditionally\}
Hover or focus this button to change its foreground. Switch the preview theme to compare the resting color; print restores a solid black label.

<DemoExample page="color" section="apply-conditionally" />

```html
<!-- Pointer, keyboard and theme -->
<button id="target" type="button"
  class="font-md text-body fg-black@print text-violet@screen@dark
         text-blue:hover@screen text-blue:focus-visible@screen"
>Preview details</button>
```

The foreground does not change the button’s background. Use [selectors](/reference/rules/selectors) for real interaction and [conditions](/reference/rules/conditions) for theme or media changes.

## Customization \{#customization\}
### Use custom text colors \{#use-custom-text-colors\}
Define a semantic name in `color-text`, then compile the theme with the class that consumes it. This token follows the preset’s light and dark text-blue values.

<DemoExample page="color" section="use-custom-text-colors" />

```css name=index.css
@theme {
  --color-text-primary: var(--color-text-blue);
}
```

```html
<!-- Configured text namespace -->
<p id="target"
  class="m:0 font-2xl leading-lg text-primary"
>A shared design language.</p>
```

```html
<!-- Explicit variable reference -->
<p id="target"
  class="m:0 font-2xl leading-lg
         fg:var(--color-text-primary,var(--color-text-blue))"
>A shared design language.</p>
```

The current preset exposes this namespace through <TextHeirs />. These consumers are derived from public native namespaces, aliases and manifest utilities. `text-primary` selects the contextual text token; `fg:var(--color-text-primary,var(--color-text-blue))` requests the variable explicitly and supplies a fallback if the custom token is absent. Use [text fill color](/reference/text-fill-color) for the separate WebKit glyph-fill property.
