## Basic usage \{#basic-usage\}
### Place an item by rows \{#place-an-item-by-rows\}
Use `grid-row` to place an item between row grid lines.
<Demo $py={0}>
  <DemoPanel>
    <div className="grid grid-cols:2 grid-template-rows:48px|48px|48px gap:xs">
      <div className="grid-row:1/3 min-w:0 p:sm b:1px|solid|blue-20 r:lg bg:blue-5 b:blue-80@dark bg:blue-95@dark">
        <div className="overflow:hidden font:11px font:bold text-ellipsis white-space:nowrap fg:blue-60">grid-row:1/3</div>
        <div className="font-weight:560 font:sm text:neutral">Item</div>
      </div>
      <div className="min-w:0 p:sm r:lg bg:gray-5 bg:gray-90@dark">A</div>
      <div className="min-w:0 p:sm r:lg bg:gray-5 bg:gray-90@dark">B</div>
    </div>
  </DemoPanel>
</Demo>
```html
<!-- @MARK grid-row:1/3 -->
<div class="grid-row:1/3">Item</div>
```

### Span rows \{#span-rows\}
```html
<!-- @MARK grid-row-span:2 -->
<div class="grid-row-span:2">Spans two rows</div>
```

### Apply conditionally \{#apply-conditionally\}
Apply styles based on different states using [selectors](/reference/rules/selectors) and [conditional queries](/reference/rules/conditions).
```html
<div class="grid-row:1/3:hover grid-row:1/3@dark grid-row:1/3@print grid-row:1/3@sm">…</div>
```
