## Basic usage
### Size implicit columns
Use `grid-auto-columns` to size columns created outside the explicit grid.
<Demo $py={0}>
    <DemoPanel>
        <div className="grid grid-auto-flow:column grid-auto-columns:96px gap:2x overflow:auto">
            <div className="min-w:0 p:3x r:8 bg:blue-5 bg:blue-95@dark border:1|solid|blue-20 border-color:blue-80@dark text-center">
                <div className="fg:blue-60 font:11 font-weight:700 text-ellipsis overflow:hidden white-space:nowrap">96px</div>
                <div className="fg:strong font:14 font-weight:560">A</div>
            </div>
            <div className="min-w:0 p:3x r:8 bg:gray-5 bg:gray-90@dark text-center">B</div>
            <div className="min-w:0 p:3x r:8 bg:gray-5 bg:gray-90@dark text-center">C</div>
        </div>
    </DemoPanel>
</Demo>
```html
<div class="grid grid-auto-flow:column">
    <!-- @MARK grid-auto-columns:96px -->
    <div class="grid-auto-columns:96px">A</div>
    <div>B</div>
    <div>C</div>
</div>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="grid-auto-columns:96px:hover grid-auto-columns:96px@sm grid-auto-columns:96px@dark grid-auto-columns:96px@print">…</div>
```
