## Examples
### Use the background shorthand
Use `bg:*` with pipe separators when several background longhands should be set together.
```html
<!-- @MARK bg:url(/hero.jpg)|center/cover|no-repeat -->
<section class="bg:url(/hero.jpg)|center/cover|no-repeat">
    ...
</section>
```

<details>
    <summary>Generated CSS</summary>
    <Class2CSS>

</details>

### Prefer focused utilities for simple changes
Use [background-color](/reference/background-color), [background-image](/reference/background-image), [background-position](/reference/background-position), [background-size](/reference/background-size), and [background-repeat](/reference/background-repeat) when only one background part should change.
```html
<!-- @MARK bg:surface --><!-- @MARK bg-center --><!-- @MARK bg-cover -->
<article class="bg:surface bg-center bg-cover">
    ...
</article>
```

The native `background` shorthand resets several background longhands. Use it intentionally when that reset is part of the design.

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="bg:surface bg:url(/hero.jpg)|center/cover|no-repeat@sm bg:surface@print">...</div>
```

Use layered backgrounds with comma-separated values only when the visual needs multiple images or gradients.
