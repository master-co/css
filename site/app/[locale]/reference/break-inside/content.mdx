## Basic usage \{#basic-usage\}
### Set the break inside behavior \{#set-the-break-inside-behavior\}
Use `break-inside:avoid` to keep a card or other block together when content flows across columns or pages. It is an avoidance request: content taller than the available fragment can still need to break.

Both previews use a 200px-tall column container. Compare the blue block with automatic breaks and with `avoid`.

<DemoExample page="break-inside" section="set-the-break-inside-behavior" />

```html
<div class="columns:2 h:12.5rem column-fill:auto">
  <div class="h:130px">1</div>
  <!-- @MARK break-inside:avoid -->
  <div class="h:90px break-inside:avoid">2</div>
  <div class="h:60px">3</div>
  <div class="h:40px">4</div>
</div>
```
Without the avoidance rule, the second block can continue into the next column:
```html
<div class="columns:2 h:12.5rem column-fill:auto">
  <div class="h:130px">1</div>
  <div class="h:90px">2</div>
  <div class="h:60px">3</div>
  <div class="h:40px">4</div>
</div>
```

### Apply conditionally \{#apply-conditionally\}
Keep fragmentation automatic at narrow widths and avoid splitting the block at `sm`. Resize the preview to compare the blue block in the same two-column context. See [conditions](/reference/rules/conditions).

<DemoExample page="break-inside" section="apply-conditionally" />

```html
<div class="columns:2 h:12.5rem column-fill:auto">
  <div class="h:130px">1</div>
  <div class="h:90px break-inside:auto break-inside:avoid@sm">2</div>
  <div class="h:60px">3</div>
  <div class="h:40px">4</div>
</div>
```
