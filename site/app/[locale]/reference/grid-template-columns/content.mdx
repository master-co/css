## Basic usage
### Define explicit columns
Use `grid-template-columns` to define the track list for grid columns.
<Demo $py={0}>
  <DemoPanel>
    <div className="grid grid-template-columns:96px|1fr|72px gap:xs">
      <div className="overflow:hidden min-w:0 p:sm b:1px|solid|blue-20 r:lg text-ellipsis white-space:nowrap bg:blue-5 b:blue-80@dark bg:blue-95@dark">96px</div>
      <div className="overflow:hidden min-w:0 p:sm r:lg text-ellipsis white-space:nowrap bg:gray-5 bg:gray-90@dark">1fr</div>
      <div className="overflow:hidden min-w:0 p:sm r:lg text-ellipsis white-space:nowrap bg:gray-5 bg:gray-90@dark">72px</div>
    </div>
  </DemoPanel>
</Demo>
```html
<!-- @MARK grid-template-columns:96px|1fr|72px -->
<div class="grid grid-template-columns:96px|1fr|72px">…</div>
```

### Use minmax
```html
<!-- @MARK grid-template-columns:minmax(0,1fr)|2fr -->
<div class="grid grid-template-columns:minmax(0,1fr)|2fr">…</div>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="grid-template-columns:96px|1fr|72px:hover grid-template-columns:96px|1fr|72px@dark grid-template-columns:96px|1fr|72px@print grid-template-columns:96px|1fr|72px@sm">…</div>
```
