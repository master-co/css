## Examples \{#examples\}
### Add space between words \{#add-space-between-words\}
Use `word-spacing:*` for short labels, all-caps headings, or dense text where words need more separation.
```html
<!-- @MARK word-spacing:.04em -->
<p class="word-spacing:.04em">
  Quarterly revenue report
</p>
```

### Use fixed spacing when needed \{#use-fixed-spacing-when-needed\}
Any valid CSS length can be used when the spacing needs to match a fixed visual rhythm.
```html
<!-- @MARK word-spacing:2px -->
<span class="word-spacing:2px">Invoice total</span>
```

### Avoid overusing wide spacing \{#avoid-overusing-wide-spacing\}
Large word spacing can hurt readability in paragraphs. Prefer it for short runs of text.
```html
<p class="word-spacing:0">Long body copy keeps normal word spacing.</p>
```

### Apply conditionally \{#apply-conditionally\}
Apply styles based on different states using [selectors](/reference/rules/selectors) and [conditional queries](/reference/rules/conditions).
```html
<p class="word-spacing:.04em:hover word-spacing:0@print word-spacing:0@sm">...</p>
```
