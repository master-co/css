## Examples \{#examples\}
### Contain layout and paint \{#contain-layout-and-paint\}
Use `contain:content` to combine layout, paint and style containment. It does not include size containment: the panel can still respond to its content. The comparison below makes the paint boundary visible.

<DemoExample page="contain" section="contain-layout-and-paint" />

```html
<!-- @MARK contain:content -->
<section class="h:8rem w:12rem contain:content">
  <div class="h:5rem w-3xs">Wide content</div>
</section>
```

### Contain painting \{#contain-painting\}
Use `contain:paint` to prevent descendants from painting beyond the panel. The violet block is wider than its parent, so clipping is visible at the boundary. This example shows painting behavior, not a measured performance improvement.

<DemoExample page="contain" section="contain-painting" />

```html
<!-- @MARK contain:paint -->
<div class="h:8rem w:12rem contain:paint">
  <div class="h:5rem w-3xs">Wide content</div>
</div>
```

### Reset containment \{#reset-containment\}
Reset containment on the element that owns it. A child with `contain:none` cannot escape an ancestor’s paint containment. Here the same panel changes from `paint` to `none` at `sm`; widen the preview to reveal the overflow.

<DemoExample page="contain" section="reset-containment" />

```html
<!-- @MARK contain:none -->
<div class="h:8rem w:12rem contain:paint contain:none@sm">
  <div class="h:5rem w-3xs">Wide content</div>
</div>
```

### Apply conditionally \{#apply-conditionally\}
Leave painting unconstrained initially, then apply paint containment at `sm`. The child keeps the same width in both states. Read [conditions](/reference/rules/conditions) for breakpoint syntax.

<DemoExample page="contain" section="apply-conditionally" />

```html
<div class="h:8rem w:12rem contain:none contain:paint@sm">
  <div class="h:5rem w-3xs">Wide content</div>
</div>
```
