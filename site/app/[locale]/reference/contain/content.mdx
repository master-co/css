## Examples \{#examples\}
### Contain layout and paint \{#contain-layout-and-paint\}
Use `contain:content` for self-contained panels where layout and paint work should not affect the outside page.
```html
<!-- @MARK contain:content -->
<section class="contain:content">
  Feed item
</section>
```

<details>

### Contain painting \{#contain-painting\}
Use `contain:paint` when overflowing visual effects should be contained without opting into every containment mode.
```html
<!-- @MARK contain:paint -->
<div class="contain:paint">
  Preview
</div>
```

### Reset containment \{#reset-containment\}
Use `contain:none` when a nested element needs to participate normally in layout or painting again.
```html
<!-- @MARK contain:none -->
<div class="contain:content">
  <div class="contain:none">Escapes containment</div>
</div>
```

### Apply conditionally \{#apply-conditionally\}
Apply styles based on different states using [selectors](/reference/rules/selectors) and [conditional queries](/reference/rules/conditions).
```html
<div class="contain:content contain:none@print contain:paint@sm">...</div>
```
