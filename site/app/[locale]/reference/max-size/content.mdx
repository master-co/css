The built-in `max-size` utility and its named token form have been removed before Master CSS 2.0. This URL remains for existing links.

Use `max-width:20px max-height:20px` for direct values, or `max-width-sm max-height-sm` when both entries resolve to the intended container token. These are independent declarations; review competing dimensions when upgrading.

See the [Master CSS v2 RC migration guide](/guide/migration/v2-rc#sizing-and-resolution) for safe migration and sorting checks, and [sizing](/guide/sizing) for current usage. Projects may still define a custom `max-size` utility with `@mixin --max-size`.

Native page-size descriptors and logical properties such as `inline-size` and `block-size` remain available.
