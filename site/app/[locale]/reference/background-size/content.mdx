## Examples
### Cover a frame
Use `bg-cover` when the background image should fill the element and may be cropped.
```html
<!-- @MARK bg:url(/hero.jpg) --><!-- @MARK bg-cover -->
<section class="bg-cover bg:url(/hero.jpg)">
  ...
</section>
```

<details>
  <summary>Generated CSS</summary>
  <Class2CSS>
    {['bg:url(/hero.jpg)', 'bg-cover']}
  </Class2CSS>
</details>

### Contain an image
Use `bg-contain` when the entire background image should remain visible.
```html
<!-- @MARK bg-contain --><!-- @MARK bg-no-repeat -->
<div class="bg-contain bg-no-repeat">...</div>
```

### Use measured sizes
Use `background-size:*` for measured or multi-layer sizes.
```html
<!-- @MARK background-size:12x|12x -->
<div class="background-size:12x|12x">...</div>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="bg-contain bg-auto@print bg-cover@sm">...</div>
```

Pair size with [background-position](/reference/background-position) to control the crop.
