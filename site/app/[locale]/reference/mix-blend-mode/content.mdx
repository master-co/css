## Examples
### Blend an element with its backdrop
Use `blend:*` to set how the entire element blends with content behind it.
```html
<!-- @MARK blend:multiply -->
<div class="blend:multiply">
    ...
</div>
```

<details>
    <summary>Generated CSS</summary>
    <Class2CSS>
        {['blend:multiply']}
    </Class2CSS>
</details>

### Restore normal blending
Use `blend:normal` to remove a blend mode.
```html
<!-- @MARK blend:normal -->
<div class="blend:normal">...</div>
```

For blending background layers inside the same element, use [background-blend-mode](/reference/background-blend-mode).

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="blend:normal blend:multiply@sm blend:normal@print">...</div>
```

Blend modes can change contrast unpredictably as the backdrop changes.
