## Examples
### Blend an element with its backdrop
Use `mix-blend-mode:*` to set how the entire element blends with content behind it.
```html
<!-- @MARK mix-blend-mode:multiply -->
<div class="mix-blend-mode:multiply">
  ...
</div>
```

<details>
  <summary>Generated CSS</summary>
  <Class2CSS>

</details>

### Restore normal blending
Use `mix-blend-mode:normal` to remove a blend mode.
```html
<!-- @MARK mix-blend-mode:normal -->
<div class="mix-blend-mode:normal">...</div>
```

For blending background layers inside the same element, use [background-blend-mode](/reference/background-blend-mode).

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="mix-blend-mode:normal mix-blend-mode:normal@print mix-blend-mode:multiply@sm">...</div>
```

Blend modes can change contrast unpredictably as the backdrop changes.
