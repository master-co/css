## Examples \{#examples\}
### Blend an element with its backdrop \{#blend-an-element-with-its-backdrop\}
Compare normal paint with multiply across two opaque backdrops. The same blue foreground overlaps a neutral parent background and a violet sibling.

<DemoExample page="mix-blend-mode" section="blend-an-element-with-its-backdrop" />

```html
<!-- Normal · one foreground color -->
<div class="position:relative isolation:isolate height:160px width:240px
         max-width:100% background-color:#e2e8f0">
  <div aria-hidden="true"
    class="position:absolute bottom:0 right:0 top:0 width:120px background-color:#c4b5fd"></div>
  <div id="target" role="img"
    aria-label="Blue foreground across two backdrops"
    class="position:absolute left:72px top-xl width:96px height:96px r-lg
           background-color:#2563eb mix-blend-mode:normal"></div>
</div>
```

```html
<!-- Multiply · combines with both backdrops -->
<div class="position:relative isolation:isolate height:160px width:240px
         max-width:100% background-color:#e2e8f0">
  <div aria-hidden="true"
    class="position:absolute bottom:0 right:0 top:0 width:120px background-color:#c4b5fd"></div>
  <div id="target" role="img"
    aria-label="Blue foreground across two backdrops"
    class="position:absolute left:72px top-xl width:96px height:96px r-lg
           background-color:#2563eb mix-blend-mode:multiply"></div>
</div>
```

<details>
  <summary>Generated CSS</summary>
  <Class2CSS>
    {['mix-blend-mode:multiply']}
  </Class2CSS>
</details>

The explicit isolated container bounds the blend group. Blending uses the backdrop already painted behind the element, not only its parent’s background. Labels stay outside the blended subject.

### Restore normal blending \{#restore-normal-blending\}
Open print preview to remove multiply with `mix-blend-mode:normal`. The blue foreground then has the same color over both backdrops.

<DemoExample page="mix-blend-mode" section="restore-normal-blending" />

```html
<!-- Multiply on screen · normal in print -->
<div class="position:relative isolation:isolate height:160px width:240px
         max-width:100% background-color:#e2e8f0">
  <div aria-hidden="true"
    class="position:absolute bottom:0 right:0 top:0 width:120px background-color:#c4b5fd"></div>
  <div id="target" role="img"
    aria-label="Blue foreground across two backdrops"
    class="position:absolute left:72px top-xl width:96px height:96px r-lg
           background-color:#2563eb mix-blend-mode:multiply
           mix-blend-mode:normal@print"></div>
</div>
```

Normal restores ordinary source-over painting without changing position or dimensions. For layers inside one element’s background, use [background-blend-mode](/reference/background-blend-mode).

### Apply conditionally \{#apply-conditionally\}
Widen to `sm` to enable multiply. Print always uses normal blending.

<DemoExample page="mix-blend-mode" section="apply-conditionally" />

```html
<!-- Normal → multiply at sm -->
<div class="position:relative isolation:isolate height:160px width:240px
         max-width:100% background-color:#e2e8f0">
  <div aria-hidden="true"
    class="position:absolute bottom:0 right:0 top:0 width:120px background-color:#c4b5fd"></div>
  <div id="target" role="img"
    aria-label="Blue foreground across two backdrops"
    class="position:absolute left:72px top-xl width:96px height:96px r-lg
           background-color:#2563eb mix-blend-mode:normal
           mix-blend-mode:normal@print
           mix-blend-mode:multiply@screen@sm"></div>
</div>
```

The fixed source colors make comparisons repeatable in both themes. In an interface, changing backdrop colors can alter contrast; keep important text readable independently of the effect.
