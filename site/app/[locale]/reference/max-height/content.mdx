## Examples
### Cap a vertical region
Use `max-h:*` when content should stop growing past a limit.
```html
<!-- @MARK max-h:64x --><!-- @MARK overflow-y:auto -->
<div class="overflow-y:auto max-h:3xs">
  ...
</div>
```

<details>
  <summary>Generated CSS</summary>
  <Class2CSS>
    {['max-h:64x', 'overflow-y:auto']}
  </Class2CSS>
</details>

### Keep media inside a frame
Use `max-h:*` with `object-contain` or `object-cover` when replaced media must stay within a visual frame.
```html
<!-- @MARK max-h:48x --><!-- @MARK w:full -->
<img class="w:full max-h:48x object-contain" src="..." alt="" />
```

### Use viewport caps
Use `max-vh` or native viewport units when overlays and menus must stay within the visible viewport.
```html
<!-- @MARK max-h:80dvh --><!-- @MARK overflow:auto -->
<div class="overflow:auto max-h:80dvh">
  ...
</div>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="max-h:none max-h:none@print max-h:3xs@sm">...</div>
```

Pair max height with an overflow rule when content can exceed the cap.
