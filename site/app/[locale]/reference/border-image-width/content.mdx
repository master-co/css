## Basic usage \{#basic-usage\}
### Set the border image width \{#set-the-border-image-width\}
Image width controls inward paint independently of the regular border. These identical 12px borders compare a multiplier of `1`, a multiplier of `2`, and an explicit `16px` image width.

<DemoExample page="border-image-width" section="set-the-border-image-width" />

```html
<!-- Width 1 · 12px paint -->
<div id="target"
  class="display:flex align-items:center justify-content:center height:130px
         width:250px max-width:100% p-md border:12px|solid|var(--color-blue-60)
         border-image-repeat:stretch
         border-image-slice:24
         border-image-source:url('/demo/border-grid.svg')
         border-image-width:1 font-md bg-surface-base
         fg-text-body box-sizing:border-box">
  <span class="px-xs py-3xs bg-surface-base fg-text-body">
    Edge sample
  </span>
</div>
```

```html
<!-- Width 2 · 24px paint -->
```

A bare number multiplies the corresponding regular border width. Larger paint can cover the padding area without resizing the 250 × 130 border box.

### Use automatic width \{#use-automatic-width\}
For this intrinsic 96 × 96 source, `auto` uses the natural 24-unit slices as 24px painted widths. Compare it with the explicit 24px result.

<DemoExample page="border-image-width" section="use-automatic-width" />

```html
<!-- Auto · natural 24px slices -->
<div id="target"
  class="display:flex align-items:center justify-content:center height:130px
         width:250px max-width:100% p-md border:12px|solid|var(--color-blue-60)
         border-image-repeat:stretch
         border-image-slice:24
         border-image-source:url('/demo/border-grid.svg')
         border-image-width:auto font-md
         bg-surface-base fg-text-body box-sizing:border-box">
  <span class="px-xs py-3xs bg-surface-base fg-text-body">
    Edge sample
  </span>
</div>
```

```html
<!-- 24px · explicit comparison -->
<div id="target"
  class="display:flex align-items:center justify-content:center height:130px
         width:250px max-width:100% p-md border:12px|solid|var(--color-blue-60)
         border-image-repeat:stretch
         border-image-slice:24
         border-image-source:url('/demo/border-grid.svg')
         border-image-width:24px font-md
         bg-surface-base fg-text-body box-sizing:border-box">
  <span class="px-xs py-3xs bg-surface-base fg-text-body">
    Edge sample
  </span>
</div>
```

When a slice has no applicable natural size, auto falls back to the regular border width. The computed value can still read `auto`; the comparison shows the actual paint.

### Apply conditionally \{#apply-conditionally\}
Widen to `sm` to double the image width from 12px to 24px. Print returns to the width multiplier `1`.

<DemoExample page="border-image-width" section="apply-conditionally" />

```html
<!-- Width 1 → 2 at sm -->
<div id="target"
  class="display:flex align-items:center justify-content:center height:130px
         width:250px max-width:100% p-md border:12px|solid|var(--color-blue-60)
         border-image-repeat:stretch
         border-image-slice:24
         border-image-source:url('/demo/border-grid.svg')
         border-image-width:1 font-md bg-surface-base
         fg-text-body box-sizing:border-box
         border-image-width:1@media(print)
         border-image-width:2@media(screen)@sm">
  <span class="px-xs py-3xs bg-surface-base fg-text-body">
    Edge sample
  </span>
</div>
```

The layout box stays fixed. Its regular border width remains 12px in every state.
