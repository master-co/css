### Use a precise size \{#use-a-precise-size\}
Use `text:*` when the type scale utility should set font size, line height, and letter spacing together.
```html
<!-- @MARK text:16px -->
<p class="text:md">
  Body copy
</p>
```

<details>
  <summary>Generated CSS</summary>

</details>

### Apply conditionally \{#apply-conditionally\}
Apply styles based on different states using [selectors](/reference/rules/selectors) and [conditional queries](/reference/rules/conditions).
```html
<div class="text:xl:hover text:md@print text:5xl@sm">...</div>
```
