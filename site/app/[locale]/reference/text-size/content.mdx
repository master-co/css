### Use a precise size
Use `text:*` when the type scale utility should set font size, line height, and letter spacing together.
```html
<!-- @MARK text:16 -->
<p class="text:16">
    Body copy
</p>
```

<details>
    <summary>Generated CSS</summary>
    <Class2CSS>
        {['text:16']}

</details>

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="text:20:hover text:40@sm text:16@print">...</div>
```
