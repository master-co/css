### Use a precise size \{#use-a-precise-size\}
For a measured size outside the named scale, set each native property explicitly. Named recipes use authored token values; there is no size-dependent line-height or letter-spacing formula.

<DemoExample page="text-size" section="use-a-precise-size" />

```html
<!-- Explicit 17px combined treatment -->
<p id="target" class="max-width:28ch margin:0 font-size:17px line-height:1.5 letter-spacing:0">Clear type gives each idea room to breathe. Keep the measure comfortable and let the content set the pace.</p>
```

### Apply conditionally \{#apply-conditionally\}
The title changes from `text-2xl` to `text-4xl` at `sm`, updating size, leading and tracking together. Print preview applies the smaller `text-xl` treatment.

<DemoExample page="text-size" section="apply-conditionally" />

```html
<!-- Responsive combined treatment -->
<h2 id="target" class="margin:0 text-2xl font-weight-regular text-xl@media(print) text-4xl@media(screen)@sm">Space for good ideas.</h2>
```

### Add a named treatment

Declare a primary token with optional companions. The preset `--text` mixin makes `text-article` available automatically:

```css
@theme {
  :root, :host {
    --text-article: 1.0625rem;
    --text-article--line-height: 1.5;
    --text-article--letter-spacing: 0;
  }
}
```

```html
<p class="text-article">A shared reading treatment.</p>
```

Missing companions use `normal`. Companion tokens alone do not create a class. `text-*` does not set family, weight or color; combine it with `font-family-sans`, `font-weight-medium`, or `fg-text-body` as needed. Use `@apply --text("article");` inside native CSS, or the explicit class `text("article")` when a function call is useful. `text(article)` fails the string parameter check.
