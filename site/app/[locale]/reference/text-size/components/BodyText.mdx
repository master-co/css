Use the smaller type steps for supporting text and body copy. Each `text-*` utility sets font size, line height and letter spacing together.

```html
<!-- text-sm -->
<p id="target" class="max-width:28ch margin:0 text-sm font-weight-regular">Clear type gives each idea room to breathe. Keep the measure comfortable and let the content set the pace.</p>
```
