Use the smaller type steps for supporting text and body copy. Each `text:*` utility sets font size, line height and letter spacing together.

```html
<!-- text:sm -->
<p id="target" class="max-w:28ch m:0 text:sm font:regular">Clear type gives each idea room to breathe. Keep the measure comfortable and let the content set the pace.</p>
```

```html
<!-- text:md -->
<p id="target" class="max-w:28ch m:0 text:md font:regular">Clear type gives each idea room to breathe. Keep the measure comfortable and let the content set the pace.</p>
```

```html
<!-- text:lg -->
<p id="target" class="max-w:28ch m:0 text:lg font:regular">Clear type gives each idea room to breathe. Keep the measure comfortable and let the content set the pace.</p>
```
