Use the middle steps to establish a heading hierarchy. The heading element expresses structure; the class controls its visual treatment.

```html
<!-- text-lg -->
<h2 id="target" class="max-w:28ch m:0 text-lg font-regular">A clearer way to work</h2>
```

```html
<!-- text-xl -->
<h2 id="target" class="max-w:28ch m:0 text-xl font-regular">A clearer way to work</h2>
```

```html
<!-- text-2xl -->
<h2 id="target" class="max-w:28ch m:0 text-2xl font-regular">A clearer way to work</h2>
```
