## Examples
### Choose the background positioning area
Use `bg-origin-padding`, `bg-origin-border`, or `bg-origin-content` to decide which box positions the background image.
```html
<!-- @MARK bg-origin-content -->
<section class="bg-origin-content p:md b:1|solid|line">
    ...
</section>
```

### Align art with borders or content
Use `bg-origin-border` when the background should start from the border box, and `bg-origin-content` when it should align with the content box.
```html
<!-- @MARK bg-origin-border --><!-- @MARK bg-origin-content -->
<div class="bg-origin-border">...</div>
<div class="bg-origin-content">...</div>
```

This affects positioning and sizing, not clipping. Use [background-clip](/reference/background-clip) to control where the background is painted.

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="bg-origin-padding bg-origin-content@sm bg-origin-padding@print">...</div>
```
