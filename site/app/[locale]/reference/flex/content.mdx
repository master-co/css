## Examples
### Let an item fill remaining space
Use `flex:1` on a flex item that should grow and shrink to take the available space.
```html
<!-- @MARK flex --><!-- @MARK flex:1 -->
<div class="flex gap:md">
  <aside class="flex:0 w:24x">...</aside>
  <main class="flex:1 min-w:0">...</main>
</div>
```

  <summary>Generated CSS</summary>

### Prevent an item from flexing
Use `flex:0` for icons, fixed media, and side controls that should keep their measured size while siblings flex around them.
```html
<!-- @MARK flex:0 --><!-- @MARK size:10x -->
<div class="flex items-center gap:sm">
  <img class="flex:0 size:10x" src="..." alt="" />
  <span class="min-w:0">Profile details</span>
</div>
```

### Set grow, shrink, and basis together
The `flex` property is shorthand for `flex-grow`, `flex-shrink`, and `flex-basis`. Use pipe separators when you need to pass multiple CSS values.
```html
<!-- @MARK flex:0|0|18x -->
<aside class="flex:0|0|18x">
  ...
</aside>
```

Reach for [flex-grow](/reference/flex-grow), [flex-shrink](/reference/flex-shrink), or [flex-basis](/reference/flex-basis) when only one part of the shorthand should change.

### Remember the parent display
`flex:*` affects a flex item. The parent still needs `flex`, `inline-flex`, or another layout mode that makes the child participate in flex sizing.
```html
<!-- @MARK flex -->
<section class="flex">
  <div class="flex:1">...</div>
</section>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="flex:0 flex:0@print flex:1@sm">...</div>
```

For text-heavy flex children, pair flexible sizing with `min-w:0` so long content can shrink.
