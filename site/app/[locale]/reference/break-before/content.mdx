## Basic usage \{#basic-usage\}
### Set the break before behavior \{#set-the-break-before-behavior\}
Use `break-before:column` to force a column break before the marked element. The break needs a fragmentation context, such as a multi-column container; it does not create a new column in ordinary block flow.

<DemoExample page="break-before" section="set-the-break-before-behavior" />

```html
<div class="columns:2 h:50x column-fill:auto">
  <div class="h:48px">01</div>
  <!-- @MARK break-before:column -->
  <div class="h:48px break-before:column">02 · Target</div>
  <div class="h:48px">03</div>
  <div class="h:48px">04</div>
</div>
```

### Apply conditionally \{#apply-conditionally\}
Leave the break automatic at narrow widths, then force a column break before the element at `sm`. Both column containers are 200px tall and fill from top to bottom. Resize the preview to compare the result. See [conditions](/reference/rules/conditions).

<DemoExample page="break-before" section="apply-conditionally" />

```html
<div class="columns:2 h:50x column-fill:auto">
  <div class="h:48px">01</div>
  <div class="h:48px break-before:auto break-before:column@sm">02 · Target</div>
  <div class="h:48px">03</div>
  <div class="h:48px">04</div>
</div>
```
