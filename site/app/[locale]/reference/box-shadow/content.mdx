## Basic usage \{#basic-usage\}

### Use shadow tokens \{#use-shadow-tokens\}
Preset `box-shadow:*` tokens define common elevation levels. Switch the preview theme: the class stays the same while each token resolves to its mode-specific paint.

<DemoExample page="box-shadow" section="use-shadow-tokens" />

```html
<!-- Small elevation -->
<article id="target"
  class="width:240px max-width:100% p-lg r-md bg-surface-base
         fg-text-body shadow-sm box-sizing:border-box">
  <h4 class="margin:0 font-lg">
    Workspace library
  </h4>
  <p class="margin-inline:0 margin-bottom:0 mt-sm font-sm">
    Shared assets and components.
  </p>
</article>
```

```html
<!-- Large elevation -->
<article id="target"
  class="width:240px max-width:100% p-lg r-md bg-surface-base
         fg-text-body shadow-lg box-sizing:border-box">
  <h4 class="margin:0 font-lg">
    Workspace library
  </h4>
  <p class="margin-inline:0 margin-bottom:0 mt-sm font-sm">
    Shared assets and components.
  </p>
</article>
```

<details>
  <summary>Generated CSS</summary>
  <Class2CSS>
    {['shadow-sm', 'shadow-lg']}
  </Class2CSS>
</details>

The shadow is visual ink outside the box; it does not add layout size or spacing. Leave enough room for its blur to remain visible.

### Use raw values \{#use-raw-values\}
Use literal shadow layers for a specific effect. The first listed layer paints above later layers. These blue shadows retain the same raw color values across themes.

<DemoExample page="box-shadow" section="use-raw-values" />

```html
<!-- Two raw layers · literal color -->
<article id="target"
  class="width:240px max-width:100% p-lg r-md bg-surface-base
         fg-text-body
         box-shadow:0|2px|4px|color-mix(in|oklab,var(--color-blue-50)|20%,transparent),0|8px|16px|color-mix(in|oklab,var(--color-blue-50)|12%,transparent)
         box-sizing:border-box">
  <h4 class="margin:0 font-lg">
    Workspace library
  </h4>
  <p class="margin-inline:0 margin-bottom:0 mt-sm font-sm">
    Shared assets and components.
  </p>
</article>
```

Raw values do not automatically acquire a separate dark-mode design. Compare against the actual surface, then promote recurring decisions into a theme token.

### Use inset shadows \{#use-inset-shadows\}
`inset` paints the shadow inside the border edge. Compare the same 4px vertical offset and 12px blur outside and inside the surface.

<DemoExample page="box-shadow" section="use-inset-shadows" />

```html
<!-- Outer shadow -->
<article id="target"
  class="width:240px max-width:100% p-lg r-md bg-surface-base
         fg-text-body box-shadow:0|4px|12px|color-mix(in|oklab,var(--color-blue-50)|20%,transparent)
         box-sizing:border-box">
  <h4 class="margin:0 font-lg">
    Workspace library
  </h4>
  <p class="margin-inline:0 margin-bottom:0 mt-sm font-sm">
    Shared assets and components.
  </p>
</article>
```

```html
<!-- Inset shadow -->
<article id="target"
  class="width:240px max-width:100% p-lg r-md bg-surface-base
         fg-text-body box-shadow:inset|0|4px|12px|color-mix(in|oklab,var(--color-blue-50)|20%,transparent)
         box-sizing:border-box">
  <h4 class="margin:0 font-lg">
    Workspace library
  </h4>
  <p class="margin-inline:0 margin-bottom:0 mt-sm font-sm">
    Shared assets and components.
  </p>
</article>
```

Neither shadow changes the box’s dimensions. An inset shadow paints over the background and beneath the content.

### Apply conditionally \{#apply-conditionally\}
Hover or keyboard-focus the button to move from a small to a large shadow token. Print removes the shadow while preserving its border and label.

<DemoExample page="box-shadow" section="apply-conditionally" />

```html
<!-- Small → large elevation on interaction -->
<button id="target" type="button"
  class="display:inline-flex align-items:center justify-content:center
         min-height:44px max-width:100% px-md py-sm
         border:1px|solid|var(--color-line-divider) r-sm font-md
         bg-surface-base fg-text-body shadow-sm
         box-sizing:border-box bg-surface-inset:focus-visible
         box-shadow:none@media(print) shadow-lg:hover@media(screen)
         shadow-lg:focus-visible@media(screen)">
  Open library
</button>
```

The independent focus outline remains visible; a shadow alone should not be the only indication of keyboard focus.

### Customize mode-specific tokens \{#customize-mode-specific-tokens\}
Override a shared shadow token separately in light and dark themes. The live preview compiles these exact declarations; use its theme control to compare the resolved layers.

<DemoExample page="box-shadow" section="customize-mode-specific-tokens" />

```css name=index.css
@theme { @media (prefers-color-scheme: light) { :root, :host {
  --shadow-sm: 0 0 0 1px oklch(0% 0 none / .08),
    0 6px 12px -2px oklch(0% 0 none / .14);
} } }

@theme { @media (prefers-color-scheme: dark) { :root, :host {
  --shadow-sm: 0 0 0 1px oklch(100% 0 none / .16),
    0 6px 12px -2px oklch(0% 0 none / .5);
} } }

```

```html
<!-- Configured small shadow · two theme definitions -->
<article id="target"
  class="width:240px max-width:100% p-lg r-md bg-surface-base
         fg-text-body shadow-sm box-sizing:border-box">
  <h4 class="margin:0 font-lg">
    Workspace library
  </h4>
  <p class="margin-inline:0 margin-bottom:0 mt-sm font-sm">
    Shared assets and components.
  </p>
</article>
```

The subtle edge layer helps separate the surface in dark mode. The shadow still occupies no layout space. Prefer shared tokens when the same elevation decision appears across a product.
