## Basic usage
### With opacity
Add the suffix `/alpha` to change the opacity of any color.
<Basic className="bg:accent-surface" />

Use `bg:*` for semantic surface tokens, theme colors, and one-off colors.
```html
<!-- @MARK bg:surface --><!-- @MARK bg:accent/.12 -->
<section class="bg:surface">...</section>
<span class="bg:accent/.12">Badge</span>
```

<details>
    <summary>Generated CSS</summary>
    <Class2CSS>
        {['bg:surface', 'bg:accent/.12']}
    </Class2CSS>
</details>

Use semantic tokens such as `surface`, `base`, or product color names for repeated UI surfaces. Use alpha suffixes for local overlays, badges, and hover states.

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="bg:surface bg:primary/.12:hover bg:surface@print">...</div>
```
