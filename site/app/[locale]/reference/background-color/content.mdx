## Basic usage
### With opacity
Add the suffix `/alpha` to change the opacity of any color.
<Basic className="bg:blue" />

Use `bg:*` for palette colors, project theme colors, and one-off colors.
```html
<!-- @MARK bg:blue --><!-- @MARK bg:pink/.12 -->
<section class="bg:blue">...</section>
<span class="bg:pink/.12">Badge</span>
```

<details>
    <summary>Generated CSS</summary>
    <Class2CSS>
        {['bg:blue', 'bg:pink/.12']}
    </Class2CSS>
</details>

Define semantic tokens such as `surface`, `base`, or product color names in your project theme for repeated UI surfaces. Use alpha suffixes for local overlays, badges, and hover states.

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="bg:blue bg:pink/.12:hover bg:white@print">...</div>
```
