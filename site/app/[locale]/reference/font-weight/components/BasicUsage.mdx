Use named weight tokens from `font-thin` to `font-heavy`. The variable Geist face in this preview supports the full 100–900 range.

```html
<!-- font-thin -->
<p id="target" class="m:0 font-thin font-xl leading-sm">Design with clarity.</p>
```

```html
<!-- font-extralight -->
<p id="target" class="m:0 font-extralight font-xl leading-sm">Design with clarity.</p>
```
