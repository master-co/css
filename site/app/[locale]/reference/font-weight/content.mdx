### Use explicit weights \{#use-explicit-weights\}
Use `font-weight:*` for a numeric value between named steps. A variable font can interpolate supported weights; a static family uses its available faces and may synthesize a heavier appearance.

<DemoExample page="font-weight" section="use-explicit-weights" />

```html
<!-- font-weight-medium -->
<p id="target" class="margin:0 font-weight-medium font-size-xl leading-sm">Design with clarity.</p>
```

```html
<!-- font-weight:550 -->
<p id="target" class="margin:0 font-weight:550 font-size-xl leading-sm">Design with clarity.</p>
```

```html
<!-- font-weight-semibold -->
<p id="target" class="margin:0 font-weight-semibold font-size-xl leading-sm">Design with clarity.</p>
```

### Apply conditionally \{#apply-conditionally\}
Hover the button or focus it with the keyboard. Both states apply `font-weight-semibold`; the default remains `font-weight-regular`.

<DemoExample page="font-weight" section="apply-conditionally" />

```html
<!-- Pointer and keyboard states -->
<button type="button" id="target" class="font-size-md font-weight-regular font-weight-semibold:hover font-weight-semibold:focus-visible">Focus or hover to compare</button>
```
