## Examples
### Wrap text around a circle
Use `shape:circle(*)` on a floated element to let inline content wrap around a circular shape.
```html
<!-- @MARK shape:circle(50%) -->
<img class="float:left shape:circle(50%) shape-margin:1rem" src="/images/avatar.jpg" alt="Avatar">
```

<details>
    <summary>Generated CSS</summary>
    <Class2CSS>
        {['shape:circle(50%)']}

</details>

### Use an inset shape
Use `shape:inset(*)` when text should wrap around a rectangular inset.
```html
<!-- @MARK shape:inset(0|20px) -->
<img class="float:left shape:inset(0|20px)" src="/images/photo.jpg" alt="Photo">
```

### Remove shape wrapping
Use `shape-none` when a responsive or print context should use the normal float box.
```html
<!-- @MARK shape-none -->
<img class="float:left shape:circle(50%) shape-none@print" src="/images/avatar.jpg" alt="Avatar">
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<img class="shape:circle(50%):hover shape:inset(0|20px)@sm shape-none@print" src="/images/avatar.jpg" alt="">
```
