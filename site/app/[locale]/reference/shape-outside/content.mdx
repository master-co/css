## Examples \{#examples\}
### Wrap text around a circle \{#wrap-text-around-a-circle\}
Use `shape-outside:circle(*)` on a floated element to let inline content wrap around a circular shape.
```html
<!-- @MARK shape-outside:circle(40px) -->
<img class="float:left shape-margin:md shape-outside:circle(40px)" src="/images/avatar.jpg" alt="Avatar">
```

### Use an inset shape \{#use-an-inset-shape\}
Use `shape-outside:inset(*)` when text should wrap around a rectangular inset.
```html
<!-- @MARK shape-outside:inset(0|20px) -->
<img class="float:left shape-outside:inset(0|20px)" src="/images/photo.jpg" alt="Photo">
```

### Remove shape wrapping \{#remove-shape-wrapping\}
Use `shape-none` when a responsive or print context should use the normal float box.
```html
<!-- @MARK shape-none -->
<img class="float:left shape-outside:circle(40px) shape-none@print" src="/images/avatar.jpg" alt="Avatar">
```

### Apply conditionally \{#apply-conditionally\}
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<img class="shape-outside:circle(40px):hover shape-none@print shape-outside:inset(0|20px)@sm" src="/images/avatar.jpg" alt="">
```
