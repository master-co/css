## Overview [sr-only]
<Overview/>

Use the native animation fill mode property directly.
```html
<div class="animation-fill-mode:both">
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="animation-fill-mode:none:hover animation-fill-mode:none@sm animation-fill-mode:none@dark animation-fill-mode:none@print">…</div>
```
