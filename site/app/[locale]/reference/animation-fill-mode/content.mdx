## Examples \{#examples\}
### Keep the final keyframe \{#keep-the-final-keyframe\}
Compare no fill with forwards fill after a one-second movement. The ordinary position is 0px; the keyframes run from 24px to 96px.

<DemoExample page="animation-fill-mode" section="keep-the-final-keyframe" />

```css name=index.css
@theme {
  @keyframes layer-slide {
    from { transform: translateX(24px); }
    to { transform: translateX(96px); }
  }
}
```

```html
<!-- None · returns to base -->
<div class="w:240px max-w:100%">
  <p class="mb-sm font-mono font-xs text-muted">Base 0 · start 24 · end 96px</p>
  <div aria-hidden="true"
    class="h:56px p-xs outline:1px|dashed|var(--color-line-muted)">
    <span id="target"
      class="grid place-items:center h:40px w:48px
             b:1px|solid|var(--color-blue-60) r-sm bg-blue-10
             fg-blue-80 transform:none
             animation-duration:1s
             animation-fill-mode:none
             animation-name:layer-slide
             animation-timing-function:linear
             animation:none@print
             animation-play-state:paused@reduce-motion">→</span>
  </div>
</div>
```


Forwards retains the value where the final iteration ends. Direction and a fractional iteration count can change that value; it is not always the 100% keyframe.

### Apply both before and after states \{#apply-both-before-and-after-states\}
Both specimens wait 600ms. Backwards fill applies the 24px starting keyframe during that delay; both also retains the 96px ending keyframe after completion.

<DemoExample page="animation-fill-mode" section="apply-both-before-and-after-states" />

```css name=index.css
@theme {
  @keyframes layer-slide {
    from { transform: translateX(24px); }
    to { transform: translateX(96px); }
  }
}
```

```html

             b:1px|solid|var(--color-blue-60) r-sm bg-blue-10

             animation-fill-mode:backwards
             animation-name:layer-slide
             animation-timing-function:linear
             animation:none@print
             animation-play-state:paused@reduce-motion">→</span>
  </div>
</div>
```

```html
<!-- Both · starting and ending states -->

```

The starting keyframe depends on direction. For reverse and alternate-reverse, backwards fill uses the end of the keyframe list during the delay.

### Reset fill behavior \{#reset-fill-behavior\}
Use none to return to ordinary styling during the 600ms delay and after the one-second active interval.

<DemoExample page="animation-fill-mode" section="reset-fill-behavior" />

```css name=index.css
@theme {
  @keyframes layer-slide {
    from { transform: translateX(24px); }
    to { transform: translateX(96px); }
  }
}
```

```html
<!-- None · base before and after -->
<div class="w:240px max-w:100%">
  <p class="mb-sm font-mono font-xs text-muted">Base 0 · start 24 · end 96px</p>
  <div aria-hidden="true"
    class="h:56px p-xs outline:1px|dashed|var(--color-line-muted)">
    <span id="target"
      class="grid place-items:center h:40px w:48px
             b:1px|solid|var(--color-blue-60) r-sm bg-blue-10
             fg-blue-80 transform:none
             animation-delay:600ms animation-duration:1s
             animation-fill-mode:none
             animation-name:layer-slide
             animation-timing-function:linear
             animation:none@print
             animation-play-state:paused@reduce-motion">→</span>
  </div>
</div>
```

The marker waits at 0px, jumps to its 24px starting keyframe when active, moves to 96px, then returns to 0px. Fill mode does not edit the underlying transform.

### Apply conditionally \{#apply-conditionally\}
Resize before replaying. Below `sm`, both retains the starting and ending states; at `sm`, none leaves ordinary styling outside the active interval.

<DemoExample page="animation-fill-mode" section="apply-conditionally" />

```css name=index.css
@theme {
  @keyframes layer-slide {
    from { transform: translateX(24px); }
    to { transform: translateX(96px); }
  }
}
```

```html
<!-- Both → none at sm -->
<div class="w:240px max-w:100%">
  <p class="mb-sm font-mono font-xs text-muted">Base 0 · start 24 · end 96px</p>
  <div aria-hidden="true"
    class="h:56px p-xs outline:1px|dashed|var(--color-line-muted)">
    <span id="target"
      class="grid place-items:center h:40px w:48px
             b:1px|solid|var(--color-blue-60) r-sm bg-blue-10
             fg-blue-80 transform:none
             animation-delay:600ms animation-duration:1s
             animation-fill-mode:both
             animation-name:layer-slide
             animation-timing-function:linear
             animation:none@print
             animation-play-state:paused@reduce-motion
             animation-fill-mode:none@sm">→</span>
  </div>
</div>
```

Changing fill mode can update an already-finished animation’s visible result. Print removes the animation completely rather than retaining a motion snapshot.
