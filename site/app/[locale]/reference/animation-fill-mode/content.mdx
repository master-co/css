## Examples
### Keep the final keyframe
Use `animation-fill-mode:forwards` when the element should keep the values from the final keyframe after the animation completes.
```html
<!-- @MARK animation-fill-mode:forwards -->
<div class="animation-duration:300ms animation-fill-mode:forwards animation-name:fade">
  Remains visible
</div>
```

<details>
  <summary>Generated CSS</summary>
  <Class2CSS>
    {['animation-fill-mode:forwards']}
  </Class2CSS>
</details>

### Apply both before and after states
Use `animation-fill-mode:both` when the element should use the first keyframe during a positive delay and keep the final keyframe after completion.
```html
<!-- @MARK animation-fill-mode:both -->
<div class="animation-delay:120ms animation-duration:300ms animation-fill-mode:both animation-name:fade">
  Delayed entrance
</div>
```

### Reset fill behavior
Use `animation-fill-mode:none` when the element should return to its ordinary styles before and after animation.
```html
<!-- @MARK animation-fill-mode:none -->
<div class="animation-fill-mode:none">
  Uses base styles outside the animation
</div>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="animation-fill-mode:both:hover animation-fill-mode:none@print animation-fill-mode:none@sm">...</div>
```
