## Examples
### Set the pivot point
Use `transform-origin:*` to define the point an element rotates, scales, or skews around.
```html
<!-- @MARK transform-origin:center -->
<div class="transform-origin:center transform:scale(.96):hover">
    Scales from center
</div>
```

    <summary>Generated CSS</summary>
    <Class2CSS>

### Use two-axis origins
Separate multi-word origins with `|` so they become space-separated CSS values.
```html
<!-- @MARK transform-origin:top|right -->
<div class="transform:rotate(2deg) transform-origin:top|right">
    Rotates from the corner
</div>
```

### Match the origin to the interaction
Menus, tooltips, and popovers usually feel more natural when their origin is close to the anchor that opened them.
```html
<div class="transform:scale(.98) transform-origin:top|left">
    Anchored menu
</div>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="transform-origin:center:hover transform-origin:center@print transform-origin:top|right@sm">...</div>
```
