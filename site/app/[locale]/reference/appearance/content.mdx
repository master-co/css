## Examples
### Remove default styling
Use `appearance:none` to remove the browser's native control styling before applying your own visual treatment.
<Demo>
    <select className="appearance:none background:revert">
        <option>Yes</option>
        <option>No</option>
    </select>
</Demo>
```html
<!-- @MARK appearance:none -->
<select class="appearance:none">
    <option>Yes</option>
    <option>No</option>
</select>
```

    <summary>Generated CSS</summary>

### Restore native appearance
Use `appearance:auto` when a variant should return to the platform control instead of the custom one.
```html
<!-- @MARK appearance:auto -->
<select class="appearance:none appearance:auto@sm">
    <option>Native on larger screens</option>
</select>
```

### Keep semantics intact
`appearance:none` only changes rendering. Keep using the correct form element and accessible label.
```html
<label>
    Sort
    <select class="appearance:none">
        <option>Newest</option>
    </select>
</label>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<select class="appearance:none:hover appearance:auto@sm appearance:auto@print">...</select>
```
