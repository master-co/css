## Examples \{#examples\}
### Align one item on both axes \{#align-one-item-on-both-axes\}
`place-self:end` sets both `align-self:end` and `justify-self:end`. The blue item moves to the bottom-right of its own area while the violet sibling follows the parent’s start alignment. The second example uses `end|start`: block-end first, then inline-start.

<DemoExample page="place-self" section="align-one-item-on-both-axes" />

```html
<div id="layout" class="display:grid grid-cols(2) grid-template-rows:160px place-items:start gap-md width:17.5rem max-width:100%">
  <div id="target" class="place-self:end height:3rem width:5rem p-sm">Target</div>
  <div id="peer" class="height:3rem width:5rem p-sm">Start</div>
</div>
```

```html
<div id="layout" class="display:grid grid-cols(2) grid-template-rows:160px place-items:start gap-md width:17.5rem max-width:100%">
  <div id="target" class="align-self:end justify-self:start height:3rem width:5rem p-sm">Target</div>
  <div id="peer" class="height:3rem width:5rem p-sm">Start</div>
</div>
```

### Center one item \{#center-one-item\}
`place-self:center` centers the blue 96 × 64px item in both dimensions of its grid area. The second item keeps the same size and follows the parent’s start alignment, making the local override visible.

<DemoExample page="place-self" section="center-one-item" />

```html
<div id="layout" class="display:grid grid-cols(2) grid-template-rows:160px place-items:start gap-md width:17.5rem max-width:100%">
  <div id="target" class="place-self:center height:4rem width:6rem p-sm">Centered</div>
  <div id="peer" class="height:4rem width:6rem p-sm">Start</div>
</div>
```

Use [place-items](/reference/place-items) when every child should follow the same two-axis default. For flex items, the `justify-self` half has no effect.

### Apply conditionally \{#apply-conditionally\}
Use [conditional queries](/reference/rules/conditions) to change alignment at a real viewport width. `place-self:auto` follows the parent’s end alignment on both axes. From `sm`, the blue item centers in its own area; the violet item stays at the bottom-right of its area.

<DemoExample page="place-self" section="apply-conditionally" />

```html
<div id="layout" class="display:grid grid-cols(2) grid-template-rows:160px place-items:end gap-md width:17.5rem max-width:100%">
  <div id="target" class="place-self:auto height:3rem width:5rem p-sm place-self:center@sm">Target</div>
  <div id="peer" class="height:3rem width:5rem p-sm">End</div>
</div>
```
