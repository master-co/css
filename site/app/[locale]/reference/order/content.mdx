## Examples
### Change visual order
Use `order:*` to change the visual order of flex or grid items.
```html
<!-- @MARK order:1 --><!-- @MARK order:2 -->
<div class="flex">
  <aside class="order:2">Sidebar</aside>
  <main class="order:1">Content</main>
</div>
```

<details>
  <summary>Generated CSS</summary>
  <Class2CSS>
    {['order:1', 'order:2']}
  </Class2CSS>
</details>

### Keep source order meaningful
Use order utilities for responsive layout adjustments, not as a replacement for semantic markup.
```html
<!-- @MARK order:2 --><!-- @MARK order:0@sm -->
<aside class="order:2 order:0@sm">...</aside>
```

(i) `order` changes visual layout only. Screen readers and keyboard navigation still follow source order in many workflows.

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="order:2 order:0@print order:0@sm">...</div>
```

Prefer source order whenever it can satisfy the layout.
