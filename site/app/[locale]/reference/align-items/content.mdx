## Examples \{#examples\}
### Align items on the cross axis \{#align-items-on-the-cross-axis\}
Use `items-center` to align the centers of flex items across a line. Here a 64px image sits beside a shorter caption. In a row flexbox, the cross axis follows the block direction; a column flexbox swaps the main and cross axes.

<DemoExample page="align-items" section="align-items-on-the-cross-axis" />

```html
<div id="layout" class="display:flex align-items:center gap-md">
  <img id="target" class="flex:none width:4rem height:4rem object-fit:cover" src="/demo/landscape.svg" alt="Sun above layered mountains" />
  <div id="peer" class="p-sm">Landscape study</div>
</div>
```

<details>
  <summary>Generated CSS</summary>
  <Class2CSS>
    {['display:flex', 'align-items:center']}
  </Class2CSS>
</details>

In Grid, `align-items` instead sets the default block-axis alignment inside each item’s grid area. It does not move the tracks themselves.

### Align to the start or end \{#align-to-the-start-or-end\}
Compare `items-start` and `items-end` with the same 96px image and two-line caption. One aligns their top edges and the other their bottom edges in this horizontal writing mode.

<DemoExample page="align-items" section="align-to-the-start-or-end" />

```html
<div id="layout" class="display:flex align-items:start gap-md">
  <img id="target" class="flex:none width:6rem height:6rem object-fit:cover" src="/demo/landscape.svg" alt="Sun above layered mountains" />
  <div id="peer" class="min-width:0 p-sm">Landscape study<br>Canvas collection</div>
</div>
```

```html
<div id="layout" class="display:flex align-items:end gap-md">
  <img id="target" class="flex:none width:6rem height:6rem object-fit:cover" src="/demo/landscape.svg" alt="Sun above layered mountains" />
  <div id="peer" class="min-width:0 p-sm">Landscape study<br>Canvas collection</div>
</div>
```

### Stretch automatic-sized children \{#stretch-children\}
`items-stretch` stretches an item whose cross-axis size is automatic, subject to its minimum and maximum size. The blue item fills the first row’s 128px height; the violet item keeps its explicitly set 64px height.

<DemoExample page="align-items" section="stretch-children" />

```html
<div id="layout" class="display:flex align-items:stretch gap-md height:8rem">
  <div id="target" class="width:6rem p-sm">Auto height</div>
  <div id="peer" class="height:4rem width:6rem p-sm">64px height</div>
</div>
```

```html
<div id="layout" class="display:flex align-items:stretch gap-md">
  <div id="target" class="width:6rem p-sm">Auto height</div>
  <div id="peer" class="width:6rem height:6rem p-sm">96px height</div>
</div>
```

The second container has no explicit height. Its taller sibling establishes a 96px line, and the automatic-sized item stretches to match it. A definite container height is not required.

### Align text baselines \{#align-text-baselines\}
Use `items-baseline` to put the first text baselines of differently sized flex items on the same line. Their top and bottom edges need not match. Both labels use a unitless line height of 1 so the different text sizes remain easy to compare.

<DemoExample page="align-items" section="align-text-baselines" />

```html
<div id="layout" class="display:flex align-items:baseline gap-sm">
  <span id="target" class="font-size-5xl line-height:1">24</span>
  <span id="peer" class="font-size-sm line-height:1">messages</span>
</div>
```

Use [align-self](/reference/align-self) to override the shared alignment for one item.

### Apply conditionally \{#apply-conditionally\}
Use [conditional queries](/reference/rules/conditions) to change alignment at a real viewport width. The blue item has an automatic height: it starts at the top, centers from `sm`, then stretches from `lg`. The violet item keeps a fixed 64px height, including in the stretch state.

<DemoExample page="align-items" section="apply-conditionally" />

```html
<div id="layout" class="display:flex align-items:start gap-md height:8rem align-items:center@sm align-items:stretch@lg">
  <div id="target" class="width:6rem p-sm">Auto height</div>
  <div id="peer" class="height:4rem width:6rem p-sm">64px height</div>
</div>
```
