## Installation [sr-only]
```bash action=install
@master/css-configer@rc
```

`@master/css-configer` loads and serializes Master CSS config CSS resources for build tools and server integrations. It is the shared config boundary used by packages such as Vite, Next.js, Webpack, and the extractor.

The package compiles explicit CSS resources through `@master/css-compiler` and returns JavaScript config objects. It does not discover workspace config paths or load JavaScript/TypeScript config files.

---

## Load CSS config
Use `loadConfig()` when the CSS resource path is already known.

```ts
import { loadConfig, loadConfigModule } from '@master/css-configer/load'

const result = await loadConfig('/project/src/index.css')
const moduleResult = await loadConfigModule('/project/src/index.css')
```

`loadConfig()` returns the config object and dependency list. `loadConfigModule()` returns JavaScript module code, which is useful for virtual modules and loader output.

```ts
import { loadConfigSync, loadConfigModuleSync } from '@master/css-configer/load-sync'

const result = loadConfigSync('/project/src/index.css')
const moduleResult = loadConfigModuleSync('/project/src/index.css')
```

## Config modules
The module utilities define the config import contract used by official integrations.

```ts
import {
    MASTER_CSS_CONFIG_QUERY,
    VIRTUAL_CONFIG_ID,
    toConfigModule,
    toVirtualDefaultConfigModulePath,
    toVirtualCSSConfigModulePath,
} from '@master/css-configer/module'
```

| API | Purpose |
| --- | --- |
| `VIRTUAL_CONFIG_ID` | The default config module id, `virtual:master-css-config`. |
| `MASTER_CSS_CONFIG_QUERY` | The query suffix, `?master-css-config`, used to compile a specific CSS config file. |
| `toConfigModule(config)` | Serializes a config object into an ESM default export. |
| `toVirtualDefaultConfigModulePath(context)` | Creates the virtual path for the default config module. |
| `toVirtualCSSConfigModulePath(context, file)` | Creates a virtual path for a specific queried CSS config file. |

Use `virtual:master-css-config` when application code should receive the integration's default config. Use `./index.css?master-css-config` when the code should compile one explicit CSS resource through the active integration.
