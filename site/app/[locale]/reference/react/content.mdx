## Installation [sr-only]
```bash action=install
@master/css.react
```
The package provides a convenient React provider and context for using `@master/css-runtime` in React applications.

The root entry is intended for projects using an official Master CSS integration and exports named React APIs:
```tsx
import { CSSRuntimeRegistry, CSSRuntimeProvider } from '@master/css.react'
```

Use `@master/css.react/runtime-provider` when you only need the provider API without the registry's default virtual module dependencies.

---

## API Reference
### `<CSSRuntimeRegistry>`
The `CSSRuntimeRegistry` initializes a `CSSRuntime` instance with the project-level manifest provided by the active Master CSS integration.
```tsx
import { CSSRuntimeRegistry } from '@master/css.react'

export default function App({ children }) {
    return (
        <CSSRuntimeRegistry>
            {children}
        </CSSRuntimeRegistry>
    )
}
```

The registry loads `virtual:master-css-manifest` and `virtual:master-css-emitted-globals` internally, so use it when the official integration should load the project-level manifest discovered from the CSS entry and the matching emittedGlobals global CSS state.

### `<CSSRuntimeProvider>`
The `CSSRuntimeProvider` initializes a `CSSRuntime` instance and manages it according to changes in manifest or root element.
```tsx
import { CSSRuntimeProvider } from '@master/css.react/runtime-provider'
import manifest from './theme.css?master-css-manifest'

export default function App({ children }) {
    return (
        <CSSRuntimeProvider manifest={manifest}>
            {children}
        </CSSRuntimeProvider>
    )
}
```

The provider calls `initCSSRuntime({ manifest, root, emittedGlobals })` on mount, refreshes the runtime with the latest `manifest` when the prop changes, and recreates the runtime when `root` changes. It destroys the runtime on unmount.

Use the provider subpath when you need a custom `?master-css-manifest` resource, custom `emittedGlobals` data, a custom `root`, or an environment that does not resolve the default virtual modules.

### `useCSSRuntime()`
Access the [`CSSRuntime`](/reference/runtime) instance from components rendered inside `CSSRuntimeProvider`.
```tsx
import { useCSSRuntime } from '@master/css.react/runtime-provider'

export function YourComponent() {
    const cssRuntime = useCSSRuntime()
    // ...
}
```
