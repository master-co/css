## Examples
### Italicize emphasis
Use `italic` for emphasized text when the typeface includes an italic style.
```html
<!-- @MARK italic -->
<em class="italic">Important</em>
```

<details>

### Use oblique text
Use `oblique` when the design calls for a slanted style rather than a true italic face.
```html
<!-- @MARK oblique -->
<span class="oblique">Draft</span>
```

### Reset font style
Use `font:normal` to cancel inherited italic or oblique styles.
```html
<!-- @MARK font:normal -->
<span class="italic">
    <span class="font:normal">Not emphasized</span>
</span>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<span class="italic:hover font:normal@sm font:normal@print">...</span>
```
