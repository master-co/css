## Installation [sr-only]
```bash action=install
@master/css.next@rc
```

```js name=next.config.mjs
import { withMasterCSS } from '@master/css.next'

/** @type {import('next').NextConfig} */
const nextConfig = withMasterCSS({
    /* your Next.js config */
})

export default nextConfig
```

### Modes
`@master/css.next` supports two integration modes:

| Mode | Description |
| --- | --- |
| `'pre-render'` | Uses the Next.js Adapter API to render CSS into static and pre-rendered HTML outputs during `next build`. |
| `'extract'` | Scans source files with `@master/css-extractor`, writes a generated stylesheet, and wires Master CSS stylesheet imports into Turbopack CSS processing. |

Use `pre-render` when you want route HTML to carry its first-render CSS. Use `extract` when your classes are statically visible in source and you want a generated CSS asset.

### Static extraction
In extract mode, import the generated stylesheet from your app stylesheet:

```css name=app/globals.css
@import '@master/css';

.main {
    background-color: var(--color-primary);
}

@master {
    --color-primary: #ff0000;
}
```

Then enable extract mode:

```js name=next.config.mjs
import { withMasterCSS } from '@master/css.next'

/** @type {import('next').NextConfig} */
const nextConfig = await withMasterCSS({
    /* your Next.js config */
}, {
    mode: 'extract'
})

export default nextConfig
```

Extract mode uses source-glob scanning as the correctness baseline. A Turbopack CSS loader replaces `@import '@master/css'` with the generated CSS. CSS files that import `@master/css` are treated as native CSS shaking roots by default, so ordinary class selectors are pruned against detected classes; `var(--*)` and animation references can pull matching variables and keyframes from the project CSS entry graph. Add `@master no-shake;` when native CSS must be preserved. A scanner loader also scans JavaScript and TypeScript modules as they pass through the build, so imported files such as `app/main.ts` can incrementally feed new classes into the generated CSS.

### Client types
Add `@master/css.next/client` to a project environment file when TypeScript imports `virtual:master-css-config`.

```ts name=master-css-env.d.ts
/// <reference types="@master/css.next/client" />
```

### Config imports
The integration exposes the canonical project-level config module:

```ts
import config from 'virtual:master-css-config'
```

Use the virtual module when application code should receive the same config graph that the integration discovered from the project CSS entry. It is backed by [`@master/css-configer`](/reference/configer).
