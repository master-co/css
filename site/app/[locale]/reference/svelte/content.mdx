## Installation [sr-only]
```bash action=install
@master/css.svelte@rc
```

`@master/css.svelte` provides the SvelteKit integration, server hook, and runtime provider for Svelte apps. The package combines static or progressive CSS generation with [`@master/css-runtime`](/reference/runtime) hydration.

```ts
import { CSSRuntimeRegistry, CSSRuntimeProvider } from '@master/css.svelte'
```

Use `@master/css.svelte/runtime-provider` when you only need the provider API without the registry's default virtual module dependencies.

Start with the [Svelte installation guide](/guide/installation/svelte) for the full project setup.

---

## API Reference
### Vite plugin
Use the Svelte Vite entry with SvelteKit.

```ts name=vite.config.ts
import { sveltekit } from '@sveltejs/kit/vite'
import { defineConfig } from 'vite'
import masterCSS from '@master/css.svelte/vite'

export default defineConfig({
    plugins: [
        sveltekit(),
        masterCSS()
    ]
})
```

### Server hook
Export the server handle to inject streamed CSS before `</head>`.

```ts name=src/hooks.server.ts
export { default as handle } from '@master/css.svelte/hooks.server'
```

If the project already has a server `handle`, compose it with SvelteKit's `sequence()`.

### `<CSSRuntimeRegistry>`
The registry initializes a `CSSRuntime` instance with the project-level manifest provided by the active Master CSS integration.

```svelte
<script lang="ts">
    import { CSSRuntimeRegistry } from '@master/css.svelte'
</script>

<CSSRuntimeRegistry>
    <slot />
</CSSRuntimeRegistry>
```

The registry loads `virtual:master-css-manifest` and `virtual:master-css-emitted-globals` internally, so use it when the official integration should load the project-level manifest discovered from the CSS entry and the matching emittedGlobals global CSS state.

### `<CSSRuntimeProvider>`
The provider initializes a `CSSRuntime` for `document` by default, refreshes it when `manifest` changes, recreates it when `root` changes, and destroys it on unmount.

```svelte
<script lang="ts">
    import { CSSRuntimeProvider } from '@master/css.svelte/runtime-provider'
    import manifest from './app.css?master-css-manifest'
</script>

<CSSRuntimeProvider {manifest}>
    <slot />
</CSSRuntimeProvider>
```

Use the provider subpath when you need a custom `?master-css-manifest` resource, custom `emittedGlobals` data, a custom `root`, or an environment that does not resolve the default virtual modules.

### Provider props
```ts
interface CSSRuntimeProviderProps {
    manifest?: MasterCSSManifest
    emittedGlobals?: MasterCSSEmittedGlobals
    root?: Document | ShadowRoot | null
}
```

`root` defaults to `document`. Pass a `ShadowRoot` when Svelte renders into a shadow tree and the runtime should observe only that tree.

### `getCSSRuntime()`
Access the runtime store provided by `CSSRuntimeProvider`.

```svelte
<script lang="ts">
    import { getCSSRuntime } from '@master/css.svelte/runtime-provider'

    const cssRuntime = getCSSRuntime()
</script>
```

The returned value is a `Writable<CSSRuntime | undefined>`. It is available to descendants of `CSSRuntimeProvider`.

### `CSS_RUNTIME_CONTEXT_KEY`
Svelte context key used by the provider and `getCSSRuntime()`.

```ts
import { CSS_RUNTIME_CONTEXT_KEY } from '@master/css.svelte/runtime-provider'
```
