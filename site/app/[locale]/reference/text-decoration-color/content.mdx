## Examples
### Set decoration color
Use `text-decoration-color:*` when only the decoration color should change.
```html
<!-- @MARK text-decoration-color:primary -->
<a class="text:underline text-decoration-color:primary">
    Colored underline
</a>
```

### Follow the current text color
Use `text-decoration:currentColor` when the decoration should track the foreground color.
```html
<!-- @MARK text-decoration:currentColor -->
<a class="fg:primary text:underline text-decoration:currentColor">
    Current color underline
</a>
```

### Hide decoration color
Use `text-decoration:transparent` when spacing or thickness should remain but the decoration should not be visible.
```html
<!-- @MARK text-decoration:transparent -->
<a class="text:underline text-decoration:transparent">
    Invisible underline
</a>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<a class="text-decoration-color:primary:hover text-decoration:currentColor@sm text-decoration:transparent@print">...</a>
```
