## Examples \{#examples\}
### Set decoration color \{#set-decoration-color\}
`text-decoration-color:blue-50` changes the line color without changing the glyph color. Both specimens explicitly supply an underline; a color alone cannot create one.

<DemoExample page="text-decoration-color" section="set-decoration-color" />

```html
<!-- Current foreground -->
<p id="target"
  class="inline-block max-w:100% m:0 font:2xl leading:xl underline
         text-decoration-color:currentColor text-decoration-thickness:2px"
>
  Design together
</p>
```

```html
<!-- Independent blue line -->
<p id="target"
  class="inline-block max-w:100% m:0 font:2xl leading:xl underline
         text-decoration-color:blue-50 text-decoration-thickness:2px"
>
  Design together
</p>
```

### Follow the current text color \{#follow-the-current-text-color\}
`text-decoration:current` sets the decoration color to `currentColor`. Change the foreground and the underline follows it.

<DemoExample page="text-decoration-color" section="follow-the-current-text-color" />

```html
<!-- Foreground · blue-50 -->
<p id="target"
  class="inline-block max-w:100% m:0 font:2xl leading:xl underline
         text-decoration-thickness:2px text-decoration:current fg:blue-50"
>
  Design together
</p>
```

```html
<!-- Foreground · violet-50 -->
<p id="target"
  class="inline-block max-w:100% m:0 font:2xl leading:xl underline
         text-decoration-thickness:2px text-decoration:current fg:violet-50"
>
  Design together
</p>
```

The line is still required. Unlike a full `text-decoration` shorthand, this color form leaves its line and style intact.

### Hide decoration color \{#hide-decoration-color\}
`text-decoration:transparent` hides the line’s paint while retaining its line type and thickness. Decoration does not reserve extra layout space in either state.

<DemoExample page="text-decoration-color" section="hide-decoration-color" />

```html
<!-- Line color · blue-50 -->
<p id="target"
  class="inline-block max-w:100% m:0 font:2xl leading:xl underline
         text-decoration-thickness:3px text-decoration:blue-50"
>
  Design together
</p>
```

```html
<!-- Line color · transparent -->
<p id="target"
  class="inline-block max-w:100% m:0 font:2xl leading:xl underline
         text-decoration-thickness:3px text-decoration:transparent"
>
  Design together
</p>
```

Use a visible treatment when the line communicates a link or status; transparent paint carries no visible cue.

### Apply conditionally \{#apply-conditionally\}
Hover or focus to change only the underline color from the current foreground to blue. Print retains the current foreground color.

<DemoExample page="text-decoration-color" section="apply-conditionally" />

```html
<!-- Pointer and keyboard states -->
<button id="target" type="button"
  class="font:2xl leading:xl underline text-decoration-thickness:2px
         text-decoration:current text-decoration:current@print
         text-decoration-color:blue-50:hover@screen
         text-decoration-color:blue-50:focus-visible@screen"
>
  Design together
</button>
```
