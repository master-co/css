## Examples
### Pad the scroll container
Use `scroll-p:*` on the scroll container to keep snapped or anchored content away from the container edges.
```html
<!-- @MARK scroll-p:0.625rem -->
<div class="overflow:auto scroll-p:0.625rem">
  ...
</div>
```

<details>
  <summary>Generated CSS</summary>
  <Class2CSS>
    {['scroll-p:0.625rem']}
  </Class2CSS>
</details>

### Reserve space for fixed headers
Use `scroll-pt:*` when vertical scrolling should stop below a sticky or fixed header.
```html
<!-- @MARK scroll-pt:16x -->
<main class="overflow:auto scroll-pt:3xl">
  ...
</main>
```

### Pad horizontal snapping
Use `scroll-px:*` on horizontal carousels so the first and last item can snap with visual breathing room.
```html
<!-- @MARK scroll-px:4x -->
<div class="overflow-x:auto scroll-px:md snap-x">
  ...
</div>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="scroll-p:0.625rem scroll-p:0@print scroll-pt:3xl@sm">...</div>
```
