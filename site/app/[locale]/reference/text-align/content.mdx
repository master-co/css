## Examples \{#examples\}
### Align contents to the left \{#align-contents-to-the-left\}
Use `text-left` to align each line to the physical left edge, regardless of the paragraph’s base direction.

<DemoExample page="text-align" section="align-contents-to-the-left" />

```html
<!-- text-left -->
<p id="target" class="width:240px max-width:100% margin:0 font-size-md line-height:24px text-align:left">A clear reading rhythm gives each idea room to breathe. Keep the measure comfortable and let the content set the pace.</p>
```

### Align contents to the right \{#align-contents-to-the-right\}
Use `text-right` to align each line to the physical right edge. The paragraph keeps the same width and position.

<DemoExample page="text-align" section="align-contents-to-the-right" />

```html
<!-- text-right -->
<p id="target" class="width:240px max-width:100% margin:0 font-size-md line-height:24px text-align:right">A clear reading rhythm gives each idea room to breathe. Keep the measure comfortable and let the content set the pace.</p>
```

### Center contents \{#center-contents\}
Use `text-center` to center each line’s inline content within the paragraph. Use layout utilities to center the paragraph itself.

<DemoExample page="text-align" section="center-contents" />


### Align contents to the left and right \{#align-contents-to-the-left-and-right\}
Use `text-justify` to distribute space across a line so both edges meet the paragraph’s sides. The final line normally stays start-aligned.

<DemoExample page="text-align" section="align-contents-to-the-left-and-right" />

```html
<!-- text-justify -->
<p id="target" class="width:240px max-width:100% margin:0 font-size-md line-height:24px text-align:justify">A clear reading rhythm gives each idea room to breathe. Keep the measure comfortable and let the content set the pace.</p>
```

Check the spacing at the actual reading width; short lines can produce large gaps between words.

### Use logical alignment \{#use-logical-alignment\}
`text-start` and `text-end` follow the inline direction. In these horizontal paragraphs, start is left for LTR and right for RTL.

<DemoExample page="text-align" section="use-logical-alignment" />

```html
<!-- LTR · text-start -->
<p id="target" lang="en" dir="ltr" class="width:240px max-width:100% margin:0 font-size-md line-height:24px text-align:start">Good tools make room for clear thinking.</p>
```

```html
<!-- LTR · text-end -->
<p id="target" lang="en" dir="ltr" class="width:240px max-width:100% margin:0 font-size-md line-height:24px text-align:end">Good tools make room for clear thinking.</p>
```

```html
<!-- RTL · text-start -->
<p id="target" lang="ar" dir="rtl" class="width:240px max-width:100% margin:0 font-size-md line-height:24px text-align:start">أدوات واضحة تمنح الأفكار مساحة.</p>
```

```html
<!-- RTL · text-end -->
<p id="target" lang="ar" dir="rtl" class="width:240px max-width:100% margin:0 font-size-md line-height:24px text-align:end">أدوات واضحة تمنح الأفكار مساحة.</p>
```

Use physical `text-left` or `text-right` only when that physical edge is intentional.

### Apply conditionally \{#apply-conditionally\}
Resize the real preview viewport. The text starts at the inline start, centers at `sm`, and aligns to the inline end at `lg`. Print restores start alignment.

<DemoExample page="text-align" section="apply-conditionally" />

```html
<!-- Responsive inline alignment -->
<p id="target" class="width:100% margin:0 font-size-md line-height:24px text-align:start text-align:start@media(print) text-align:center@media(screen)@sm text-align:end@media(screen)@lg">A clear reading rhythm gives each idea room to breathe. Keep the measure comfortable and let the content set the pace.</p>
```

The screen-qualified conditions keep viewport breakpoints from overriding the print rule.
