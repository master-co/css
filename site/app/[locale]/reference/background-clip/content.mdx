### Clip a background to a box \{#clip-a-background-to-a-box\}
Compare identical boxes with an 8px dashed border and 24px padding. Only the background painting area changes; border, padding and layout size stay the same.

<DemoExample page="background-clip" section="clip-a-background-to-a-box" />

```html
<!-- Border box · paint beneath the border -->
<div id="target" role="img" aria-label="Blue background clipped to border box"
  class="height:176px width:280px max-width:100% p-lg border:8px|dashed|color-mix(in|oklab,var(--color-violet-50)|50%,transparent)
         background-clip:border-box bg-blue-30"
></div>
```

```html
<!-- Padding box · border band stays clear -->
<div id="target" role="img" aria-label="Blue background clipped to padding box"
  class="height:176px width:280px max-width:100% p-lg border:8px|dashed|color-mix(in|oklab,var(--color-violet-50)|50%,transparent)
         background-clip:padding-box bg-blue-30"
></div>
```

```html
<!-- Content box · padding stays clear -->
<div id="target" role="img" aria-label="Blue background clipped to content box"
  class="height:176px width:280px max-width:100% p-lg border:8px|dashed|color-mix(in|oklab,var(--color-violet-50)|50%,transparent)
         background-clip:content-box bg-blue-30"
></div>
```

### Clip a background to text \{#clip-a-background-to-text\}
Clip a real gradient to the glyphs and make the glyph fill transparent only when text clipping is supported. The solid foreground remains the fallback.

<DemoExample page="background-clip" section="clip-a-background-to-text" />

```html
<!-- Supported screen paint · solid print fallback -->
<p id="target"
  class="display:inline-block max-width:100% margin:0 font-4xl font-semibold leading-lg
         background-clip:text text-fill-color-current
         background-image:linear-gradient(90deg,var(--color-blue-50),var(--color-violet-50))@supports((background-clip:text))@screen
         text-fill-color-current@print
         -webkit-text-fill-color:transparent@supports((background-clip:text))@screen"
>Clear type</p>
```

Use this treatment sparingly for display text. Open print preview to check the solid label when background printing is disabled. The same guarded glyph-paint pattern is available in [text fill color](/reference/text-fill-color#make-text-fill-transparent).

### Apply conditionally \{#apply-conditionally\}
Widen to `sm` to move the painting edge from the border box to the content box. The geometry does not change. Print restores border-box clipping.

<DemoExample page="background-clip" section="apply-conditionally" />

```html
<!-- Border → content at sm -->
<div id="target" role="img" aria-label="Responsive background painting area"
  class="height:176px width:280px max-width:100% p-lg border:8px|dashed|color-mix(in|oklab,var(--color-violet-50)|50%,transparent)
         background-clip:border-box bg-blue-30 background-clip:border-box@print
         background-clip:content-box@screen@sm"
></div>
```

Use [background-origin](/reference/background-origin) to change the image’s positioning area instead of its painting boundary.
