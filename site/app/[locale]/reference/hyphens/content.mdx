## Examples \{#examples\}
### Allow automatic hyphenation \{#allow-automatic-hyphenation\}
Use `hyphens:auto` for narrow text columns where long words can otherwise create uneven lines.
```html
<!-- @MARK hyphens:auto -->
<p lang="en" class="hyphens:auto">
  Antidisestablishmentarianism can hyphenate when the browser has language data.
</p>
```

### Respect manual hyphenation points \{#respect-manual-hyphenation-points\}
Use `hyphens:manual` when the content includes soft hyphens or explicit hyphenation decisions.
```html
<!-- @MARK hyphens:manual -->
<p class="hyphens:manual">trans&shy;formation</p>
```

### Disable hyphenation \{#disable-hyphenation\}
Use `hyphens:none` for codes, product names, or text where inserted hyphens would change meaning.
```html
<!-- @MARK hyphens:none -->
<code class="hyphens:none">MASTERCSS_RUNTIME_TOKEN</code>
```

### Apply conditionally \{#apply-conditionally\}
Apply styles based on different states using [selectors](/reference/rules/selectors) and [conditional queries](/reference/rules/conditions).
```html
<p class="hyphens:auto hyphens:none@print hyphens:none@sm">...</p>
```
