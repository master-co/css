## Examples
### Clip to a circle
Use `clip-path:circle(*)` to apply a circular clip path.
```html
<!-- @MARK clip-path:circle(50%) -->
<img class="clip-path:circle(50%)" src="/images/avatar.jpg" alt="Avatar">
```

<details>
    <summary>Generated CSS</summary>
    <Class2CSS>
        {['clip-path:circle(50%)']}

</details>

### Clip with an inset
Use `clip-path:inset(*)` with `|` between values when the inset has multiple sides.
```html
<!-- @MARK clip-path:inset(0|20px) -->
<div class="clip-path:inset(0|20px)">
    Cropped content
</div>
```

### Remove clipping
Use `clip-none` when a responsive or state variant should restore the full element.
```html
<!-- @MARK clip-none -->
<img class="clip-path:circle(50%) clip-none@sm" src="/images/avatar.jpg" alt="Avatar">
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="clip-path:inset(0|20px):hover clip-path:circle(50%)@sm clip-none@print">...</div>
```
