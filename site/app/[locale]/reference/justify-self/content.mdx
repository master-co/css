## Examples
### Align one grid item inline
Use `justify-self:*` to override inline-axis alignment for a single grid item.
```html
<!-- @MARK grid --><!-- @MARK justify-self:end -->
<div class="grid">
  <button class="justify-self:end">Save</button>
</div>
```

<details>
  <summary>Generated CSS</summary>
  <Class2CSS>
    {['grid', 'justify-self:end']}
  </Class2CSS>
</details>

### Center an item inside its area
Use `justify-self:center` when the grid area is wider than the item.
```html
<!-- @MARK justify-self:center -->
<img class="justify-self:center" src="..." alt="" />
```

Use [justify-items](/reference/justify-items) when every child should share the same inline alignment.

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="justify-self:stretch justify-self:stretch@print justify-self:end@sm">...</div>
```

For cross-axis item overrides, use [align-self](/reference/align-self).
