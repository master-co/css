## Examples \{#examples\}
### Hint an upcoming transform \{#hint-an-upcoming-transform\}
This visible native button declares an upcoming transform. Press and hold it, or focus it and hold Space, to apply the actual movement.

<DemoExample page="will-change" section="hint-an-upcoming-transform" />

```html
<!-- Transform hint · press to move -->
<div class="p-lg">
  <div class="position:relative height:96px width:160px outline-width:1px outline-style:dashed outline-line-subtle">
    <button id="target" type="button"
      class="display:grid place-items:center height:96px width:160px p-sm
             border-width:1px border-style:solid b-blue-60 r-sm font-sm bg-blue-10
             fg-blue-80 transform:none
             will-change:transform
             outline-width:2px:focus-visible outline-style:solid:focus-visible outline-blue:focus-visible
             outline-offset:3px:focus-visible
             transform:none@media(print)
             transition-property:transform@motion-safe transition-duration:var(--duration-fast)@motion-safe transition-timing-function:ease-out@motion-safe
             will-change:auto@media(print)
             transform:translateY(-8px):active@media(screen)">
      Move preview
    </button>
  </div>
</div>
```

The readout shows the declared hint. It does not measure speed or prove layer promotion. Add hints only after measuring a real need; keeping them on many elements can consume resources.

### Hint opacity changes \{#hint-opacity-changes\}
Press this visible button to lower its opacity. The hint names opacity; a separate active-state class performs the fade.

<DemoExample page="will-change" section="hint-opacity-changes" />

```html
<!-- Opacity hint · press to fade -->
<div class="p-lg">
  <div class="position:relative height:96px width:160px outline-width:1px outline-style:dashed outline-line-subtle">
    <button id="target" type="button"
      class="display:grid place-items:center height:96px width:160px p-sm
             border-width:1px border-style:solid b-blue-60 r-sm font-sm bg-blue-10
             fg-blue-80 opacity:1 will-change:opacity
             outline-width:2px:focus-visible outline-style:solid:focus-visible outline-blue:focus-visible
             outline-offset:3px:focus-visible
             opacity:1@media(print)
             transition-property:opacity@motion-safe transition-duration:var(--duration-fast)@motion-safe transition-timing-function:ease-out@motion-safe
             will-change:auto@media(print)
             opacity:.64:active@media(screen)">
      Preview overlay
    </button>
  </div>
</div>
```

The button remains named and keyboard operable. Will-change does not animate or hide the element. Reduced motion removes the timed fade while preserving the native pressed state.

### Reset when the hint is no longer useful \{#reset-when-the-hint-is-no-longer-useful\}
Hover or focus to prepare a transform hint before pressing. Move away and remove focus to return it to auto.

<DemoExample page="will-change" section="reset-when-the-hint-is-no-longer-useful" />

```html
<!-- Auto → prepare → press → auto -->
<div class="p-lg">
  <div class="position:relative height:96px width:160px outline-width:1px outline-style:dashed outline-line-subtle">
    <button id="target" type="button"
      class="display:grid place-items:center height:96px width:160px p-sm
             border-width:1px border-style:solid b-blue-60 r-sm font-sm bg-blue-10
             fg-blue-80 transform:none will-change:auto
             outline-width:2px:focus-visible outline-style:solid:focus-visible outline-blue:focus-visible
             outline-offset:3px:focus-visible
             transform:none@media(print)
             transition-property:transform@motion-safe transition-duration:var(--duration-fast)@motion-safe transition-timing-function:ease-out@motion-safe
             will-change:auto@media(print)
             will-change:transform:hover@media(screen)
             will-change:transform:focus-visible@media(screen)
             transform:translateY(-8px):active@media(screen)">
      Prepare and press
    </button>
  </div>
</div>
```

Preparing before the change gives the browser time to act on the hint. Auto releases this explicit request when the interaction ends. Applications with longer scripted sequences should remove their hint after the sequence finishes.

### Apply conditionally \{#apply-conditionally\}
Widen the actual viewport to `sm` to declare an opacity hint. Pressing the native button still controls the fade; changing the hint alone does not change its appearance.

<DemoExample page="will-change" section="apply-conditionally" />

```html
<!-- Auto → opacity hint at sm -->
<div class="p-lg">
  <div class="position:relative height:96px width:160px outline-width:1px outline-style:dashed outline-line-subtle">
    <button id="target" type="button"
      class="display:grid place-items:center height:96px width:160px p-sm
             border-width:1px border-style:solid b-blue-60 r-sm font-sm bg-blue-10
             fg-blue-80 opacity:1 will-change:auto
             outline-width:2px:focus-visible outline-style:solid:focus-visible outline-blue:focus-visible
             outline-offset:3px:focus-visible
             opacity:1@media(print)
             transition-property:opacity@motion-safe transition-duration:var(--duration-fast)@motion-safe transition-timing-function:ease-out@motion-safe
             will-change:auto@media(print)
             opacity:.64:active@media(screen)
             will-change:opacity@media(screen)@sm">
      Press to preview
    </button>
  </div>
</div>
```

Print returns the hint to auto. This viewport rule demonstrates conditional syntax; choose hint lifetimes from actual interaction needs, not screen size alone.
