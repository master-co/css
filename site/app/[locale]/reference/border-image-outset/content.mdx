## Basic usage
### Extend the border image outside the box
Use `border-image-outset` to paint the border image beyond the element's border box. The outset area does not create extra layout space.
<Demo $py={0}>
    <DemoPanel>
        <div className="m:8x b:12|solid|transparent border-image-source:linear-gradient(45deg,dodgerblue,hotpink) border-image-slice:30 border-image-outset:8 p:10x r:8 bg:white bg:gray-95@dark">
            <div className="fg:strong font:18 font-weight:560">Outset 8</div>
            <p className="fg:muted font:14 my:4x">The painted border image extends outward.</p>
        </div>
    </DemoPanel>
</Demo>
```html
<!-- @MARK border-image-outset:8 -->
<div class="b:12|solid|transparent border-image-source:linear-gradient(45deg,dodgerblue,hotpink) border-image-slice:30 border-image-outset:8">
    Outset 8
</div>
```

### Use separate vertical and horizontal values
```html
<!-- @MARK border-image-outset:8|16 -->
<div class="b:12|solid|transparent border-image-source:linear-gradient(45deg,dodgerblue,hotpink) border-image-slice:30 border-image-outset:8|16">
    Vertical and horizontal outset
</div>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="border-image-outset:8:hover border-image-outset:8@sm border-image-outset:8@dark border-image-outset:8@print">…</div>
```
