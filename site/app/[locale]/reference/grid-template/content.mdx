## Basic usage
### Define rows and columns together
Use `grid-template` to set grid rows and columns in one shorthand.
<Demo $py={0}>
    <DemoPanel>
        <div className="grid grid-template:64px|1fr/120px|1fr gap:2x h:180px">
            <div className="min-w:0 p:3x r:8px bg:blue-5 bg:blue-95@dark border:px|solid|blue-20 border-color:blue-80@dark text-ellipsis overflow:hidden white-space:nowrap">Nav</div>
            <div className="min-w:0 p:3x r:8px bg:gray-5 bg:gray-90@dark text-ellipsis overflow:hidden white-space:nowrap">Header</div>
            <div className="min-w:0 p:3x r:8px bg:gray-5 bg:gray-90@dark text-ellipsis overflow:hidden white-space:nowrap">Main</div>
        </div>
    </DemoPanel>
</Demo>
```html
<!-- @MARK grid-template:64px|1fr/120px|1fr -->
<div class="grid grid-template:64px|1fr/120px|1fr">…</div>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="grid-template:64px|1fr/120px|1fr:hover grid-template:64px|1fr/120px|1fr@sm grid-template:64px|1fr/120px|1fr@dark grid-template:64px|1fr/120px|1fr@print">…</div>
```
