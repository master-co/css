## Basic usage
### Round repeated edge slices
Use `border-image-repeat` to control how the edge slices fit the border image area.
<Demo $py={0}>
    <DemoPanel>
        <div className="b:16px|solid|transparent border-image-source:linear-gradient(45deg,dodgerblue,hotpink) border-image-slice:30 border-image-repeat:round p:10x r:8px surface:base">
            <div className="text:neutral font:18px font-weight:560">Round repeat</div>
            <p className="text:gray font:14px my:4x">The slices are adjusted so repetitions fit evenly.</p>
        </div>
    </DemoPanel>
</Demo>
```html
<!-- @MARK border-image-repeat:round -->
<div class="b:16px|solid|transparent border-image-source:linear-gradient(45deg,dodgerblue,hotpink) border-image-slice:30 border-image-repeat:round">
    Round repeat
</div>
```

### Set vertical and horizontal behavior
```html
<!-- @MARK border-image-repeat:round|stretch -->
<div class="b:16px|solid|transparent border-image-source:linear-gradient(45deg,dodgerblue,hotpink) border-image-slice:30 border-image-repeat:round|stretch">
    Round vertically, stretch horizontally
</div>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="border-image-repeat:round:hover border-image-repeat:round@sm border-image-repeat:round@dark border-image-repeat:round@print">…</div>
```
