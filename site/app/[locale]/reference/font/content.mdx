## Examples
### Set the complete font shorthand
Use the native CSS `font` shorthand when an environment provides native property fallback. The value can include style, variant, weight, size, line height, and family in one declaration.
```html
<!-- @MARK font:italic|small-caps|bold|1rem/1.5|serif -->
<p class="font:italic|small-caps|bold|1rem/1.5|serif">
    Sphinx of black quartz, judge my vow.
</p>
```

<details>
    <summary>Generated CSS</summary>
    <Class2CSS>
        {['font:italic|small-caps|bold|1rem/1.5|serif']}
    </Class2CSS>
</details>

The shorthand resets font-related longhands that are part of the CSS `font` shorthand. Use narrower utilities such as [font-size](/reference/font-size), [font-weight](/reference/font-weight), [font-style](/reference/font-style), and [line-height](/reference/line-height) when only one part should change.

### Use system font keywords
Use system keywords such as `font:caption` or `font:menu` when an element should inherit the platform UI font for that role.
```html
<!-- @MARK font:caption -->
<span class="font:caption">Native caption text</span>
```

System font keywords replace the whole font shorthand, so avoid mixing them with separate font-size or font-family expectations on the same element.

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="font:caption:hover font:menu@sm font:caption@dark font:caption@print">...</div>
```

For design-system typography, prefer [text-size](/reference/text-size) or [font-size](/reference/font-size) tokens unless you intentionally need the full shorthand.
