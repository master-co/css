## Examples \{#examples\}
### Set text stroke width \{#set-text-stroke-width\}
Use `text-stroke:*` with a length to control only the stroke width.
```html
<!-- @MARK text-stroke:2px -->
<h2 class="text-stroke:2px text-stroke:blue-60">
  Thick outline
</h2>
```

### Use the explicit property name \{#use-the-explicit-property-name\}
`text-stroke-width:*` is also supported when the property name makes the intent clearer.
```html
<!-- @MARK text-stroke-width:1px -->
<h2 class="text-stroke-width:1px text-stroke:blue-60">
  Thin outline
</h2>
```

### Remove the stroke width \{#remove-the-stroke-width\}
Use `text-stroke:0` to remove the visible stroke in a condition.
```html
<!-- @MARK text-stroke:0@print -->
<h2 class="text-stroke:1px text-stroke:0@print">
  Printed without stroke
</h2>
```

### Apply conditionally \{#apply-conditionally\}
Apply styles based on different states using [selectors](/reference/rules/selectors) and [conditional queries](/reference/rules/conditions).
```html
<h2 class="text-stroke:2px:hover text-stroke:0@print text-stroke:1px@sm">...</h2>
```
