## Examples
### Set text stroke width
Use `text-stroke:*` with a length to control only the stroke width.
```html
<!-- @MARK text-stroke:2px -->
<h2 class="text-stroke:2px text-stroke:primary">
    Thick outline
</h2>
```

    <summary>Generated CSS</summary>

### Use the explicit property name
`text-stroke-width:*` is also supported when the property name makes the intent clearer.
```html
<!-- @MARK text-stroke-width:1px -->
<h2 class="text-stroke-width:1px text-stroke:primary">
    Thin outline
</h2>
```

### Remove the stroke width
Use `text-stroke:0` to remove the visible stroke in a condition.
```html
<!-- @MARK text-stroke:0@print -->
<h2 class="text-stroke:1px text-stroke:0@print">
    Printed without stroke
</h2>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<h2 class="text-stroke:2px:hover text-stroke:1px@sm text-stroke:0@print">...</h2>
```
