## Examples
### Align inline content
Use `vertical:*` or `v:*` to align inline-level or table-cell content along the inline formatting context.
```html
<!-- @MARK v:middle -->
<span class="v:middle">Aligned text</span>
```

### Align icons with text
Use `v:middle`, `v:text-bottom`, or `v:text-top` to tune inline icons next to text.
```html
<!-- @MARK inline-block --><!-- @MARK v:text-bottom -->
<svg class="inline-block size:1em v:text-bottom" aria-hidden="true"></svg>
<span>Download</span>
```

### Align table cells
Use vertical alignment on table cells when content should sit at the top, middle, or bottom of the row.
```html
<!-- @MARK table-cell --><!-- @MARK v:top -->
<td class="table-cell v:top">Long cell content</td>
```

(i) `vertical-align` does not align flex or grid items. Use [align-items](/reference/align-items), [align-self](/reference/align-self), or [place-items](/reference/place-items) for those layouts.

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="v:baseline v:middle@sm v:top@print">...</div>
```
