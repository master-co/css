## Examples
### Cover a fixed frame
Use `object-cover` when media should fill its frame while preserving its aspect ratio.
```html
<!-- @MARK object-cover -->
<img class="w:full aspect-ratio:16/9 object-cover" src="/images/cover.jpg" alt="Cover">
```

<details>
    <summary>Generated CSS</summary>
    <Class2CSS>
        {['object-cover']}

</details>

### Contain the full media
Use `object-contain` when the full image or video must remain visible inside the frame.
```html
<!-- @MARK object-contain -->
<img class="w:full aspect-ratio:1/1 object-contain" src="/images/logo.png" alt="Logo">
```

### Disable object fitting
Use `object-fit:none` when the media should render at its intrinsic size within the content box.
```html
<!-- @MARK object-fit:none -->
<img class="object-fit:none" src="/images/icon.png" alt="Icon">
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<img class="object-cover:hover object-contain@sm object-fit:none@print" src="/images/photo.jpg" alt="">
```
