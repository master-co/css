## Usage

Use `collapse` for ordinary text, `preserve` for code, and `preserve-breaks` to retain authored line breaks. Set wrapping independently with `text-wrap-mode:*`.

### Preserve authored spaces and breaks \{#preserve-authored-spaces-and-breaks\}

<DemoExample page="white-space-collapse" section="preserve-authored-spaces-and-breaks" />

```html
<p id="target" class="white-space-collapse:preserve text-wrap-mode:wrap width:20rem max-width:100%">Name:    Master CSS
Status:  Ready
Spaces and line breaks remain visible.</p>
```
