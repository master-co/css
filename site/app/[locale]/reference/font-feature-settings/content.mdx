## Examples
### Enable a font feature
Use `font-feature:*` to pass OpenType feature tags directly to `font-feature-settings`.
```html
<!-- @MARK font-feature:'tnum' -->
<span class="font-feature:'tnum'">1234567890</span>
```

<details>
    <summary>Generated CSS</summary>
    <Class2CSS>
        {["font-feature:'tnum'"]}

### Reset features
Use `font-feature:normal` when a nested element should not inherit custom feature settings.
```html
<!-- @MARK font-feature:normal -->
<span class="font-feature:'tnum'">
    <span class="font-feature:normal">Reset</span>
</span>
```

### Prefer semantic numeric utilities
For common numeric features, prefer [`font:tabular-nums`](/reference/font-variant-numeric) or related numeric utilities because they are easier to read than raw feature tags.
```html
<span class="font:tabular-nums">12:45</span>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<span class="font-feature:'tnum':hover font-feature:normal@sm font-feature:normal@print">...</span>
```
