## Examples
### Delay animation start
Use `animation-delay:*` to wait before the first animation cycle begins.
```html
<!-- @MARK animation-delay:120ms -->
<div class="animation-delay:120ms animation-duration:300ms animation-name:fade">
    Staggered item
</div>
```

<details>
    <summary>Generated CSS</summary>
    <Class2CSS>
        {['animation-delay:120ms']}
    </Class2CSS>
</details>

### Offset looping animations
Negative delays start an animation partway through its cycle. This is useful for spinner segments that should not all begin at the same frame.
```html
<!-- @MARK animation-delay:-120ms -->
<svg class="animation-delay:-120ms animation-duration:1s animation-name:fade">
    ...
</svg>
```

### Stagger a list
Apply increasing delays to siblings when each item should enter after the previous one.
```html
<li class="animation-delay:0ms animation-name:fade">One</li>
<li class="animation-delay:80ms animation-name:fade">Two</li>
<li class="animation-delay:160ms animation-name:fade">Three</li>
```

### Use duration tokens
Define `duration-*` tokens when the same delay appears across several animation patterns. This example assumes your project defines a `fade` keyframe.

```css name=index.css
@theme {
    --duration-stagger: 120ms;
}
```

```html
<li class="animation:fade|fast|smooth animation-delay:stagger">...</li>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="animation-delay:120ms:hover animation-delay:0ms@print animation-delay:0ms@sm">...</div>
```
