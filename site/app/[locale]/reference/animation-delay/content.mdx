## Examples \{#examples\}
### Delay animation start \{#delay-animation-start\}
Compare no delay with a 600ms wait before the same one-second movement. Press Replay to start both timelines together.

<DemoExample page="animation-delay" section="delay-animation-start" />

```css name=index.css
@theme {

}
@keyframes layer-slide {
    from { transform: translateX(24px); }
    to { transform: translateX(96px); }
  }

```

```html
<!-- No delay -->
<div class="width:240px max-width:100%">
  <p class="mb-sm font-family-mono font-size-xs fg-text-muted">Base 0 · start 24 · end 96px</p>
  <div aria-hidden="true"
    class="height:56px p-xs outline-width:1px outline-style:dashed outline-line-subtle">
    <span id="target"
      class="display:grid place-items:center height:40px width:48px
             border-width:1px border-style:solid b-blue-60 r-sm bg-blue-10
             fg-blue-80 transform:none
             animation-delay:0ms animation-duration:1s
             animation-fill-mode:forwards
             animation-name:layer-slide
             animation-timing-function:linear
             animation:none@media(print)
             animation-play-state:paused@motion-reduce">→</span>
  </div>
</div>
```

```html
<!-- 600ms delay -->
<div class="width:240px max-width:100%">
  <p class="mb-sm font-family-mono font-size-xs fg-text-muted">Base 0 · start 24 · end 96px</p>
  <div aria-hidden="true"
    class="height:56px p-xs outline-width:1px outline-style:dashed outline-line-subtle">
    <span id="target"
      class="display:grid place-items:center height:40px width:48px
             border-width:1px border-style:solid b-blue-60 r-sm bg-blue-10
             fg-blue-80 transform:none
             animation-delay:600ms animation-duration:1s
             animation-fill-mode:forwards
             animation-name:layer-slide
             animation-timing-function:linear
             animation:none@media(print)
             animation-play-state:paused@motion-reduce">→</span>
  </div>
</div>
```

<details>

A positive delay postpones the first cycle, not every repetition. Without backwards fill, the delayed marker stays at its ordinary position (0px) until its first keyframe (24px) applies.

### Offset looping animations \{#offset-looping-animations\}
Use a negative delay to begin partway through an animation. Both hands have a two-second cycle; the second starts 500ms ahead.

<DemoExample page="animation-delay" section="offset-looping-animations" />

```html
<!-- No offset -->
<div class="display:flex align-items:center gap-md p-sm">
  <svg id="target" aria-hidden="true" width="48" height="48" viewBox="0 0 48 48"
    fill="none" stroke="currentColor" stroke-width="2"
    class="fg-text-blue animation-delay:0ms
           animation-duration:2s
           animation-iteration-count:infinite
           animation-name:rotate
           animation-timing-function:linear
           animation:none@media(print)
           animation-play-state:paused@motion-reduce">
    <circle cx="24" cy="24" r="17" opacity=".25" />
    <path d="M24 8v16h12 M19 13l5-5 5 5" />
  </svg>
  <span class="font-size-sm">No offset</span>
</div>
```

```html
<!-- 500ms ahead -->
<div class="display:flex align-items:center gap-md p-sm">
  <svg id="target" aria-hidden="true" width="48" height="48" viewBox="0 0 48 48"
    fill="none" stroke="currentColor" stroke-width="2"
    class="fg-text-blue animation-delay:-500ms
           animation-duration:2s
           animation-iteration-count:infinite
           animation-name:rotate
           animation-timing-function:linear
           animation:none@media(print)
           animation-play-state:paused@motion-reduce">
    <circle cx="24" cy="24" r="17" opacity=".25" />
    <path d="M24 8v16h12 M19 13l5-5 5 5" />
  </svg>
  <span class="font-size-sm">500ms ahead</span>
</div>
```

The negative delay changes the starting phase, not the duration. After 500ms, the first hand reaches the second hand’s original quarter-turn position.

### Stagger a list \{#stagger-a-list\}
Give each decorative child its own animation and delay. The 200ms offsets overlap these 800ms entrances instead of waiting for each preceding entrance to finish.

<DemoExample page="animation-delay" section="stagger-a-list" />

```html
<!-- Three independent entrance timelines -->
<ul class="display:grid gap-sm margin:0 p-sm list-style:none">
  <li class="display:flex align-items:center gap-sm font-size-sm">
    <span aria-hidden="true"
      class="display:inline-block height:32px width:64px
             border-width:1px border-style:solid b-blue-60 r-sm bg-blue-10
             animation-name:fade animation-duration:var(--duration-slowest) animation-timing-function:linear animation-fill-mode:both
             animation-delay:0ms animation:none@media(print)
             animation-play-state:paused@motion-reduce"></span>
    <span>Item 1 · 0ms</span>
  </li>
  <li class="display:flex align-items:center gap-sm font-size-sm">
    <span aria-hidden="true"
      class="display:inline-block height:32px width:64px
             border-width:1px border-style:solid b-blue-60 r-sm bg-blue-10
             animation-name:fade animation-duration:var(--duration-slowest) animation-timing-function:linear animation-fill-mode:both
             animation-delay:200ms animation:none@media(print)
             animation-play-state:paused@motion-reduce"></span>
    <span>Item 2 · 200ms</span>
  </li>
  <li class="display:flex align-items:center gap-sm font-size-sm">
    <span id="target" aria-hidden="true"
      class="display:inline-block height:32px width:64px
             border-width:1px border-style:solid b-blue-60 r-sm bg-blue-10
             animation-name:fade animation-duration:var(--duration-slowest) animation-timing-function:linear animation-fill-mode:both
             animation-delay:400ms animation:none@media(print)
             animation-play-state:paused@motion-reduce"></span>
    <span>Item 3 · 400ms</span>
  </li>
</ul>
```

Animation properties are not inherited. Backwards fill, included in both, keeps each waiting marker at the fade keyframe’s transparent start; the item labels remain visible.

### Use duration tokens \{#use-duration-tokens\}
Define a duration token for a shared waiting interval. This example resolves `stagger` to 120ms and uses the preset fade keyframes.

<DemoExample page="animation-delay" section="use-duration-tokens" />

```css name=index.css
@theme { :root, :host {
  --duration-stagger: 120ms;
} }

```

```html
<!-- 120ms delayed marker -->
<div class="display:flex align-items:center gap-md p-sm">
  <span id="target" aria-hidden="true"
    class="display:block height:40px width:64px border-width:1px border-style:solid b-blue-60 r-sm
           bg-blue-10 opacity:1 animation-duration:1s
           animation-fill-mode:both animation-name:fade
           animation-timing-function-smooth
           animation:none@media(print)
           animation-play-state:paused@motion-reduce
           animation-delay-stagger"></span>
  <span class="font-size-sm">120ms delayed marker</span>
</div>
```

The duration and delay can use the same namespace independently. This delay is 120ms; the animation still takes one second after it begins.

### Apply conditionally \{#apply-conditionally\}
Resize before replaying. The marker waits 600ms below `sm` and starts immediately at `sm`; its one-second movement stays the same.

<DemoExample page="animation-delay" section="apply-conditionally" />

```css name=index.css
@theme {

}
@keyframes layer-slide {
    from { transform: translateX(24px); }
    to { transform: translateX(96px); }
  }

```

```html
<!-- 600ms → no delay at sm -->
<div class="width:240px max-width:100%">
  <p class="mb-sm font-family-mono font-size-xs fg-text-muted">Base 0 · start 24 · end 96px</p>
  <div aria-hidden="true"
    class="height:56px p-xs outline-width:1px outline-style:dashed outline-line-subtle">
    <span id="target"
      class="display:grid place-items:center height:40px width:48px
             border-width:1px border-style:solid b-blue-60 r-sm bg-blue-10
             fg-blue-80 transform:none
             animation-delay:600ms animation-duration:1s
             animation-fill-mode:forwards
             animation-name:layer-slide
             animation-timing-function:linear
             animation:none@media(print)
             animation-play-state:paused@motion-reduce
             animation-delay:0ms@sm">→</span>
  </div>
</div>
```

Changing a delay while an animation already exists can move its current phase. Replay compares the newly selected value from time zero.
