## Basic usage
### Fill by column
Use `grid-auto-flow` to control how auto-placed grid items flow into the grid.
<Demo $py={0}>
    <DemoPanel>
        <div className="grid grid-auto-flow:column grid-template-rows:56px|56px gap:xs">
            <div className="min-w:0 p:sm b:1px|solid|blue-20 r:lg text-center bg:blue-5 b:blue-80@dark bg:blue-95@dark">1</div>
            <div className="min-w:0 p:sm r:lg text-center bg:gray-5 bg:gray-90@dark">2</div>
            <div className="min-w:0 p:sm r:lg text-center bg:gray-5 bg:gray-90@dark">3</div>
            <div className="min-w:0 p:sm r:lg text-center bg:gray-5 bg:gray-90@dark">4</div>
        </div>
    </DemoPanel>
</Demo>
```html
<!-- @MARK grid-auto-flow:column -->
<div class="grid grid-auto-flow:column grid-template-rows:56px|56px">
    <div>1</div>
    <div>2</div>
    <div>3</div>
    <div>4</div>
</div>
```

### Fill gaps densely
Use `dense` to let later items fill earlier holes when possible.
```html
<!-- @MARK grid-auto-flow:row|dense -->
<div class="grid grid-auto-flow:row|dense">…</div>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="grid-auto-flow:column:hover grid-auto-flow:column@dark grid-auto-flow:column@print grid-auto-flow:column@sm">…</div>
```
