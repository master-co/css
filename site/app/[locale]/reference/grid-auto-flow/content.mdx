## Basic usage
### Fill by column
Use `grid-auto-flow` to control how auto-placed grid items flow into the grid.
<Demo $py={0}>
    <DemoPanel>
        <div className="grid grid-template-rows:56px|56px grid-auto-flow:column gap:2x">
            <div className="min-w:0 p:3x r:8px bg:blue-5 bg:blue-95@dark border:1px|solid|blue-20 border-color:blue-80@dark text-center">1</div>
            <div className="min-w:0 p:3x r:8px bg:gray-5 bg:gray-90@dark text-center">2</div>
            <div className="min-w:0 p:3x r:8px bg:gray-5 bg:gray-90@dark text-center">3</div>
            <div className="min-w:0 p:3x r:8px bg:gray-5 bg:gray-90@dark text-center">4</div>
        </div>
    </DemoPanel>
</Demo>
```html
<!-- @MARK grid-auto-flow:column -->
<div class="grid grid-template-rows:56px|56px grid-auto-flow:column">
    <div>1</div>
    <div>2</div>
    <div>3</div>
    <div>4</div>
</div>
```

### Fill gaps densely
Use `dense` to let later items fill earlier holes when possible.
```html
<!-- @MARK grid-auto-flow:row|dense -->
<div class="grid grid-auto-flow:row|dense">…</div>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="grid-auto-flow:column:hover grid-auto-flow:column@sm grid-auto-flow:column@dark grid-auto-flow:column@print">…</div>
```
