## Installation [sr-only]
```bash action=install
@master/css.vue@rc
```

`@master/css.vue` provides Vue runtime helpers around [`@master/css-runtime`](/reference/runtime). Use it when a Vue app or a Vue-managed shadow root needs an explicit runtime provider and injectable runtime instance.

```ts
import { CSSRuntimeRegistry, CSSRuntimeProvider } from '@master/css.vue'
```

Use `@master/css.vue/runtime-provider` when you only need the provider API without the registry's `virtual:master-css-config` dependency.

For a Vite-powered Vue app that only needs automatic runtime injection, start with the [Vue installation guide](/guide/installation/vuejs). For Nuxt SSR and progressive rendering, use the [Nuxt guide](/guide/installation/nuxtjs).

---

## API Reference
### `<CSSRuntimeRegistry>`
The registry initializes a `CSSRuntime` instance with the project-level config provided by the active Master CSS integration.

```vue
<script setup lang="ts">
import { CSSRuntimeRegistry } from '@master/css.vue'
</script>

<template>
    <CSSRuntimeRegistry>
        <slot />
    </CSSRuntimeRegistry>
</template>
```

The registry loads `virtual:master-css-config` internally, so use it when the official integration should load the project-level config discovered from the CSS entry.

### `<CSSRuntimeProvider>`
The provider initializes a `CSSRuntime` for `document` by default, refreshes it when `config` changes, recreates it when `root` changes, and destroys it on unmount.

```vue
<script setup lang="ts">
import { CSSRuntimeProvider } from '@master/css.vue/runtime-provider'
import config from './app.css?master-css-config'
</script>

<template>
    <CSSRuntimeProvider :config="config">
        <slot />
    </CSSRuntimeProvider>
</template>
```

Use the provider subpath when you need a custom `?master-css-config` resource, a custom `root`, or an environment that does not resolve `virtual:master-css-config`.

### Provider props
```ts
interface CSSRuntimeProviderProps {
    config?: Config
    root?: Document | ShadowRoot | null
}
```

`root` defaults to `document`. Pass a `ShadowRoot` when Vue renders into a shadow tree and the runtime should observe only that tree.

### `useCSSRuntime()`
Access the runtime ref provided by `CSSRuntimeProvider`.

```vue
<script setup lang="ts">
import { useCSSRuntime } from '@master/css.vue/runtime-provider'

const cssRuntime = useCSSRuntime()
</script>
```

The returned value is a `ShallowRef<CSSRuntime | undefined> | undefined`. It is `undefined` outside the provider, and its `.value` is set after the provider mounts.

### `CSS_RUNTIME_INJECTION_KEY`
Vue injection key used by the provider and `useCSSRuntime()`.

```ts
import { CSS_RUNTIME_INJECTION_KEY } from '@master/css.vue/runtime-provider'
```
