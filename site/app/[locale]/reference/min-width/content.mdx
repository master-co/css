## Examples \{#examples\}
### Preserve a minimum width \{#preserve-a-minimum-inline-size\}
`min-w:*` sets a lower bound on physical width. This button prefers 80px but `min-w:32x` keeps it at least 128px wide. Padding and text remain part of its border-box width.

<DemoExample page="min-width" section="preserve-a-minimum-inline-size" />

```html
<div id="layout" class="w:70x max-w:full" role="group" aria-label="Available space">
  <button id="target" class="w:20x min-w:32x p:sm b:0" type="button">Continue</button>
</div>
```

The property is physical width, even in vertical writing. Use `min-size-x:*` for a logical inline minimum.

### Allow flexible children to shrink \{#allow-flexible-children-to-shrink\}
A flex item’s automatic minimum can keep it as wide as an unbreakable child. Here the content is 224px wide beside a fixed 48px sibling. `min-w:0` lets the blue flex item shrink to the 176px remaining after the 16px gap.

<DemoExample page="min-width" section="allow-flexible-children-to-shrink" />

```html
<!-- Automatic minimum -->
<div id="layout" class="flex gap:md w:60x" role="group" aria-label="Available space">
  <div id="peer" class="flex:0|0|48px p:sm">01</div>
  <div id="target" class="overflow:clip flex:1|1|0"><span id="item-3" class="block w:56x p:sm">Unbreakable content</span></div>
</div>
```

```html
<!-- Zero minimum -->
<div id="layout" class="flex gap:md w:60x" role="group" aria-label="Available space">
  <div id="peer" class="flex:0|0|48px p:sm">01</div>
  <div id="target" class="overflow:clip flex:1|1|0 min-w:0"><span id="item-3" class="block w:56x p:sm">Unbreakable content</span></div>
</div>
```

Both versions use `overflow:clip`, which is non-scrollable and preserves the automatic-minimum comparison. `overflow:hidden` or a scroll container can already change automatic minimum sizing, so they would obscure what `min-w:0` does here. The fixed content itself stays 224px wide.

### Combine with width and max-width \{#combine-with-width-and-max-width\}
The preferred width is constrained by its minimum and maximum. Compare a 140px preferred width raised to 160px, a 240px preferred width capped at 200px, and conflicting bounds where the 224px minimum wins over a 192px maximum.

<DemoExample page="min-width" section="combine-with-width-and-max-width" />

```html
<!-- Minimum wins over preference -->
<div id="layout" class="w:70x max-w:full" role="group" aria-label="Available space">
  <div id="target" class="w:50% min-w:40x max-w:50x p:sm">160px</div>
</div>
```

```html
<!-- Maximum caps preference -->
<div id="layout" class="w:70x max-w:full" role="group" aria-label="Available space">
  <div id="target" class="w:60x min-w:40x max-w:50x p:sm">200px</div>
</div>
```

```html
<!-- Minimum wins over maximum -->
<div id="layout" class="w:70x max-w:full" role="group" aria-label="Available space">
  <div id="target" class="w:60x min-w:56x max-w:48x p:sm">224px</div>
</div>
```

### Use intrinsic keywords \{#use-intrinsic-keywords\}
Intrinsic minimums can raise a small preferred width. All three boxes request `w:0` inside a 112px parent. `min-w:min` uses the longest unbreakable word; `min-w:fit` also considers the available width; `min-w:max` keeps the phrase on one line.

<DemoExample page="min-width" section="use-intrinsic-keywords" />

```html
<!-- Minimum content -->
<div id="layout" class="w:28x" role="group" aria-label="Available space">
  <div id="target" class="w:0 min-w:min p:sm font:md font:mono leading:24px">Design systems</div>
</div>
```

```html
<!-- Fit content -->
<div id="layout" class="w:28x" role="group" aria-label="Available space">
  <div id="target" class="w:0 min-w:fit p:sm font:md font:mono leading:24px">Design systems</div>
</div>
```

```html
<!-- Maximum content -->
<div id="layout" class="w:28x" role="group" aria-label="Available space">
  <div id="target" class="w:0 min-w:max p:sm font:md font:mono leading:24px">Design systems</div>
</div>
```

### Apply conditionally \{#apply-conditionally\}
Resize past `sm` to raise the lower bound from zero to 160px. The preferred width remains 80px, so the change comes from the minimum alone.

<DemoExample page="min-width" section="apply-conditionally" />

```html
<div id="layout" class="w:70x max-w:full" role="group" aria-label="Available space">
  <div id="target" class="w:20x min-w:0 p:sm min-w:40x@sm">Floor</div>
</div>
```
