## Examples \{#examples\}
### Preserve a minimum width \{#preserve-a-minimum-inline-size\}
`min-width:*` sets a lower bound on physical width. This button prefers 80px but `min-width:8rem` keeps it at least 128px wide. Padding and text remain part of its border-box width.

<DemoExample page="min-width" section="preserve-a-minimum-inline-size" />

```html
<div id="layout" class="width:17.5rem max-width:100%" role="group" aria-label="Available space">
  <button id="target" class="width:5rem min-width:8rem p-sm border-width:0" type="button">Continue</button>
</div>
```

The property is physical width, even in vertical writing. Use `min-inline-size:*` for a logical inline minimum.

### Allow flexible children to shrink \{#allow-flexible-children-to-shrink\}
A flex item’s automatic minimum can keep it as wide as an unbreakable child. Here the content is 224px wide beside a fixed 48px sibling. `min-width:0` lets the blue flex item shrink to the 176px remaining after the 16px gap.

<DemoExample page="min-width" section="allow-flexible-children-to-shrink" />

```html
<!-- Automatic minimum -->
<div id="layout" class="display:flex gap-md width:15rem" role="group" aria-label="Available space">
  <div id="peer" class="flex-grow:0 flex-shrink:0 flex-basis:48px p-sm">01</div>
  <div id="target" class="overflow:clip flex-grow:1 flex-shrink:1 flex-basis:0px"><span id="item-3" class="display:block width:14rem p-sm">Unbreakable content</span></div>
</div>
```

```html
<!-- Zero minimum -->
<div id="layout" class="display:flex gap-md width:15rem" role="group" aria-label="Available space">
  <div id="peer" class="flex-grow:0 flex-shrink:0 flex-basis:48px p-sm">01</div>
  <div id="target" class="overflow:clip flex-grow:1 flex-shrink:1 flex-basis:0px min-width:0"><span id="item-3" class="display:block width:14rem p-sm">Unbreakable content</span></div>
</div>
```

Both versions use `overflow:clip`, which is non-scrollable and preserves the automatic-minimum comparison. `overflow:hidden` or a scroll container can already change automatic minimum sizing, so they would obscure what `min-width:0` does here. The fixed content itself stays 224px wide.

### Combine with width and max-width \{#combine-with-width-and-max-width\}
The preferred width is constrained by its minimum and maximum. Compare a 140px preferred width raised to 160px, a 240px preferred width capped at 200px, and conflicting bounds where the 224px minimum wins over a 192px maximum.

<DemoExample page="min-width" section="combine-with-width-and-max-width" />

```html
<!-- Minimum wins over preference -->
<div id="layout" class="width:17.5rem max-width:100%" role="group" aria-label="Available space">
  <div id="target" class="width:50% min-width:10rem max-width:12.5rem p-sm">160px</div>
</div>
```

```html
<!-- Maximum caps preference -->
<div id="layout" class="width:17.5rem max-width:100%" role="group" aria-label="Available space">
  <div id="target" class="width:15rem min-width:10rem max-width:12.5rem p-sm">200px</div>
</div>
```

```html
<!-- Minimum wins over maximum -->
<div id="layout" class="width:17.5rem max-width:100%" role="group" aria-label="Available space">
  <div id="target" class="width:15rem min-width:14rem max-width:12rem p-sm">224px</div>
</div>
```

### Use intrinsic keywords \{#use-intrinsic-keywords\}
Intrinsic minimums can raise a small preferred width. All three boxes request `width:0` inside a 112px parent. `min-width:min-content` uses the longest unbreakable word; `min-width:fit-content` also considers the available width; `min-width:max-content` keeps the phrase on one line.

<DemoExample page="min-width" section="use-intrinsic-keywords" />

```html
<!-- Minimum content -->
<div id="layout" class="width:7rem" role="group" aria-label="Available space">
  <div id="target" class="width:0 min-width:min-content p-sm font-size-md font-family-mono line-height:24px">Design systems</div>
</div>
```

```html
<!-- Fit content -->
<div id="layout" class="width:7rem" role="group" aria-label="Available space">
  <div id="target" class="width:0 min-width:fit-content p-sm font-size-md font-family-mono line-height:24px">Design systems</div>
</div>
```

```html
<!-- Maximum content -->
<div id="layout" class="width:7rem" role="group" aria-label="Available space">
  <div id="target" class="width:0 min-width:max-content p-sm font-size-md font-family-mono line-height:24px">Design systems</div>
</div>
```

### Apply conditionally \{#apply-conditionally\}
Resize past `sm` to raise the lower bound from zero to 160px. The preferred width remains 80px, so the change comes from the minimum alone.

<DemoExample page="min-width" section="apply-conditionally" />

```html
<div id="layout" class="width:17.5rem max-width:100%" role="group" aria-label="Available space">
  <div id="target" class="width:5rem min-width:0 p-sm min-width:10rem@sm">Floor</div>
</div>
```
