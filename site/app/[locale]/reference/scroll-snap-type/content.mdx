## Examples \{#examples\}
### Snap on the horizontal axis \{#snap-on-the-horizontal-axis\}
Use `snap-x` on a horizontal scroll container. Add snap alignment to the children.
```html
<!-- @MARK snap-x -->
<div class="overflow-x:auto snap-x">
  <article class="snap-start">One</article>
</div>
```

### Require a snap point \{#require-a-snap-point\}
Use `scroll-snap-type:*|mandatory` when the container must settle on a snap point after scrolling.
```html
<!-- @MARK scroll-snap-type:y|mandatory -->
<div class="overflow-y:auto scroll-snap-type:y|mandatory">
  <section class="snap-start">Step</section>
</div>
```

### Allow nearby snap points \{#allow-nearby-snap-points\}
Use `proximity` when snapping should help alignment without taking over every scroll gesture.
```html
<!-- @MARK scroll-snap-type:x|proximity -->
<div class="overflow-x:auto scroll-snap-type:x|proximity">
  ...
</div>
```

### Apply conditionally \{#apply-conditionally\}
Apply styles based on different states using [selectors](/reference/rules/selectors) and [conditional queries](/reference/rules/conditions).
```html
<div class="snap-x scroll-snap-type:none@print scroll-snap-type:y|mandatory@sm">...</div>
```
