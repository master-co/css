## Examples \{#examples\}
### Set decoration thickness \{#set-decoration-thickness\}
`text-decoration-thickness` sets the weight of an existing underline, overline or strike-through. Compare 1px and 3px with the same font and offset.

<DemoExample page="text-decoration-thickness" section="set-decoration-thickness" />

```html
<!-- Thickness · 1px -->
<p id="target"
  class="inline-block max-w:100% m:0 font:2xl leading:xl underline
         text-decoration-color:blue-50 text-decoration-thickness:1px
         text-underline:3xs"
>
  Design together
</p>
```

```html
<!-- Thickness · 3px -->
<p id="target"
  class="inline-block max-w:100% m:0 font:2xl leading:xl underline
         text-decoration-color:blue-50 text-decoration-thickness:3px
         text-underline:3xs"
>
  Design together
</p>
```

### Use font-provided thickness \{#use-font-provided-thickness\}
`text-decoration-thickness:from-font` requests the font’s preferred underline thickness. If that metric is unavailable, the browser falls back to its automatic choice.

<DemoExample page="text-decoration-thickness" section="use-font-provided-thickness" />

```html
<!-- Thickness · auto -->
<p id="target"
  class="inline-block max-w:100% m:0 font:2xl leading:xl underline
         text-decoration-thickness:auto"
>
  Design together
</p>
```

```html
<!-- Thickness · from-font -->
<p id="target"
  class="inline-block max-w:100% m:0 font:2xl leading:xl underline
         text-decoration-thickness:from-font"
>
  Design together
</p>
```

The two values may look identical. The readout reports the requested keyword, not a measured stroke thickness. Use the thickness longhand to retain the underline.

### Pair with underline offset \{#pair-with-underline-offset\}
Offset and thickness control separate parts of the underline. Compare the same 3px line at 2px and 6px offsets; neither changes the text box’s layout height.

<DemoExample page="text-decoration-thickness" section="pair-with-underline-offset" />

```html
<!-- 3px thickness · 2px offset -->
<p id="target"
  class="inline-block max-w:100% m:0 font:2xl leading:xl underline
         text-decoration-thickness:3px text-underline-offset:2px"
>
  Design together
</p>
```

```html
<!-- 3px thickness · 6px offset -->
<p id="target"
  class="inline-block max-w:100% m:0 font:2xl leading:xl underline
         text-decoration-thickness:3px text-underline-offset:6px"
>
  Design together
</p>
```

Inspect the actual font’s descenders and line spacing before selecting an offset.

### Apply conditionally \{#apply-conditionally\}
Hover or focus to increase the underline from 1px to 3px. Print uses the thinner line. The label keeps its font size and line height.

<DemoExample page="text-decoration-thickness" section="apply-conditionally" />

```html
<!-- Pointer and keyboard states -->
<button id="target" type="button"
  class="font:2xl leading:xl underline text-decoration-thickness:1px
         text-underline:3xs text-decoration-thickness:1px@print
         text-decoration-thickness:3px:hover@screen
         text-decoration-thickness:3px:focus-visible@screen"
>
  Design together
</button>
```
