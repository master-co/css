## Examples
### Set decoration thickness
Use `text-decoration-thickness:*` to control underline, overline, or line-through weight.
```html
<!-- @MARK text-decoration-thickness:2px -->
<a class="underline text-decoration-thickness:2px">
  Strong underline
</a>
```

### Use font-provided thickness
Use `text-decoration:from-font` when the typeface provides an underline thickness that should be respected.
```html
<!-- @MARK text-decoration:from-font -->
<a class="underline text-decoration:from-font">
  Typeface underline
</a>
```

### Pair with underline offset
Thicker decorations usually need a slightly larger [`text-underline-offset`](/reference/text-underline-offset).
```html
<a class="underline text-decoration-thickness:2px text-underline:3xs">
  Balanced underline
</a>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<a class="text-decoration-thickness:2px:hover text-decoration-thickness:1px@print text-decoration:from-font@sm">...</a>
```
