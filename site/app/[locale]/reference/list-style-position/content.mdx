## Examples \{#examples\}
### Place markers inside the content box \{#place-markers-inside-the-content-box\}
An inside marker occupies the first inline box of each item. Wrapped lines begin at the item’s content edge, underneath the marker’s starting position. Compare the same content and width outside and inside.

<DemoExample page="list-style-position" section="place-markers-inside-the-content-box" />

```html
<!-- Outside · hanging marker -->
<ul id="target" class="width:260px max-width:100% margin:0 pl-lg font-md leading-lg
    list-style-type:disc list-style-position:outside list-style-image:initial">
  <li class="mb-2xs">Collect references</li>
  <li class="mb-2xs">Compare the spacing across every screen size.</li>
  <li class="mb-2xs">Review the composition</li>
</ul>
```

```html
<!-- Inside · marker on first line -->
<ul id="target" class="width:260px max-width:100% margin:0 pl-lg font-md leading-lg
    list-style-type:disc list-style-position:outside list-style-image:initial list-style-position:inside">
  <li class="mb-2xs">Collect references</li>
  <li class="mb-2xs">Compare the spacing across every screen size.</li>
  <li class="mb-2xs">Review the composition</li>
</ul>
```

### Keep markers outside \{#keep-markers-outside\}
An outside marker hangs beside the item’s principal box. Wrapped text aligns with the first text line. Leave enough inline-start padding so the marker stays within the surrounding surface.

<DemoExample page="list-style-position" section="keep-markers-outside" />

```html
<!-- Outside · aligned text lines -->
<ul id="target" class="width:260px max-width:100% margin:0 pl-lg font-md leading-lg
    list-style-type:disc list-style-position:inside list-style-image:initial list-style-position:outside">
  <li class="mb-2xs">Collect references</li>
  <li class="mb-2xs">Compare the spacing across every screen size.</li>
  <li class="mb-2xs">Review the composition</li>
</ul>
```

### Apply conditionally \{#apply-conditionally\}
Resize past `sm` to place decimal markers inside. The dedicated position property preserves their type. Print returns them outside.

<DemoExample page="list-style-position" section="apply-conditionally" />

```html
<!-- Real viewport · position only -->
<ol id="target" class="width:260px max-width:100% margin:0 pl-lg font-md leading-lg
    list-style-type:decimal list-style-position:outside list-style-image:initial list-style-position:outside@media(print)
    list-style-position:inside@media(screen)@sm">
  <li class="mb-2xs">Collect references</li>
  <li class="mb-2xs">Compare the spacing across every screen size.</li>
  <li class="mb-2xs">Review the composition</li>
</ol>
```
