## Basic usage
### Clearing both left and right floats
Use `both:clear` to move the element below all floated elements.
<Demo>
    <div>
        <div className="box w:150px h:200px float:left">Left</div>
        <div className="box w:150px h:120px float:right">Right</div>
        <div className="box w:300px h:80px clear:both">Clear</div>
    </div>
</Demo>
```html
<div>
    <div class="float:left">Left</div>
    <div class="float:right">Right</div>
    <!-- @MARK clear:both -->
    <div class="clear:both">Clear</div>
</div>
```

### Clearing left floats
Use `both:left` to move the element below all left floated elements.
<Demo>
    <div>
        <div className="box w:150px h:200px float:right">Right</div>
        <div className="box w:150px h:200px float:right">Right</div>
        <div className="box w:150px h:120px float:left">Left</div>
        <div className="box w:150px h:120px clear:left">Clear</div>
    </div>
</Demo>
```html
<div>
    <div class="float:right">Right</div>
    <div class="float:right">Right</div>
    <div class="float:left">Left</div>
    <!-- @MARK clear:left -->
    <div class="clear:left">Clear</div>
</div>
```

### Clearing right floats
Use `both:right` to move the element below all right floated elements.
<Demo>
    <div>
        <div className="box w:150px h:200px float:left">Left</div>
        <div className="box w:150px h:200px float:left">Left</div>
        <div className="box w:150px h:120px float:right">Right</div>
        <div className="box w:150px h:120px clear:right">Clear</div>
    </div>
</Demo>
```html
<div>
    <div class="float:left">Left</div>
    <div class="float:left">Left</div>
    <div class="float:right">Right</div>
    <!-- @MARK clear:left -->
    <div class="clear:left">Clear</div>
</div>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="clear:both:hover clear:both@sm clear:both@dark clear:both@print">…</div>
```
