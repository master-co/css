## Basic usage \{#basic-usage\}
### Clearing both left and right floats \{#clearing-both-left-and-right-floats\}
Use `clear:both` on the block that must start below preceding floats on either side. Clearing applies within the same block formatting context; it does not change the floats themselves.

The preview gives the two floats different heights so you can distinguish clearing one side from clearing both.

<DemoExample page="clear" section="clearing-both-left-and-right-floats" />

```html
<div>
  <div class="float:left h:34x w:34%">Left</div>
  <div class="float:right h:22x w:34%">Right</div>
  <!-- @MARK clear:both -->
  <div class="clear:both">Clear</div>
</div>
```

### Clearing left floats \{#clearing-left-floats\}
Use `clear:left` when the block must pass the left float. It can still sit beside a taller right float.

<DemoExample page="clear" section="clearing-left-floats" />

```html
<div>
  <div class="float:left h:18x w:34%">Left</div>
  <div class="float:right h:34x w:34%">Right</div>
  <!-- @MARK clear:left -->
  <div class="clear:left">Clear</div>
</div>
```

### Clearing right floats \{#clearing-right-floats\}
Use `clear:right` when the block must pass the right float. It can still sit beside a taller left float.

<DemoExample page="clear" section="clearing-right-floats" />

```html
<div>
  <div class="float:left h:34x w:34%">Left</div>
  <div class="float:right h:18x w:34%">Right</div>
  <!-- @MARK clear:right -->
  <div class="clear:right">Clear</div>
</div>
```

### Apply conditionally \{#apply-conditionally\}
Use `clear:left` initially, then clear both sides at `sm` or in print. The preview also applies `clear:both` on keyboard focus: press Tab to reach the blue block and compare its position. See [selectors](/reference/rules/selectors) and [conditions](/reference/rules/conditions) for the syntax.

<DemoExample page="clear" section="apply-conditionally" />

```html
<div tabindex="0" class="clear:left clear:both:focus-visible clear:both@print clear:both@sm">
  Focus with Tab
</div>
```
