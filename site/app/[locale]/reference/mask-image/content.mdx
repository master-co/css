## Examples
### Apply a mask image
Use `mask-image:*` to control the alpha mask for an element.
```html
<!-- @MARK mask-image:linear-gradient(black,transparent) -->
<div class="mask-image:linear-gradient(black,transparent)">
    ...
</div>
```

<details>
    <summary>Generated CSS</summary>
    <Class2CSS>

</details>

### Fade overflowing media
Gradient masks are useful when media or scroll regions should fade out without changing layout.
```html
<!-- @MARK overflow:hidden --><!-- @MARK mask-image:linear-gradient(black,transparent) -->
<figure class="overflow:hidden mask-image:linear-gradient(black,transparent)">
    ...
</figure>
```

Masks affect painting and hit testing can still follow the original element box. Keep interactive controls outside heavily masked regions.

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="mask-image:none mask-image:linear-gradient(black,transparent)@sm mask-image:none@print">...</div>
```
