## Examples
### Slice
Use `box-decoration:slice` when inline fragments should share one continuous background, border, shadow, and decoration.
```html
<!-- @MARK box-decoration:slice -->
<span class="box-decoration:slice bg:primary/.12">
    Wrapped inline text
</span>
```

### Clone
Use `box-decoration:clone` when each wrapped line should get its own background, border, shadow, and decoration.
```html
<!-- @MARK box-decoration:clone -->
<span class="box-decoration:clone bg:primary/.12 px:1x">
    Wrapped inline text
</span>
```

### Use on inline content
This property is most visible when inline content wraps across multiple lines.
```html
<span class="box-decoration:clone bg:accent-surface">
    A highlighted phrase that can wrap
</span>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<span class="box-decoration:clone:hover box-decoration:slice@sm box-decoration:slice@print">...</span>
```
