## Basic usage
### Setup ESLint configuration
Use the latest flat configuration. As an example of checking Master CSS syntax in TypeScript and HTML files:
```js name=eslint.config.js
import css from '@master/eslint-config-css' /* [!code ++] */
import htmlParser from "@angular-eslint/template-parser"
import tsParser from '@typescript-eslint/parser'

/** @type {import('eslint').Linter.Config[]} */
export default [
    {
        files: ['**/*.html'],
        languageOptions: {
            parser: htmlParser
        }
    },
    {
        files: ['**/*.{ts,tsx}'],
        languageOptions: {
            parser: tsParser
        }
    },
    css, /* [!code ++] */
    {
        rules: {
            '@master/css/class-validation': ['error', {
                disallowUnknownClass: true
            }],
        }
    },
]
```
Use flat config for new projects. It is the supported configuration style shown throughout this reference.

## API Reference
### `rules.class-order`
Enforce a consistent and logical order of classes.
```js name=eslint.config.js
export default [
    {
        rules: {
            "@master/css/class-order": "warn"
        }
    }
]
```

### `rules.class-validation`
Detect syntax errors early when writing classes.
```js name=eslint.config.js
export default [
    {
        rules: {
            "@master/css/class-validation": "error"
        }
    }
]
```
Set `disallowUnknownClass: true` to disallow unknow classes and enforce strict checks:
```js name=eslint.config.js
export default [
    {
        rules: {
            "@master/css/class-validation": ["error", {
                "disallowUnknownClass": true
            }]
        }
    }
]
```

### `rules.class-collision`
Avoid applying classes with the same CSS declaration.
```js name=eslint.config.js
export default [
    {
        rules: {
            "@master/css/class-collision": "warn"
        }
    }
]
```

### `settings.classAttributes`
Specify the element attribute containing classes.
<Code lang="js" name="eslint.config.js" beautify>
{`
    export default [
        {
            settings: {
                "@master/css": {
                    "classAttributes": ${JSON.stringify(settings.classAttributes, null, 4)}
                }
            }
        }
    ]
`}
</Code>

### `settings.classFunctions`

### `settings.config`
Specify an explicit Master CSS configuration object. By default, ESLint loads the project CSS entry discovered from the current working directory.
<Code lang="js" name="eslint.config.js">
{`
    export default [
        {
            settings: {
                "@master/css": {
                    config: ${JSON.stringify(settings.config, null, 4)}
                }
            }
        }
    ]
`}
</Code>
If the discovered project CSS entry is not the config you want for this ESLint run, pass an explicit config object:
```js name=eslint.config.js
export default [
    {
        settings: {
            "@master/css": {
                config: {
                    variables: {
                        color: {
                            primary: '#4f46e5'
                        }
                    }
                }
            }
        }
    }
]
```
