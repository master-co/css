The leading tokens are unitless multipliers. Each paragraph uses 16px type and the same maximum line width, making its line spacing directly comparable.

```html
<!-- leading:xs -->
<p id="target" class="max-w:24ch m:0 font:md leading:xs">Clear type gives each idea room to breathe. Keep the measure comfortable and let the content set the pace.</p>
```
