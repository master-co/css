### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="animation-timing-function:smooth:hover animation-timing-function:crisp@sm animation-timing-function:overshoot@dark animation-timing-function:ease-in-out@print">…</div>
```
