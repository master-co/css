### Set keyframe easing \{#set-keyframe-easing\}
Compare linear, ease-in and ease-out over the same one-second path. Replay starts all three native timelines together.

<DemoExample page="animation-timing-function" section="set-keyframe-easing" />

  @keyframes layer-slide {
    from { transform: translateX(24px); }
    to { transform: translateX(96px); }
  }
}

### Match easing to intent \{#match-easing-to-intent\}
For a deliberately stepped movement, place a timing function on the starting keyframe. It controls the interval leading to the next keyframe.

<DemoExample page="animation-timing-function" section="match-easing-to-intent" />

```css name=index.css
@theme {
  @keyframes layer-slide {
    from { transform: translateX(24px); animation-timing-function:steps(4,end); }
    to { transform: translateX(96px); }
  }
}
```

```html
<!-- Keyframe easing · four 18px steps -->
<div class="w:240px max-w:100%">
  <p class="mb:sm font:mono font:xs text:muted">Base 0 · start 24 · end 96px</p>
  <div aria-hidden="true"
    class="h:56px p:xs outline:1px|dashed|muted">
    <span id="target"
      class="grid place-items:center h:40px w:48px
             b:1px|solid|blue-60 r:sm bg:blue-10
             fg:blue-80 transform:none
             animation-duration:1s
             animation-fill-mode:forwards
             animation-name:layer-slide
             animation-timing-function:linear
             animation:none@print
             animation-play-state:paused@reduce-motion">→</span>
  </div>
</div>
```

The element declares linear, but the keyframe’s steps(4,end) overrides it for this interval. Easing on the final 100% keyframe has no following interval to affect.

### Apply conditionally \{#apply-conditionally\}
Resize before replaying to switch from ease-out to linear at `sm`. The one-second duration and 72px path remain unchanged.

<DemoExample page="animation-timing-function" section="apply-conditionally" />

```css name=index.css
@theme {
  @keyframes layer-slide {
    from { transform: translateX(24px); }
    to { transform: translateX(96px); }
  }
}
```

```html
<!-- Ease-out → linear at sm -->
<div class="w:240px max-w:100%">
  <p class="mb:sm font:mono font:xs text:muted">Base 0 · start 24 · end 96px</p>
  <div aria-hidden="true"
    class="h:56px p:xs outline:1px|dashed|muted">
    <span id="target"
      class="grid place-items:center h:40px w:48px
             b:1px|solid|blue-60 r:sm bg:blue-10
             fg:blue-80 transform:none
             animation-duration:1s
             animation-fill-mode:forwards
             animation-name:layer-slide
             animation-timing-function:ease-out
             animation:none@print
             animation-play-state:paused@reduce-motion
             animation-timing-function:linear@sm">→</span>
  </div>
</div>
```

The native query changes the element’s easing. A keyframe-level easing would take precedence for its own interval; these keyframes contain no such override.
