## Examples \{#examples\}
### Set keyframe easing \{#set-keyframe-easing\}
Use `animation-timing-function:*` to control how keyframes progress between each keyframe stop.
```html
<!-- @MARK animation-timing-function:ease-out -->
<div class="animation-duration:300ms animation-name:fade animation-timing-function:ease-out">
  Enters
</div>
```

### Use linear timing for rotation \{#use-linear-timing-for-rotation\}
Continuous indicators usually need `linear` so the motion does not speed up and slow down every cycle.
```html
<!-- @MARK animation-timing-function:linear -->
<svg class="animation-duration:1s animation-name:rotate animation-timing-function:linear">
  ...
</svg>
```

### Match easing to intent \{#match-easing-to-intent\}
Use `ease-out` for entrance motion and `ease-in` for exit motion. Prefer `linear` for clocks, progress, and loading rotation.
```html
<!-- @MARK animation-timing-function:ease-in -->
<div class="animation-timing-function:ease-out animation-timing-function:ease-in:hover">
  Dismiss
</div>
```

### Apply conditionally \{#apply-conditionally\}
Apply styles based on different states using [selectors](/reference/rules/selectors) and [conditional queries](/reference/rules/conditions).
```html
<div class="animation-timing-function:ease-out:hover animation-timing-function:ease-in@print animation-timing-function:linear@sm">...</div>
```
