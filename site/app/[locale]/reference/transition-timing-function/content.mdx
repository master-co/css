## Examples
### Choose an easing curve
Use `transition-timing-function:*` to control acceleration during a transition. Pair it with a duration so the curve is visible.
```html
<!-- @MARK transition-timing-function:ease-out -->
<button class="transition-duration:180ms transition-property:transform transition-timing-function:ease-out transform:translateY(-2px):hover">
  Hover
</button>
```

### Use linear timing for continuous motion
Use `linear` when the transition represents steady progress instead of physical easing.
```html
<!-- @MARK transition-timing-function:linear -->
<div class="transition-duration:1s transition-property:opacity transition-timing-function:linear">
  Syncing
</div>
```

### Keep entrance and exit curves intentional
`ease-out` works well for elements entering or becoming more prominent. `ease-in` can work for elements leaving the interface.
```html
<!-- @MARK transition-timing-function:ease-in -->
<div class="transition-timing-function:ease-out transition-timing-function:ease-in:hover">
  Dismiss
</div>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="transition-timing-function:ease-out:hover transition-timing-function:ease-in@print transition-timing-function:linear@sm">...</div>
```
