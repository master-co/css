### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="transition-timing-function:smooth:hover transition-timing-function:crisp@sm transition-timing-function:overshoot@dark transition-timing-function:ease-in-out@print">…</div>
```
