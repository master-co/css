An easing function maps elapsed progress to the interpolated value. It changes the distribution of movement through time, not the declared duration or destination.

Linear timing gives constant progress between these numeric endpoints. Steps creates intentional jumps. Use steps() for stepped timing; it is distinct from a continuously interpolated curve.

### Keep entrance and exit curves intentional \{#keep-entrance-and-exit-curves-intentional\}
Check to move the layer out with ease-out. After it arrives, uncheck to return with ease-in. Each direction keeps the same duration.

<DemoExample page="transition-timing-function" section="keep-entrance-and-exit-curves-intentional" />

```html
<!-- Ease out → ease in on return -->
<label
  class="display:block width:280px max-width:100% font-sm
         transform:translateX(96px):has(input:checked)>span>span@media(screen)
         transition-timing-function:ease-out:has(input:checked)>span>span@media(screen)">
  <input type="checkbox" aria-label="Move layer"
    class="mr-xs accent-color-blue
           outline-width:2px:focus-visible outline-style:solid:focus-visible outline-blue:focus-visible
           outline-offset:3px:focus-visible">
  Move layer
  <span aria-hidden="true"
    class="display:block height:64px mt-md p-xs
           outline-width:1px outline-style:dashed outline-line-subtle">
    <span id="target"
      class="display:grid place-items:center height:48px width:128px
             border-width:1px border-style:solid b-blue-60 r-sm font-sm bg-blue-10
             fg-blue-80 opacity:1 transform:none
             transition:none@media(print)
             transition-property:transform@media(screen)@motion-safe transition-duration:var(--duration-slowest)@media(screen)@motion-safe transition-timing-function:ease-in@media(screen)@motion-safe">
      Layer 01
    </span>
  </span>
</label>
```

A transition uses the timing function selected for its new state. The checked rule supplies ease-out for the outward move, and the resting rule supplies ease-in for the return. Reversing an unfinished transition can shorten its return interval.

### Apply conditionally \{#apply-conditionally\}
Resize before toggling. Below `sm`, the layer uses ease-out; at `sm`, it uses linear timing. Duration and distance remain fixed.

<DemoExample page="transition-timing-function" section="apply-conditionally" />

```html
<!-- Ease out → linear at sm -->
<label class="display:block width:280px max-width:100% font-sm
         transform:translateX(96px):has(input:checked)>span>span@media(screen)">
  <input type="checkbox" aria-label="Move layer"
    class="mr-xs accent-color-blue
           outline-width:2px:focus-visible outline-style:solid:focus-visible outline-blue:focus-visible
           outline-offset:3px:focus-visible">
  Move layer
  <span aria-hidden="true"
    class="display:block height:64px mt-md p-xs
           outline-width:1px outline-style:dashed outline-line-subtle">
    <span id="target"
      class="display:grid place-items:center height:48px width:128px
             border-width:1px border-style:solid b-blue-60 r-sm font-sm bg-blue-10
             fg-blue-80 opacity:1 transform:none
             transition:none@media(print)
             transition-property:transform@media(screen)@motion-safe transition-duration:var(--duration-slowest)@media(screen)@motion-safe transition-timing-function:ease-out@media(screen)@motion-safe
             transition-timing-function:linear@media(screen)@sm">
      Layer 01
    </span>
  </span>
</label>
```

The easing value follows the real iframe viewport. Reduced motion and print remove the interpolation, so a reported curve does not imply visible motion when the duration is zero.
