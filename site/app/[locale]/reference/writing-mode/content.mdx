## Examples \{#examples\}
### Use vertical right-to-left flow \{#use-vertical-right-to-left-flow\}
`writing-mode:vertical-rl` makes lines vertical and advances columns from right to left. Compare `vertical-lr`, which advances columns in the opposite direction.

<DemoExample page="writing-mode" section="use-vertical-right-to-left-flow" />

```html
<!-- writing-mode:vertical-rl -->
<p id="target" lang="zh-Hant" class="h:128px w:120px m:0 font-md leading:24px writing-mode:vertical-rl">清晰設計讓每個想法都有空間</p>
```

```html
<!-- writing-mode:vertical-lr -->
<p id="target" lang="zh-Hant" class="h:128px w:120px m:0 font-md leading:24px writing-mode:vertical-lr">清晰設計讓每個想法都有空間</p>
```

In horizontal-tb, the inline axis is horizontal and the block axis is vertical; vertical modes exchange those roles.

### Restore horizontal text \{#restore-horizontal-text\}
A nested block with `writing-mode:horizontal-tb` establishes its own horizontal writing context inside vertical content.

<DemoExample page="writing-mode" section="restore-horizontal-text" />

```html
<!-- Vertical parent · horizontal block -->
<div id="context" class="h:160px font-md leading:24px writing-mode:vertical-rl">
  <p lang="zh-Hant" class="m:0">設計筆記</p>
  <p id="target" class="w:160px max-w:100% m:0 font-md leading:24px writing-mode:horizontal-tb">A horizontal note inside vertical flow.</p>
</div>
```

Use an actual block or inline-block for the independent writing context; an ordinary non-replaced inline span cannot switch its writing mode independently.

### Pair with text orientation \{#pair-with-text-orientation\}
Writing mode sets the flow, while [text-orientation](/reference/text-orientation) controls the glyphs inside it. Compare the same four digits.

<DemoExample page="writing-mode" section="pair-with-text-orientation" />

```html
<!-- writing-mode:vertical-rl text-orientation:mixed -->
<p id="target" class="h:128px m:0 font-md leading:24px text-orientation:mixed writing-mode:vertical-rl">2026</p>
```

```html
<!-- writing-mode:vertical-rl text-orientation:upright -->
<p id="target" class="h:128px m:0 font-md leading:24px text-orientation:upright writing-mode:vertical-rl">2026</p>
```

### Apply conditionally \{#apply-conditionally\}
The compact label starts in vertical flow and becomes horizontal at `sm` on screen. Print uses horizontal flow as well.

<DemoExample page="writing-mode" section="apply-conditionally" />

```html
<!-- Vertical label · horizontal at sm -->
<p id="target" class="size:160px m:0 font-md leading:24px writing-mode:vertical-rl writing-mode:horizontal-tb@print writing-mode:horizontal-tb@screen@sm">Design 2026</p>
```
