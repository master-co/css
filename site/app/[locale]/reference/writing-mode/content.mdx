## Examples
### Use vertical right-to-left flow
Use `writing-mode:vertical-rl` when text should flow vertically with columns progressing from right to left.
```html
<!-- @MARK writing-mode:vertical-rl -->
<p class="writing-mode:vertical-rl">
  Vertical label
</p>
```

<details>
  <summary>Generated CSS</summary>

</details>

### Restore horizontal text
Use `writing-mode:horizontal-tb` to return nested content to normal horizontal flow.
```html
<!-- @MARK writing-mode:horizontal-tb -->
<div class="writing-mode:vertical-rl">
  <span class="writing-mode:horizontal-tb">ABC</span>
</div>
```

### Pair with text orientation
Use [`text-orientation:upright`](/reference/text-orientation) when characters should remain upright inside vertical writing.
```html
<p class="text-orientation:upright writing-mode:vertical-rl">2026</p>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<p class="writing-mode:vertical-rl:hover writing-mode:horizontal-tb@print writing-mode:horizontal-tb@sm">...</p>
```
