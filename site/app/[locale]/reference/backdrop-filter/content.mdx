## Examples
### Blur content behind an element
Use `bd:blur(...)` to apply a backdrop filter to pixels behind the element.
```html
<!-- @MARK bg:surface/.72 --><!-- @MARK bd:blur(12) -->
<header class="bg:surface/.72 bd:blur(12)">
    ...
</header>
```

<details>
    <summary>Generated CSS</summary>
    <Class2CSS>
        {['bd:blur(12)']}
    </Class2CSS>
</details>

### Combine with translucent backgrounds
Backdrop filters are only visible when the element lets the backdrop show through, usually with an alpha background.
```html
<!-- @MARK bg:white/.64 --><!-- @MARK bd:saturate(1.5) -->
<div class="bg:white/.64 bd:saturate(1.5)">...</div>
```

### Reset backdrop filters
Use `bd:none` to disable a backdrop filter.
```html
<!-- @MARK bd:none -->
<div class="bd:none@print">...</div>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="bd:none bd:blur(12)@sm bd:none@print">...</div>
```

Backdrop filters can be costly and browser-dependent; verify important surfaces in target browsers.
