## Examples \{#examples\}
### Blur content behind an element \{#blur-content-behind-an-element\}
The foreground panel filters pixels behind it. Compare the same translucent panel before and after blur; its own text stays sharp.

<DemoExample page="backdrop-filter" section="blur-content-behind-an-element" />

```html
<!-- No filter · sharp backdrop -->
<div class="position:relative height:168px width:240px max-width:100%">
  <img src="/demo/landscape.svg"
  width="320" height="200"
  alt=""
  class="display:block height:168px width:240px max-width:100%
         object-fit:cover" />
  <div id="target"
    class="position:absolute inset-md display:flex align-items:center
           justify-content:center p-sm border:1px|solid|var(--color-line-divider) r-sm
           font-md bg-surface-base/.64 fg-text-strong
           backdrop-filter:none">
    Preview layer
  </div>
</div>
```

```html
<!-- Blur · softened backdrop -->
<div class="position:relative height:168px width:240px max-width:100%">
  <img src="/demo/landscape.svg"
  width="320" height="200"
  alt=""
  class="display:block height:168px width:240px max-width:100%
         object-fit:cover" />
  <div id="target"
    class="position:absolute inset-md display:flex align-items:center
           justify-content:center p-sm border:1px|solid|var(--color-line-divider) r-sm
           font-md bg-surface-base/.64 fg-text-strong
           backdrop-filter:blur(8px)">
    Preview layer
  </div>
</div>
```

The complete example supplies the image, positioned panel and translucent background. The panel’s border box bounds the visible filtered area. The effect stays inside this iframe.

### Combine with translucent backgrounds \{#combine-with-translucent-backgrounds\}
A translucent background lets the filtered result show through. An opaque background covers it even though the computed filter remains active.

<DemoExample page="backdrop-filter" section="combine-with-translucent-backgrounds" />

```html
<!-- Translucent · filtered pixels visible -->
<div class="position:relative height:168px width:240px max-width:100%">
  <img src="/demo/landscape.svg"
  width="320" height="200"
  alt=""
  class="display:block height:168px width:240px max-width:100%
         object-fit:cover" />
  <div id="target"
    class="position:absolute inset-md display:flex align-items:center
           justify-content:center p-sm border:1px|solid|var(--color-line-divider) r-sm
           font-md bg-surface-base/.48 fg-text-strong
           backdrop-filter:saturate(0)">
    Preview layer
  </div>
</div>
```

```html
<!-- Opaque · filtered pixels covered -->
<div class="position:relative height:168px width:240px max-width:100%">
  <img src="/demo/landscape.svg"
  width="320" height="200"
  alt=""
  class="display:block height:168px width:240px max-width:100%
         object-fit:cover" />
  <div id="target"
    class="position:absolute inset-md display:flex align-items:center
           justify-content:center p-sm border:1px|solid|var(--color-line-divider) r-sm
           font-md bg-surface-base fg-text-strong
           backdrop-filter:saturate(0)">
    Preview layer
  </div>
</div>
```

These panels both remove backdrop saturation. Only their background alpha differs. Keep enough surface contrast for text in each theme; applying opacity to the whole panel would also fade its text.

### Reset backdrop filters \{#reset-backdrop-filters\}
Use `backdrop-filter:none` to restore the unfiltered backdrop. Open print preview to disable blur on this panel.

<DemoExample page="backdrop-filter" section="reset-backdrop-filters" />

```html
<!-- Blur on screen · none in print -->
<div class="position:relative height:168px width:240px max-width:100%">
  <img src="/demo/landscape.svg"
  width="320" height="200"
  alt=""
  class="display:block height:168px width:240px max-width:100%
         object-fit:cover" />
  <div id="target"
    class="position:absolute inset-md display:flex align-items:center
           justify-content:center p-sm border:1px|solid|var(--color-line-divider) r-sm
           font-md bg-surface-base/.64 fg-text-strong
           backdrop-filter:blur(8px)
           backdrop-filter:none@media(print)">
    Preview layer
  </div>
</div>
```

The translucent background remains declared. Removing a backdrop filter does not remove the panel or its background color.

### Apply conditionally \{#apply-conditionally\}
Widen the preview to `sm` to blur the backdrop. Print keeps the original sharp image behind the same panel.

<DemoExample page="backdrop-filter" section="apply-conditionally" />

```html
<!-- No filter → blur at sm -->
<div class="position:relative height:168px width:240px max-width:100%">
  <img src="/demo/landscape.svg"
  width="320" height="200"
  alt=""
  class="display:block height:168px width:240px max-width:100%
         object-fit:cover" />
  <div id="target"
    class="position:absolute inset-md display:flex align-items:center
           justify-content:center p-sm border:1px|solid|var(--color-line-divider) r-sm
           font-md bg-surface-base/.64 fg-text-strong
           backdrop-filter:none
           backdrop-filter:none@media(print)
           backdrop-filter:blur(8px)@media(screen)@sm">
    Preview layer
  </div>
</div>
```

The utility emits standard and WebKit-prefixed declarations. Backdrop sampling can vary with browser support and surrounding compositing contexts; verify the actual surface in target browsers. Keep the content readable when the effect is unavailable.
