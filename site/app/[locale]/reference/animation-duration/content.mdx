## Examples \{#examples\}
### Set animation speed \{#set-animation-speed\}
Compare the same 72px path over 500ms and one second. Duration controls one cycle, independently of delay and repetition.

<DemoExample page="animation-duration" section="set-animation-speed" />

```css name=index.css
@theme {
  @keyframes layer-slide {
    from { transform: translateX(24px); }
    to { transform: translateX(96px); }
  }
}
```

```html
<!-- 500ms cycle -->
<div class="w:240px max-w:100%">
  <p class="mb:sm font:mono font:xs text:muted">Base 0 · start 24 · end 96px</p>

    <span id="target"
      class="grid place-items:center h:40px w:48px

             animation-name:layer-slide
             animation-timing-function:linear
             animation:none@print
             animation-play-state:paused@reduce-motion">→</span>
  </div>
</div>
```


Use a duration token or a nonnegative CSS time. At 250ms the first marker is halfway through its cycle; the second is one quarter through.

Zero duration is not the same as animation:none: fill can still apply a keyframe and start/end events can still occur. These snippets remove the animation in print, which restores the ordinary 0px position.

### Apply conditionally \{#apply-conditionally\}
Resize before replaying to switch from a 500ms cycle to one second at `sm`. The path and linear easing stay fixed.

<DemoExample page="animation-duration" section="apply-conditionally" />

```css name=index.css
@theme {
  @keyframes layer-slide {
    from { transform: translateX(24px); }
    to { transform: translateX(96px); }
  }
}
```

```html
<!-- 500ms → one second at sm -->
<div class="w:240px max-w:100%">
  <p class="mb:sm font:mono font:xs text:muted">Base 0 · start 24 · end 96px</p>
  <div aria-hidden="true"
    class="h:56px p:xs outline:1px|dashed|muted">
    <span id="target"
      class="grid place-items:center h:40px w:48px
             b:1px|solid|blue-60 r:sm bg:blue-10
             fg:blue-80 transform:none
             animation-duration:slower
             animation-fill-mode:forwards
             animation-name:layer-slide
             animation-timing-function:linear
             animation:none@print
             animation-play-state:paused@reduce-motion
             animation-duration:1s@sm">→</span>
  </div>
</div>
```

Changing duration can update the phase of an existing animation. Replay makes the selected cycle length easy to compare from its start.
