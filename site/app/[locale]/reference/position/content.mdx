## Examples
### Positioning elements as static
Use `static` to position an element according to the normal document flow. HTML elements are static by default.
<Demo className="pb:15x">
    <code className="static p:5x box-perspective-pink">
        <div>static parent</div>
        <code className="abs left:10px bottom:10px box w:fit">abs child</code>
    </code>
</Demo>
```html
<!-- @MARK static -->
<div class="static p:5x">
    <div>static parent</div>
    <div class="abs left:10px bottom:10px">abs child</div>
</div>
```

### Positioning elements as relative
Use `rel` to keep an element in the normal document flow while offsetting it relative to itself with top, right, bottom, and left values.
<Demo className="pb:15x">
    <div className="bg:stripe">
        <code className="rel p:5x top:30px left:20px box-perspective-pink inline-block">
            <div>relative parent</div>
        </code>
    </div>
</Demo>
```html
<!-- @MARK rel -->
<div class="rel p:5x top:30px left:20px">
    <div>relative parent</div>
</div>
```

### Positioning elements as absolute
Use `abs` to remove an element from the normal document flow and position it relative to its closest positioned ancestor.
<Demo>
    <code className="rel p:12x! box bg:stripe">
        <div>relative parent</div>
        <code className="box-perspective-pink abs left:0 top:0 w:fit">abs child</code>
    </code>
</Demo>
```html
<!-- @MARK rel -->
<div class="rel p:12x">
    <div>relative parent</div>
    <!-- @MARK abs -->
    <div class="abs left:0 top:0">abs child</div>
</div>
```

### Positioning elements as fixed
Use `fixed` to remove an element from the normal document flow and position it relative to the viewport.
<Demo>
    <div className="box align-items:initial! justify-content:initial! p:2x|5x_li p:0.625rem|0! r:10px w:full max-w:340px@sm max-h:250px overflow:auto">
        <input className="fixed z:1 bg:gray-23 bg:gray-18:focus fg:gray-40::placeholder outline:0 font:14px w:300px mi:0.625rem p:3x leading:1 r:5px" placeholder="Search for chats and messages" type="search" />
        <ul className="list-style:none mt:0.625rem pl:0 w:full">
            {users.map((user, index) =>
                <li className="bg:gray-28:hover bg:gray-32:active flex gap:3x cursor:pointer" key={index}>
                    <div className="rel">
                        <Image src={user.url} width="40" height="40" className="round object-cover" alt="avatar" />
                        {index < 2 && <svg className="abs right:1px bottom:1px bg:green-70 outline:2px|solid|white outline:gray-20@dark round w:7px h:7px" />}
                    </div>
                    <div>
                        <div className="flex align-items:center">
                            <div className="text:14px font:medium fg:gray-88@dark capitalize">{user.name}</div>
                            <div className="font:12px fg:slate-54 fg:gray-44@dark ml:2x">{user.time}</div>
                        </div>
                        <p className="text:13px m:0 text-left">{user.message}</p>
                    </div>
                </li>
            )}
        </ul>
    </div>
</Demo>
```html
<div>
    <!-- @MARK fixed -->
    <input type="search" class="fixed">
    <ul>
        <li>
            <div class="rel">
                <img src="...">
            </div>
            <div>
                <div class="flex">
                    <div>Aron</div>
                    <div>3:03 a.m</div>
                </div>
                <p>Front-end needs a revolution</p>
            </div>
        </li>
        ...
    </ul>
</div>
```

### Positioning elements as sticky
Use `sticky` to position an element based on scroll position. It behaves like a relatively positioned element until a given offset is reached, then sticks to that offset.
<Demo>
    <div className="box block! p:2x|5x_li p:0.625rem|0! r:10px w:full max-w:340px@sm max-h:250px overflow:auto">
        <ul className="list-style:none mt:0.625rem pl:0 w:full">
            {users.map((user, index) =>
                <li className={clsx(index === 1 ? 'sticky top:0 z:1' : '', 'bg:gray-30 bg:gray-28:hover bg:gray-32:active flex gap:3x cursor:pointer')} key={index}>
                    <div className="rel">
                        <Image src={user.url} width="40" height="40" className="round object-cover" alt="avatar" />
                        {index < 2 && <svg className="abs right:1px bottom:1px bg:green-70 outline:2px|solid|white outline:gray-20@dark round w:7px h:7px" />}
                    </div>
                    <div>
                        <div className="flex align-items:center">
                            <div className="text:14px font:medium fg:gray-88@dark capitalize">{user.name}</div>
                            <div className="font:12px fg:slate-54 fg:gray-44@dark ml:2x">{user.time}</div>
                        </div>
                        <p className="text:13px m:0 text-left">{user.message}</p>
                    </div>
                </li>
            )}
        </ul>
    </div>
</Demo>
```html
<ul class="overflow:auto">
    ...
    <!-- @MARK sticky -->
    <li class="sticky top:0">
        <img src="...">
        <div>Joy</div>
        ...
    </li>
    ...
</ul>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="rel:hover rel@sm rel@dark rel@print">...</div>
```
