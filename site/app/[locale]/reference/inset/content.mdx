## Examples \{#examples\}
### Pin all sides \{#pin-all-sides\}
`inset:*` sets `top`, `right`, `bottom`, and `left` together. An absolutely positioned box with automatic width and height stretches between those edges.

<DemoExample page="inset" section="pin-all-sides" />

```html
<div class="rel h:10rem">
  <!-- @MARK inset-md -->
  <div class="abs inset-md">Inset on all four sides</div>
</div>
```

### Pin one side \{#pin-one-side\}
Use individual side utilities to place an object against selected edges. This button keeps its content size and sits one `md` inset from the top and right of its positioned parent.

<DemoExample page="inset" section="pin-one-side" />

```html
<div class="rel h:10rem">
  <!-- @MARK top-md --><!-- @MARK right-md -->
  <button type="button" class="abs right-md top-md">Close</button>
</div>
```

### Cover a positioned parent \{#center-overlays-with-inset\}
Use `abs inset:0` to cover the parent’s positioning area. Leave the overlay’s width and height automatic so the opposing insets can determine its size.

<DemoExample page="inset" section="center-overlays-with-inset" />

```html
<div class="rel h:10rem">
  <!-- @MARK inset:0 -->
  <div class="abs inset:0">Overlay</div>
</div>
```

### Apply conditionally \{#apply-conditionally\}
Use [selectors](/reference/rules/selectors) and [conditional queries](/reference/rules/conditions) to change the behavior when a state or viewport condition applies. Focus the blue box with Tab to increase all four insets. The responsive class supplies a larger resting inset from `sm` upward.

<DemoExample page="inset" section="apply-conditionally" />

```html
<div class="rel h:10rem">
  <div tabindex="0" class="abs inset-sm inset-xl:focus-visible inset-lg@sm">
    Focus with Tab
  </div>
</div>
```
