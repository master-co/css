## Examples \{#examples\}
### Pin all sides \{#pin-all-sides\}
Use `inset:*` on positioned elements to set `top`, `right`, `bottom`, and `left` together.
<Demo>
  <div className="bg:stripe-pink">
    <div className="box rel inset:20px w:180px aspect-ratio:1/1">`inset:20px`</div>
  </div>
</Demo>
```html
<!-- @MARK inset:20px -->
<div>
  <div class="rel inset:20px">inset:5x</div>
</div>
```

### Pin one side \{#pin-one-side\}
Use side utilities such as `top:*`, `right:*`, `bottom:*`, and `left:*` when only one edge should move.
```html
<!-- @MARK top:0 --><!-- @MARK right:0 -->
<button class="abs right:0 top:0">
  Close
</button>
```

### Center overlays with inset \{#center-overlays-with-inset\}
`inset:0` is useful for overlays that should cover their positioned parent.
```html
<div class="rel">
  <div class="abs inset:0"></div>
</div>
```

### Apply conditionally \{#apply-conditionally\}
Apply styles based on different states using [selectors](/reference/rules/selectors) and [conditional queries](/reference/rules/conditions).
```html
<div class="inset:0.625rem:hover inset:0@print inset:20px@sm">...</div>
```
