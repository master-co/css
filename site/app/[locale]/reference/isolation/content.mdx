## Examples
### Create a stacking context
Use `isolate` when a component's blending, z-index, or effects should be contained inside its own stacking context.
```html
<!-- @MARK isolate -->
<section class="isolate">
  <div class="mix-blend-mode:multiply">Blend locally</div>
</section>
```

### Return to automatic isolation
Use `isolation:auto` when a variant should let the browser use normal stacking behavior.
```html
<!-- @MARK isolation:auto -->
<section class="isolate isolation:auto@sm">
  Normal stacking on larger screens
</section>
```

### Protect layered components
Isolation is useful for cards, modals, and previews that use blend modes or negative z-index children.
```html
<article class="rel isolate">
  <div class="abs inset:0 z:-1"></div>
</article>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="isolate:hover isolation:auto@print isolation:auto@sm">...</div>
```
