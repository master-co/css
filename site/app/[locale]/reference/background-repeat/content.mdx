## Examples \{#examples\}

### Disable tiling \{#disable-tiling\}
Compare the same small background tile with repetition enabled and disabled. Neither image size nor position changes.

<DemoExample page="background-repeat" section="disable-tiling" />

```html
<!-- Repeat · both axes -->
<div id="target" role="img" aria-label="Geometric landscape"
  class="h:160px w:xs max-w:100% bg-repeat background-position:0|0
         background-size:80px|50px bg:surface-muted
         bg:url(/demo/landscape.svg)"
></div>
```

```html
<!-- No repeat · one tile -->
<div id="target" role="img" aria-label="Geometric landscape"
  class="h:160px w:xs max-w:100% bg-no-repeat background-position:0|0
         background-size:80px|50px bg:surface-muted
         bg:url(/demo/landscape.svg)"
></div>
```

### Repeat on one axis \{#repeat-on-one-axis\}
`bg-repeat-x` tiles horizontally; `bg-repeat-y` tiles vertically. The perpendicular axis keeps a single row or column.

<DemoExample page="background-repeat" section="repeat-on-one-axis" />

```html
<!-- Repeat horizontally -->
<div id="target" role="img" aria-label="Geometric landscape"
  class="h:160px w:xs max-w:100% bg-repeat-x background-position:0|0
         background-size:80px|50px bg:surface-muted
         bg:url(/demo/landscape.svg)"
></div>
```

```html
<!-- Repeat vertically -->
<div id="target" role="img" aria-label="Geometric landscape"
  class="h:160px w:xs max-w:100% bg-repeat-y background-position:0|0
         background-size:80px|50px bg:surface-muted
         bg:url(/demo/landscape.svg)"
></div>
```

Use the native `background-repeat:*` form for other values, such as `space` or `round`. Repetition is independent of [background size](/reference/background-size).

### Apply conditionally \{#apply-conditionally\}
Widen to `sm` to repeat the tile on both axes. Narrow screens and print show it once, with the same explicit size and position.

<DemoExample page="background-repeat" section="apply-conditionally" />

```html
<!-- One tile → repeat at sm -->
<div id="target" role="img" aria-label="Geometric landscape"
  class="h:160px w:xs max-w:100% bg-no-repeat background-position:0|0
         background-size:80px|50px bg:surface-muted
         bg:url(/demo/landscape.svg) bg-no-repeat@print bg-repeat@screen&sm"
></div>
```

Set `bg-no-repeat` explicitly for photographic compositions when tiling is not intended.
