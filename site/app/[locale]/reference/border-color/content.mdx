## Examples \{#examples\}

### Set border color \{#set-border-color\}
A color needs a visible border width and style. Compare identical 2px solid borders; only their color changes.

<DemoExample page="border-color" section="set-border-color" />

```html
<!-- Primary · blue -->
<div id="target"
  class="display:flex align-items:center justify-content:center height:96px
         width:240px max-width:100% p-md border:2px|solid
         border-color-blue font-md bg-surface-inset
         fg-text-body box-sizing:border-box">
  Preview panel
</div>
```

```html
<!-- Comparison · violet -->
<div id="target"
  class="display:flex align-items:center justify-content:center height:96px

         border-color-violet font-md bg-surface-inset

  Preview panel
</div>
```

### Use side-specific color utilities \{#use-side-specific-color-utilities\}
`border-top-color:transparent` changes only the top edge’s paint. Its 6px border still occupies space, keeping content and outer dimensions aligned with the fully painted box.

<DemoExample page="border-color" section="use-side-specific-color-utilities" />

```html
<!-- Four painted edges -->
<div id="target"
  class="display:flex align-items:center justify-content:center height:96px
         width:240px max-width:100% p-md border:6px|solid|var(--color-blue)
         font-md bg-surface-inset fg-text-body
         box-sizing:border-box">
  Preview panel
</div>
```

```html
<!-- Transparent top · width preserved -->
<div id="target"
  class="display:flex align-items:center justify-content:center height:96px
         width:240px max-width:100% p-md border:6px|solid|var(--color-blue)
         border-top-color:transparent font-md bg-surface-inset
         fg-text-body box-sizing:border-box">
  Preview panel
</div>
```

Transparent color differs from `border-top-width:0` or `bt-none`, which remove the used border width.

### Follow the current text color \{#follow-the-current-text-color\}
`border-color:currentColor` follows the same element’s foreground. Hover or keyboard-focus this button: one foreground change updates both its text and border.

<DemoExample page="border-color" section="follow-the-current-text-color" />

```html
<!-- Current color · foreground and edge -->
<button id="target" type="button"
  class="display:inline-flex align-items:center justify-content:center
         min-height:44px max-width:100% px-md py-sm
         border:2px|solid border-color:currentColor r-sm
         font-md bg-surface-base fg-text-blue box-sizing:border-box
         bg-surface-inset:focus-visible
         fg-text-violet:hover@screen
         fg-text-violet:focus-visible@screen">
  Current color
</button>
```

`currentColor` refers to the computed `color` of this element. It does not inherit a parent’s border color.

### Apply conditionally \{#apply-conditionally\}
At `sm`, the blue border follows the violet foreground through `currentColor`. Print makes the border transparent while preserving its width.

<DemoExample page="border-color" section="apply-conditionally" />

```html
<!-- Blue → current color at sm -->
<button id="target" type="button"
  class="display:inline-flex align-items:center justify-content:center
         min-height:44px max-width:100% px-md py-sm
         border:2px|solid border-color-blue r-sm font-md
         bg-surface-base fg-text-violet box-sizing:border-box
         bg-surface-inset:focus-visible
         border-color:transparent@print
         border-color:currentColor@screen@sm">
  Preview details
</button>
```

Resize the actual preview viewport. Width and style stay constant across these conditions.

## Customization \{#customization\}
### Customize line colors \{#customize-line-colors\}
Define a semantic line token in each theme, then compile the token declarations with their consuming classes. Switch the preview theme to inspect the resulting separator color.

<DemoExample page="border-color" section="customize-line-colors" />

```css name=index.css
@theme { @media (prefers-color-scheme: light) { :root, :host {
  --color-line-divider:
    color-mix(in oklab, var(--color-slate-60) 40%, transparent);
} } }

@theme { @media (prefers-color-scheme: dark) { :root, :host {
  --color-line-divider:
    color-mix(in oklab, var(--color-gray-30) 50%, transparent);
} } }

```

```html
<!-- Configured divider · mode-aware paint -->
<div id="target"
  class="display:flex align-items:center justify-content:center height:96px
         width:240px max-width:100% p-md border:2px|solid font-md
         bg-surface-inset fg-text-body box-sizing:border-box
         border-color-line-divider">
  Project divider
</div>
```

The example retains the authored `@theme` declarations. The border keeps its own width and style; only the resolved color changes.
