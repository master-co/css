## Examples
### Set border color
Use `border-color:*` when only the border color should change.
```html
<!-- @MARK border-color:primary -->
<div class="b:1px|solid border-color:primary">
    Primary border
</div>
```

<details>
    <summary>Generated CSS</summary>
    <Class2CSS>
        {['border-color:primary']}

</details>

### Use side-specific color utilities
Use side aliases when only one edge should change.
```html
<!-- @MARK bt:transparent -->
<div class="b:1px|solid|line bt:transparent">
    No top border color
</div>
```

### Follow the current text color
Use `border-color:currentColor` when the border should track the foreground color.
```html
<!-- @MARK border-color:currentColor -->
<button class="fg:primary b:1px|solid border-color:currentColor">
    Current color
</button>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="border-color:primary:hover border-color:currentColor@sm border-color:transparent@print">...</div>
```

## Customization
### Use custom border colors
Add a color to the theme color namespace.
```css name=index.css
@theme light {
    --color-line-accent: $color-slate-60/.2; /* [!code highlight] */
}

@theme dark {
    --color-line-accent: $color-gray-30/.2; /* [!code highlight] */
}
```
Apply the defined token to a border color.
```html
<div class="b:1px|solid border-color:line-accent"></div>
```
