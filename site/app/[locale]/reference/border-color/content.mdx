## Examples
### Set border color
Use `border-color:*` when only the border color should change.
```html
<!-- @MARK border-color:blue-60 -->
<div class="b:1px|solid border-color:blue-60">
    Primary border
</div>
```

<details>
    <summary>Generated CSS</summary>
    <Class2CSS>
        {['border-color:blue-60']}
    </Class2CSS>
</details>

### Use side-specific color utilities
Use side aliases when only one edge should change.
```html
<!-- @MARK bt:transparent -->
<div class="b:1px|solid|gray-20 bt:transparent">
    No top border color
</div>
```

### Follow the current text color
Use `border-color:currentColor` when the border should track the foreground color.
```html
<!-- @MARK border-color:currentColor -->
<button class="fg:blue-60 b:1px|solid border-color:currentColor">
    Current color
</button>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="border-color:blue-60:hover border-color:currentColor@sm border-color:transparent@print">...</div>
```

## Customization
### Customize line colors
Define a project line color token when separators need a semantic, mode-aware value.
```css name=index.css
@theme light {
    --color-line-divider: $color-slate-60/.2; /* [!code highlight] */
}

@theme dark {
    --color-line-divider: $color-gray-30/.2; /* [!code highlight] */
}
```
Apply the token to a border color.
```html
<div class="b:1px|solid border-color:divider"></div>
```
