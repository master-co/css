## Examples
### Order positioned elements
Use `z:*` to control the stacking order of overlapping positioned elements. Values can be positive, negative, or zero.
<Demo className="py:0">
    <div className="flex p:xl ml:-2x>div">
        <div className="box z:9 b:2px fg:white bg:blue-58!">1</div>
        <div className="box z:3 b:2px fg:white bg:blue-58!">2</div>
        <div className="box z:1 b:2px fg:white bg:blue-58!">3</div>
        <div className="box z:-1 b:2px fg:white bg:blue-58!">4</div>
        <div className="box z:-9 b:2px fg:white bg:blue-58!">5</div>
    </div>
</Demo>
```html
<div class="z:9">1</div>
<div class="z:3">2</div>
<!-- @MARK z:1 -->
<div class="z:1">3</div>
<div class="z:-1">4</div>
<div class="z:-9">5</div>
```

### Use negative stacking when intentional
Negative z-index is useful for decorative layers inside an isolated component.
```html
<!-- @MARK z:-1 -->
<div class="rel isolate">
    <div class="abs inset:0 z:-1"></div>
</div>
```

### Prefer local stacking contexts
Use `isolate` or another stacking-context boundary when z-index values should not compete with the whole page.
```html
<article class="rel isolate">
    <div class="z:10">Menu</div>
</article>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="z:1:hover z:0@print z:10@sm">...</div>
```
