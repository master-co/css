## Examples \{#examples\}
### Order positioned elements \{#order-positioned-elements\}
`z-index:*` controls paint order within a stacking context. These positioned boxes overlap; larger values paint above smaller ones. Flex and grid items can also use z-index without a non-static position.

<DemoExample page="z-index" section="order-positioned-elements" />

```html
<div class="position:relative isolation:isolate height:11rem">
  <div class="position:absolute left:0 top:0 z-index:30 height:6rem width:10rem">Layer 30</div>
  <div class="position:absolute left-lg top-lg z-index:20 height:6rem width:10rem">Layer 20</div>
  <!-- @MARK z-index:10 -->
  <div class="position:absolute left-2xl top-2xl z-index:10 height:6rem width:10rem">Layer 10</div>
</div>
```

### Use negative stacking when intentional \{#use-negative-stacking-when-intentional\}
A negative z-index can place decoration behind content. `isolate` establishes a local stacking context, keeping this decoration above the parent’s background and behind its ordinary content.

<DemoExample page="z-index" section="use-negative-stacking-when-intentional" />

```html
<article class="position:relative isolation:isolate height:10rem p-md">
  <!-- @MARK z-index:-1 -->
  <div class="position:absolute inset:0 z-index:-1" aria-hidden="true"></div>
  <p>Foreground content</p>
</article>
```

### Prefer local stacking contexts \{#prefer-local-stacking-contexts\}
A child’s z-index competes inside its own stacking context. The blue `z-index:99` child cannot rise above the violet `z-index:1` sibling because its entire parent context is at `z-index:0`.

<DemoExample page="z-index" section="prefer-local-stacking-contexts" />

```html
<div class="position:relative height:11rem">
  <article class="position:relative z-index:0 isolation:isolate height:10rem width:12rem">
    <div class="position:absolute left-md top-md z-index:99 height:6rem width:10rem">Child 99</div>
  </article>
  <div class="position:absolute left-2xl top-2xl z-index:1 height:6rem width:10rem">Sibling 1</div>
</div>
```

### Apply conditionally \{#apply-conditionally\}
Use [selectors](/reference/rules/selectors) and [conditional queries](/reference/rules/conditions) to change the behavior when a state or viewport condition applies. Focus the blue box with Tab to bring it above the violet box. The same paint order applies from `sm` upward.

<DemoExample page="z-index" section="apply-conditionally" />

```html
<div class="position:relative isolation:isolate height:11rem">
  <div tabindex="0" class="position:absolute left:0 top:0 z-index:0 height:6rem width:10rem z-index:20:focus-visible z-index:20@sm">
    Focus with Tab
  </div>
  <div class="position:absolute left-2xl top-2xl z-index:10 height:6rem width:10rem">Layer 10</div>
</div>
```
