## Examples
### Offset anchor targets
Use `scroll-mt:*` on the target element so anchor navigation leaves room for fixed headers.
```html
<!-- @MARK scroll-mt:16x -->
<section id="pricing" class="scroll-mt:3xl">
    Pricing
</section>
```

<details>
    <summary>Generated CSS</summary>

### Add horizontal snap margin
Use `scroll-mx:*` on snap items when the item should stop with space on both sides.
```html
<!-- @MARK scroll-mx:4x -->
<article class="scroll-mx:md snap-start">
    Slide
</article>
```

### Use all-side margin for compact cases
Use `scroll-m:*` when the same offset should apply on every side of the target.
```html
<!-- @MARK scroll-m:0.625rem -->
<h2 class="scroll-m:0.625rem">Overview</h2>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<section class="scroll-mt:3xl scroll-m:0@print scroll-mt:xl@sm">...</section>
```
