## Examples
### Align multiple rows or tracks
Use `content-*` utilities to distribute rows in a multi-line flex container or tracks in a grid container along the cross axis.
```html
<!-- @MARK flex --><!-- @MARK flex-wrap --><!-- @MARK content-between -->
<div class="flex flex-wrap content-between h:3xs">
  ...
</div>
```

<details>
  <summary>Generated CSS</summary>
  <Class2CSS>
    {['flex', 'flex-wrap', 'content-between', 'h:64x']}
  </Class2CSS>
</details>

### Center wrapped lines
Use `content-center` when the group of rows should sit in the middle of the container.
```html
<!-- @MARK content-center -->
<section class="grid content-center h:3xs">
  ...
</section>
```

`align-content` needs extra space in the cross axis. If there is only one line or no free space, it may not visibly change the layout.

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="content-start content-start@print content-between@sm">...</div>
```

Use [align-items](/reference/align-items) for item alignment within each row.
