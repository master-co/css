## Basic usage \{#basic-usage\}
### Capitalized text \{#capitalized-text\}
`capitalize` changes the initial letter of each word. It leaves other letters intact, so `CSS` remains uppercase. It does not implement editorial title-case rules.

<DemoExample page="text-transform" section="capitalized-text" />

```html
<!-- text-transform:none -->
<p id="target" lang="en" class="w:240px max-w:100% m:0 font-md leading:24px text-transform:none">clear CSS for every screen</p>
```

```html
<!-- capitalize -->
<p id="target" lang="en" class="w:240px max-w:100% m:0 font-md leading:24px capitalize">clear CSS for every screen</p>
```

### Lowercase text \{#lowercase-text\}
`lowercase` changes the displayed casing. The source text remains uppercase, and language-specific mappings use the element’s `lang`.

<DemoExample page="text-transform" section="lowercase-text" />

```html
<!-- text-transform:none -->
<p id="target" lang="en" class="w:240px max-w:100% m:0 font-md leading:24px text-transform:none">CLEAR CSS FOR EVERY SCREEN</p>
```

```html
<!-- lowercase -->
<p id="target" lang="en" class="w:240px max-w:100% m:0 font-md leading:24px lowercase">CLEAR CSS FOR EVERY SCREEN</p>
```

### Uppercase text \{#uppercase-text\}
`uppercase` changes the displayed letters without rewriting the document’s text. Supply the correct language for language-specific casing.

<DemoExample page="text-transform" section="uppercase-text" />

```html
<!-- English uppercase -->
<p id="target" lang="en" class="w:240px max-w:100% m:0 font-md leading:24px uppercase">clear type</p>
```

```html
<!-- Turkish dotted i -->
<p id="target" lang="tr" class="w:240px max-w:100% m:0 font-md leading:24px uppercase">istanbul</p>
```

### Transform the first letter \{#sentence\}
Apply `uppercase::first-letter` to the first formatted letter of a block. It does not capitalize the first letter of every sentence: the second sentence below still starts with a lowercase letter.

<DemoExample page="text-transform" section="sentence" />

```html
<!-- One block · two sentences -->
<p id="target" class="w:240px max-w:100% m:0 font-md leading:24px uppercase::first-letter">clear type helps readers. good spacing keeps the rhythm.</p>
```

Write meaningful casing into the actual content when it is part of the text’s meaning.

### Apply conditionally \{#apply-conditionally\}
Hover or focus the button to uppercase its label. Keyboard users receive the same state and a visible focus outline.

<DemoExample page="text-transform" section="apply-conditionally" />

```html
<!-- Pointer and keyboard states -->
<button id="target" type="button" tabindex="0" class="font-md text-transform:none uppercase:hover uppercase:focus-visible">Explore the canvas</button>
```
