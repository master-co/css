## Examples
### Center cropped media
Use `obj:center` to keep the center of an image visible when `obj:cover` crops the edges.
```html
<!-- @MARK obj:center -->
<img class="aspect:16/9 obj:cover obj:center" src="/images/photo.jpg" alt="Photo">
```

<details>
    <summary>Generated CSS</summary>

</details>

### Pin the top of an image
Use `obj:top` for portraits or screenshots where the important content is near the top.
```html
<!-- @MARK obj:top -->
<img class="aspect:4/3 obj:cover obj:top" src="/images/portrait.jpg" alt="Portrait">
```

### Use precise positions
Use `object-position:*|*` when the focal point needs a custom x and y position.
```html
<!-- @MARK object-position:50%|25% -->
<img class="obj:cover object-position:50%|25%" src="/images/scene.jpg" alt="Scene">
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<img class="obj:center:hover obj:top@sm object-position:50%|50%@print" src="/images/photo.jpg" alt="">
```
