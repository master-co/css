## Examples \{#examples\}
### Distribute items or grid tracks \{#align-items-on-the-main-axis\}
Use `justify-between` to place the first and last flex items at the main-axis edges. In Grid, the same utility distributes the column tracks along the inline axis. These containers are both 280px wide; their fixed 80px items or tracks leave visible space between them.

<DemoExample page="justify-content" section="align-items-on-the-main-axis" />

```html
<div id="layout" class="display:flex justify-content:space-between width:17.5rem max-width:100%">
  <div id="target" class="flex:none height:3rem width:5rem p-sm">01</div>
  <div id="peer" class="flex:none height:3rem width:5rem p-sm">02</div>
</div>
```

```html
<div id="layout" class="display:grid grid-template-columns:5rem|5rem grid-template-rows:48px justify-content:space-between width:17.5rem max-width:100%">
  <div id="target" class="p-sm">01</div>
  <div id="peer" class="p-sm">02</div>
</div>
```

<details>
  <summary>Generated CSS</summary>
  <Class2CSS>
    {['display:flex', 'justify-content:space-between']}
  </Class2CSS>
</details>

In horizontal writing, a row flexbox and Grid both distribute these boxes horizontally. A column flexbox distributes them vertically instead.

### Start, center, or end a group \{#start-center-or-end-a-group\}
`justify-start`, `justify-center` and `justify-end` place the whole group while keeping its 16px gap. The first three examples differ only in their alignment. The final example uses `flex-col`, so the same centering acts vertically.

<DemoExample page="justify-content" section="start-center-or-end-a-group" />

```html
<div id="layout" class="display:flex justify-content:start gap-md width:17.5rem max-width:100%">
  <div id="target" class="flex:none height:3rem width:4rem p-sm">01</div>
  <div id="peer" class="flex:none height:3rem width:4rem p-sm">02</div>
</div>
```

```html
<div id="layout" class="display:flex justify-content:center gap-md width:17.5rem max-width:100%">
  <div id="target" class="flex:none height:3rem width:4rem p-sm">01</div>
  <div id="peer" class="flex:none height:3rem width:4rem p-sm">02</div>
</div>
```

```html
<div id="layout" class="display:flex justify-content:end gap-md width:17.5rem max-width:100%">
  <div id="target" class="flex:none height:3rem width:4rem p-sm">01</div>
  <div id="peer" class="flex:none height:3rem width:4rem p-sm">02</div>
</div>
```

```html
<div id="layout" class="display:flex flex-direction:column justify-content:center gap-md height:14rem width:17.5rem max-width:100%">
  <div id="target" class="flex:none height:3rem width:4rem p-sm">01</div>
  <div id="peer" class="flex:none height:3rem width:4rem p-sm">02</div>
</div>
```

### Distribute extra space \{#distribute-extra-space\}
Compare `justify-between`, `justify-around` and `justify-evenly` with three fixed 48px items. Between leaves no outer space; around assigns half as much extra space at each outer edge as between items; evenly assigns the same extra space at all four positions.

<DemoExample page="justify-content" section="distribute-extra-space" />

```html
<div id="layout" class="display:flex justify-content:space-between gap-md width:17.5rem max-width:100%">
  <div id="target" class="flex:none width:3rem height:3rem p-sm">01</div>
  <div id="peer" class="flex:none width:3rem height:3rem p-sm">02</div>
  <div id="item-3" class="flex:none width:3rem height:3rem p-sm">03</div>
</div>
```

```html
<div id="layout" class="display:flex justify-content:space-around gap-md width:17.5rem max-width:100%">
  <div id="target" class="flex:none width:3rem height:3rem p-sm">01</div>
  <div id="peer" class="flex:none width:3rem height:3rem p-sm">02</div>
  <div id="item-3" class="flex:none width:3rem height:3rem p-sm">03</div>
</div>
```

```html
<div id="layout" class="display:flex justify-content:space-evenly gap-md width:17.5rem max-width:100%">
  <div id="target" class="flex:none width:3rem height:3rem p-sm">01</div>
  <div id="peer" class="flex:none width:3rem height:3rem p-sm">02</div>
  <div id="item-3" class="flex:none width:3rem height:3rem p-sm">03</div>
</div>
```

The authored 16px `gap-md` is a minimum gap. Distributed space is added between the items, so with a nonzero gap even `justify-evenly` has larger inner gaps than outer edges. Flexible growth or automatic margins can consume the free space before this alignment runs.

### Keep overflowing content reachable \{#use-explicit-css-values\}
Pass a native multiword value with pipes: `justify-content:safe|center` centers content when it fits and falls back to the start when it would overflow. Compare a 280px item inside a 240px scrollport with explicit unsafe centering, then a 192px item that fits.

<DemoExample page="justify-content" section="use-explicit-css-values" />

```html
<div id="layout" class="display:flex overflow:auto justify-content:safe|center width:15rem max-width:100%" tabindex="0" role="region" aria-label="Safe centered overflow">
  <div id="target" class="display:flex flex:none justify-content:space-between height:4rem width:17.5rem p-xs"><span>Start</span><span>End</span></div>
</div>
```

```html
<div id="layout" class="display:flex overflow:auto justify-content:unsafe|center width:15rem max-width:100%" tabindex="0" role="region" aria-label="Unsafe centered overflow">
  <div id="target" class="display:flex flex:none justify-content:space-between height:4rem width:17.5rem p-xs"><span>Start</span><span>End</span></div>
</div>
```

```html
<div id="layout" class="display:flex overflow:auto justify-content:safe|center width:15rem max-width:100%" tabindex="0" role="region" aria-label="Safe centered fitting content">
  <div id="target" class="display:flex flex:none justify-content:space-between height:4rem width:12rem p-xs"><span>Start</span><span>End</span></div>
</div>
```

Unsafe centering pushes 20px beyond the starting edge in this example; that portion cannot be reached by scrolling. Safe alignment keeps the start visible and allows the remaining overflow to scroll at the end.

### Apply conditionally \{#apply-conditionally\}
Use [conditional queries](/reference/rules/conditions) to change alignment at a real viewport width. The same two items start at the leading edge, center from `sm`, and move to opposite edges from `lg`. The 280px container keeps the amount of free space consistent as the iframe crosses each breakpoint.

<DemoExample page="justify-content" section="apply-conditionally" />

```html
<div id="layout" class="display:flex justify-content:start gap-md width:17.5rem max-width:100% justify-content:center@sm justify-content:space-between@lg">
  <div id="target" class="flex:none height:3rem width:4rem p-sm">01</div>
  <div id="peer" class="flex:none height:3rem width:4rem p-sm">02</div>
</div>
```
