## Overview [sr-only] \{#overview\}
<Overview />

`user-select` controls ordinary user text selection. It does not prevent copying, protect confidential text or disable a control’s native action.

## Examples \{#examples\}
### Disable selection on controls \{#disable-selection-on-controls\}
Use `user-select:none` on a control label when dragging across it should not start a text selection. The checkbox still toggles normally.

<DemoExample page="user-select" section="disable-selection-on-controls" />

```html
<label id="target"

class="display:inline-flex align-items:center gap-sm p-md
       border-width:1px border-style:solid b-line-divider r-sm user-select:none">
  <input type="checkbox"> Snap objects to the grid
</label>
```

<details>
  <summary>Generated CSS</summary>
  <Class2CSS>{['user-select:none']}</Class2CSS>
</details>

Click or press Space on the checkbox to change its state. Keep selectable text in reading content; selection policy and activation behavior are separate.

### Select a whole value \{#select-all-text-in-one-click\}
Use `user-select:all` for a short value that should be selected atomically. Try selecting only one word: the browser expands a selection within this element to the whole value.

<DemoExample page="user-select" section="select-all-text-in-one-click" />

```html
<code id="target"
  class="display:block p-sm border-width:1px border-style:solid b-line-divider r-sm font-family-mono
         user-select:all">pnpm install @master/css</code>
```

The initiating gesture varies by browser and input device. This property defines the selection boundary; it does not guarantee that a single tap or click always creates a selection.

### Preserve normal reading selection \{#preserve-normal-reading-selection\}
An explicit `user-select:text` restores partial text selection within this otherwise nonselectable region.

<DemoExample page="user-select" section="preserve-normal-reading-selection" />

```html
<div class="p-md border-width:1px border-style:solid b-line-divider r-sm user-select:none">
  <p class="font-size-xs fg-text-muted">Panel label · selection disabled</p>
  <p id="target" class="margin-bottom:0 user-select:text">Select only a few words from this sentence.</p>
</div>
```

Drag across a few words or use the platform’s text-selection gesture. The paragraph can be partially selected without selecting the surrounding label.

### Apply conditionally \{#apply-conditionally\}
Use a checkbox to protect the paragraph from ordinary text selection. The selector targets a separate paragraph, so the trigger stays stable while you select.

<DemoExample page="user-select" section="apply-conditionally" />

```html
<div class="user-select:none:has(>label>input:checked)>p">
  <label class="display:flex align-items:center gap-sm mb-md">
    <input type="checkbox"> Protect text from selection
  </label>
  <p id="target" class="margin-bottom:0 user-select:text">Select only a few words from this sentence.</p>
</div>
```

The readout follows the actual computed property. Clear an existing selection before comparing new gestures; changing selection policy is not a request to erase selection or clipboard data.
