## Examples \{#examples\}
### Disable selection on controls \{#disable-selection-on-controls\}
Use `user-select:none` for controls where accidental text selection makes the interaction feel broken.
```html
<!-- @MARK user-select:none -->
<button class="user-select:none">
  Drag handle
</button>
```

### Select all text in one click \{#select-all-text-in-one-click\}
Use `user-select:all` for short values that users commonly copy whole, such as tokens or command snippets.
```html
<!-- @MARK user-select:all -->
<code class="user-select:all">pnpm install @master/css</code>
```

### Preserve normal reading selection \{#preserve-normal-reading-selection\}
Use `user-select:text` for article content, code examples, and any text users may need to copy partially.
```html
<!-- @MARK user-select:text -->
<p class="user-select:text">Select part of this sentence.</p>
```

### Apply conditionally \{#apply-conditionally\}
Apply styles based on different states using [selectors](/reference/rules/selectors) and [conditional queries](/reference/rules/conditions).
```html
<div class="user-select:none:hover user-select:auto@print user-select:text@sm">...</div>
```
