## Examples
### Use an image marker
Use `list-style:url(*)` when each list item should use an image marker.
```html
<!-- @MARK list-style:url(/marker.svg) -->
<ul class="list-style:url(/marker.svg)">
    <li>Custom marker</li>
</ul>
```

<details>
    <summary>Generated CSS</summary>
    <Class2CSS>
        {['list-style:url(/marker.svg)']}
    </Class2CSS>
</details>

### Use a gradient marker
Gradient functions can also be used when a generated marker is more appropriate than an asset.
```html
<!-- @MARK list-style:linear-gradient(primary|primary) -->
<ul class="list-style:linear-gradient(primary|primary)">
    <li>Gradient marker</li>
</ul>
```

### Fall back to type markers
Use `list-style:disc` or another type utility when image markers are not desired in a condition.
```html
<ul class="list-style:url(/marker.svg) list-style:disc@print">
    <li>Printable marker</li>
</ul>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<ul class="list-style:url(/marker.svg):hover list-style:disc@sm list-style:disc@print">...</ul>
```
