## Overview [sr-only]
<Overview/>

Use the native animation iteration count property directly.
```html
<div class="animation-iteration-count:infinite">
```

---

## Basic usage
### Loop animation
Play the animation in an infinite loop.
<Basic className="animation-iteration-count:infinite animation:rotate|1s|linear"/>

### Specify N iterations
Specifies the number of times the animation iterates, even decimals.

(hover) Hover over the icon to see animation iterations
<Basic className="animation-iteration-count:2.5:hover animation:rotate|1s|linear|forwards:hover"/>

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="animation-iteration-count:infinite:hover animation-iteration-count:infinite@sm animation-iteration-count:infinite@dark animation-iteration-count:infinite@print">…</div>
```
