## Examples \{#examples\}
### Set SVG fill color \{#set-svg-fill-color\}
Fill paints the interior of an SVG shape. `fill-current` uses its computed foreground color; the explicit stroke keeps the triangle’s outline visible in every comparison.

<DemoExample page="fill" section="set-svg-fill-color" />

```html
<!-- Current color · solid interior -->
<svg id="target" role="img" aria-label="Triangle"
  width="96" height="96" viewBox="0 0 24 24"
  class="display:block fg-blue-60 fill-current stroke-blue-60
         stroke-width:1">
  <path d="M12 4 20 20H4Z" />
</svg>
```

```html
<!-- None · no interior paint -->
<svg id="target" role="img" aria-label="Triangle"
  width="96" height="96" viewBox="0 0 24 24"
  class="display:block fill:none stroke-blue-60 stroke-width:1">
  <path d="M12 4 20 20H4Z" />
</svg>
```

```html
<!-- Transparent · zero-alpha interior paint -->
<svg id="target" role="img" aria-label="Triangle"
  width="96" height="96" viewBox="0 0 24 24"
  class="display:block fill:transparent stroke-blue-60
         stroke-width:1">
  <path d="M12 4 20 20H4Z" />
</svg>
```

<details>
  <summary>Generated CSS</summary>
  <Class2CSS>
    {['fill-current', 'fill:none', 'fill:transparent']}
  </Class2CSS>
</details>

The last two shapes look alike here, but `none` means no paint while transparent is a color with zero alpha. Fill and stroke are separate properties. Declaring paint on the SVG lets its child path inherit it.

### Use theme colors \{#use-theme-colors\}
The named `blue` alias follows the active theme; `blue-60` selects one palette step. Switch the preview theme to compare the actual fill values.

<DemoExample page="fill" section="use-theme-colors" />

```html
<!-- Theme alias · follows the mode -->
<svg id="target" role="img" aria-label="Triangle"
  width="96" height="96" viewBox="0 0 24 24"
  class="display:block fill-blue stroke:none">
  <path d="M12 4 20 20H4Z" />
</svg>
```

```html
<!-- Palette step · fixed blue-60 -->
<svg id="target" role="img" aria-label="Triangle"
  width="96" height="96" viewBox="0 0 24 24"
  class="display:block fill-blue-60 stroke:none">
  <path d="M12 4 20 20H4Z" />
</svg>
```

Use a theme alias when paint should adapt with the interface. Choose a numbered step when that exact palette color is intentional. The same SVG geometry is preserved in both modes.

### Apply conditionally \{#apply-conditionally\}
Hover or keyboard-focus the native button to change its inherited icon fill. Its visible label remains unchanged, and print restores the current foreground color.

<DemoExample page="fill" section="apply-conditionally" />

```html
<!-- Hover or focus · inherited icon fill -->
<button id="target" type="button"
  class="display:inline-flex align-items:center gap-xs px-md py-sm
         border-width:1px border-style:solid b-line-divider r-sm font-size-md
         bg-surface-base fg-text-body fill-current
         fill-current@media(print)
         fill-blue-60:hover@media(screen)
         fill-blue-60:focus-visible@media(screen)">
  <svg width="32" height="32" viewBox="0 0 24 24"
    aria-hidden="true" class="display:block stroke:none">
    <path d="M12 3 21 8v8l-9 5-9-5V8Z" />
  </svg>
  <span>Save palette</span>
</button>
```

The decorative icon is hidden from the accessibility tree because the button already has the name “Save palette”. The button supplies the state; the path inherits its fill through the SVG. Use [stroke](/reference/stroke) for outline paint.
