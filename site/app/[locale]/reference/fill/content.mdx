## Examples
### Set SVG fill color
Use `fill:*` to set the fill paint for SVG shapes.
```html
<!-- @MARK fill:current -->
<svg class="fill:current" viewBox="0 0 16 16" aria-hidden="true">
    <path d="M8 2 14 14H2Z" />
</svg>
```

<details>
    <summary>Generated CSS</summary>
    <Class2CSS>
        {['fill:current']}
    </Class2CSS>
</details>

### Use theme colors
Use color tokens when SVG paint should match the design system.
```html
<!-- @MARK fill:primary -->
<svg class="fill:primary" aria-hidden="true"></svg>
```

Use `fill:transparent` for shapes that should only show their stroke.

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<svg class="fill:current fill:primary:hover fill:current@print">...</svg>
```

Use [stroke](/reference/stroke) for outline paint.
