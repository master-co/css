## Examples \{#examples\}
### Set width and height together \{#set-width-and-height-together\}
Use `size:*` when the same value should apply to both `width` and `height`. This keeps square UI pieces readable in markup.
```html
<!-- @MARK size:10x -->
<button class="grid place-content:center size:10x">
  ...
</button>
```

### Build square media and controls \{#build-square-media-and-controls\}
`size:*` is a good fit for icons, avatars, swatches, checkboxes, handles, and fixed loading indicators.
```html
<!-- @MARK size:12x --><!-- @MARK round -->
<img class="size:12x round object-cover" src="..." alt="" />
```

### Set one logical axis \{#set-one-logical-axis\}
Use `size-x:*` for inline size and `size-y:*` for block size.
```html
<!-- @MARK size-x:md --><!-- @MARK size-y:20x -->
<aside class="size-x:md size-y:20x">...</aside>
```

Use [aspect-ratio](/reference/aspect-ratio) when the element should keep a non-square ratio while one axis remains fluid.
```html
<!-- @MARK w:full --><!-- @MARK aspect-ratio:16/9 -->
<video class="w:full aspect-ratio:16/9" controls></video>
```

### Use the `full` static utility \{#use-the-full-static-utility\}
The `full` utility sets both axes to `100%`. Use `w:full` or `h:full` when only one axis should fill.
```html
<!-- @MARK full -->
<div class="full">...</div>

<!-- @MARK w:full -->
<div class="w:full">...</div>
```

### Use intrinsic static utilities \{#use-intrinsic-static-utilities\}
Use `fit` when both axes should follow `fit-content`, or `full` when both axes should fill the available space.
```html
<!-- @MARK fit -->
<div class="fit">
  Compact content
</div>
```

### Apply conditionally \{#apply-conditionally\}
Apply styles based on different states using [selectors](/reference/rules/selectors) and [conditional queries](/reference/rules/conditions).
```html
<div class="size:8x full@dark size:6x@print size:10x@sm">...</div>
```

For physical one-axis sizing, use [width](/reference/width) and [height](/reference/height).
