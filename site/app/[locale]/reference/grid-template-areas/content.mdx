## Basic usage
### Name areas in a grid
Use `grid-template-areas` to define named layout regions, then place children with [`grid-area`](/reference/grid-area).
<Demo $py={0}>
    <DemoPanel>
        <div className="grid grid-template-areas:'head_head'|'nav_main' grid-template-columns:96px|1fr grid-template-rows:56px|96px gap:2x">
            <div className="grid-area:head min-w:0 p:3x r:8 bg:blue-5 bg:blue-95@dark border:1|solid|blue-20 border-color:blue-80@dark text:ellipsis overflow:hidden white-space:nowrap">Head</div>
            <div className="grid-area:nav min-w:0 p:3x r:8 bg:gray-5 bg:gray-90@dark text:ellipsis overflow:hidden white-space:nowrap">Nav</div>
            <div className="grid-area:main min-w:0 p:3x r:8 bg:gray-5 bg:gray-90@dark text:ellipsis overflow:hidden white-space:nowrap">Main</div>
        </div>
    </DemoPanel>
</Demo>
```html
<!-- @MARK grid-template-areas:'head_head'|'nav_main' -->
<div class="grid grid-template-areas:'head_head'|'nav_main'">
    <header class="grid-area:head">Head</header>
    <nav class="grid-area:nav">Nav</nav>
    <main class="grid-area:main">Main</main>
</div>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="grid-template-areas:none:hover grid-template-areas:none@sm grid-template-areas:none@dark grid-template-areas:none@print">…</div>
```
