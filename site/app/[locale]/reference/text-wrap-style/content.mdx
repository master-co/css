## Usage

Use `balance` for short headings and `pretty` for prose. These strategies apply when `text-wrap-mode:wrap` permits wrapping.

### Balance a short heading \{#balance-a-short-heading\}

<DemoExample page="text-wrap-style" section="balance-a-short-heading" />

```html
<h2 id="target" class="text-wrap-style:balance text-wrap-mode:wrap width:18rem max-width:100%">A shared language for thoughtful interfaces</h2>
```
