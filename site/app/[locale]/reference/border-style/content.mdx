## Examples \{#examples\}

### Set border style \{#set-border-style\}
`b-solid` sets the style independently of width and color. A border needs all three to be visible.

<DemoExample page="border-style" section="set-border-style" />

```html
<!-- Solid style · 3px width -->
<div id="target"
  class="display:flex align-items:center justify-content:center height:96px
         width:240px max-width:100% p-md border-style:solid border-width:3px b-blue
         font-size-md bg-surface-inset fg-text-body
         box-sizing:border-box">
  Preview panel
</div>
```

### Use dashed or dotted borders \{#use-dashed-or-dotted-borders\}
Compare dashed and dotted borders of the same box. Both use a 3px border; the browser distributes the pattern along each edge.

<DemoExample page="border-style" section="use-dashed-or-dotted-borders" />

```html
<!-- Dashed border -->
<div id="target"
  class="display:flex align-items:center justify-content:center height:96px
         width:240px max-width:100% p-md border-style:dashed border-width:3px
         b-blue font-size-md bg-surface-inset fg-text-body
         box-sizing:border-box">
  Dashed frame
</div>
```

```html
<!-- Dotted border -->
<div id="target"
  class="display:flex align-items:center justify-content:center height:96px
         width:240px max-width:100% p-md border-style:dotted border-width:3px
         b-blue font-size-md bg-surface-inset fg-text-body
         box-sizing:border-box">
  Dotted frame
</div>
```

Use these patterns to support a visible label. The decorative samples do not imply an active upload or drag target.

### Remove border style \{#remove-border-style\}
`b-none` and `b-hidden` both produce zero used border width on these ordinary boxes. Compare them with a solid 6px border while the declared content dimensions remain 160 × 48.

<DemoExample page="border-style" section="remove-border-style" />

```html
<!-- Solid · border adds to content box -->
<div id="target"
  class="height:48px width:160px p-md border-style:solid border-width:6px b-blue
         bg-surface-inset fg-text-body box-sizing:content-box">
  Content box
</div>
```

```html
<!-- None · no used border width -->
<div id="target"
  class="height:48px width:160px p-md border-style:none border-width:6px b-blue
         bg-surface-inset fg-text-body box-sizing:content-box">
  Content box
</div>
```

```html
<!-- Hidden · same ordinary box geometry -->
<div id="target"
  class="height:48px width:160px p-md border-style:hidden border-width:6px b-blue
         bg-surface-inset fg-text-body box-sizing:content-box">
  Content box
</div>
```

`hidden` differs from `none` in collapsed-table border conflict resolution. It does not hide the element or its content; see [border collapse](/reference/border-collapse).

### Apply conditionally \{#apply-conditionally\}
Hover or keyboard-focus this button to switch from solid to dashed without changing its width or color. Print removes the border style.

<DemoExample page="border-style" section="apply-conditionally" />

```html
<!-- Solid → dashed · width stays 2px -->
<button id="target" type="button"
  class="display:inline-flex align-items:center justify-content:center
         min-height:44px max-width:100% px-md py-sm border-style:solid
         border-width:2px b-blue r-sm font-size-md bg-surface-base
         fg-text-body box-sizing:border-box
         bg-surface-inset:focus-visible border-style:none@media(print)
         border-style:dashed:hover@media(screen)
         border-style:dashed:focus-visible@media(screen)">
  Preview details
</button>
```

A side alias such as `bt-dashed` changes only the top edge. The button’s independent focus ring remains available.
