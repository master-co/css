## Examples \{#examples\}
### Set left-to-right direction \{#set-left-to-right-direction\}
Use `direction:ltr` for content that should flow left to right regardless of the surrounding document direction.
```html
<!-- @MARK direction:ltr -->
<p class="direction:ltr">Invoice #1048</p>
```

<details>
  <summary>Generated CSS</summary>
  <Class2CSS>
    {['direction:ltr']}

</details>

### Set right-to-left direction \{#set-right-to-left-direction\}
Use `direction:rtl` for right-to-left content embedded in a left-to-right page.
```html
<!-- @MARK direction:rtl -->
<p class="direction:rtl">Right-to-left text</p>
```

### Prefer semantic document direction \{#prefer-semantic-document-direction\}
Use the `dir` attribute for user content and document-level language direction. Use the utility for localized component exceptions.
```html
<section dir="rtl">
  <code class="direction:ltr">npm install</code>
</section>
```

### Apply conditionally \{#apply-conditionally\}
Apply styles based on different states using [selectors](/reference/rules/selectors) and [conditional queries](/reference/rules/conditions).
```html
<p class="direction:ltr@print direction:rtl@sm">...</p>
```
