## Basic usage
### Define explicit rows
Use `grid-template-rows` to define the track list for grid rows.
<Demo $py={0}>
    <DemoPanel>
        <div className="grid grid-template-rows:48px|80px|48px gap:2x">
            <div className="min-w:0 p:3x r:8px bg:blue-5 bg:blue-95@dark border:1|solid|blue-20 border-color:blue-80@dark text-ellipsis overflow:hidden white-space:nowrap">48px</div>
            <div className="min-w:0 p:3x r:8px bg:gray-5 bg:gray-90@dark text-ellipsis overflow:hidden white-space:nowrap">80px</div>
            <div className="min-w:0 p:3x r:8px bg:gray-5 bg:gray-90@dark text-ellipsis overflow:hidden white-space:nowrap">48px</div>
        </div>
    </DemoPanel>
</Demo>
```html
<!-- @MARK grid-template-rows:48px|80px|48px -->
<div class="grid grid-template-rows:48px|80px|48px">…</div>
```

### Use minmax
```html
<!-- @MARK grid-template-rows:minmax(48px,auto)|1fr -->
<div class="grid grid-template-rows:minmax(48px,auto)|1fr">…</div>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="grid-template-rows:48px|80px|48px:hover grid-template-rows:48px|80px|48px@sm grid-template-rows:48px|80px|48px@dark grid-template-rows:48px|80px|48px@print">…</div>
```
