## Basic usage
### Define explicit rows
Use `grid-template-rows` to define the track list for grid rows.
<Demo $py={0}>
  <DemoPanel>
    <div className="grid grid-template-rows:48px|80px|48px gap:xs">
      <div className="overflow:hidden min-w:0 p:sm b:1px|solid|blue-20 r:lg text-ellipsis white-space:nowrap bg:blue-5 b:blue-80@dark bg:blue-95@dark">48px</div>
      <div className="overflow:hidden min-w:0 p:sm r:lg text-ellipsis white-space:nowrap bg:gray-5 bg:gray-90@dark">80px</div>
      <div className="overflow:hidden min-w:0 p:sm r:lg text-ellipsis white-space:nowrap bg:gray-5 bg:gray-90@dark">48px</div>
    </div>
  </DemoPanel>
</Demo>
```html
<!-- @MARK grid-template-rows:48px|80px|48px -->
<div class="grid grid-template-rows:48px|80px|48px">…</div>
```

### Use minmax
```html
<!-- @MARK grid-template-rows:minmax(48px,auto)|1fr -->
<div class="grid grid-template-rows:minmax(48px,auto)|1fr">…</div>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="grid-template-rows:48px|80px|48px:hover grid-template-rows:48px|80px|48px@dark grid-template-rows:48px|80px|48px@print grid-template-rows:48px|80px|48px@sm">…</div>
```
