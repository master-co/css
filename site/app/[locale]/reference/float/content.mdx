## Examples
### Float elements to the left
Use `float:left` when inline content should wrap around an element on the left.
```html
<!-- @MARK float:left -->
<img class="float:left mr:4x" src="/images/avatar.jpg" alt="Avatar">
```

### Float elements to the right
Use `float:right` to place a pull quote, image, or callout on the right side of a text flow.
```html
<!-- @MARK float:right -->
<aside class="float:right ml:4x">
    Pull quote
</aside>
```

### Reset floats
Use `float:none` when a responsive or print context should return the element to normal flow.
```html
<!-- @MARK float:none -->
<img class="float:left float:none@print" src="/images/avatar.jpg" alt="Avatar">
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<img class="float:left:hover float:right@sm float:none@print" src="/images/avatar.jpg" alt="">
```
