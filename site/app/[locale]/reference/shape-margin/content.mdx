## Examples
### Add space around a shape
Use `shape-margin:*` with floated shapes so inline content does not sit directly on the shape boundary.
```html
<!-- @MARK shape-margin:1rem -->
<img class="float:left shape-outside:circle(40px) shape-margin:1rem" src="/images/avatar.jpg" alt="Avatar">
```

### Increase margin for large media
Use a larger shape margin when the floated media is visually heavy or the text column is narrow.
```html
<!-- @MARK shape-margin:2rem -->
<img class="float:left shape-outside:circle(40px) shape-margin:2rem" src="/images/photo.jpg" alt="Photo">
```

### Pair with shape outside
`shape-margin:*` only has an effect when the element participates in shape layout, usually with `float:*` and `shape-outside:*`.
```html
<img class="float:left shape-outside:circle(40px) shape-margin:1rem" src="/images/avatar.jpg" alt="">
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<img class="shape-margin:1rem:hover shape-margin:2rem@sm shape-margin:0@print" src="/images/avatar.jpg" alt="">
```
