## Examples \{#examples\}
### Use antialiased text \{#use-antialiased-text\}
Use `font-antialiased` when display text should use grayscale antialiasing.
```html
<!-- @MARK font-antialiased -->
<h1 class="font-antialiased">Dashboard</h1>
```

### Restore subpixel antialiasing \{#restore-subpixel-antialiasing\}
Use `font-subpixel-antialiased` when you want to return to the platform default smoothing behavior.
```html
<!-- @MARK font-subpixel-antialiased -->
<p class="font-antialiased font-subpixel-antialiased@sm">
  Body text
</p>
```

### Use sparingly \{#use-sparingly\}
Font smoothing is platform-specific. Prefer testing it on the actual surfaces where the text will appear.
```html
<h2 class="font-antialiased">Large heading</h2>
```

### Apply conditionally \{#apply-conditionally\}
Apply styles based on different states using [selectors](/reference/rules/selectors) and [conditional queries](/reference/rules/conditions).
```html
<p class="font-antialiased:hover font-subpixel-antialiased@print font-subpixel-antialiased@sm">...</p>
```
