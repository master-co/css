## Basic usage \{#basic-usage\}
### Block and inline boxes \{#block--inline\}
Use `block` to start a new block, `inline` to participate in the surrounding text, and `inline-block` for an inline box that accepts width and height. Compare where the text before and after each specimen ends up.

<DemoExample page="display" section="block--inline" />

```html
<div>
  Block elements start on a new line.
  <span class="block">
    display:block
  </span>
  Inline elements stay in text flow.
  <span class="inline">
    display:inline
  </span>
  Inline-block elements accept dimensions.
  <span class="inline-block">
    display:inline-block
  </span>
  Choose the display mode for the layout.
</div>
```

### Flex \{#flex\}
Use `flex` when direct children should share one row or column. The container itself participates in the outer layout as a block.

<DemoExample page="display" section="flex" />

```html
<div class="flex items-center gap-sm">
  <div>01</div>
  <div>02</div>
  <div>03</div>
</div>
```

### Inline flex \{#inline-flex\}
Use `inline-flex` for a badge or compact control whose children need flex alignment while the whole object stays in a line of text.

<DemoExample page="display" section="inline-flex" />

```html
<p>
  Status: <span class="inline-flex items-center gap-xs">
    <span aria-hidden="true">●</span><span>In progress</span>
  </span> while the next task is queued.
</p>
```

### Grid \{#grid\}
Use `grid` to place direct children in rows and columns. Define tracks with [`grid-template-columns`](/reference/grid-template-columns) or [`grid-template-rows`](/reference/grid-template-rows).

<DemoExample page="display" section="grid" />

```html
<div class="grid grid-template-columns:repeat(2,auto) gap-sm">
  <div>01</div>
  <div>02</div>
  <div>03</div>
  <div>04</div>
</div>
```

### Inline grid \{#inline-grid\}
Use `inline-grid` when a small grid should sit within text or beside other inline content. Its children use grid layout; the grid itself remains inline.

<DemoExample page="display" section="inline-grid" />

```html
<p>
  Before <span class="inline-grid grid-template-columns:repeat(2,auto) gap-sm">
    <span>01</span><span>02</span>
    <span>03</span><span>04</span>
  </span> after.
</p>
```

### Table \{#table\}
Table display values reproduce the visual table layout model. Use native `<table>`, `<tr>`, `<th>` and `<td>` elements for tabular data: CSS display values do not supply their accessibility semantics.

<DemoExample page="display" section="table" />

```html
<div class="table">
  <div class="table-caption">Orders</div>
  <div class="table-header-group">
    <div class="table-row">
      <div class="table-cell">Product</div>
      <div class="table-cell">Qty</div>
      <div class="table-cell">Price</div>
    </div>
  </div>
  <div class="table-row-group">
    <div class="table-row">
      <div class="table-cell">Milk</div>
      <div class="table-cell">2</div>
      <div class="table-cell">10.00</div>
    </div>
    <div class="table-row">
      <div class="table-cell">Cola</div>
      <div class="table-cell">3</div>
      <div class="table-cell">12.00</div>
    </div>
    <div class="table-row">
      <div class="table-cell">Juice</div>
      <div class="table-cell">5</div>
      <div class="table-cell">18.00</div>
    </div>
  </div>
  <div class="table-footer-group">
    <div class="table-row">
      <div class="table-cell">Total</div>
      <div class="table-cell text-center">10</div>
      <div class="table-cell text-center">40.00</div>
    </div>
  </div>
</div>
```

### Contents \{#contents\}
Use `contents` to omit a wrapper’s own layout box. Its children then participate directly in the parent’s layout. The wrapper remains in the DOM, but its own background, border and dimensions no longer produce a box.

<DemoExample page="display" section="contents" />

```html
<div class="flex gap:1.25rem">
  <div class="flex:1">01</div>
  <div class="contents">
    <div class="flex:1">02</div>
    <div class="flex:1">03</div>
  </div>
  <div class="flex:1">04</div>
</div>
```

### Flow root \{#flow-root\}
Use `flow-root` on a wrapper that should contain its floated children. It establishes a block formatting context without using overflow clipping.

<DemoExample page="display" section="flow-root" />

```html
<div class="flow-root">
  <img class="float:left w:8rem mr-md" src="/demo/landscape.svg" alt="Landscape">
  <p>The paragraph wraps around the floated image.</p>
</div>
```

### List items \{#list-item\}
Use `list-item` to generate a list-item box and marker. Prefer `<ul>` or `<ol>` with `<li>` for semantic lists; this utility controls their visual display.

<DemoExample page="display" section="list-item" />

```html
<div>
  <div class="list-item">01</div>
  <div class="list-item">02</div>
  <div class="list-item">03</div>
</div>
```

### Hidden \{#hidden\}
Use `hidden` to apply `display:none`. The element and its descendants produce no layout boxes and are absent from the accessibility tree. Use [`visibility`](/reference/visibility) when its space should remain.

<DemoExample page="display" section="hidden" />

```html
<div class="flex gap:1.25rem">
  <div>01</div>
  <div class="hidden">02</div>
  <div>03</div>
</div>
```

### Apply conditionally \{#apply-conditionally\}
Switch the same items from a grid to a flex row on screens at `sm`, then use ordinary block flow in print. Combining `screen` and `sm` keeps the wide-screen rule from also applying to wide printed pages. Read [conditions](/reference/rules/conditions) for breakpoint and media syntax.

<DemoExample page="display" section="apply-conditionally" />

```html
<div class="grid grid-cols:2 gap-sm block@print flex@screen@sm">
  <div>01</div>
  <div>02</div>
  <div>03</div>
</div>
```
