## Basic usage
### Block & Inline
Use `block`, `inline`, and `inline-block` to set the flow of elements.
<Demo $py={0}>
    <div className='bg:float p:8x'>
        <p>
            Block elements start on a new line and take the available width.
            <span className="box block! bg:slate-95!@light">
                `display:block`
            </span>
            Inline elements stay in the same text flow and only occupy the space they need.
            <span className="box inline! my:8 bg:slate-95!@light">
                `display:inline`
            </span>
            Inline-block elements stay inline but can accept box dimensions.
            <span className="box inline-block! my:8 bg:slate-95!@light">
                `display:inline-block`
            </span>
            Use the display mode that matches the element's role in the flow.
        </p>
    </div>
</Demo>
```html
<div>
    Block elements start on a new line.
    <span class="block">
        display:block
    </span>
    Inline elements stay in text flow.
    <span class="inline">
        display:inline
    </span>
    Inline-block elements accept dimensions.
    <span class="inline-block">
        display:inline-block
    </span>
    Choose the display mode for the layout.
</div>
```

### Flex
Use `flex` to create a block-level flex container.
<Demo>
    <div className="flex gap:12 align-items:center bg:float p:8|20 r:10">
        <Image src={aron} alt="avatar" className="object:cover round h:auto" width="64" height="64" />
        <div>
            <div className="text:14 font:medium font:gray-88@dark capitalize">aron</div>
            <p className="text:13 m:0">Front-end needs a revolution</p>
        </div>
    </div>
</Demo>
```html
<div class="flex gap:12 align-items:center">
    <img src="...">
    <div>
        <div>aron</div>
        <p>Front-end needs a revolution</p>
    </div>
</div>
```

### Inline Flex
Use `inline-flex` to create an inline-level flex container.
<Demo $py={0}>
    <div className='bg:float p:8x'>
        <p className="font:16 leading:1.75rem">
            Inline flex is useful when an inline phrase needs aligned children.
            The element still participates in text flow while its contents use flex alignment.
            <span className="inline-flex! align-items:baseline! mx:12 box b:0 bg:slate-95!@light p:0! overflow:hidden">
                <Image src={aron} alt="avatar" className="object:cover h:auto align-self:end" width="24" height="24" />
                <span className="text:14 font:medium font:gray-88@dark capitalize px:10">aron</span>
            </span>
            This keeps the badge baseline-aligned with the surrounding sentence.
        </p>
    </div>
</Demo>
```html
<div>
    Inline flex keeps this badge in the text flow.
    <div class="inline-flex align-items:baseline mx:12">
        <img src="...">
        <div>Aron</div>
    </div>
    The surrounding sentence continues after it.
</div>
```

### Contents
Use `contents` to make the element's children behave like direct children of the element's parent, ignoring the element itself.
<Demo>
    <div className="flex gap:20 w:full">
        <div className="flex:1 box">01</div>
        <div className="contents">
            <div className="box flex:1">02</div>
            <div className="box flex:1">03</div>
        </div>
        <div className="flex:1 box">04</div>
    </div>
</Demo>
```html
<div class="flex gap:20">
    <div class="flex:1">01</div>
    <div class="contents">
        <div class="flex:1">02</div>
        <div class="flex:1">03</div>
    </div>
    <div class="flex:1">04</div>
</div>
```

### Flow Root
Use `flow-root` to create a block-level element that establishes a new block formatting context.
{<Demo $py={0}>
    <div className="bg:float p:8x w:full">
        <div className="w:full flow-root bg:stripe-pink">
            <Image src="/images/blur.png" className="r:8 object:cover my:0 mr:30 float:left" width={160} height={90} alt="Float Image" />
            <p className="my:0">The paragraph wraps around the floated image because the parent establishes a new formatting context.</p>
        </div>
        <p>Use `flow-root` to clear floats.</p>
    </div>
</Demo>}
```html
<div class="flow-root">
    <img class="float:left" .../>
    <p>The paragraph wraps around the floated image.</p>
</div>
Use flow-root to clear floats
```

### Hidden
Use `hidden` to hide the element. The element is not rendered in the document.
<Demo>
    <div className="flex gap:20 w:full flex:1_:where(div)">
        <div className="box">01</div>
        <div className="box hidden!">02</div>
        <div className="box">03</div>
    </div>
</Demo>
```html
<div class="flex gap:20">
    <div>01</div>
    <div class="hidden">02</div>
    <div>03</div>
</div>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="display:block:hover display:block@sm display:block@dark display:block@print">...</div>
```
