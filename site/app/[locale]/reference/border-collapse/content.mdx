## Examples
### Collapse table borders
Use `border-collapse:collapse` when adjacent table cell borders should merge into a single border.
```html
<!-- @MARK border-collapse:collapse -->
<table class="border-collapse:collapse">
    <tr><td>Cell</td></tr>
</table>
```

### Separate table borders
Use `border-collapse:separate` when cells need their own border boxes and spacing.
```html
<!-- @MARK border-collapse:separate -->
<table class="border-collapse:separate">
    <tr><td>Cell</td></tr>
</table>
```

### Match border spacing to the mode
Collapsed borders ignore `border-spacing`. Use separate borders when spacing between cells is part of the design.
```html
<table class="border-collapse:separate border-spacing:xs">
    <tr><td>Cell</td></tr>
</table>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<table class="border-collapse:collapse border-collapse:collapse@print border-collapse:separate@sm">...</table>
```
