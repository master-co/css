## Examples \{#examples\}
### Limit what can animate \{#limit-what-can-animate\}
Toggle each checkbox to move and fade the same layer. The first transition includes only opacity, so its position changes immediately; the second includes both properties.

<DemoExample page="transition-property" section="limit-what-can-animate" />

```html
<!-- Opacity only · position changes immediately -->
<label class="display:block width:280px max-width:100% font-sm
         opacity:.72:has(input:checked)>span>span@media(screen)
         transform:translateX(96px):has(input:checked)>span>span@media(screen)">
  <input type="checkbox" aria-label="Move and fade"
    class="mr-xs accent-color-blue
           outline:2px|solid|var(--color-blue):focus-visible
           outline-offset:3px:focus-visible">
  Move and fade
  <span aria-hidden="true"
    class="display:block height:64px mt-md p-xs
           outline:1px|dashed|var(--color-line-subtle)">
    <span id="target"
      class="display:grid place-items:center height:48px width:128px
             border:1px|solid|var(--color-blue-60) r-sm font-sm bg-blue-10
             fg-blue-80 opacity:1 transform:none
             transition-property:opacity
             transition-timing-function:linear
             transition-duration:0ms@media(print)
             transition-duration-slowest@media(screen)@motion-safe">
      Layer 01
    </span>
  </span>
</label>
```

```html
<!-- Opacity + transform · both interpolate -->
<label class="display:block width:280px max-width:100% font-sm
         opacity:.72:has(input:checked)>span>span@media(screen)
         transform:translateX(96px):has(input:checked)>span>span@media(screen)">
  <input type="checkbox" aria-label="Move and fade"
    class="mr-xs accent-color-blue
           outline:2px|solid|var(--color-blue):focus-visible
           outline-offset:3px:focus-visible">
  Move and fade
  <span aria-hidden="true"
    class="display:block height:64px mt-md p-xs
           outline:1px|dashed|var(--color-line-subtle)">
    <span id="target"
      class="display:grid place-items:center height:48px width:128px
             border:1px|solid|var(--color-blue-60) r-sm font-sm bg-blue-10
             fg-blue-80 opacity:1 transform:none
             transition-property:opacity,transform
             transition-timing-function:linear
             transition-duration:0ms@media(print)
             transition-duration-slowest@media(screen)@motion-safe">
```

The 800ms duration makes the difference visible. A property list selects which changed values interpolate; it neither creates the value change nor animates other properties.

### Pair with duration and easing \{#pair-with-duration-and-easing\}
Focus or hover this native button. A 200ms duration and the smooth easing token turn its explicit transform change into a transition.

<DemoExample page="transition-property" section="pair-with-duration-and-easing" />

```html
<!-- Transform · 200ms smooth -->
<div class="p-sm">
  <button id="target" type="button"
    class="display:inline-grid place-items:center height:64px
           width:160px p-sm border:1px|solid|var(--color-blue-60) r-sm
           font-sm bg-blue-10 fg-blue-80 transform:none
           transition-property:transform
           transition-timing-function-smooth
           outline:2px|solid|var(--color-blue):focus-visible
           outline-offset:3px:focus-visible
           transform:none@media(print)
           transition-duration:0ms@media(print)
           transition-duration-normal@media(screen)@motion-safe
           transform:translateY(-8px):is(:hover,:focus-visible)@media(screen)">
    Lift layer
  </button>
</div>
```

The initial duration is zero. Choosing a property alone does not add time. For multiple properties, duration, delay and easing lists match by position; shorter lists repeat and extra values are unused.

Use none to override a component or variant declaration through the cascade. Transition properties are not inherited, and disabling a transition does not disable the control or prevent the final CSS value from applying.

### Apply conditionally \{#apply-conditionally\}
Toggle the layer after resizing. Below `sm`, only opacity interpolates; at `sm`, transform joins the property list. The endpoints stay the same.

<DemoExample page="transition-property" section="apply-conditionally" />

```html
<!-- Opacity → opacity + transform at sm -->
<label class="display:block width:280px max-width:100% font-sm
         opacity:.72:has(input:checked)>span>span@media(screen)
         transform:translateX(96px):has(input:checked)>span>span@media(screen)">
  <input type="checkbox" aria-label="Move and fade"
    class="mr-xs accent-color-blue
           outline:2px|solid|var(--color-blue):focus-visible
           outline-offset:3px:focus-visible">
  Move and fade
  <span aria-hidden="true"
    class="display:block height:64px mt-md p-xs
           outline:1px|dashed|var(--color-line-subtle)">
    <span id="target"
      class="display:grid place-items:center height:48px width:128px
             border:1px|solid|var(--color-blue-60) r-sm font-sm bg-blue-10
             fg-blue-80 opacity:1 transform:none
             transition-property:opacity
             transition-timing-function:linear
             transition-duration-slowest@media(screen)@motion-safe
             transition-property:none@media(print)
             transition-property:opacity,transform@media(screen)@sm">
      Layer 01
    </span>
  </span>
</label>
```

This is a native property-list change inside the resized viewport. Reduced motion removes the duration, and print selects none.
