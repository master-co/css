## Examples
### Lay out items in a row
Use `flex-row` for the default horizontal main axis.
```html
<!-- @MARK flex --><!-- @MARK flex-row -->
<nav class="flex flex-row gap:sm">
    ...
</nav>
```

<details>
    <summary>Generated CSS</summary>
    <Class2CSS>

</details>

### Stack items in a column
Use `flex-col` when children should stack vertically.
```html
<!-- @MARK flex --><!-- @MARK flex-col -->
<section class="flex flex-col gap:md">
    ...
</section>
```

### Reverse visual order
Use `flex-row-reverse` or `flex-col-reverse` only when the visual order intentionally differs from source order.
```html
<!-- @MARK flex-row-reverse -->
<div class="flex flex-row-reverse">...</div>
```

(i) Reversed flex direction changes visual order, but it does not rewrite the document source. Keep keyboard and reading order in mind.

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="flex flex-col flex-col@print flex-row@sm">...</div>
```

Use [gap](/reference/gap), [justify-content](/reference/justify-content), and [align-items](/reference/align-items) to control spacing and alignment along the chosen axis.
