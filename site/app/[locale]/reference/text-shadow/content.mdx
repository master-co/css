## Examples
### Add a text shadow
Use `text-shadow:*` to apply a shadow to glyphs.
```html
<!-- @MARK text-shadow:0|1px|2px|black/.2 -->
<h1 class="text-shadow:0|1px|2px|black/.2">
    Readable heading
</h1>
```

<details>
    <summary>Generated CSS</summary>
    <Class2CSS>
        {['text-shadow:0|1px|2px|black/.2']}
    </Class2CSS>
</details>

### Use text shadows sparingly
Text shadows can help over images, but they can also blur small text. Prefer solid contrast for body copy and reserve text shadows for display text or media overlays.
```html
<!-- @MARK fg:white --><!-- @MARK text-shadow:0|1px|3px|black/.45 -->
<h2 class="fg:white text-shadow:0|1px|3px|black/.45">
    Mountain retreat
</h2>
```

### Apply conditionally
Apply styles based on different states using [selectors](/guide/state-selectors) and [conditional queries](/guide/conditional-queries).
```html
<div class="text-shadow:none text-shadow:0|1px|2px|black/.2@sm text-shadow:none@print">...</div>
```

Use [box-shadow](/reference/box-shadow) for element shadows.
