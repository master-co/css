## New Configuration API

### `.animations`
You can now customize CSS [animations](/guide/theme#motion) in the project CSS entry:
```css name=index.css
@keyframes fade {
    0% {
        opacity: 0;
    }

    to {
        opacity: 1;
    }
}
```
Apply the `fade` keyframe via [animation syntax](/reference/animation):
```html
<!-- @MARK animation:fade|.5s|ease -->
<div class="animation:fade|.5s|ease"></div>
```
It only generates the CSS keyframe rule used:
```css
@keyframes fade {
    0% {
        opacity: 0
    }

    to {
        opacity: 1
    }
}

.animation\:fade\|\.5s\|ease {
    animation: fade .5s ease
}
```

## Explicit Motion Declarations

Animation and transition longhands use their full CSS property keys:
```html
<div class="animation-play-state:paused">
<div class="animation-fill-mode:forwards">
<div class="animation-iteration-count:infinite">
<div class="animation-direction:alternate">
```
To learn more, check out the [animation](/reference/animation) documentation.
