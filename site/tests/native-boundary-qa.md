# Native boundary implementation QA

Baseline source: `f771c70f76459165de45d899a71bdba54d5deac0`.
Scope: the user's approved “原生 CSS 邊界、確定性建置與工具契約收斂” implementation plan.

Intentional CSS changes in this implementation:

- Authored native values retain their whitespace, dollar signs, pipes and escapes.
  Official `--alpha()` macros now use equivalent `color-mix(in oklab, …)` values.
- Equivalent simple media ranges use the same priority domain; direct values
  override tokens within the existing cascade tiers. The browser regression
  previously computed 16px padding and now computes the intended 8px.
- Hydration priorities carry explicit feature ranges and nullable bounds.
- Literal ampersands are preserved. Nesting selectors are transformed as tokens;
  mode selector lists activate each element and its descendants.
- Historical Markdown fences and prose do not generate CSS or receive class fixes.

Validation completed before updating the site CSS contract:

- Production Next build, static postprocessing and public asset validation passed.
  The first build hit a stale Turbopack generated-stylesheet resolution; a clean
  Next cache and rebuild completed successfully. The subsequent warm production
  build and its static asset checks also passed.
- Documentation examples: 14 passed; Reference: 20 passed; v2 RC guide: 3 passed.
- Chromium and WebKit runtime matrix: 256 passed, including static, SSR, runtime,
  progressive, computed styles, hydration and subsequent class updates.
- Migration Frameworks entrance and v2 RC page checked at 1440px and 390px in
  Chromium and WebKit. Both back links exist; neither width has page overflow.
  Chromium desktop/mobile entrance and Chromium/WebKit mobile guide screenshots
  were inspected.
  Hard navigation in the initial harness cancelled WebKit prefetch requests.
  Repeating the actual link-click flow passed all four browser/viewport cases
  without page errors, including client navigation and the guide's back links.

This record explains the intentional contract update; it is not an assertion that
all release gates passed. Firefox cannot launch a profile in this environment,
and historical migration-ledger approvals are not rewritten by this work.
Measurements and the final release gate status belong in
`parity/native-boundary-validation.md`.

contracts, 1,863 generated rules and 3,708 CSS segments. Comparing generated CSS

also changes delivery bytes. These are intentionally regenerated by the contract
tool, with the original snapshot retained in the saved HEAD baseline.
