# Reference prose: sr-only

## title \{#copy-title\}


螢幕閱讀器文字

## summary \{#copy-summary\}


在視覺上隱藏文字，同時將它保留在無障礙樹中。

## note \{#copy-note\}


將這個 class 用在仍應供輔助技術讀取的文字上。它不是停用元素或將元素移出鍵盤導覽的方式。

## explanation-title \{#copy-explanation-title\}


視覺裁切與無障礙命名是兩件事

## explanation-paragraphs-0 \{#copy-explanation-paragraphs-0\}


`sr-only` 讓元素脫離一般流向，將它設為 1px 的盒子，並裁切繪製區域。它不會套用 `display: none`、`visibility: hidden` 或 `aria-hidden`，因此文字仍可用來形成無障礙名稱。

## explanation-paragraphs-1 \{#copy-explanation-paragraphs-1\}


將 class 放在控制項內的標籤文字上，讓控制項本身保持可見且可聚焦。標記為 `aria-hidden="true"` 的圖示不會參與名稱計算，便可由文字描述動作。

## explanation-paragraphs-2 \{#copy-explanation-paragraphs-2\}


不要將可聚焦的控制項放進始終被裁切的區域，否則鍵盤使用者可能會移到看不見的控制項。跳至內容連結需要自行設定聚焦時顯示的樣式；預設集沒有提供 `not-sr-only` 反向 utility。

## explanation-paragraphs-3 \{#copy-explanation-paragraphs-3\}


如果祖先元素將整個子樹移出無障礙樹，這段文字也會一併移除。`sr-only` 無法抵消祖先元素上的 `hidden`、`display: none` 或 `aria-hidden="true"`。請在實際控制項中測試最終的角色與名稱。

## explanation-links-0-label \{#copy-explanation-links-0-label\}


無障礙名稱

## usage-lead \{#copy-usage-lead\}


為只有圖示的連結提供名稱，讓它開啟下方的 utility 定義。

## caption \{#copy-caption\}


連結的無障礙名稱是「Read the utility definition」，箭頭不會參與名稱計算。
