# Reference prose: sr-only

## title \{#copy-title\}


스크린 리더용 텍스트

## summary \{#copy-summary\}


텍스트를 시각적으로 숨기되 접근성 트리에는 유지합니다.

## note \{#copy-note\}


보조 기술이 계속 읽을 수 있어야 하는 텍스트에 이 클래스를 사용하세요. 요소를 비활성화하거나 키보드 탐색에서 제외하는 방법이 아닙니다.

## explanation-title \{#copy-explanation-title\}


시각적 잘라 내기와 접근 가능한 이름은 별개입니다

## explanation-paragraphs-0 \{#copy-explanation-paragraphs-0\}


`sr-only`는 요소를 일반 흐름에서 빼고 1px 상자를 지정한 다음 그리기 영역을 잘라 냅니다. `display: none`, `visibility: hidden`, `aria-hidden`은 적용하지 않습니다. 따라서 텍스트는 접근 가능한 이름을 구성하는 데 계속 사용될 수 있습니다.

## explanation-paragraphs-1 \{#copy-explanation-paragraphs-1\}


클래스는 컨트롤 안의 레이블 텍스트에 지정하세요. 컨트롤 자체는 보이고 포커스를 받을 수 있어야 합니다. 아이콘에 `aria-hidden="true"`를 지정하면 이름 계산에서 제외되므로 텍스트가 동작을 설명하게 됩니다.

## explanation-paragraphs-2 \{#copy-explanation-paragraphs-2\}


항상 잘리는 영역 안에 포커스를 받을 수 있는 컨트롤을 넣지 마세요. 키보드 사용자가 보이지 않는 컨트롤에 도달할 수 있습니다. 건너뛰기 링크에는 포커스를 받으면 보이는 별도 스타일이 필요하며, 프리셋은 반대로 되돌리는 `not-sr-only` 유틸리티를 제공하지 않습니다.

## explanation-paragraphs-3 \{#copy-explanation-paragraphs-3\}


상위 요소가 하위 트리를 접근성 트리에서 제거하면 이 텍스트도 제거됩니다. `sr-only`는 상위 요소의 `hidden`, `display: none`, `aria-hidden="true"`를 상쇄할 수 없습니다. 실제 컨트롤에서 최종 역할과 이름을 확인하세요.
