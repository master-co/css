# Reference prose: grid-tracks

## title \{#copy-title\}


그리드 트랙

## summary \{#copy-summary\}


하나의 클래스로 동일한 크기의 Grid 트랙이나 트랙에 걸치는 배치를 지정합니다.

## note \{#copy-note\}


`grid-cols()`와 `grid-rows()`는 Grid를 만들고, span 함수는 기존 Grid 안에 항목을 배치합니다.

## explanation-title \{#copy-explanation-title\}


트랙 수와 항목 배치는 서로 다른 요소가 지정합니다

## explanation-paragraphs-0 \{#copy-explanation-paragraphs-0\}


`grid-cols(3)`는 `display: grid`와 `minmax(0, 1fr)` 열 세 개를 설정합니다. `grid-rows(3)`는 같은 형태의 행 세 개와 `grid-auto-flow: column`을 설정합니다. 나머지 배치가 기본값이면 동일한 자식 여섯 개가 첫 번째에서는 가로로, 두 번째에서는 아래로 채워집니다.

## explanation-paragraphs-1 \{#copy-explanation-paragraphs-1\}


트랙 수와 span에는 양의 정수를 사용하세요. 트랙 함수는 gap을 추가하지 않습니다. 동일한 비율은 gap을 제외한 가용 공간을 나눕니다. 최솟값이 0이면 트랙을 줄일 수 있지만, 이 설정 자체가 내용을 줄바꿈하거나 잘라 내지는 않습니다.

## explanation-paragraphs-2 \{#copy-explanation-paragraphs-2\}


`grid-col-span(2)`와 `grid-row-span(2)`는 항목의 배치를 지정하며 부모 요소의 display는 설정하지 않습니다. span이 명시적 Grid를 넘으면 암시적 트랙이 생길 수 있습니다. 중단점별로 트랙 수와 span을 조정하는 방법은 레이아웃 가이드에서 다룹니다.

## explanation-paragraphs-3 \{#copy-explanation-paragraphs-3\}


`grid-cols()`는 `grid-rows()`가 설정한 열 방향 흐름을 초기화하지 않습니다. 둘 다 적용되면 두 트랙 정의가 모두 유지되고 자동 배치는 계속 열을 따라 아래로 진행합니다. 행 방향 흐름이 필요하면 `(grid-auto-flow:row)`를 명시적으로 추가하세요.

## explanation-paragraphs-4 \{#copy-explanation-paragraphs-4\}


행의 비율로 고정된 세로 공간을 나누려면 가용 높이에 제약이 있어야 합니다. 높이가 auto인 Grid에서는 콘텐츠도 행 크기 계산에 참여합니다. `grid-rows(3)`는 높이를 제한하지 않습니다.
