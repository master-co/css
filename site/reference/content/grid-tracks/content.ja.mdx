# Reference prose: grid-tracks

## title \{#copy-title\}


グリッドのトラック

## summary \{#copy-summary\}


等分の Grid トラックとトラックをまたぐ配置を、1 つのクラスで指定します。

## note \{#copy-note\}


`grid-cols()` と `grid-rows()` は Grid を作成します。span 関数は、既存の Grid 内で項目を配置します。

## explanation-title \{#copy-explanation-title\}


トラック数と項目の配置は別の要素が指定する

## explanation-paragraphs-0 \{#copy-explanation-paragraphs-0\}


`grid-cols(3)` は `display: grid` と 3 本の `minmax(0, 1fr)` 列を設定します。`grid-rows(3)` は同じ指定の行を 3 本作り、さらに `grid-auto-flow: column` を設定します。そのほかが既定の配置なら、同じ 6 個の子要素が、前者では横方向に、後者では下方向に埋まります。

## explanation-paragraphs-1 \{#copy-explanation-paragraphs-1\}


トラック数と span には正の整数を使います。トラック関数は gap を追加しません。等しい比率で分割されるのは gap を差し引いた利用可能な空間です。最小値をゼロにするとトラックは縮められますが、それ自体で内容が折り返されたり切り取られたりするわけではありません。

## explanation-paragraphs-2 \{#copy-explanation-paragraphs-2\}


`grid-col-span(2)` と `grid-row-span(2)` は項目の配置を指定するもので、親要素の display は設定しません。span が明示的な Grid を超えると、暗黙のトラックが作られることがあります。ブレークポイントに応じてトラック数と span を調整する方法は、レイアウトガイドで説明しています。

## explanation-paragraphs-3 \{#copy-explanation-paragraphs-3\}


`grid-cols()` は、`grid-rows()` が設定した列方向のフローをリセットしません。両方が適用されると、どちらのトラック定義も残り、自動配置は引き続き列を下方向に進みます。行方向のフローが必要なら、明示的に `(grid-auto-flow:row)` を追加します。

## explanation-paragraphs-4 \{#copy-explanation-paragraphs-4\}


行の比率で固定の縦方向の空間を分割するには、利用可能な高さが制約されている必要があります。高さが auto の Grid では内容も行サイズの計算に関わります。`grid-rows(3)` は高さを制限する指定ではありません。
