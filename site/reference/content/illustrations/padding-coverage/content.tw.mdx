# Reference prose: illustrations/padding-coverage

## title \{#copy-title\}


單邊覆寫只改變該邊

## alt \{#copy-alt\}


兩個相同內容框比較 p(24) 與 p(24) pt(8)。只有上方內距從 24px 縮為 8px。

## caption \{#copy-caption\}


色帶是檢查輔助線，不是生成的背景色彩。兩個範例使用真正的預設集 CSS，內容尺寸也相同。

## description-0 \{#copy-description-0\}


p(24) 為內容四邊提供 24px 內距。

## description-1 \{#copy-description-1\}


加入 pt(8) 將上方內距改為 8px。相同條件下，其餘三邊維持 24px，不受兩個 HTML class 的順序影響。
