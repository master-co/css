# Reference prose: illustrations/padding-coverage

## title \{#copy-title\}


片側の上書きはその側だけを変更

## alt \{#copy-alt\}


同じ内容ボックスで p(24) と p(24) pt(8) を比較し、上の余白だけが 24px から 8px に縮む。

## caption \{#copy-caption\}


帯は検査の補助表示であり、生成した背景色ではありません。両例は実際のプリセット CSS を使い、内容の寸法も同じです。

## description-0 \{#copy-description-0\}


p(24) は内容の四辺に 24px の内側の余白を設定します。

## description-1 \{#copy-description-1\}


pt(8) を加えると上の余白が 8px になります。同条件では HTML の両クラスの順序によらず、他の三辺は 24px のままです。
