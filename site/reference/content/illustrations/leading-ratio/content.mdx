# Reference prose: illustrations/leading-ratio

## title \{#copy-title\}

The same inherited ratio produces different line heights

## alt \{#copy-alt\}

Two children inherit leading-md, or 1.6. Equal-width columns show three full line boxes: a 16px font produces 25.6px lines; a 24px font produces 38.4px lines.

## caption \{#copy-caption\}

The children inherit a unitless 1.6 and use different font sizes. Tinted bands show complete line boxes, not the blank gaps between glyphs. The columns keep the same width.

## description-0 \{#copy-description-0\}

A common parent uses leading-md, whose preset value is the number 1.6.

## description-1 \{#copy-description-1\}

The first child uses font-md at a 16px root font size, giving 16px text and a 25.6px line height.

## description-2 \{#copy-description-2\}

The second child uses font-2xl, giving 24px text and a 38.4px line height. It inherits the same ratio rather than a fixed 25.6px length.

## description-3 \{#copy-description-3\}

Each column contains the same three lines. Colored bands are inspection annotations of the complete line boxes; they are not padding or gaps generated by leading-md.
