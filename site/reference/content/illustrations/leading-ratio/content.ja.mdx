# Reference prose: illustrations/leading-ratio

## title \{#copy-title\}


同じ比率を継承しても行の高さは異なる

## alt \{#copy-alt\}


2 つの子要素が leading-md、つまり 1.6 を継承します。等幅の列に完全な行ボックスを 3 つずつ示し、16px のフォントでは 25.6px、24px のフォントでは 38.4px の行の高さになります。

## caption \{#copy-caption\}


子要素は単位なしの 1.6 を継承し、異なるフォントサイズを使います。薄い色の帯が示すのは行ボックス全体であり、字形の間の空白ではありません。列の幅は同じです。

## description-0 \{#copy-description-0\}


共通の親要素は leading-md を使い、そのプリセット値は数値の 1.6 です。

## description-1 \{#copy-description-1\}


最初の子は、ルートのフォントサイズが 16px の状態で font-md を使い、テキストは 16px、行の高さは 25.6px になります。

## description-2 \{#copy-description-2\}


2 番目の子は font-2xl を使い、テキストは 24px、行の高さは 38.4px になります。継承するのは同じ比率であり、固定の 25.6px という長さではありません。

## description-3 \{#copy-description-3\}


各列には同じ 3 行のテキストが入っています。色付きの帯は行ボックス全体を確認する注記であり、leading-md が生成する padding や gap ではありません。
