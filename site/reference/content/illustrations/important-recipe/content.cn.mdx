# Reference prose: illustrations/important-recipe

## title \{#copy-title\}


重要性应用于配方内的每条声明

## alt \{#copy-alt\}


text-sm! 末尾的感叹号连接到 font-size、line-height 和 letter-spacing 的重要性标记。

## caption \{#copy-caption\}


末尾一个 ! 标记全部三条声明；省略号省去令牌引用。它不会将相邻 HTML 类或主题令牌定义标为重要。

## description-0 \{#copy-description-0\}


text-sm 使用主要令牌及伴随引用，写入 font-size、line-height 和 letter-spacing。

## description-1 \{#copy-description-1\}


text-sm! 将三条生成声明均标为 !important。依赖声明仍是普通主题令牌。
