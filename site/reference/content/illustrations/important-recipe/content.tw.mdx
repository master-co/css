# Reference prose: illustrations/important-recipe

## title \{#copy-title\}


重要性套用到組合樣式內每個宣告

## alt \{#copy-alt\}


text-sm! 末端的驚嘆號連到 font-size、line-height 與 letter-spacing 的重要性標記。

## caption \{#copy-caption\}


末端一個 ! 會標記全部三個宣告；省略號略去 token 參照。它不會將鄰近 HTML class 或主題 token 定義標為重要。

## description-0 \{#copy-description-0\}


text-sm 使用主要 token 與伴隨參照，寫入 font-size、line-height 與 letter-spacing。

## description-1 \{#copy-description-1\}


text-sm! 將三個生成宣告都標為 !important。相依宣告仍是一般主題 token。
