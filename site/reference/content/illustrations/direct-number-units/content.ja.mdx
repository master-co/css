# Reference prose: illustrations/direct-number-units

## title \{#copy-title\}


直接渡した数値はピクセル長か単位なしの係数になる

## alt \{#copy-alt\}


p(12) は内容ボックスの周囲に 12 ピクセルの内側余白を作ります。grow(1) と grow(2) は、基準サイズがともにゼロの同じ flex 行の空き空間を、1 対 2 で分配します。

## caption \{#copy-caption\}


左の数値はピクセル長になります。右の数値は flex 係数です。基準サイズをゼロにし、内容の最小サイズの制約をなくして、1:2 の分配だけを示しています。基準サイズや最小サイズが異なると、最終的な幅は変わり得ます。

## description-0 \{#copy-description-0\}


padding の例は実際の p(12) を適用し、内容と各外縁の間にちょうど 12px を設けます。青い注記で、その内側余白を示しています。

## description-1 \{#copy-description-1\}


flex の例は、幅 252px、gap 12px の行に、flex 基準サイズと最小幅がともにゼロの 2 項目を置き、それぞれ grow(1) と grow(2) を適用します。

## description-2 \{#copy-description-2\}


残りの 240px は 80px と 160px に分配されます。係数は引き続き単位なしであり、ピクセル幅ではありません。

## description-3 \{#copy-description-3\}


これらは条件を揃えた比較です。基準サイズがゼロでなかったり、内容の最小サイズがあったりすると、最終的な幅が拡張比率どおりになるとは限りません。各関数の宣言は記事に掲載しています。
