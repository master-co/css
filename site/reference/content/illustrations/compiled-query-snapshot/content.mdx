# Reference prose: illustrations/compiled-query-snapshot

## title \{#copy-title\}

A compiled complement already contains its expanded query

## alt \{#copy-alt\}

An authored max-md reference to md becomes a concrete 64rem complement in a compiled manifest. Changing only md to 60rem leaves that existing complement at 64rem.

## caption \{#copy-caption\}

This compares two definition-loading stages. It is not the behavior of compiling both authored definitions together.

## description-0 \{#copy-description-0\}

When --md and --max-md are compiled together, not (--md) expands using the matching minimum definition.

## description-1 \{#copy-description-1\}

A compiled manifest already contains the expanded query. Adding a new --md: 60rem definition does not re-expand the old --max-md complement of 64rem.

## description-2 \{#copy-description-2\}

Redeclare both names in a later configuration fragment when both ranges must move together.
