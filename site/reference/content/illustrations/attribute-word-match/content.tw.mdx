# Reference prose: illustrations/attribute-word-match

## title \{#copy-title\}


屬性值完全相等與單字比對不同

## alt \{#copy-alt\}


比較矩陣用完全相等與空白分詞比對，檢查 title 值 css、master css 與 css-in-js。

## caption \{#copy-caption\}


每列以兩個後綴檢查同一個 DOM 屬性值。連字號不構成以空白分隔的單字邊界。

## description-0 \{#copy-description-0\}


[title=css] 只符合恰為 css 的值。[title~=css] 則符合以空白分隔、且等於 css 的單字。

## description-1 \{#copy-description-1\}


兩個選擇器都符合 css。只有單字選擇器符合 master css。兩者都不符合 css-in-js。

## description-2 \{#copy-description-2\}


選擇器檢查屬性，不會分割 class 字串，也不會編輯屬性值。
