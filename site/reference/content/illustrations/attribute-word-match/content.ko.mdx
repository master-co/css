# Reference prose: illustrations/attribute-word-match

## title \{#copy-title\}


속성의 정확한 값과 단어 일치는 다름

## alt \{#copy-alt\}


비교 표가 title 값 css, master css, css-in-js에 대해 정확한 일치와 공백 단어 일치를 검사한다.

## caption \{#copy-caption\}


각 행은 같은 DOM 속성 값을 두 접미사로 검사합니다. 하이픈은 공백으로 구분하는 단어 경계가 아닙니다.

## description-0 \{#copy-description-0\}


[title=css]는 정확히 css인 값에만 일치합니다. [title~=css]는 공백으로 구분한 단어가 css와 같으면 일치합니다.

## description-1 \{#copy-description-1\}


css에는 두 선택자가 모두 일치합니다. master css에는 단어 선택자만 일치하며 css-in-js에는 둘 다 일치하지 않습니다.

## description-2 \{#copy-description-2\}


선택자는 속성을 검사하며 클래스 문자열을 나누거나 속성 값을 수정하지 않습니다.
