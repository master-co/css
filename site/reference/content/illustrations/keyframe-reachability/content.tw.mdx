# Reference prose: illustrations/keyframe-reachability

## title \{#copy-title\}


動畫名稱可在沒有 class 時保留定義

## alt \{#copy-alt\}


關鍵影格安全清單直接指向 reveal 定義。交付輸出包含關鍵影格，但沒有動畫宣告或 class 規則。

## caption \{#copy-caption\}


檔案啟用 @prune native。關鍵影格安全清單保留資源，不會啟動動畫。

## description-0 \{#copy-description-0\}


在含 @prune native 的檔案中，@safelist keyframes "reveal" 會保留相符的 @keyframes reveal 定義。

## description-1 \{#copy-description-1\}


輸出包含關鍵影格定義，但不會僅因安全清單就生成 class 或動畫宣告。

## description-2 \{#copy-description-2\}


仍需其他原生宣告或指令碼選取動畫。沒有該使用情況時，單純保留定義不會產生可見動畫效果。
