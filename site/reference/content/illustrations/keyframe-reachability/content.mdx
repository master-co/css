# Reference prose: illustrations/keyframe-reachability

## title \{#copy-title\}

An animation name can retain a definition without a class

## alt \{#copy-alt\}

A keyframe safelist points directly to a reveal definition. The delivered output contains keyframes, with no animation declaration or class rule.

## caption \{#copy-caption\}

The file opts into @prune native. A keyframe safelist retains a resource; it does not start an animation.

## description-0 \{#copy-description-0\}

In a file with @prune native, @safelist keyframes "reveal" retains the matching @keyframes reveal definition.

## description-1 \{#copy-description-1\}

The output contains the keyframe definition but no generated class or animation declaration solely because of this safelist.

## description-2 \{#copy-description-2\}

Another native declaration or script must select the animation. Without that use, retaining the definition alone has no visible animation effect.
