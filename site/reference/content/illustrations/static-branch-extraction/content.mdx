# Reference prose: illustrations/static-branch-extraction

## title \{#copy-title\}

Static alternatives are visible before a branch runs

## alt \{#copy-alt\}

Both literal arms of a conditional expression connect to extracted classes. A concatenation with a runtime tone ends at an unresolved fragment.

## caption \{#copy-caption\}

The two branches are source alternatives, not executed steps. Extraction neither predicts the chosen branch nor invents a concatenated class name.

## description-0 \{#copy-description-0\}

error ? "bg-red-60" : "bg-green-60" exposes both complete static class strings to extraction.

## description-1 \{#copy-description-1\}

"bg-" + tone does not expose a complete resulting class. The scanner does not infer the value of tone.

## description-2 \{#copy-description-2\}

Use complete alternatives for bounded choices, or a stable class with a dynamic CSS variable when the value itself is unbounded.
