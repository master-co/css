# Reference prose: illustrations/reading-measure

## title \{#copy-title\}


テキストの幅が変わると改行も変わる

## alt \{#copy-alt\}


同じ段落、文字サイズ、行の高さでも、176px と 304px の幅で行数が変わる。

## caption \{#copy-caption\}


変えるのは内容幅だけです。両段落は 14px の Geist と 24px の行の高さを使い、全文が収まる高さに伸びます。

## description-0 \{#copy-description-0\}


狭い幅は早く折り返すため同じ段落が高くなり、広い幅は 1 行に多くの単語を保ちます。

## description-1 \{#copy-description-1\}


両例とも固定の高さや省略したテキストはありません。構成を評価するときは文字サイズだけでなく実際の段落幅も確認してください。
