# Reference prose: illustrations/font-properties

## title \{#copy-title\}

The font prefix can change three independent properties

## alt \{#copy-alt\}

Three rows compare the same Field notes text with one baseline. A serif class changes the face, a larger size class changes the size, and a semibold class changes the weight.

## caption \{#copy-caption\}

Every row starts with font-sans, font-2xl and font-regular. The result replaces only the class for the named property. The available fonts determine the rendered faces.

## description-0 \{#copy-description-0\}

The baseline text uses the sans family, 1.5rem size and weight 400, with a 16px root font size.

## description-1 \{#copy-description-1\}

The font-serif row changes only font-family. The font-4xl row changes only font-size, to 2.25rem. The font-semibold row changes only font-weight, to 600.

## description-2 \{#copy-description-2\}

Each result uses the same words. A common unitless line-height of 1.5 keeps the samples readable; these font classes do not set line-height.

## description-3 \{#copy-description-3\}

The samples render real preset CSS with available system fonts. They do not imply that a family class downloads a font file.
