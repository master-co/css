# Reference prose: illustrations/font-properties

## title \{#copy-title\}


font 接頭辞は独立した 3 つのプロパティを変える

## alt \{#copy-alt\}


3 行で、同じ「Field notes」というテキストを共通の基準と比較します。serif のクラスは書体を、大きいサイズのクラスはサイズを、semibold のクラスはウェイトを変えます。

## caption \{#copy-caption\}


各行は font-sans、font-2xl、font-regular から始まり、結果では対象のプロパティのクラスだけを置き換えます。実際の書体は利用可能なフォントによって決まります。

## description-0 \{#copy-description-0\}


基準のテキストは sans ファミリー、1.5rem のサイズ、400 のウェイトを使い、ルートのフォントサイズは 16px です。

## description-1 \{#copy-description-1\}


font-serif の行は font-family だけを変えます。font-4xl の行は font-size だけを 2.25rem に変え、font-semibold の行は font-weight だけを 600 に変えます。

## description-2 \{#copy-description-2\}


各結果は同じ言葉を使います。共通の単位なしの line-height 1.5 で読みやすさを保っていますが、これらの font クラスが line-height を設定するわけではありません。

## description-3 \{#copy-description-3\}


見本は実際のプリセット CSS と利用可能なシステムフォントで描画しています。ファミリーのクラスがフォントファイルをダウンロードするという意味ではありません。
