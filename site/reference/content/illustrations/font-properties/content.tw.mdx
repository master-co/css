# Reference prose: illustrations/font-properties

## title \{#copy-title\}


font 前綴可改變三個獨立屬性

## alt \{#copy-alt\}


三列以同一個基準比較相同的 Field notes 文字。serif class 改變字型，較大尺寸的 class 改變大小，semibold class 則改變字重。

## caption \{#copy-caption\}


每列都從 font-sans、font-2xl 與 font-regular 開始，結果只替換指定屬性對應的 class。實際呈現的字型取決於可用字型。

## description-0 \{#copy-description-0\}


基準文字使用 sans 家族、1.5rem 大小與 400 字重，根元素字型大小為 16px。

## description-1 \{#copy-description-1\}


font-serif 列只改變 font-family。font-4xl 列只將 font-size 改為 2.25rem。font-semibold 列則只將 font-weight 改為 600。

## description-2 \{#copy-description-2\}


每個結果都使用相同文字，並共用無單位的 line-height 1.5，讓範例易於閱讀；這些 font class 本身不會設定 line-height。

## description-3 \{#copy-description-3\}


範例使用真正的預設 CSS 與可用的系統字型，不表示字型家族 class 會下載字型檔。
