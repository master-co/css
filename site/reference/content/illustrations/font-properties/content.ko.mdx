# Reference prose: illustrations/font-properties

## title \{#copy-title\}


font 접두사는 세 가지 독립 속성을 바꿀 수 있습니다

## alt \{#copy-alt\}


세 행이 같은 “Field notes” 문구를 하나의 기준과 비교합니다. serif 클래스는 글꼴을, 더 큰 크기 클래스는 크기를, semibold 클래스는 굵기를 바꿉니다.

## caption \{#copy-caption\}


각 행은 font-sans, font-2xl, font-regular에서 시작하며 결과에서는 지정된 속성의 클래스만 바꿉니다. 실제 표시되는 글꼴은 사용 가능한 글꼴에 따라 결정됩니다.

## description-0 \{#copy-description-0\}


기준 텍스트는 sans 계열, 1.5rem 크기, 400 굵기를 사용하며 루트 글꼴 크기는 16px입니다.

## description-1 \{#copy-description-1\}


font-serif 행은 font-family만 바꿉니다. font-4xl 행은 font-size만 2.25rem으로, font-semibold 행은 font-weight만 600으로 바꿉니다.

## description-2 \{#copy-description-2\}


각 결과는 같은 문구를 사용합니다. 공통으로 단위 없는 line-height 1.5를 지정해 읽기 쉽게 했으며, 이 font 클래스들이 line-height를 설정하는 것은 아닙니다.

## description-3 \{#copy-description-3\}


견본은 실제 프리셋 CSS와 사용 가능한 시스템 글꼴로 렌더링합니다. 글꼴 계열 클래스가 글꼴 파일을 다운로드한다는 뜻은 아닙니다.
