# Reference prose: illustrations/font-properties

## title \{#copy-title\}


font 前缀可改变三个独立属性

## alt \{#copy-alt\}


三行以同一个基准比较相同的 Field notes 文本。serif 类改变字体，较大尺寸的类改变字号，semibold 类则改变字重。

## caption \{#copy-caption\}


每行都从 font-sans、font-2xl 和 font-regular 开始，结果只替换指定属性对应的类。实际呈现的字体取决于可用字体。

## description-0 \{#copy-description-0\}


基准文本使用 sans 字体族、1.5rem 大小和 400 字重，根元素字号为 16px。

## description-1 \{#copy-description-1\}


font-serif 行只改变 font-family。font-4xl 行只将 font-size 改为 2.25rem。font-semibold 行则只将 font-weight 改为 600。

## description-2 \{#copy-description-2\}


每个结果都使用相同文本，并共享无单位的 line-height 1.5 以便阅读；这些 font 类本身不会设置 line-height。

## description-3 \{#copy-description-3\}


示例使用实际的预设 CSS 和可用系统字体，并不表示字体族类会下载字体文件。
