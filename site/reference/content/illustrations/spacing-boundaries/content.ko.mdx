# Reference prose: illustrations/spacing-boundaries

## title \{#copy-title\}


padding은 콘텐츠를 둘러싸고 gap은 항목을 분리합니다

## alt \{#copy-alt\}


같은 spacing-md 토큰을 두 Grid 예제에 사용합니다. padding 예제는 바깥 가장자리 안쪽의 띠를 강조하고, gap 예제는 두 행 사이의 공간만 강조합니다.

## caption \{#copy-caption\}


강조된 두 거리는 모두 1rem이며 루트 글꼴 크기 16px를 기준으로 표시합니다. 파란색과 보라색은 확인용 오버레이이며 p-md와 gap-md가 추가하는 색상이 아닙니다.

## description-0 \{#copy-description-0\}


두 예제 모두 Grid와 프리셋 --spacing-md 값인 1rem을 사용합니다. 콘텐츠 행은 같은 타이포그래피와 내부 치수를 사용합니다.

## description-1 \{#copy-description-1\}


왼쪽 예제에는 p-md가 있고 gap은 없습니다. 파란색 띠는 상자 가장자리 안쪽에서 콘텐츠의 네 면을 둘러쌉니다.

## description-2 \{#copy-description-2\}


오른쪽 예제에는 gap-md가 있고 padding은 없습니다. 보라색 띠는 두 행 사이에만 있으며 바깥쪽에는 같은 띠가 없습니다.

## description-3 \{#copy-description-3\}


그림의 루트 글꼴 크기는 16px이므로 강조된 각 거리는 16px입니다. 예제는 실제로 생성한 padding과 gap을 사용하지만 주석 색상과 점선 경계는 유틸리티 출력이 아닙니다.
