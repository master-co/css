# Reference prose: illustrations/spacing-boundaries

## title \{#copy-title\}


padding 包围内容，gap 分隔项目

## alt \{#copy-alt\}


同一个 spacing-md 令牌提供给两个 Grid 示例。padding 示例标示外缘内侧的一圈区域，gap 示例则只标示两行之间的空间。

## caption \{#copy-caption\}


两个标示的距离都是 1rem，以 16px 的根元素字号呈现。蓝色和紫色是检查用的叠加标注，p-md 与 gap-md 不会添加这些颜色。

## description-0 \{#copy-description-0\}


两个示例都使用 Grid，以及预设的 --spacing-md 值 1rem。内容行的文字排版与内部尺寸相同。

## description-1 \{#copy-description-1\}


左侧示例使用 p-md，没有 gap。蓝色区域位于盒子边缘内侧，从四个方向包围内容。

## description-2 \{#copy-description-2\}


右侧示例使用 gap-md，没有 padding。紫色区域只位于两行之间，外围没有对应的区域。

## description-3 \{#copy-description-3\}


图中根元素字号为 16px，因此每个标示距离都是 16px。示例使用实际生成的 padding 与 gap，但标注颜色和虚线边界不是工具类的输出。
