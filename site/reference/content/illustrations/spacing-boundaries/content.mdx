# Reference prose: illustrations/spacing-boundaries

## title \{#copy-title\}

Padding surrounds content; gap separates items

## alt \{#copy-alt\}

The same spacing-md token feeds two Grid examples. The padding example highlights a band inside the outer edge. The gap example highlights only the space between two rows.

## caption \{#copy-caption\}

Both highlighted distances are 1rem, shown at a 16px root font size. Blue and violet are inspection overlays; p-md and gap-md do not add those colors.

## description-0 \{#copy-description-0\}

Both examples use Grid and the preset --spacing-md value of 1rem. Their content rows use the same typography and internal dimensions.

## description-1 \{#copy-description-1\}

The left example has p-md and no gap. Its blue band lies inside the box edge, surrounding the content on all four sides.

## description-2 \{#copy-description-2\}

The right example has gap-md and no padding. Its violet band lies only between the two rows, with no matching band around the outside.

## description-3 \{#copy-description-3\}

At the depicted 16px root font size, each highlighted distance is 16px. The examples use real generated padding and gap; the annotation colors and dashed boundaries are not utility output.
