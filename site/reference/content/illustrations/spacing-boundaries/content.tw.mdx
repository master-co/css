# Reference prose: illustrations/spacing-boundaries

## title \{#copy-title\}


padding 圍住內容，gap 隔開項目

## alt \{#copy-alt\}


同一個 spacing-md token 提供給兩個 Grid 範例。padding 範例標示出外緣內側的一圈區域，gap 範例則只標示兩列之間的空間。

## caption \{#copy-caption\}


兩個標示的距離都是 1rem，以 16px 的根元素字型大小呈現。藍色與紫色是檢查用的疊加標註，p-md 與 gap-md 不會加入這些色彩。

## description-0 \{#copy-description-0\}


兩個範例都使用 Grid，以及預設的 --spacing-md 值 1rem。內容列的文字排版與內部尺寸相同。

## description-1 \{#copy-description-1\}


左側範例使用 p-md，沒有 gap。藍色區帶位於盒子邊緣內側，從四個方向圍住內容。

## description-2 \{#copy-description-2\}


右側範例使用 gap-md，沒有 padding。紫色區帶只位於兩列之間，外圍沒有對應的區帶。

## description-3 \{#copy-description-3\}


圖中根元素字型大小為 16px，因此每個標示距離都是 16px。範例使用真正生成的 padding 與 gap，但標註色彩與虛線邊界不是 utility 的輸出。
