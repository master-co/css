# Reference prose: illustrations/spacing-boundaries

## title \{#copy-title\}


padding は内容を囲み、gap は項目を隔てる

## alt \{#copy-alt\}


同じ spacing-md トークンを 2 つの Grid の例で使っています。padding の例は外縁の内側を帯で示し、gap の例は 2 行の間の空間だけを示します。

## caption \{#copy-caption\}


強調した 2 つの距離はどちらも 1rem で、ルートのフォントサイズを 16px として表示しています。青と紫は確認用のオーバーレイであり、p-md や gap-md が追加する色ではありません。

## description-0 \{#copy-description-0\}


両方の例は Grid と、プリセットの --spacing-md の値 1rem を使います。内容の行には同じタイポグラフィと内部寸法を使っています。

## description-1 \{#copy-description-1\}


左の例は p-md を使い、gap はありません。青の帯はボックスの縁の内側にあり、内容を四方から囲んでいます。

## description-2 \{#copy-description-2\}


右の例は gap-md を使い、padding はありません。紫の帯は 2 行の間にだけあり、外周には同じ帯がありません。

## description-3 \{#copy-description-3\}


図のルートのフォントサイズは 16px なので、強調した各距離は 16px です。例には実際に生成した padding と gap を使いますが、注記の色と破線の境界はユーティリティの出力ではありません。
