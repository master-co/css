# Reference prose: illustrations/independent-registrations

## title \{#copy-title\}


靜態名稱與函式各自獨立註冊

## alt \{#copy-alt\}


兩條獨立路徑將 badge 連到 display 定義，將 badge(8px) 連到 padding 函式。靜態路徑的取代不會跨到函式路徑。

## caption \{#copy-caption\}


路徑表達註冊身分。名稱相同不會讓兩個定義變成多載或合併本體。

## description-0 \{#copy-description-0\}


@utility badge \{ display: inline-block; \} 註冊靜態 badge class。@utility badge(--inset) \{ padding: var(--inset); \} 註冊獨立函式。

## description-1 \{#copy-description-1\}


將靜態定義改為 display: block 會改變 badge，但 badge(8px) 仍寫入 padding: 8px。

## description-2 \{#copy-description-2\}


取代影響的是同形式、同名稱的完整本體。函式不是靜態 class 的備援。
