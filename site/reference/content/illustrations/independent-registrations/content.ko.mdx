# Reference prose: illustrations/independent-registrations

## title \{#copy-title\}


정적 이름과 함수는 별도 등록

## alt \{#copy-alt\}


두 독립 경로가 badge를 display 정의에, badge(8px)를 padding 함수에 연결한다. 정적 경로의 교체는 함수 경로로 넘어가지 않는다.

## caption \{#copy-caption\}


경로는 등록의 정체성을 나타냅니다. 이름이 같아도 두 정의가 오버로드나 병합 본문이 되지 않습니다.

## description-0 \{#copy-description-0\}


@utility badge \{ display: inline-block; \}는 정적 badge 클래스를 등록합니다. @utility badge(--inset) \{ padding: var(--inset); \}는 별도 함수를 등록합니다.

## description-1 \{#copy-description-1\}


정적 정의를 display: block으로 교체하면 badge가 바뀌지만 badge(8px)는 여전히 padding: 8px를 작성합니다.

## description-2 \{#copy-description-2\}


교체는 같은 형식과 이름의 전체 본문에 영향을 줍니다. 함수는 정적 클래스의 대체 경로가 아닙니다.
