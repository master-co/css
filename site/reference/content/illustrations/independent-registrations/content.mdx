# Reference prose: illustrations/independent-registrations

## title \{#copy-title\}

A static name and a function are separate registrations

## alt \{#copy-alt\}

Two independent lanes connect badge to a display definition and badge(8px) to a padding function. A replacement on the static lane does not cross into the function lane.

## caption \{#copy-caption\}

The lanes encode registration identity. Equal names do not make the two definitions overloads or a merged body.

## description-0 \{#copy-description-0\}

@utility badge \{ display: inline-block; \} registers the static badge class. @utility badge(--inset) \{ padding: var(--inset); \} registers a separate function.

## description-1 \{#copy-description-1\}

Replacing the static definition with display: block changes badge, while badge(8px) still writes padding: 8px.

## description-2 \{#copy-description-2\}

Replacement affects the complete body of the same form and name. The function is not a fallback for the static class.
