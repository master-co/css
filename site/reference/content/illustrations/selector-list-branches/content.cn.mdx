# Reference prose: illustrations/selector-list-branches

## title \{#copy-title\}


选择器列表从类所属元素重新开始

## alt \{#copy-alt\}


同一个类所属元素分出两条分支，分别到 hover 与 focus-visible，两者均指向同一下划线声明。

## caption \{#copy-caption\}


逗号分隔不同选项。每个选择器均从带有类的元素开始；任一状态均可匹配。

## description-0 \{#copy-description-0\}


underline:hover,:focus-visible 生成选择器列表，每条分支均重复完整且已转义的类所属元素选择器。

## description-1 \{#copy-description-1\}


hover 与 focus-visible 是可选状态，不要求同时匹配。两条分支共用声明。
