# Reference prose: illustrations/selector-list-branches

## title \{#copy-title\}


選擇器清單從 class 所屬元素重新起算

## alt \{#copy-alt\}


同一個 class 所屬元素分出兩條分支，分別到 hover 與 focus-visible，兩者都指向相同的底線宣告。

## caption \{#copy-caption\}


逗號分隔不同選項。每個選擇器都從帶有 class 的元素開始；任一狀態皆可符合。

## description-0 \{#copy-description-0\}


underline:hover,:focus-visible 生成選擇器清單，每個分支都重複完整、跳脫後的 class 所屬元素選擇器。

## description-1 \{#copy-description-1\}


hover 與 focus-visible 是可擇一的狀態，不要求同時符合。兩條分支共用宣告。
