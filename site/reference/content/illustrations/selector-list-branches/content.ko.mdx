# Reference prose: illustrations/selector-list-branches

## title \{#copy-title\}


선택자 목록은 클래스 소유 요소에서 다시 시작

## alt \{#copy-alt\}


하나의 클래스 소유 요소에서 hover와 focus-visible로 두 분기가 나뉘어 같은 밑줄 선언으로 이어진다.

## caption \{#copy-caption\}


쉼표는 대안을 구분합니다. 각 선택자는 클래스를 가진 요소에서 시작하며 어느 상태든 일치할 수 있습니다.

## description-0 \{#copy-description-0\}


underline:hover,:focus-visible은 각 분기에서 전체 이스케이프 클래스 소유 요소를 반복하는 선택자 목록을 생성합니다.

## description-1 \{#copy-description-1\}


hover와 focus-visible은 대안이며 두 상태에 모두 일치할 필요는 없습니다. 두 분기는 선언을 공유합니다.
