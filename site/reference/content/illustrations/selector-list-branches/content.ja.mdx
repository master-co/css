# Reference prose: illustrations/selector-list-branches

## title \{#copy-title\}


セレクターリストはクラスの起点から分岐

## alt \{#copy-alt\}


1 つのクラスの起点から hover と focus-visible の 2 分岐が伸び、同じ下線の宣言につながる。

## caption \{#copy-caption\}


カンマは選択肢を区切ります。各セレクターはクラスを持つ要素から始まり、どちらかの状態に一致すれば適用されます。

## description-0 \{#copy-description-0\}


underline:hover,:focus-visible はセレクターリストを生成し、各分岐で完全にエスケープされた起点のクラスを繰り返します。

## description-1 \{#copy-description-1\}


hover と focus-visible は選択肢であり、両状態への一致は不要です。宣言は両分岐で共有します。
