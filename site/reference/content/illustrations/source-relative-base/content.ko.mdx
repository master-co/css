# Reference prose: illustrations/source-relative-base

## title \{#copy-title\}


소스 경로는 선언한 스타일시트에서 시작합니다

## alt \{#copy-alt\}


가져온 styles/shared.css가 ./views/*.html을 선언하고 styles/views를 가리킵니다. 애플리케이션의 작업 디렉터리는 별도로 표시됩니다.

## caption \{#copy-caption\}


트리는 하나의 파일 시스템을 보여 줍니다. apps/shop에서 스타일시트를 가져와도 작성된 @source 패턴의 기준이 해당 앱으로 바뀌지 않습니다.

## description-0 \{#copy-description-0\}


저장소에는 styles/shared.css와 styles/views/card.html이 있습니다. shared.css는 @source "./views/*.html"을 선언합니다.

## description-1 \{#copy-description-1\}


상대 패턴은 styles/shared.css를 기준으로 해석하므로 사용하는 앱이 apps/shop에서 실행되어도 styles/views/card.html을 포함합니다.

## description-2 \{#copy-description-2\}


스캐너에 프로그램으로 별도 전달하는 cwd 옵션에는 고유한 계약이 있습니다. 이 그림은 CSS에 작성한 지시문을 설명합니다.
