# Reference prose: illustrations/span-includes-gaps

## title \{#copy-title\}


跨列项目包含轨道间距

## alt \{#copy-alt\}


三个 96px 列之间有 16px 间距。一个项目跨越前两列，宽度为 208px。

## caption \{#copy-caption\}


320px 网格使用 grid-cols(3)、gap(16) 和 grid-col-span(2)。标尺呈现实际 CSS 几何尺寸，并非任意比例。

## description-0 \{#copy-description-0\}


可用宽度为 320px。扣除两个 16px 间距后，288px 平分给三条 96px 轨道。

## description-1 \{#copy-description-1\}


跨两条轨道的项目覆盖 96px + 16px + 96px，即 208px。它与第三条轨道之间仍保留下一个 16px 间距。

## description-2 \{#copy-description-2\}


改变列数可能改变轨道宽度；请在同一断点一并更新相关跨度。
