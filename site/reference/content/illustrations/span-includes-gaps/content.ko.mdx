# Reference prose: illustrations/span-includes-gaps

## title \{#copy-title\}


여러 트랙을 차지하는 항목은 간격도 포함

## alt \{#copy-alt\}


96px 열 세 개 사이에 16px 간격이 있다. 항목 하나가 처음 두 열을 차지하여 너비가 208px가 된다.

## caption \{#copy-caption\}


320px 그리드는 grid-cols(3), gap(16), grid-col-span(2)를 사용합니다. 눈금은 임의 척도가 아닌 실제 CSS 기하를 보여 줍니다.

## description-0 \{#copy-description-0\}


가용 너비는 320px입니다. 16px 간격 두 개를 빼면 288px가 같은 96px 트랙 세 개에 배분됩니다.

## description-1 \{#copy-description-1\}


두 트랙을 차지하는 항목은 96px + 16px + 96px, 즉 208px를 덮습니다. 세 번째 트랙과의 사이에는 다음 16px 간격이 남습니다.

## description-2 \{#copy-description-2\}


열 수를 바꾸면 트랙 너비도 바뀔 수 있으므로 관련 스팬을 같은 중단점에서 갱신하세요.
