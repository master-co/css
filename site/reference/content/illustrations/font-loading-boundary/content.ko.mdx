# Reference prose: illustrations/font-loading-boundary

## title \{#copy-title\}


글꼴 계열 지정에도 사용 가능한 글꼴이 필요

## alt \{#copy-alt\}


하나의 font-family 요청이 지정한 글꼴을 사용할 수 있으면 해당 글꼴로, 없으면 serif 대체 글꼴로 분기한다.

## caption \{#copy-caption\}


예시는 두 가용성 경우를 보여 주며 측정한 다운로드 타임라인이 아닙니다. 지정 글꼴은 불러온 Geist 파일로, 대체 글꼴은 브라우저의 serif로 표현합니다.

## description-0 \{#copy-description-0\}


font-family 선언은 순서 있는 선호도를 지정하며 자체적으로 글꼴을 다운로드하지 않습니다.

## description-1 \{#copy-description-1\}


일치하는 글꼴을 사용할 수 있으면 텍스트를 렌더링하고 없으면 브라우저가 다음 계열을 시도합니다. 글리프 지원 범위도 중요하므로 한 줄의 다른 문자가 다른 글꼴을 사용할 수 있습니다.

## description-2 \{#copy-description-2\}


웹 글꼴은 @font-face나 공급자 스타일시트로 불러오고 계산된 font-family 문자열만 보지 말고 실제 렌더링 글꼴을 검사하세요.
