# Reference prose: illustrations/pruning-global-selectors

## title \{#copy-title\}


네이티브 가지치기는 클래스 없는 규칙을 유지

## alt \{#copy-alt\}


card를 사용하면 body와 root 규칙이 card와 함께 남고 사용하지 않은 클래스 규칙은 지워진다.

## caption \{#copy-caption\}


소스는 @prune native를 활성화합니다. 유지된 클래스 없는 선택자도 일반 CSS 일치와 캐스케이드 규칙을 따릅니다.

## description-0 \{#copy-description-0\}


body와 :root에는 클래스 선택자가 없으므로 네이티브 가지치기가 규칙을 유지합니다.

## description-1 \{#copy-description-1\}


이 예제에서는 사용하는 .card 규칙은 남고 사용하지 않는 .unused 클래스 규칙은 제거됩니다.

## description-2 \{#copy-description-2\}


네이티브 가지치기는 클래스 사용에 기반하며 브라우저로 모든 선택자를 분석하거나 유지한 모든 규칙이 현재 일치한다고 보장하지 않습니다.
