# Reference prose: illustrations/logical-inline-axis

## title \{#copy-title\}


行內內距依書寫模式調整

## alt \{#copy-alt\}


px(16) 在橫書中產生左右內距，在直書中則產生上下內距。

## caption \{#copy-caption\}


兩個正方形內容框尺寸相同。色帶標示實際 16px 的 padding-inline 區域。

## description-0 \{#copy-description-0\}


px(16) 輸出 padding-inline: calc(16 * 1px)。在 horizontal-tb 中，兩側內距位於左、右。

## description-1 \{#copy-description-1\}


在 vertical-rl 中，行內軸為垂直方向，因此相同 class 將內距放在上、下。

## description-2 \{#copy-description-2\}


Master CSS 的 x、y 名稱指行內軸與區塊軸。實體 t、r、b、l 名稱則保留實體方向。
