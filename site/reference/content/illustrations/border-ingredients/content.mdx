# Reference prose: illustrations/border-ingredients

## title \{#copy-title\}

A line color needs a width and a style

## alt \{#copy-alt\}

Three matched boxes add border color, then a two-pixel width, then solid style. Only the third paints a border.

## caption \{#copy-caption\}

All boxes start with border-style: none. The specimens share their border-box size; only the listed border declarations change.

## description-0 \{#copy-description-0\}

b-line-divider supplies border-color, and b(2) supplies border-width. Neither changes a none border style.

## description-1 \{#copy-description-1\}

Adding b-solid allows the 2px border to paint. A border can inherit other authored prerequisites from a component, so inspect the complete style when only a color class is shown.
