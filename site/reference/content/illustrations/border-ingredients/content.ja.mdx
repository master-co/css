# Reference prose: illustrations/border-ingredients

## title \{#copy-title\}


線の色には太さとスタイルが必要

## alt \{#copy-alt\}


同じ 3 ボックスに枠線の色、2 ピクセルの太さ、実線スタイルを順に加え、3 番目だけが枠線を描く。

## caption \{#copy-caption\}


全ボックスは border-style: none から始まります。border-box のサイズは同じで、記載した枠線宣言だけが変わります。

## description-0 \{#copy-description-0\}


b-line-divider は border-color、b(2) は border-width を設定します。どちらも none の枠線スタイルは変えません。

## description-1 \{#copy-description-1\}


b-solid を加えると 2px の枠線を描けます。必要な他の指定がコンポーネントにある場合もあるため、色クラスだけが見える場合はスタイル全体を確認してください。
