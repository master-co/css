# Reference prose: illustrations/border-ingredients

## title \{#copy-title\}


邊框色彩需要寬度與樣式搭配

## alt \{#copy-alt\}


三個相同方框依序加入邊框色彩、兩像素寬度與實線樣式。只有第三個畫出邊框。

## caption \{#copy-caption\}


所有方框起始皆為 border-style: none。範例的 border-box 尺寸相同，只改變所列邊框宣告。

## description-0 \{#copy-description-0\}


b-line-divider 提供 border-color，b(2) 提供 border-width。兩者都不會改變 none 的邊框樣式。

## description-1 \{#copy-description-1\}


加入 b-solid 後，2px 邊框才會畫出。邊框可沿用元件中其他已撰寫的必要條件，因此只看到色彩 class 時，請檢查完整樣式。
