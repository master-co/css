# Reference prose: illustrations/border-ingredients

## title \{#copy-title\}


边框颜色需要宽度与样式配合

## alt \{#copy-alt\}


三个相同方框依次加入边框颜色、两像素宽度和实线样式。仅第三个绘制边框。

## caption \{#copy-caption\}


所有方框初始均为 border-style: none。示例的 border-box 尺寸相同，仅改变所列边框声明。

## description-0 \{#copy-description-0\}


b-line-divider 提供 border-color，b(2) 提供 border-width。两者均不改变 none 的边框样式。

## description-1 \{#copy-description-1\}


加入 b-solid 后才会绘制 2px 边框。边框可沿用组件中其他已编写的必要条件，因此仅看到颜色类时请检查完整样式。
