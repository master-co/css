# Reference prose: illustrations/pseudo-element-origin

## title \{#copy-title\}

Generated content belongs to the pseudo-elements

## alt \{#copy-alt\}

A single span’s rendered line has an opening quote in before, its text in the middle, and a closing quote in after.

## caption \{#copy-caption\}

Quotes are generated by real ::before and ::after content declarations. The three brackets identify parts of one rendered element, not three DOM children.

## description-0 \{#copy-description-0\}

The span contains the text Keep the interface clear. Its (content:open-quote)::before and (content:close-quote)::after classes supply the visible quote marks.

## description-1 \{#copy-description-1\}

Each declaration targets its pseudo-element. Master CSS does not create separate child elements or add a content declaration just because a pseudo-element suffix is present.
