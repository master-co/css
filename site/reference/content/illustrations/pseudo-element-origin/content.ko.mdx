# Reference prose: illustrations/pseudo-element-origin

## title \{#copy-title\}


생성 콘텐츠는 의사 요소에 속함

## alt \{#copy-alt\}


하나의 span 렌더링 줄에 before의 여는 인용부호, 가운데 텍스트, after의 닫는 인용부호가 있다.

## caption \{#copy-caption\}


인용부호는 실제 ::before와 ::after의 content 선언이 생성합니다. 세 괄호는 하나의 렌더링 요소의 부분을 나타내며 DOM 자식 세 개가 아닙니다.

## description-0 \{#copy-description-0\}


span은 Keep the interface clear 텍스트를 포함합니다. (content:open-quote)::before와 (content:close-quote)::after 클래스가 보이는 인용부호를 제공합니다.

## description-1 \{#copy-description-1\}


각 선언은 해당 의사 요소를 대상으로 합니다. Master CSS는 별도 자식 요소를 만들거나 의사 요소 접미사가 있다는 이유만으로 content 선언을 추가하지 않습니다.
