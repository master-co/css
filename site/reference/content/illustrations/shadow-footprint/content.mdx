# Reference prose: illustrations/shadow-footprint

## title \{#copy-title\}

Shadow paint does not reserve layout space

## alt \{#copy-alt\}

Identical surfaces use shadow-xs and shadow-xl. Their box edges and following elements align at the same heights, while the larger shadow extends farther into the surrounding space.

## caption \{#copy-caption\}

The surfaces keep identical geometry and a 16px gap to the next element. Only the shadow token changes. Rulers measure the gap between boxes, not the shadow’s visible edge.

## labels-title \{#copy-labels-title\}

One surface

## description-0 \{#copy-description-0\}

Both columns contain the same surface and following element. Their dimensions, padding and 16px layout gap are identical.

## description-1 \{#copy-description-1\}

The left surface uses the preset shadow-xs token. The right surface uses shadow-xl, which paints more layers over a wider area.

## description-2 \{#copy-description-2\}

The next element starts at the same height in both columns. Box shadows do not change the dimensions or spacing used by layout.

## description-3 \{#copy-description-3\}

Both shadows use actual preset values. Their colors adapt to the image’s scheme while their offsets, blur and spread lengths remain unchanged. Gap rulers are inspection annotations.
