# Reference prose: illustrations/sibling-direction

## title \{#copy-title\}


同層選擇器從所屬元素向後選取

## alt \{#copy-alt\}


兩排相同的同層元素比較 +a 選取下一個連結，以及 ~a 選取後方兩個連結。前方的連結未被選取。

## caption \{#copy-caption\}


每排所有節點具有同一個父元素。外框標出的所屬元素帶有 class；底線標示被選取的連結。

## description-0 \{#copy-description-0\}


同層順序為連結 A、帶有 class 的元素、連結 B、連結 C。

## description-1 \{#copy-description-1\}


underline+a 選取下一個同層元素 B。underline~a 選取後方的同層連結 B 與 C。

## description-2 \{#copy-description-2\}


兩個選擇器都不會選取前方的同層元素 A。若下一個元素不是連結，+a 就不會選取任何元素。
