# Reference prose: illustrations/sibling-direction

## title \{#copy-title\}


兄弟セレクターは起点より後を選ぶ

## alt \{#copy-alt\}


同じ兄弟要素の 2 行で、+a が次のリンクを、~a が後続の 2 つのリンクを選ぶ様子を比較する。前のリンクは選ばれない。

## caption \{#copy-caption\}


各行の全ノードは同じ親を持ちます。輪郭付きの起点要素がクラスを持ち、下線は選択されたリンクです。

## description-0 \{#copy-description-0\}


兄弟の順序はリンク A、クラスを持つ要素、リンク B、リンク C です。

## description-1 \{#copy-description-1\}


underline+a は次の兄弟要素 B を、underline~a は後続の兄弟リンク B と C を選びます。

## description-2 \{#copy-description-2\}


どちらも前の兄弟 A は選びません。次の要素がリンクでなければ、+a は何も選びません。
