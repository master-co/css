# Reference prose: illustrations/sibling-direction

## title \{#copy-title\}

Sibling selectors look forward from the owner

## alt \{#copy-alt\}

Two identical sibling rows compare the next link selected by +a with both later links selected by ~a. An earlier link stays unselected.

## caption \{#copy-caption\}

Every node in a row has the same parent. The outlined owner carries the class; underlines identify the selected links.

## description-0 \{#copy-description-0\}

The sibling order is link A, the class-bearing element, link B and link C.

## description-1 \{#copy-description-1\}

underline+a selects B, the next element sibling. underline~a selects B and C, the later sibling links.

## description-2 \{#copy-description-2\}

Neither selector selects earlier sibling A. If the next element were not a link, +a would select nothing.
