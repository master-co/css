# Reference prose: illustrations/condition-eligibility

## title \{#copy-title\}


쿼리가 일치하면 규칙이 적용 후보가 됩니다

## alt \{#copy-alt\}


같은 컴파일된 미디어 규칙이 두 뷰포트 경우와 연결됩니다. 임계값 미만에서는 비활성이고 임계값에 도달하면 캐스케이드에 참여합니다.

## caption \{#copy-caption\}


컴파일러는 두 브라우저 경우를 평가하기 전에 쿼리를 출력합니다. 쿼리가 일치해도 캐스케이드에서 우선한다고 보장되지는 않습니다.

## description-0 \{#copy-description-0\}


grid@media(width>=40rem)는 현재 뷰포트를 확인하지 않고 display: grid가 들어 있는 @media 규칙을 출력합니다.

## description-1 \{#copy-description-1\}


39rem에서는 브라우저가 규칙을 적용하지 않습니다. 40rem에서는 조건이 일치해 선언이 캐스케이드에 참여합니다.

## description-2 \{#copy-description-2\}


최종 display 값은 다른 캐스케이드 규칙이 결정할 수도 있습니다. 컴파일, 쿼리 매칭, 최종 계산 스타일은 서로 다른 확인 항목입니다.
