# Reference prose: illustrations/contents-insertion

## title \{#copy-title\}


ラッパーが呼び出し元の宣言を配置

## alt \{#copy-alt\}


is-hover-or-focus-visible セレクター内の contents スロットに、underline クラスの text-decoration-line: underline を挿入する。

## caption \{#copy-caption\}


強調したスロットと挿入宣言はセレクターの境界内の同じ位置です。ラッパーが宣言の適用先を制御します。

## description-0 \{#copy-description-0\}


@mixin --hocus \{ &:is(:hover, :focus-visible) \{ @contents; \} \} は明示的な contents スロットを持つセレクターラッパーを定義します。

## description-1 \{#copy-description-1\}


underline@apply(--hocus) は text-decoration-line: underline をスロットに渡します。出力規則はどちらの状態でも起点の要素に一致します。

## description-2 \{#copy-description-2\}


位置を読みやすくするため、図の結果はエスケープされた起点クラスを & と略記します。生成 CSS は完全な起点を保持します。
