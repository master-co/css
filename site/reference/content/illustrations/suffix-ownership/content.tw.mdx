# Reference prose: illustrations/suffix-ownership

## title \{#copy-title\}


後綴屬於一個完整 class

## alt \{#copy-alt\}


拆解 p(12):hover@sm!，旁邊另有獨立的圓角 class。

## caption \{#copy-caption\}


括弧對應精確的字元範圍。空白結束第一個 class；它的狀態、條件與重要性不會延伸到 r-md。

## description-0 \{#copy-description-0\}


p(12) 提供內距。:hover 檢查帶有 class 的元素，@sm 將規則限制於具名媒體條件，結尾 ! 將其宣告標為重要。

## description-1 \{#copy-description-1\}


獨立的 r-md class 不含這些後綴。沒有 hover 或 sm 條件也能套用，且宣告不具重要性。
