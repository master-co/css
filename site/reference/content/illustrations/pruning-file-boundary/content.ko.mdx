# Reference prose: illustrations/pruning-file-boundary

## title \{#copy-title\}


가지치기 지시문은 파일 경계에서 멈춤

## alt \{#copy-alt\}


app.css는 가지치기를 활성화하고 cards.css를 가져온다. local만 사용된다. 사용하지 않는 로컬 규칙은 제거되고 참여하지 않은 cards.css의 두 규칙은 남는다.

## caption \{#copy-caption\}


이 컴파일은 local만 사용합니다. app.css는 활성화하고 cards.css는 하지 않습니다. cards.css를 가져와도 가지치기 지시문은 전달되지 않습니다.

## description-0 \{#copy-description-0\}


app.css는 @prune native를 포함하고 cards.css를 가져오며 .local과 .unused-local을 정의합니다. 사용하는 클래스는 local뿐입니다.

## description-1 \{#copy-description-1\}


출력은 .local을 유지하고 .unused-local을 제거합니다.

## description-2 \{#copy-description-2\}


cards.css는 가지치기나 보존 지시문을 선언하지 않습니다. 두 클래스 모두 사용하지 않아도 기본 정책이 .card와 .unused-card를 유지합니다.

## description-3 \{#copy-description-3\}


프로젝트 전체 pruneNativeCSS 옵션은 프로젝트 파일을 별도로 참여시킬 수 있습니다. @preserve native는 자신의 파일 안에서 우선합니다. 이 예제는 명시적인 파일별 정책만 보여 줍니다.
