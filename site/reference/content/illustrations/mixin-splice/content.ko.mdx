# Reference prose: illustrations/mixin-splice

## title \{#copy-title\}


믹스인은 호출 위치에서 확장

## alt \{#copy-alt\}


네이티브 caption 규칙의 강조된 apply 줄을 두 강조 선언이 대체하며 앞뒤의 color와 font-weight 줄은 유지된다.

## caption \{#copy-caption\}


삽입 앞뒤의 같은 줄은 정렬된 상태입니다. 선택자, 선언 순서, 바깥 레이어는 호출자의 것으로 유지됩니다.

## description-0 \{#copy-description-0\}


--caption 믹스인은 font-size: 14px와 line-height: 1.5를 제공합니다.

## description-1 \{#copy-description-1\}


.caption 안의 @apply --caption은 color: currentColor와 font-weight: 600 사이에서 확장됩니다.

## description-2 \{#copy-description-2\}


확장은 클래스를 등록하거나 네이티브 규칙을 생성 레이어로 옮기지 않습니다. 중복 선언과 작성 순서를 유지합니다.
