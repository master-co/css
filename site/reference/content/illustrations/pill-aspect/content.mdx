# Reference prose: illustrations/pill-aspect

## title \{#copy-title\}

The same pill radius follows the box shape

## alt \{#copy-alt\}

A 64 by 64 box becomes a circle while a 192 by 64 box becomes a capsule, both using pill.

## caption \{#copy-caption\}

The height stays 64px. pill supplies the radius; the specimen dimensions come from separate sizing declarations.

## description-0 \{#copy-description-0\}

pill sets a fully rounded border radius without setting width, height or padding.

## description-1 \{#copy-description-1\}

Equal width and height produce a circle. A wider box with the same height produces a capsule, so the class alone does not promise a circle.
