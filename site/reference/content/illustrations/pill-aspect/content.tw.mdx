# Reference prose: illustrations/pill-aspect

## title \{#copy-title\}


相同 pill 圓角隨方框形狀調整

## alt \{#copy-alt\}


64 乘 64 的方框成為圓形，192 乘 64 的方框成為膠囊形，兩者皆使用 pill。

## caption \{#copy-caption\}


高度維持 64px。pill 提供圓角半徑，範例尺寸來自獨立的尺寸宣告。

## description-0 \{#copy-description-0\}


pill 設定全圓角半徑，不設定寬度、高度或內距。

## description-1 \{#copy-description-1\}


寬高相等時形成圓形。同高度但較寬的方框會形成膠囊，因此單靠 class 不保證圓形。
