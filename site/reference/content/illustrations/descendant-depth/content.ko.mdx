# Reference prose: illustrations/descendant-depth

## title \{#copy-title\}


자식 선택자는 첫 번째 단계까지만

## alt \{#copy-alt\}


동일한 두 DOM 트리에서 underline>a는 직계 링크에만 닿고 underline_a는 section 안에 중첩된 링크에도 닿는다.

## caption \{#copy-caption\}


두 트리는 구조가 같습니다. 밑줄은 실제 대상 링크를, 들여쓰기와 연결 가지는 깊이를 나타냅니다.

## description-0 \{#copy-description-0\}


클래스를 가진 article은 링크 A와 링크 B를 포함하는 section을 가집니다.

## description-1 \{#copy-description-1\}


underline>a는 직계 자식 링크 A에만 밑줄을 적용합니다. underline_a는 A와 B가 모두 하위 링크이므로 둘 다 적용합니다.

## description-2 \{#copy-description-2\}


선언은 해당 링크를 직접 대상으로 합니다. 이 그림은 article에서 텍스트 장식을 상속하는 모습을 나타내지 않습니다.
