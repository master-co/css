# Reference prose: illustrations/preserve-wins

## title \{#copy-title\}

Preserve wins over prune in the same file

## alt \{#copy-alt\}

Two reversed directive orders both keep the native widget rule, showing that preserve precedence is independent of textual order.

## caption \{#copy-caption\}

Native delivery is enabled in both cases. This policy retains native CSS; it does not safelist unused managed utilities.

## description-0 \{#copy-description-0\}

When @preserve native and @prune native occur in the same file, preservation wins in either order.

## description-1 \{#copy-description-1\}

The native .widget rule is therefore retained even without a scanned widget class.

## description-2 \{#copy-description-2\}

preserveNativeCSS: false is a separate output switch and can suppress native delivery regardless of either directive.
