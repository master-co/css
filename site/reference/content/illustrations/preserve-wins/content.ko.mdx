# Reference prose: illustrations/preserve-wins

## title \{#copy-title\}


같은 파일에서는 preserve가 prune보다 우선

## alt \{#copy-alt\}


두 반대 지시문 순서가 모두 네이티브 widget 규칙을 유지하여 preserve 우선순위가 텍스트 순서와 무관함을 보여 준다.

## caption \{#copy-caption\}


두 경우 모두 네이티브 전달이 활성화되어 있습니다. 이 정책은 네이티브 CSS를 보존하며 사용하지 않는 관리 유틸리티를 세이프리스트에 넣지 않습니다.

## description-0 \{#copy-description-0\}


같은 파일에 @preserve native와 @prune native가 있으면 순서와 관계없이 보존이 우선합니다.

## description-1 \{#copy-description-1\}


따라서 스캔한 widget 클래스가 없어도 네이티브 .widget 규칙이 유지됩니다.

## description-2 \{#copy-description-2\}


preserveNativeCSS: false는 별도 출력 스위치이며 두 지시문과 관계없이 네이티브 전달을 억제할 수 있습니다.
