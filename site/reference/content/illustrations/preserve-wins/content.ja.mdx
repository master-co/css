# Reference prose: illustrations/preserve-wins

## title \{#copy-title\}


同一ファイルでは preserve が prune に優先

## alt \{#copy-alt\}


逆順にした 2 ケースともネイティブ widget 規則を保持し、preserve の優先が記述順によらないことを示す。

## caption \{#copy-caption\}


両ケースでネイティブ配信は有効です。この方針はネイティブ CSS を保持するもので、未使用の管理ユーティリティをセーフリストには入れません。

## description-0 \{#copy-description-0\}


同じファイルに @preserve native と @prune native があれば、どちらの順でも保持が優先します。

## description-1 \{#copy-description-1\}


そのためスキャンした widget クラスがなくてもネイティブの .widget 規則を保持します。

## description-2 \{#copy-description-2\}


preserveNativeCSS: false は別の出力スイッチで、両ディレクティブに関係なくネイティブ配信を抑制できます。
