# Reference prose: illustrations/native-value-boundary

## title \{#copy-title\}


따옴표 안의 괄호는 값의 일부

## alt \{#copy-alt\}


하나의 온전한 클래스 안에서 content 속성, 따옴표 안의 닫는 괄호, before 의사 요소를 표시한다.

## caption \{#copy-caption\}


첫 번째 닫는 괄호는 따옴표 안의 값 텍스트입니다. 다음 괄호가 선언을 닫고 ::before는 그 바깥에서 시작합니다.

## description-0 \{#copy-description-0\}


(content:')')::before에서 content는 속성이고 ')'는 따옴표로 감싼 값입니다.

## description-1 \{#copy-description-1\}


문자열 안의 )는 유지됩니다. 다음 )가 네이티브 선언의 선두 부분을 닫습니다.

## description-2 \{#copy-description-2\}


::before 접미사는 의사 요소를 대상으로 합니다. 생성 선언은 content: ')';입니다.
