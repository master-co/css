# Reference prose: illustrations/cli-output-destinations

## title \{#copy-title\}

Printed CSS and published assets have different delivery boundaries

## alt \{#copy-alt\}

The generate command branches to stdout with no-export, or to a CSS entry and required stylesheet and resource files with output. Only the file-export branch publishes the asset set.

## caption \{#copy-caption\}

Both commands read project sources. --no-export prints CSS; --output publishes the entry and its required assets. Deliver the complete file set when imports or resources remain separate.

## description-0 \{#copy-description-0\}

master-css generate reads the selected project sources and stylesheet entries in either case.

## description-1 \{#copy-description-1\}

--no-export --verbose 0 sends the CSS result to stdout without publishing output files. The caller remains responsible for referenced resources and their URL bases.

## description-2 \{#copy-description-2\}

--output dist/app.css publishes the named entry and any separate stylesheet or resource assets required by its import graph.

## description-3 \{#copy-description-3\}

The file group is an asset set, not a promise that every project produces additional files. When such files are produced, deploy them together with the entry.
