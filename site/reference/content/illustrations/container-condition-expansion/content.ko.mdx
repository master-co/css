# Reference prose: illustrations/container-condition-expansion

## title \{#copy-title\}


명명된 조건의 확장은 컨테이너를 선택하지 않음

## alt \{#copy-alt\}


--dense 조건은 명명된 너비 조건과 스타일 쿼리를 결합한다. @container card에서 사용하면 조건을 확장하고 card는 컨테이너 이름으로 유지한다.

## caption \{#copy-caption\}


정의는 조건을 저장합니다. 사용 위치가 컨테이너 이름 card를 제공합니다. --dense 확장은 너비 검사와 스타일 검사를 모두 유지합니다.

## description-0 \{#copy-description-0\}


--md는 너비 조건 (width >= 28rem)을 정의합니다. --dense는 해당 참조와 style(--density: compact)를 결합합니다.

## description-1 \{#copy-description-1\}


사용 위치 @container card (--dense)가 card라는 컨테이너를 선택합니다.

## description-2 \{#copy-description-2\}


확장 결과는 @container card (width >= 28rem) and style(--density: compact)입니다. 컨테이너 이름은 바뀌거나 정의의 일부가 되지 않습니다.

## description-3 \{#copy-description-3\}


같은 조건은 다른 컨테이너 이름이나 가장 가까운 적격 컨테이너와 재사용할 수 있습니다. 그림은 컴파일 시 치환이며 DOM 트리가 아닙니다.
