# Reference prose: illustrations/source-replacement

## title \{#copy-title\}


ソースの更新はそのソースの結果を置き換える

## alt \{#copy-alt\}


同じページの更新前後の集合は r-md を共有しています。再スキャンすると p-sm が抜け、p-lg が加わります。

## caption \{#copy-caption\}


同じファイル名は 1 つのソースを表します。この例では、古いクラスを保持する別のソースやセーフリストはありません。

## description-0 \{#copy-description-0\}


最初の card.html は p-sm と r-md を提供します。次の内容は p-lg と r-md を提供します。

## description-1 \{#copy-description-1\}


同じソースを再スキャンすると、その結果を置き換えます。r-md は残り、p-lg が追加され、p-sm は保持されなくなります。

## description-2 \{#copy-description-2\}


別の現在のソースやセーフリストが、引き続き p-sm を保持する場合もあります。ソースの更新は、過去に見つけた全クラスを蓄積しません。
