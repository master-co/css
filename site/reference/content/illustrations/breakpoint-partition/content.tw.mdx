# Reference prose: illustrations/breakpoint-partition

## title \{#copy-title\}


最小值與補集銜接且不重疊

## alt \{#copy-alt\}


兩個對齊的數線區間在 64rem 相接。max-md 的端點空心，md 的端點實心。

## caption \{#copy-caption\}


圓點表示排除或包含邊界。座標軸只呈現預設 md 門檻附近，不是裝置尺寸圖表。

## description-0 \{#copy-description-0\}


預設 @md 從 width >= 64rem 開始。@max-md 是其補集，不包含門檻本身。

## description-1 \{#copy-description-1\}


63.999rem 時只有 max-md 符合；64rem 時只有 md 符合。邊界沒有間隙，也不重疊。

## description-2 \{#copy-description-2\}


取代已展開的 manifest 定義時，也要重新宣告補集；改變一個編譯後定義，不會讓另一個重新展開。
