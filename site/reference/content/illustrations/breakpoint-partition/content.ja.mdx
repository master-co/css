# Reference prose: illustrations/breakpoint-partition

## title \{#copy-title\}


最小条件と補集合は重ならず接する

## alt \{#copy-alt\}


揃えた 2 つの数直線区間が 64rem で接する。max-md は白抜き、md は塗りつぶしの端点。

## caption \{#copy-caption\}


点は境界を含むかどうかを示します。軸はプリセットの md しきい値付近だけを表し、デバイスサイズ表ではありません。

## description-0 \{#copy-description-0\}


プリセットの @md は width >= 64rem から始まります。@max-md は補集合で、そのしきい値自体は含みません。

## description-1 \{#copy-description-1\}


63.999rem では max-md だけ、64rem では md だけが一致します。境界に隙間や重なりはありません。

## description-2 \{#copy-description-2\}


展開済み manifest 定義を置き換える場合は補集合も再宣言します。片方のコンパイル済み定義を変えても、もう片方は再展開しません。
