# Reference prose: illustrations/breakpoint-partition

## title \{#copy-title\}


最小值与补集衔接且不重叠

## alt \{#copy-alt\}


两个对齐的数轴区间在 64rem 相接。max-md 端点空心，md 端点实心。

## caption \{#copy-caption\}


圆点表示排除或包含边界。坐标轴仅呈现预设 md 阈值附近，并非设备尺寸图表。

## description-0 \{#copy-description-0\}


预设 @md 从 width >= 64rem 开始。@max-md 为其补集，不包含阈值本身。

## description-1 \{#copy-description-1\}


63.999rem 时仅 max-md 匹配；64rem 时仅 md 匹配。边界没有间隙，也不重叠。

## description-2 \{#copy-description-2\}


替换已展开的 manifest 定义时，也要重新声明补集；改变一个已编译定义不会使另一个重新展开。
