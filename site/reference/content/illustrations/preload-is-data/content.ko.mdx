# Reference prose: illustrations/preload-is-data

## title \{#copy-title\}


프리로드로 프로그램을 가져오고 런타임이 시작할 때 사용합니다

## alt \{#copy-alt\}


프리로드 링크가 프로그램 바이트를 브라우저로 가져온다. 나중에 런타임이 해당 응답을 사용하고 연결된 클래스 사용에 대한 규칙을 생성한다.

## caption \{#copy-caption\}


그림은 런타임 전용 페이지와 일치하는 fetch 프리로드를 보여 줍니다. 연결선 길이는 요청 시간이나 시작 속도를 나타내지 않습니다.

## description-0 \{#copy-description-0\}


as="fetch"와 일치하는 crossorigin을 가진 프리로드는 문서를 파싱하는 동안 프로그램 요청을 시작합니다.

## description-1 \{#copy-description-1\}


이 힌트는 엔진을 실행하거나 DOM 클래스를 검사하거나 CSS를 생성하지 않습니다. 런타임 초기화가 일치하는 응답을 사용해 그 작업을 수행합니다.

## description-2 \{#copy-description-2\}


엔진과 프로그램을 의도적으로 지연하는 점진적 페이지에는 이 프로그램 프리로드를 추가하지 마세요. 페이지 하이드레이션 manifest는 별도 리소스입니다.
