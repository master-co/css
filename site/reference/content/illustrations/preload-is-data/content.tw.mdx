# Reference prose: illustrations/preload-is-data

## title \{#copy-title\}


預載入取得程式，執行階段啟動時才使用

## alt \{#copy-alt\}


預載入連結將程式位元組取回瀏覽器。執行階段稍後使用該回應，並為已連接的 class 使用情況產生規則。

## caption \{#copy-caption\}


圖示呈現僅使用執行階段的頁面，以及相符的 fetch 預載入。連線長度不代表請求時長或啟動速度。

## description-0 \{#copy-description-0\}


含有 as="fetch" 與相符 crossorigin 的預載入，會在文件解析期間開始請求程式。

## description-1 \{#copy-description-1\}


這個提示不會執行引擎、檢查 DOM class 或生成 CSS。執行階段初始化才會使用相符回應並執行這些工作。

## description-2 \{#copy-description-2\}


刻意延後引擎與程式載入的漸進式頁面，不應加入這個程式預載入。頁面的 hydration manifest 是另一項資源。
