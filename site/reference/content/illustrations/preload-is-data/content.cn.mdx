# Reference prose: illustrations/preload-is-data

## title \{#copy-title\}


预加载获取程序，运行时启动时才使用

## alt \{#copy-alt\}


预加载链接将程序字节获取到浏览器。运行时稍后使用该响应，并为已连接的类使用情况生成规则。

## caption \{#copy-caption\}


图示呈现仅使用运行时的页面及匹配的 fetch 预加载。连线长度不代表请求时长或启动速度。

## description-0 \{#copy-description-0\}


带有 as="fetch" 和匹配 crossorigin 的预加载，会在文档解析期间开始请求程序。

## description-1 \{#copy-description-1\}


该提示不会执行引擎、检查 DOM 类或生成 CSS。运行时初始化才会使用匹配响应并执行这些工作。

## description-2 \{#copy-description-2\}


刻意延后引擎与程序加载的渐进式页面不应添加此程序预加载。页面的 hydration manifest 是另一项资源。
