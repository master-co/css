# Reference prose: specimens

## animation-caption \{#copy-animation-caption\}


這裡的每個預設動畫只播放一次，初始狀態為暫停。「播放」、「暫停」與「重播」控制原生時間軸。偏好減少動態效果時，內容會保持靜止；上方表格仍保留完整的預設簡寫值。

## duration-caption \{#copy-duration-caption\}


所有標記都沿著相同路徑以線性時間函數移動，只有持續時間不同。初始狀態為暫停，可一起播放或重播。偏好減少動態效果時，標記會保持靜止。

## easing-caption \{#copy-easing-caption\}


所有標記都在一秒內走過相同路徑，只有時間函數不同。超越終點或倒退的曲線可能讓標記越過路徑端點。偏好減少動態效果時，標記會保持靜止。
