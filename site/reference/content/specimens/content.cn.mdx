# Reference prose: specimens

## animation-caption \{#copy-animation-caption\}


这里的每个预设动画只播放一次，初始状态为暂停。“播放”“暂停”和“重播”控制原生时间线。偏好减少动态效果时，内容保持静止；上方表格仍保留完整的预设简写值。

## duration-caption \{#copy-duration-caption\}


所有标记都沿着相同路径以线性时间函数移动，只有持续时间不同。初始状态为暂停，可一起播放或重播。偏好减少动态效果时，标记保持静止。

## easing-caption \{#copy-easing-caption\}


所有标记都在一秒内走过相同路径，只有时间函数不同。超出终点或回退的曲线可能让标记越过路径端点。偏好减少动态效果时，标记保持静止。
