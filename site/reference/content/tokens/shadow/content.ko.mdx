# Reference prose: tokens/shadow

## title \{#copy-title\}


그림자

## summary \{#copy-summary\}


라이트와 다크에 맞게 조정한 여러 겹의 입체 그림자입니다.

## note \{#copy-note\}


`shadow-<name>`은 전체 `box-shadow` 값을 설정합니다. 두 그림자 클래스의 목록은 이어 붙지 않으며 우선하는 선언이 그림자 전체를 결정합니다.

## valuesLead \{#copy-valuesLead\}


각 토큰은 쉼표로 구분된 네이티브 그림자 목록을 저장합니다. 값을 펼치면 모든 겹을 확인할 수 있습니다. 라이트와 다크는 오프셋, 흐림, 확산 길이가 같으며 light-dark()의 색상만 다릅니다.

## explanation-title \{#copy-explanation-title\}


그림자는 그리기를 바꾸며 레이아웃은 바꾸지 않습니다

## explanation-paragraphs-0 \{#copy-explanation-paragraphs-0\}


`shadow-xs`와 `shadow-xl`은 같은 상자 주변에 서로 다른 크기의 그림자를 그립니다. 어느 쪽도 그림자를 위한 공간을 확보하지 않으므로 다음 요소의 위치와 간격은 그대로 유지됩니다.

## explanation-paragraphs-1 \{#copy-explanation-paragraphs-1\}


토큰 목록의 첫 그림자는 뒤따르는 그림자 위에 그려집니다. `shadow-inset`은 안쪽 그림자를, 여섯 크기 단계는 바깥쪽 그림자를 사용합니다. 이 토큰들은 표면 색상, 모서리 반경, 쌓임 순서, 잘라 내기 정책을 지정하지 않습니다.

## explanation-paragraphs-2 \{#copy-explanation-paragraphs-2\}


요소가 사용하는 색 구성표가 각 `light-dark()` 색상을 선택합니다. 따라서 그림자의 길이를 바꾸거나 다른 유틸리티 클래스를 추가하지 않고도 그리기 결과를 바꿀 수 있습니다. 로컬 색 구성표 선택은 색상 역할을 참고하세요.

## explanation-paragraphs-3 \{#copy-explanation-paragraphs-3\}


그림자를 제거하려면 네이티브 선언 `(box-shadow:none)`을 사용하세요. 안쪽 그림자와 바깥쪽 그림자를 결합하려면 두 목록을 모두 담은 토큰 하나를 정의하세요. 별도의 클래스는 목록을 합치지 않습니다.

## explanation-links-0-label \{#copy-explanation-links-0-label\}


색상 역할

## explanation-links-1-label \{#copy-explanation-links-1-label\}


네이티브 그림자 그리기와 레이아웃

## usage-lead \{#copy-usage-lead\}


기본 표면은 낮게 유지하고 그 위에 떠 있는 요소만 높입니다.

## customize-lead \{#copy-customize-lead\}


프리셋 값을 변경하거나 토큰을 추가하세요. `--shadow-card`를 정의하면 `shadow-card`가 생성됩니다.

## guide-label \{#copy-guide-label\}


색상
