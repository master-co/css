# Reference prose: tokens/container

## title \{#copy-title\}


컨테이너 크기

## summary \{#copy-summary\}


너비, 높이, 최소 크기, 최대 크기에 사용하는 프리셋 길이입니다.

## note \{#copy-note\}


컨테이너 토큰은 길이를 설정하며 뷰포트 쿼리나 컨테이너 쿼리를 정의하지 않습니다. `w-full`, `max-w-fit`, `basis-min` 같은 전체 크기 및 내재 크기 지정은 고정 유틸리티이며 이 토큰과 독립적입니다.

## valuesLead \{#copy-valuesLead\}


각 값은 크기 속성이 사용하는 길이입니다. 픽셀 환산값은 루트 글꼴 크기가 16px라고 가정합니다. 이 값들은 뷰포트 중단점이나 컨테이너 쿼리 정의가 아닙니다.

## explanation-title \{#copy-explanation-title\}


최대 크기는 상한을 정합니다

## explanation-paragraphs-0 \{#copy-explanation-paragraphs-0\}


`max-w-3xs`는 `max-width: var(--container-3xs)`를 설정하며 프리셋 값은 `16rem`입니다. 너비가 auto인 일반 블록은 포함 블록의 공간이 부족하면 이보다 좁아질 수 있습니다.

## explanation-paragraphs-1 \{#copy-explanation-paragraphs-1\}


반면 `w-3xs`는 너비 자체를 설정합니다. 두 클래스 모두 가운데 정렬, padding, 쿼리용 격리를 추가하지 않습니다. `--container-md`를 변경해도 `@container(--md)`나 명시적인 쿼리 임계값이 다시 정의되지는 않습니다. 쿼리 컨테이너를 만들려면 네이티브 `container-type`과 `container-name`을 사용하세요.

## explanation-paragraphs-2 \{#copy-explanation-paragraphs-2\}


실제 크기에는 네이티브 레이아웃도 영향을 줍니다. 최소 크기, 상자 크기 계산, Flexbox, Grid가 사용 크기를 바꿀 수 있습니다. 최대 크기는 텍스트 줄바꿈이나 오버플로 규칙을 바꾸지 않습니다. 페이지 래퍼와 반응형 레이아웃을 결정하는 방법은 레이아웃 가이드에서 확인하세요.

프리셋 값을 변경하거나 크기를 추가하세요. `--container-prose`를 정의하면 `max-w-prose`, `w-prose` 및 다른 크기 클래스가 생성됩니다.
