# Reference prose: tokens/families

## intro \{#copy-intro\}


토큰 계열은 클래스 접두사, 토큰 네임스페이스, 작성하는 CSS 속성을 연결합니다. 이 표에는 프리셋 값이 없는 계열을 포함해 프리셋에 등록된 모든 계열이 나와 있습니다.

## mapping \{#copy-mapping\}


키만으로는 토큰을 식별할 수 없습니다. `p-md`에서 `p-`는 `spacing` 네임스페이스를 참조하고 `md`는 `--spacing-md`를 선택합니다. 같은 키라도 다른 계열에서는 다른 토큰을 선택할 수 있습니다.

## lookup \{#copy-lookup\}


각 행을 접두사 → 토큰 이름 패턴 → 네이티브 속성 순서로 읽으세요. `*`를 등록된 키로 바꿉니다. 연결된 값 페이지에는 사용 가능한 키가, 네임스페이스 열에는 해당 계열이 허용하는 토큰이 나와 있습니다.

## shared \{#copy-shared\}


`font-`에는 `--font-family-*`, `--font-size-*`, `--font-weight-*`에 대응하는 별도의 계열이 있습니다. 키는 그중 하나를 선택해야 합니다. 같은 키가 둘 이상의 네임스페이스에 있으면 클래스가 모호해져 CSS를 출력하지 않습니다.

## registration \{#copy-registration\}


토큰은 `@theme`에 등록하세요. 그 밖에 작성한 네이티브 사용자 지정 속성은 키를 등록하지 않으며, 새 네임스페이스가 유틸리티 계열을 자동으로 만들지도 않습니다. 계열을 추가할 때는 일치하는 `@utility` 패턴을 정의하세요.

## roles \{#copy-roles\}


`--color-text-muted`는 `color` 네임스페이스에 속하며 키는 `text-muted`입니다. 색상 역할은 팔레트 색상과 같은 계열을 사용하며 별도의 유틸리티 네임스페이스가 아닙니다.

## limits \{#copy-limits\}


이 색인은 토큰을 참조하는 계열을 설명합니다. `w-full` 같은 고정 표기는 같은 키의 토큰이 있어도 자체 정의를 유지합니다. `p(4)`처럼 값을 직접 받는 함수와 `(padding:1rem)` 같은 네이티브 선언은 토큰 조회 없이 값을 받습니다.

## title \{#copy-title\}


토큰 계열

## description \{#copy-description\}


모든 프리셋 토큰 계열의 클래스 접두사, 토큰 네임스페이스, 네이티브 속성입니다.
