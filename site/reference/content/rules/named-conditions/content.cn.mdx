# Reference prose: rules/named-conditions


## intro \{#copy-intro\}


预设定义了各自独立的媒体与容器条件。它们共享简短名称，但这两个注册表都不是主题令牌集合。单独的 `@md` 查询视口，`@container(--md)` 则查询符合条件的祖先容器。

## media \{#copy-media\}


媒体名称来自 `media.css`。宽度条件使用原本编写的 rem 值，方向与偏好条件则使用原生媒体特性。`@dark` 和 `@light` 检查的是系统偏好，不是手动选择的网站主题。

## container \{#copy-container\}


容器名称来自 `container.css`。定义只提供查询条件：`@container(--md)` 使用最近且符合条件的容器，`@container(card|--md)` 则选择名为 `card` 且符合条件的容器。两种形式都不会创建容器。

## scope \{#copy-scope\}


同一个键可以在不同查询领域表示不同阈值。`--container-md` 这类容器尺寸令牌则属于第三种独立用途：为尺寸工具类提供长度。

## complement \{#copy-complement\}


每个预设 `max-` 条件都是对应最小值条件的互补条件。下方展开的查询在边界处不会重叠。原始定义通过 `not (--name)` 引用对应名称。

## customize \{#copy-customize\}


为视口或偏好查询声明自定义媒体名称，或为组件查询声明自定义容器名称。原生单位会保留。在已编译的 manifest 中替换条件时，如果两个阈值都要改变，也必须重新声明其互补条件。

## viewport-widths-title \{#copy-viewport-widths-title\}


最小视口宽度

## below-viewport-widths-title \{#copy-below-viewport-widths-title\}


视口宽度低于阈值

## media-features-title \{#copy-media-features-title\}


方向与偏好设置

## container-widths-title \{#copy-container-widths-title\}


最小容器宽度

## below-container-widths-title \{#copy-below-container-widths-title\}


容器宽度低于阈值

## usage-lead \{#copy-usage-lead\}


这个布局在预设 md 视口阈值以下使用单列，从阈值起改用三列。

## title \{#copy-title\}


具名条件

## description \{#copy-description\}


所有预设媒体与容器条件、展开后的查询以及各自测量的范围。
