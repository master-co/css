# Reference prose: direct-values

## title \{#copy-title\}


直接值

## summary \{#copy-summary\}


將一個靜態數字傳給長度或數值屬性。

## note \{#copy-note\}


長度函式將數字乘上 `1px`；`grow()`、`shrink()` 與 `order()` 則直接傳入該數字。需要其他單位或動態值時，請使用 `(margin:1rem)` 這類原生宣告。

## explanation-title \{#copy-explanation-title\}


數字的意義由屬性決定

## explanation-paragraphs-0 \{#copy-explanation-paragraphs-0\}


`p(12)` 產生 `padding: calc(12 * 1px)`，因此數字代表像素數量，不是間距尺度的鍵，也不是主題間距 token 的倍數。可以使用小數，例如 `p(1.5)`。

## explanation-paragraphs-1 \{#copy-explanation-paragraphs-1\}


`grow(1)` 與 `shrink(1)` 是無單位的 flex 係數。擴張會分配剩餘空間；圖中使用零基底且不受內容最小尺寸限制，藉此單獨呈現 1:2 比例。使用其他基底或最小尺寸時，只靠係數無法決定最終寬度。收縮分配也會納入每個項目的 flex 基底尺寸。

## explanation-paragraphs-2 \{#copy-explanation-paragraphs-2\}


`order()` 直接輸出數字，但 CSS 屬性要求整數。負值仍受各屬性的規則限制：`m(-4)` 是合法的負外距，但負內距或負 flex 係數無法要求負的使用值。

## explanation-paragraphs-3 \{#copy-explanation-paragraphs-3\}


只能傳入一個靜態數字。單位、`var()` 與算術運算式應寫在原生宣告中，例如 `(padding:var(--panel-space))`。共用的具名長度則應使用主題 token，例如 `p-card`。

## explanation-paragraphs-4 \{#copy-explanation-paragraphs-4\}


這些函式只會設定表中列出的宣告。`b(1)` 仍需要邊框樣式；`top(4)` 需要支援 inset 的定位方式；`gap(12)` 需要可套用間隙的版面配置。表格會區分邏輯屬性與實體屬性。
