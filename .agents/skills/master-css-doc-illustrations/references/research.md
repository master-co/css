# Research and adoption

External skills are research material, not inherited instructions or installed dependencies. The repository's ownership and content rules remain authoritative. Review current upstream instructions before borrowing implementation code; the local workflow does not copy those implementations.

| Source | Adopt | Do not inherit |
| --- | --- | --- |
| [Next.js project structure](https://nextjs.org/docs/app/getting-started/project-structure) and the user's paired screenshots | Restrained neutral materials, readable structural labels, matching light/dark composition | Exact branding, page layout, or unverified claims about source design tokens |
| [svg-infographic](https://github.com/kyungseo/skillstead/blob/main/skills/svg-infographic/SKILL.md) | Editable SVG, shared theme inputs, explicit layout and output verification | Its profile framework, fonts, installation workflow, and presentation-export machinery |
| [baoyu-diagram](https://github.com/JimLiu/baoyu-skills/blob/main/skills/baoyu-diagram/SKILL.md) | Select diagram grammar by relationship; budget groups and connectors before rendering | A default saturated dark palette, tiny labels, remote fonts, or generic output locations |
| [excalidraw-diagram](https://github.com/coleam00/excalidraw-diagram-skill/blob/main/SKILL.md) | Make a visual argument; choose meaningful topology; render and inspect | A required Excalidraw format, fixed composition quotas, or arbitrary spacing rules |
| [baoyu-article-illustrator](https://github.com/JimLiu/baoyu-skills/blob/main/skills/baoyu-article-illustrator/SKILL.md) | Identify where a reader needs visual help; distinguish structure from visual treatment | Fixed image density, mandatory repeated preference questions, or a raster-generation-only backend |

## Why a project-specific skill

The required combination is exact technical labels, coordinated themes, responsive display of one composition, restrained depth, repository-owned sources, and consistent article/search/Markdown output. None of the reviewed skills supplies that complete integration.

Positioned HTML scenes with SVG routes suit these technical figures because text, arrows, and geometry stay deterministic and editable, and because the site's own tokens, elevation and variable font paint them exactly. The repository's Playwright Chromium renders them without a new dependency; resvg, used for the first set, could not render the 350 weight or the converged multi-layer shadows. This choice does not make diagrams preferable for every illustration: photography, painterly artwork, and other bitmap-first work belong to a suitable image-generation workflow.

The project requires at least one explanatory image per article. The writing skill chooses the relationship and placement; this skill produces and verifies the figure. This minimum comes from the owner's direction, not an upstream image-density rule. Local wording edits can retain an existing qualifying figure.
