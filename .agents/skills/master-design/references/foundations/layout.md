# Layout and hierarchy

A composition should make the next useful action and its context recognizable. Start with the content's relationships, then choose columns, alignment and enclosure. A grid coordinates those relationships; it does not decide their importance.

## Establish reading order

Identify the page's purpose, primary content, supporting evidence and next action. On an article, the heading, introduction and body should remain a coherent reading sequence without the contents rail. On a service page, explain suitability and consequences before asking people to begin. A promotional page still needs a useful description, evidence and an honest action label.

Use headings to describe sections, not to obtain a font size. Keep DOM order meaningful before adding visual columns. Reordering a sidebar visually must not make keyboard focus jump between unrelated regions.

## Choose the composition

| Need | Useful starting point | Watch for |
| --- | --- | --- |
| Sustained reading | A controlled text measure with optional supporting rail | A wide display stretching every paragraph |
| Comparing shared attributes | Aligned rows or a table | Cards hiding the comparison behind repeated labels |
| Scanning distinct destinations | A list or card collection | Equal visual weight suggesting equal priority |
| Editing while retaining context | Main work region and nearby contextual tools | Two independently scrolling regions with unclear ownership |
| Introducing a service | Clear proposition, evidence and next step | A large image displacing the explanation or action |

Establish a few shared alignment edges. An image can break out from the reading column without forcing the text to follow. Let content determine minimum tracks; an evenly divided grid is not required when one region needs more room.

## Communicate grouping

Space, alignment, headings and common regions can all explain grouping. Use the weakest treatment that still makes the relationship clear in the actual composition. Removing a boundary is not an improvement if fields become ambiguous; adding a card is not an improvement if it hides the page hierarchy.

For a comparison, hold content and type sizes constant while changing grouping. Otherwise the reader cannot tell whether enclosure or a larger heading created the difference. See [spacing](spacing.md) and [layout craft](../layout.md).

## Adapt the task

When a rail no longer fits, move its useful contents into an accessible disclosure or place them in reading order. Keep primary actions near their decision, and avoid duplicating controls with inconsistent state. A sticky action must not obscure content, errors or keyboard focus.

## Verify

Read the page without its imagery, then with long real content. Explain its purpose and next action from the heading and introduction. Check source order, narrow layout, zoom, heading destinations and keyboard progression. Compare the same task in a content site and a dense tool without forcing them into one composition. Continue with [responsive composition](../patterns/responsive.md).
