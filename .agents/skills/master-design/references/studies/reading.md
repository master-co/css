# Content discovery and reading

Review a complete journey from a question to useful content and back. The same relationships apply to documentation, editorial collections and service information without prescribing their typography or brand.

## Establish the task

The reader wants guidance about a topic. Show a named search scope, optional category filter, useful result titles and descriptions. A service or promotional introduction should explain the offer and its evidence before the primary action; a large image cannot carry that explanation alone.

Keep query and category connected to the visible result count. A failed request retains the criteria and offers retry. No matches offers a way to broaden the query; it must not imply that the collection itself is empty.

## Enter and return

Each result has a real destination. A detail view has a meaningful heading, readable introduction, body structure and section links. Preserve query and filter state in the URL when the results are shareable. Returning should recover the useful result context and a logical focus destination, with scroll restoration where appropriate.

Do not replace a result link with a button solely to support a preview. Client enhancement must respect modified clicks, browser history and direct loading. In a local teaching example, mock content and simulated failures must be identified as such.

## Acceptance walkthrough

1. Search for a topic and add a category filter. Confirm the URL and result count describe the same criteria.
2. Open a result, follow a heading link and return using browser Back. Confirm the criteria and result identity survive.
3. Search with an unfinished IME composition; it must not submit prematurely.
4. Produce no matches, broaden the criteria, simulate a failed response and retry without retyping.
5. Repeat at narrow width, with long text and keyboard navigation. Check title changes, focus, actual destinations and no-JavaScript content.

The observable result is a continuous reading journey. See [layout](../foundations/layout.md), [search](../patterns/search.md), [navigation](../patterns/navigation.md) and [scrolling](../scrolling.md).
