# Motion that follows intent

State feedback remains understandable when motion is reduced or unavailable. A default state should not animate merely because enhancement mounted.

Occasional contextual icon changes can overlap glyphs in a stable cell and fade opacity. The Aron specimen uses 150ms ease-out with reserved label space. Preserve project timing where established; scale and blur are optional.

Typing, row hover and tabs need direct feedback. Reserve expressive motion for moments that benefit from it. Gate hover-only effects by hover-capable pointers.

Test open/close with another activation during movement. CSS transitions can retarget the current interpolated value. A fixed keyframe replay often restarts at its authored endpoint; timeline animation can also reverse with explicit playback control. Explain the actual implementation, not an absolute claim about all keyframes.

Hold distance, duration and easing constant in comparisons. Check a controlled intermediate reversal as well as rapid real input; two running samples can naturally differ by a frame.

Staged first entrances may group heading, copy and actions. Exits usually need less travel and attention. Do not stagger routine updates. Name changing properties instead of `all`; add compositing hints only after observing a need.

Honor reduced motion by removing unnecessary travel, scale and blur while retaining state and a static/opacity cue. Test initial render, keyboard, touch, rapid changes and disabled activation. Theme swaps should not accidentally trigger unrelated page-wide transitions.
