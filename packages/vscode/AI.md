# AI Notes For `master-css-vscode`

## Responsibility

`master-css-vscode` builds the VS Code extension. It starts the language server, contributes settings and restart commands, and registers active semantic token highlighting.

## Owns

- VS Code extension activation and server startup.
- Generated VS Code contributions.
- Extension packaging and target-specific VSIX staging.
- Active semantic token provider integration.

## Does Not Own

- Language server feature semantics.
- TextMate grammar source; it comes from `@master/css-language/syntaxes/master-css.tmLanguage.json`.
- CSS custom-data or proposed API contribution flows.
- Native runtime package implementation.

## Public Surface

- VS Code extension package.
- `./server` extension server entry.

## Key Files

- `src/extension.min.ts`
- `src/server.min.ts`
- `generate.ts`
- `package.json`
- `scripts/package-target-core.mjs`
- `scripts/package-targets.mjs`
- `techor.config.ts`

## Risk Areas

- `package.json` contributions are generated by `generate.ts`.
- Setting defaults must stay in sync with `@master/css-language-server`.
- Extension package changes affect published VS Code behavior.
- Native loader packages such as OXC and Lightning CSS must stay external to Rollup.
- Target-specific VSIX files must stage native runtime packages under `dist/node_modules`.
- Generic VSIX packages without `node_modules` can fail because the server imports native runtime packages at startup.

## Safe Changes

- Edit source settings and regenerate generated contributions.
- Packaging script fixes that preserve staged native runtime packages.
- Extension activation or command fixes with tests.

## Dangerous Changes

- Manually drifting generated contributions from source packages.
- Using `contributes.css` or CSS custom-data contributions that require proposed APIs.
- Adding `.mcss` language ids, file associations, or replacement CSS language modes without explicit request.
- Changing publisher, package name, activation, exports, or native externalization casually.

## Validation

```sh
pnpm --filter master-css-vscode test
pnpm --filter master-css-vscode lint
pnpm --filter master-css-vscode type-check
pnpm --filter master-css-vscode build
```

Run `pnpm --filter master-css-vscode vscode:package -- --target darwin-arm64` for packaging changes.
