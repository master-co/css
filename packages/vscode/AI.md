# AI Notes For `master-css-vscode`

## Responsibility

This package builds the VS Code extension. It starts the language server, contributes language grammars, settings, and restart commands.

## Main Files

- `src/extension.min.ts`
- `src/server.min.ts`
- `generate.ts`
- `package.json`
- `syntaxes/*`

## Risks

- `package.json` contributions are generated by `generate.ts`.
- Grammar and setting defaults should stay in sync with `@master/css-language` and `@master/css-language-server`.
- Extension package changes affect published VS Code behavior.

## Rules

- Prefer editing source settings/grammar packages, then regenerate.
- Do not manually drift generated contributions from source packages.
- Do not change publisher, package name, activation, or exports casually.

## Validation

```sh
pnpm --filter master-css-vscode build
pnpm --filter master-css-vscode test
pnpm --filter master-css-vscode type-check
pnpm --filter master-css-vscode lint
```
