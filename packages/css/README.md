## Getting started

- Check out our [homepage](https://css.master.co/).
- Read the [installation guide](https://css.master.co/guide/installation) to set up Master CSS for an application.

## Community

- [Documentation](https://css.master.co/guide/installation) — Set up Master CSS and look up supported behavior.
- [GitHub Discussions](https://github.com/master-co/css/discussions) — Ask questions, discuss ideas, and share your work. English and Chinese are welcome.
- [GitHub Issues](https://github.com/master-co/css/issues) — Report reproducible bugs and track implementation work.
- [Releases](https://github.com/master-co/css/releases) — Follow version changes and release notes.

Use Discussions for technical support so answers remain available to other users. [Discord](https://discord.com/invite/sZNKpAAAw6) remains a secondary community space; real-time support is not guaranteed. See the [support guide](https://github.com/master-co/css/blob/rc/.github/SUPPORT.md).

Our [Code of Conduct](https://github.com/master-co/css/blob/rc/.github/CODE_OF_CONDUCT.md) applies to all Master CSS community channels.

## Contributing
Please see our [CONTRIBUTING](https://github.com/master-co/css/blob/rc/.github/CONTRIBUTING.md) for workflow.

## Inspiration
Some of the core concepts and designs are inspired by these giants.
- The concept of enhanced syntax is inspired by [SASS](https://sass-lang.com/) and [TypeScript](https://www.typescriptlang.org/)
- The concept of Virtual CSS is inspired by the [Virtual DOM](https://reactjs.org/docs/faq-internals.html)
- CSS-first theme configuration and the `@theme` directive are inspired by [Tailwind CSS](https://tailwindcss.com/docs/theme).
