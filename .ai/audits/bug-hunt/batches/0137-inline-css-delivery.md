## Implementation

1. Rust `renderStylesheetBundle` accepts optional `inlineImports: true`; default output remains split. A private iterative graph pass expands import-free children only when namespace and import-preamble rules remain valid, reusing the existing import qualifier renderer. Reverse import traversal preserves an earlier local import when a later external import must remain. Namespace-bearing or externally importing children retain their own stylesheet scope, except an otherwise empty unqualified wrapper can promote its one child. Cycles retain original boundaries. The request field flows through the codegen template and regenerated protocol; no handwritten TypeScript CSS semantics.
2. Vite managed inline requests use independent stylesheet collections, without registering an automatic output stylesheet. The post build plugin composes final scanner usage, renders the safe inline root, publishes retained CSS/resource assets, and substitutes the completed CSS string during renderChunk before final JavaScript hashes. Cached CSS/Sass inline modules are transformed again based on request identity so a JS-only rebuild can re-register them after lifecycle cleanup.
3. The host emits a constant CSS asset as a URL-base anchor, letting the actual output naming policy supply its directory. Rust-reported import/resource UTF-16 ranges identify host-owned URLs to relocate. Opaque author strings and unrelated namespace/external URLs are preserved. Runtime URL substitution resolves relative to the emitted asset base, independently of the caller's insertion location. IIFE/UMD use the current script location rather than unsupported import.meta.url; CJS has an explicit Node URL expression but has not yet been executed as a format control.
4. Graph-only children loaded from inline roots no longer leave a false global scanner-slot flag. The existing removeGraphOnlyStylesheetEntries path now clears the flag when no global root or virtual importer remains; genuine lost-slot controls remain in the full suite.
5. Compiler/Vite README and the formal directive contract document the bounded string behavior, retained imports/assets and constructable-sheet limitation. The inliner currently returns all descendants and Vite emits them plus the anchor even when unused; pruning, lazy reachability and other output-host formats remain follow-ups.
