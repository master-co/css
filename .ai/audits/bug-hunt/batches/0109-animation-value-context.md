- Lexer now distinguishes signed/fractional/exponent numbers, dimensions and percentages from identifiers, preserves escaped units, and checks identifier starts. - Engine value interpretation tracks occupied easing/iteration/direction/fill/play/duration/delay/name slots, comma lists and CSS-wide keywords. Duplicate names in one shorthand item invalidate that branch. A negative time can fill delay before duration. Math quantities preserve duration/iteration possibilities; numeric-returning functions such as sign are not classified from their argument units alone.
- Manifest variable values and modes are interpreted at the original token position, with separate fallback/cycle handling. Heap frames avoid recursive variable evaluation; equal grammar states merge retained-name annotations. A cache keyed by variable/value/incoming state avoids repeated mode-DAG expansion; caller annotations are carried separately and dependency intersections prevent inappropriate cache reuse through cycles. Known values do not activate unused fallbacks. Raw stylesheet animation discovery no longer treats each variable value as a separate declaration.
- Unknown host-provided custom properties and opaque CSS functions remain conservative resource-discovery inputs; this is not a complete browser CSS-function validator or a DOM/cascade evaluator. Named-mode alternatives retain the union needed across modes. Uncertain math types retain possible resource names rather than dropping them; no claim of evaluating arbitrary CSS math or user-defined future functions. Core generated-class resource collection remains separate and unchanged.
