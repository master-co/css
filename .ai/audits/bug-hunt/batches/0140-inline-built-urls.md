## Reproduction and implementation

1. [Original custom SSR probe](../evidence/0140-custom-before.log):four client/server pairs,8builds,12browser failures plus4URL/callback failures. The plugin bypassed Vite's public renderBuiltUrl callback for its own emitted resources/imports. CSS still pointed at the default asset base instead of the callback's public location.
2. The host now calls the public callback for each actual referenced file, with hostId, hostType js/css, type asset and the producing environment's ssr flag. Static strings, runtime expressions for JavaScript, relative overrides and default public/relative/CDN bases are handled separately. Runtime expressions in emitted CSS retain Vite's unsupported-contract error; that rejection is not evidence of new runtime-CSS support.
3. URL replacement now goes through the existing Rust prepare/render bundle resource mapping API. A unique temporary independent prefix lets Rust serialize relative targets and escape CSS correctly, then only that introduced prefix is removed. No TypeScript CSS parser/serializer fallback or ABI change. Only owned URLs change values; unrelated URLs and opaque author strings retain their values.
4. URI transport encoding preserves existing percent escapes and encodes spaces/quotes. Runtime expressions are evaluated at JavaScript execution time and their URL strings receive the same URI normalization. The first36case matrix had35PASS/1FirefoxFAIL: all target styles/images loaded, but Firefox also requested a truncated URL containing the raw quoted path. Encoding the URL removes that extra request in the final matrix; the browser-internal cause is not otherwise asserted.
5. The new [cache regression](../evidence/0140-url-tests-first.log) passed four static/runtime format tests but failed when changing the callback CDN: CSS bytes changed under the same emitted filename. The publisher now hashes the mapped stylesheet graph using canonical provisional filenames, then renders references with the final graph names. A one→two→one callback target test checks changed-content filename separation and repeat stability. CSS callbacks may run during both naming and final publication; mappings must be deterministic for their inputs.
6. The stronger [paired asset probe](../evidence/0140-paired-assets-first.log) then found6browser failures with relative base and SSR asset emission disabled. Vite normalizes the server module base to '/', making retained CSS contents/names differ from the matching client build. The post config hook preserves the configured relative base for browser-loaded stylesheet files while server-exported strings keep the server's public base. The [paired final probe](../evidence/0140-paired-assets-final.log) passes all8builds/12browser comparisons.
7. A first attempt to copy Vite environment configuration with object spread lost its inherited/getter experimental property and failed the new paired regression. The final code reads only the needed properties explicitly. A new test also required explicit OutputAsset narrowing for TypeScript; this test typing error did not represent a product behavior failure. All raw failed logs remain preserved.
