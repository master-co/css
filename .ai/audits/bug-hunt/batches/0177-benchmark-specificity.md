## Contract and reproduction

- [Selectors4 specificity](https://www.w3.org/TR/2026/WD-selectors-4-20260122/#specificity-rules): ignore universal selectors; is/not/has use their greatest argument without an extra pseudo-class component; where contributes zero; nth-child/nth-last-child include their own component plus the greatest of-list argument. Compare ID/class/type components lexicographically, not as decimal weights. Repeated selectors retain their contributions.
- [CSS Nesting](https://www.w3.org/TR/2026/WD-css-nesting-1-20260122/): explicit and implicit parents use the parent selector-list maximum; repeated parents add repeatedly; where can suppress a parent; conditional groups retain context and scope boundaries reset it. [CSS Shadow](https://drafts.csswg.org/css-shadow-1/#host-selector): host/host-context and slotted add their argument to the pseudo's own component. These sources govern benchmark measurement, not a product CSS implementation change.
