## Implementation

- Added Rust `compiled_stylesheet_graph.rs`. It parses each file once, merges authoring inputs in import-occurrence postorder (including repeated imports), uses existing manifest normalization and managed dependency lowering, and then resolves native composition against the finalized shared resolution manifest. Import conditions/layers stay on the file edges, rather than wrapping authoring directives into invalid nested directives.
- Output contains the entry ID, every compiled stylesheet's ID/href/CSS/nativeCSS/generatedCSS, the manifest, resolution manifest and combined directive metadata. Host-provided URLs remain host policy; all CSS parsing, order, manifest and composition semantics remain in Rust. Reference-only definitions require an explicit prepared `resolutionManifest` and are excluded from the emitted manifest. This guard is not automatic reference-file resolution.
- Added native `compile_css_stylesheet_graph_json`, Wasm `compileCSSStylesheetGraph`, typed binding adapters/provider forwarding, and public `MasterCSSCompiler.compileStylesheets(request)`. The existing sync compiler instance exposes the same method. Extraction blocklist wire patterns are revived through the existing host helper; public results/stylesheets are frozen. The protocol was generated from the xtask template; no generated file was edited independently.
- Public request/result types and a concrete delivery example are documented in [compiler README](../../../../packages/compiler/README.md). Consumers must deliver **all** returned stylesheets. The API currently requires preserving declaration URL bases and preparing reference context. It does not silently claim that existing file/build helpers already emit the assets.
- The first graph lowering used `lower_css_directives`' pre-finalization resolution manifest, so three new tests could not resolve managed `paint`. Recompiled the finalized input with the existing manifest compiler before per-file lowering. This was an implementation error within unfinished BH-0004, not a setup failure. [First](../evidence/0114-compiled-first.log), [corrected](../evidence/0114-compiled-corrected.log).
- Further composition ordering review found that appending all generated CSS after native CSS reverses `.example{@compose paint}.example{color:blue}`. The initial built graph API produced red while the explicit native reference produced blue in Chromium. [Browser before](../evidence/0114-compose-browser-before.log). Rust now retains private, collision-checked native-composition positions through parsing/printing, then replaces each position with its lowered rule. Author-supplied escaped at-rule names cannot collide with these private positions. The original string compiler wrapper keeps its existing mode; its own composition ordering is not claimed fixed by this graph-only change.
